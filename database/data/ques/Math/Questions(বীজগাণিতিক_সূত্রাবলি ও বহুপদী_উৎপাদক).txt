যদি $a + b = 8$ এবং $a - b = 4$ হয়, তবে ab এর মান কত?
A. 10
B. 12
C. 16
D. 32
উত্তর: B
ব্যাখ্যা:
ab = $\frac{(a+b)^{2}}{4}$ - $\frac{(a-b)^{2}}{4}$
ab = $\frac{8^{2} - 4^{2}}{4}$ = $\frac{64 - 16}{4}$ = $\frac{48}{4}$ = 12।

$x + y = 12$ এবং $xy = 35$ হলে, $x^{2}$ + $y^{2}$ এর মান কত?
A. 74
B. 104
C. 144
D. 214
উত্তর: A
ব্যাখ্যা:
$x^{2}$ + $y^{2}$ = $(x + y)^{2}$ - 2xy
= $12^{2}$ $- 2(35) = 144 - 70 = 74$।

$a - b = 5$ এবং $a^{2}$ - $b^{2}$ = 55 হলে, a + b এর মান কত?
A. 9
B. 10
C. 11
D. 12
উত্তর: C
ব্যাখ্যা:
$a^{2}$ - $b^{2}$ = $(a + b)(a - b) 55 = (a + b) × 5 a + b$ = $\frac{55}{5}$ = 11।

x + $\frac{1}{x}$ = 4 হলে, $x^{2}$ + $\frac{1}{x^{2}}$ এর মান কত?
A. 12
B. 14
C. 16
D. 18
উত্তর: B
ব্যাখ্যা:
$x^{2}$ + $\frac{1}{x^{2}}$ = $(x + \frac{1}{x})^{2}$ - 2 = $4^{2}$ $- 2 = 16 - 2 = 14$।

x - $\frac{1}{x}$ = 3 হলে, $(x + \frac{1}{x})^{2}$ এর মান কত?
A. 9
B. 11
C. 13
D. 15
উত্তর: C
ব্যাখ্যা:
$(x + \frac{1}{x})^{2}$ = $(x - \frac{1}{x})^{2}$ + 4 = $3^{2}$ + 4 = 9 + 4 = 13।

$x^{2}$ - 5x + 6 এর উৎপাদকে বিশ্লেষিত রূপ কোনটি?
A. (x - 2)(x + 3)
B. (x + 2)(x - 3)
C. (x - 2)(x - 3)
D. (x + 2)(x + 3)
উত্তর: C
ব্যাখ্যা:
$x^{2}$ - 5x + 6 = $x^{2}$ $- 3x - 2x + 6 = x(x - 3) - 2(x - 3) = (x - 2)(x - 3)$।

$a^{2}$ - 2ab + $b^{2}$ - $c^{2}$ এর উৎপাদক কোনটি?
A. (a - b + c)(a + b - c)
B. (a - b + c)(a - b - c)
C. (a + b + c)(a - b - c)
D. (a + b - c)(a - b + c)
উত্তর: B
ব্যাখ্যা:
প্রদত্ত রাশি = $(a - b)^{2}$ - $c^{2}$
এটি $x^{2}$ - $y^{2}$ এর সূত্রে পড়ে, তাই = (a - b + c)(a - b - c)।

$x^{3}$ + 8 এর একটি উৎপাদক x + 2 হলে, অপর উৎপাদকটি কত?
A. $x^{2}$ + 2x + 4
B. $x^{2}$ - 2x + 4
C. $x^{2}$ - 4x + 4
D. $x^{2}$ + 4x + 4
উত্তর: B
ব্যাখ্যা:
$x^{3}$ + $2^{3}$ = (x + 2)($x^{2}$ - 2x + $2^{2}$) = (x + 2)($x^{2}$ - 2x + 4)।

$a + b + c = 9$ এবং $ab + bc + ca = 31$ হলে, $a^{2}$ + $b^{2}$ + $c^{2}$ এর মান কত?
A. 17
B. 19
C. 21
D. 23
উত্তর: B
ব্যাখ্যা:
$a^{2}$ + $b^{2}$ + $c^{2}$ = $(a + b + c)^{2}$ - 2(ab + bc + ca)
= $9^{2}$ $- 2(31) = 81 - 62 = 19$।

f(x) = $x^{3}$ - $2x^{2}$ + 4x - 8 কে (x - 2) দ্বারা ভাগ করলে ভাগশেষ কত হবে?
A. 0
B. 2
C. 4
D. 8
উত্তর: A
ব্যাখ্যা:
ভাগশেষ উপপাদ্য অনুযায়ী, $x = 2$ বসালে:
f(2) = $2^{3}$ - 2$(2)^{2}$ + 4(2) - 8 = 8 - 8 + 8 - 8 = 0। (অর্থাৎ, এটি একটি উৎপাদক)।

x + $\frac{1}{x}$ = $\sqrt{3}$ হলে, $x^{3}$ + $\frac{1}{x^{3}}$ এর মান কত?
A. 0
B. 3$\sqrt{3}$
C. 6$\sqrt{3}$
D. 9
উত্তর: A
ব্যাখ্যা:
$x^{3}$ + $\frac{1}{x^{3}}$ = $(x + \frac{1}{x})^{3}$ - 3(x + $\frac{1}{x}$)
= $(\sqrt{3})^{3}$ - 3($\sqrt{3}$) = 3$\sqrt{3}$ - 3$\sqrt{3}$ = 0।

a - $\frac{1}{a}$ = 4 হলে, $a^{3}$ - $\frac{1}{a^{3}}$ এর মান কত?
A. 52
B. 64
C. 76
D. 88
উত্তর: C
ব্যাখ্যা:
$a^{3}$ - $\frac{1}{a^{3}}$ = $(a - \frac{1}{a})^{3}$ + 3(a - $\frac{1}{a}$)
= $4^{3}$ + 3(4) = 64 + 12 = 76।

যদি $4x^{2}$ - 12x + k একটি পূর্ণবর্গ রাশি হয়, তবে k এর মান কত?
A. 4
B. 9
C. 16
D. 36
উত্তর: B
ব্যাখ্যা:
পূর্ণবর্গ রাশির আকার $(2x - a)^{2}$ = $4x^{2}$ - 4ax + $a^{2}$।
এখানে $4ax = 12x$, অর্থাৎ $a = 3$।
তাহলে k = $a^{2}$ = $3^{2}$ = 9।

$a^{2}$ + $b^{2}$ = 51 এবং $ab = 15$ হলে, $(a - b)^{2}$ এর মান কত?
A. 21
B. 36
C. 66
D. 81
উত্তর: A
ব্যাখ্যা:
$(a - b)^{2}$ = $a^{2}$ + $b^{2}$ $- 2ab = 51 - 2(15) = 51 - 30 = 21$।

$x^{4}$ - $y^{4}$ এর উৎপাদক বিশ্লেষিত রূপ কোনটি?
A. $(x - y)^{4}$
B. ($x^{2}$ - $y^{2}$)(x - y)
C. ($x^{2}$ + $y^{2}$)(x + y)(x - y)
D. ($x^{2}$ + $y^{2}$)$(x^{2} - y^{2})^{2}$
উত্তর: C
ব্যাখ্যা:
$x^{4}$ - $y^{4}$ = $(x^{2})^{2}$ - $(y^{2})^{2}$ = ($x^{2}$ + $y^{2}$)($x^{2}$ - $y^{2}$)
= ($x^{2}$ + $y^{2}$)(x + y)(x - y)।

x = $\sqrt{5}$ + $\sqrt{4}$ হলে, x + $\frac{1}{x}$ এর মান কত?
A. 2$\sqrt{5}$
B. 2$\sqrt{4}$
C. 4
D. 2
উত্তর: A
ব্যাখ্যা:
x = $\sqrt{5}$ + 2।
$\frac{1}{x}$ = $\frac{1}{\sqrt{5} + 2}$ = $\sqrt{5}$ - 2 (লব ও হরকে অনুবন্ধী রাশি দ্বারা গুণ করে)।
তাহলে, x + $\frac{1}{x}$ = ($\sqrt{5}$ + 2) + ($\sqrt{5}$ - 2) = 2$\sqrt{5}$।

$2x^{2}$ - x - 3 এর উৎপাদক কোনটি?
A. (2x - 3)(x + 1)
B. (2x + 3)(x - 1)
C. (2x - 1)(x + 3)
D. (2x + 1)(x - 3)
উত্তর: A
ব্যাখ্যা:
$2x^{2}$ $- 3x + 2x - 3 = x(2x - 3) + 1(2x - 3) = (2x - 3)(x + 1)$।

$a^{3}$ + $b^{3}$ = 35 এবং $a + b = 5$ হলে, ab এর মান কত?
A. 4
B. 6
C. 8
D. 10
উত্তর: B
ব্যাখ্যা:
$a^{3}$ + $b^{3}$ = $(a + b)^{3}$ - 3ab(a + b)
35 = $5^{3}$ $- 3ab(5) 35 = 125 - 15ab 15ab = 90 \Rightarrow  ab = 6$।

যদি $x + y = a$ এবং $x - y = b$ হয়, তবে 2($x^{2}$ + $y^{2}$) এর মান কত?
A. $a^{2}$ - $b^{2}$
B. $a^{2}$ + $b^{2}$
C. 2($a^{2}$ + $b^{2}$)
D. 4ab
উত্তর: B
ব্যাখ্যা:
সূত্রানুসারে, $(x + y)^{2}$ + $(x - y)^{2}$ = 2($x^{2}$ + $y^{2}$)।
সুতরাং, 2($x^{2}$ + $y^{2}$) = $a^{2}$ + $b^{2}$।

$x^{2}$ $- 2x - 1 = 0$ হলে, x + $\frac{1}{x}$ এর মান কত? (যেখানে x > 0)
A. $\sqrt{2}$
B. 2
C. 2$\sqrt{2}$
D. 4
উত্তর: C
ব্যাখ্যা:
$x^{2}$ $- 1 = 2x \Rightarrow  x -$ $\frac{1}{x}$ = 2।
$(x + \frac{1}{x})^{2}$ = $(x - \frac{1}{x})^{2}$ + 4 = $2^{2}$ + 4 = 8।
সুতরাং, x + $\frac{1}{x}$ = $\sqrt{8}$ = 2$\sqrt{2}$।

$a + b + c = 0$ হলে, $a^{3}$ + $b^{3}$ + $c^{3}$ এর মান কত?
A. 0
B. abc
C. 3abc
D. $(a+b+c)^{3}$
উত্তর: C
ব্যাখ্যা:
আমরা জানি, $a^{3}$ + $b^{3}$ + $c^{3}$ - 3abc = (a+b+c)($a^{2}$+$b^{2}$+$c^{2}$-ab-bc-ca)।
যেহেতু $a+b+c = 0$, তাই ডানপক্ষ 0 হবে।
সুতরাং $a^{3}$ + $b^{3}$ + $c^{3}$ = 3abc।

$8x^{3}$ - $27y^{3}$ এর উৎপাদক কোনটি?
A. (2x - 3y)($4x^{2}$ - 6xy + $9y^{2}$)
B. (2x - 3y)($4x^{2}$ + 6xy + $9y^{2}$)
C. (2x + 3y)($4x^{2}$ - 6xy + $9y^{2}$)
D. (2x + 3y)($4x^{2}$ + 6xy + $9y^{2}$)
উত্তর: B
ব্যাখ্যা:
এটি $a^{3}$ - $b^{3}$ এর সূত্র।
$(2x)^{3}$ - $(3y)^{3}$ = (2x - 3y)($(2x)^{2}$ + 2x·3y + $(3y)^{2}$) = (2x - 3y)($4x^{2}$ + 6xy + $9y^{2}$)।

f(x) = $x^{3}$ - $ax^{2}$ + 5x - 6 বহুপদীর একটি উৎপাদক x - 3 হলে, a এর মান কত?
A. 2
B. 3
C. 4
D. 5
উত্তর: C
ব্যাখ্যা:
x - 3 উৎপাদক হওয়ায় $f(3) = 0$ হবে।
$3^{3}$ - a$(3)^{2}$ + 5(3) - 6 = 0
27 - 9a + 15 - 6 = 0
36 - 9a = 0 => 9a = 36 => a = 4।

$x^{4}$ + $x^{2}$ + 1 এর উৎপাদক বিশ্লেষিত রূপ কোনটি?
A. ($x^{2}$ + x + 1)($x^{2}$ - x + 1)
B. ($x^{2}$ + x - 1)($x^{2}$ - x + 1)
C. $(x^{2} + x + 1)^{2}$
D. $(x^{2} - x - 1)^{2}$
উত্তর: A
ব্যাখ্যা:
$x^{4}$ + $2x^{2}$ + 1 - $x^{2}$ = $(x^{2} + 1)^{2}$ - $x^{2}$
= ($x^{2}$ + 1 + x)($x^{2}$ + 1 - x) = ($x^{2}$ + x + 1)($x^{2}$ - x + 1)।

$x - y = 2$ এবং $xy = 24$ হলে, x + y এর মান কত? (যেখানে x, y ধনাত্মক)
A. 8
B. 10
C. 12
D. 14
উত্তর: B
ব্যাখ্যা:
$(x + y)^{2}$ = $(x - y)^{2}$ + 4xy = $2^{2}$ + 4(24) = 4 + 96 = 100।
যেহেতু মান ধনাত্মক, তাই x + y = $\sqrt{100}$ = 10।

$\frac{a}{b}$ + $\frac{b}{a}$ = 2 হলে, (a - b) এর মান কত?
A. -1
B. 0
C. 1
D. 2
উত্তর: B
ব্যাখ্যা:
$\frac{a}{b}$ + $\frac{b}{a}$ = 2
=> $\frac{a^{2} + b^{2}}{ab}$ = 2
=> $a^{2}$ + $b^{2}$ = 2ab
=> $a^{2}$ - 2ab + $b^{2}$ = 0
=> $(a - b)^{2}$ = $0 \Rightarrow  a - b = 0$।

$x^{3}$ - 7x - 6 এর একটি উৎপাদক কোনটি?
A. x - 1
B. x + 2
C. x - 2
D. x + 3
উত্তর: B
ব্যাখ্যা:
ভাগশেষ উপপাদ্য (Vanishing method) প্রয়োগ করি।
$x = -1$ বসালে: $-1 + 7 - 6 = 0$। সুতরাং (x+1) একটি উৎপাদক।
$x = -2$ বসালে: $-8 + 14 - 6 = 0$। সুতরাং (x+2) একটি উৎপাদক।
$x = 3$ বসালে: $27 - 21 - 6 = 0$। সুতরাং (x-3) একটি উৎপাদক।
অপশনগুলোর মধ্যে x+2 রয়েছে।

$x^{2}$ + $\frac{1}{x^{2}}$ = 38 হলে, x - $\frac{1}{x}$ এর মান কত? (x > 0)

$a^{2}$ - 1 + 2b - $b^{2}$ এর উৎপাদক কোনটি?

$a^{2}$ - ($b^{2}$ - 2b + 1) = $a^{2}$ - $(b - 1)^{2}$

যদি $p + q = 7$ এবং $pq = 10$ হয়, তবে $(p-q)^{2}$ এর মান কত?
A. 3
B. 9
C. 21
D. 29
উত্তর: B
ব্যাখ্যা:
$(p-q)^{2}$ = $(p+q)^{2}$ - 4pq = $7^{2}$ $- 4(10) = 49 - 40 = 9$।

x + $\frac{1}{x}$ = 3 হলে, $x^{4}$ + $\frac{1}{x^{4}}$ এর মান কত?

B. 49
C. 79
D. 81

$x^{4}$ + $\frac{1}{x^{4}}$ = $(x^{2} + \frac{1}{x^{2}})^{2}$ - 2 = $7^{2}$ $- 2 = 49 - 2 = 47$।

$3x^{2}$ - 7x - 6 এর উৎপাদক কোনটি?
A. (3x - 2)(x + 3)

a + b = $\sqrt{7}$ এবং a - b = $\sqrt{3}$ হলে, 8ab($a^{2}$ + $b^{2}$) এর মান কত?
A. 20
B. 24
C. 40
D. 50
উত্তর: C
ব্যাখ্যা:
8ab($a^{2}$ + $b^{2}$) = 4ab × 2($a^{2}$ + $b^{2}$)
4ab = $(\sqrt{7})^{2}$ - $(\sqrt{3})^{2}$ = $7 - 3 = 4$।
2($a^{2}$ + $b^{2}$) = $(\sqrt{7})^{2}$ + $(\sqrt{3})^{2}$ = $7 + 3 = 10$।
মান = $4 × 10 = 40$।

$x^{3}$ + $3x^{2}$ + 3x + 2 এর একটি উৎপাদক কত?
A. x - 1
B. x + 1
C. x + 2
D. x - 2

= (x + 1 + 1)($(x+1)^{2}$ - (x+1) + 1) = (x + 2)($x^{2}$ + 2x + 1 - x - 1 + 1) = (x + 2)($x^{2}$ + x + 1)।

$9x^{2}$ - 30xy + c একটি পূর্ণবর্গ হলে c এর মান কত?

সুতরাং c = $25y^{2}$।

যদি $x^{2}$ $- 3x + 1 = 0$ হয়, তবে $x^{3}$ + $\frac{1}{x^{3}}$ এর মান কত?
A. 18
B. 27

D. 0

$x^{2}$ + 1 = 3x => x + $\frac{1}{x}$ = 3।

$a + b + c = 6$ এবং $a^{2}$ + $b^{2}$ + $c^{2}$ = 14 হলে, $(a - b)^{2}$ + $(b - c)^{2}$ + $(c - a)^{2}$ এর মান কত?
A. 14
B. 12
C. 8
D. 6
উত্তর: D
ব্যাখ্যা:
ab + bc + ca = $\frac{6^{2} - 14}{2}$ = $\frac{22}{2}$ = 11।
$(a - b)^{2}$ + $(b - c)^{2}$ + $(c - a)^{2}$ = 2($a^{2}$ + $b^{2}$ + $c^{2}$) $- 2(ab + bc + ca) = 2(14) - 2(11) = 28 - 22 = 6$।

= $(\sqrt{3})^{3}$ + 3($\sqrt{3}$) = 3$\sqrt{3}$ + 3$\sqrt{3}$ = 6$\sqrt{3}$।

$x^{4}$ + $\frac{1}{x^{4}}$ = 119 হলে, x - $\frac{1}{x}$ এর মান কত? (যেখানে x > 1)

B. 4

($x^{2}$ + $\frac{1}{x^{2}})^{2}$ $- 2 = 119$ => $(x^{2} + \frac{1}{x^{2}})^{2}$ = 121 => $x^{2}$ + $\frac{1}{x^{2}}$ = 11।
$(x - \frac{1}{x})^{2}$ + 2 = 11 => $(x - \frac{1}{x})^{2}$ = $9 \Rightarrow  x -$ $\frac{1}{x}$ = 3।

$x^{2}$ + $\frac{1}{x^{2}}$ = 2 হলে, x এর মান কত?
A. 1
B. 2
C. 3
D. 4
উত্তর: A
ব্যাখ্যা:
$(x - \frac{1}{x})^{2}$ + 2 = 2 => $(x - \frac{1}{x})^{2}$ = $0 \Rightarrow  x$ = $\frac{1}{x}$ => $x^{2}$ = $1 \Rightarrow  x = 1$।

$a^{3}$ + $b^{3}$ = $125, a + b = 5$ হলে, ab = ?
A. 0
B. 5
C. 10
D. 25
উত্তর: A
ব্যাখ্যা:
125 = $5^{3}$ $- 3ab(5) \Rightarrow  125 = 125 - 15ab \Rightarrow  15ab = 0 \Rightarrow  ab = 0$।
