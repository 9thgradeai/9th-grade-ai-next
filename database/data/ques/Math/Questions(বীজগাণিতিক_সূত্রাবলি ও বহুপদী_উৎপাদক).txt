প্রশ্ন 1. যদি a + b = 8 এবং a - b = 4 হয়, তবে ab এর মান কত?
A. 10
B. 12
C. 16
D. 32
উত্তর: B
ব্যাখ্যা:
ab = (a+b)²/4 - (a-b)²/4
ab = (8² - 4²)/4 = (64 - 16)/4 = 48/4 = 12।


প্রশ্ন 2. x + y = 12 এবং xy = 35 হলে, x² + y² এর মান কত?
A. 74
B. 104
C. 144
D. 214
উত্তর: A
ব্যাখ্যা:
x² + y² = (x + y)² - 2xy
= 12² - 2(35) = 144 - 70 = 74।


প্রশ্ন 3. a - b = 5 এবং a² - b² = 55 হলে, a + b এর মান কত?
A. 9
B. 10
C. 11
D. 12
উত্তর: C
ব্যাখ্যা:
a² - b² = (a + b)(a - b)
55 = (a + b) × 5
a + b = 55 / 5 = 11।


প্রশ্ন 4. x + 1/x = 4 হলে, x² + 1/x² এর মান কত?
A. 12
B. 14
C. 16
D. 18
উত্তর: B
ব্যাখ্যা:
x² + 1/x² = (x + 1/x)² - 2 = 4² - 2 = 16 - 2 = 14।


প্রশ্ন 5. x - 1/x = 3 হলে, (x + 1/x)² এর মান কত?
A. 9
B. 11
C. 13
D. 15
উত্তর: C
ব্যাখ্যা:
(x + 1/x)² = (x - 1/x)² + 4 = 3² + 4 = 9 + 4 = 13।


প্রশ্ন 6. x² - 5x + 6 এর উৎপাদকে বিশ্লেষিত রূপ কোনটি?
A. (x - 2)(x + 3)
B. (x + 2)(x - 3)
C. (x - 2)(x - 3)
D. (x + 2)(x + 3)
উত্তর: C
ব্যাখ্যা:
x² - 5x + 6 = x² - 3x - 2x + 6
= x(x - 3) - 2(x - 3) = (x - 2)(x - 3)।


প্রশ্ন 7. a² - 2ab + b² - c² এর উৎপাদক কোনটি?
A. (a - b + c)(a + b - c)
B. (a - b + c)(a - b - c)
C. (a + b + c)(a - b - c)
D. (a + b - c)(a - b + c)
উত্তর: B
ব্যাখ্যা:
প্রদত্ত রাশি = (a - b)² - c²
এটি x² - y² এর সূত্রে পড়ে, তাই = (a - b + c)(a - b - c)।


প্রশ্ন 8. x³ + 8 এর একটি উৎপাদক x + 2 হলে, অপর উৎপাদকটি কত?
A. x² + 2x + 4
B. x² - 2x + 4
C. x² - 4x + 4
D. x² + 4x + 4
উত্তর: B
ব্যাখ্যা:
x³ + 2³ = (x + 2)(x² - 2x + 2²) = (x + 2)(x² - 2x + 4)।


প্রশ্ন 9. a + b + c = 9 এবং ab + bc + ca = 31 হলে, a² + b² + c² এর মান কত?
A. 17
B. 19
C. 21
D. 23
উত্তর: B
ব্যাখ্যা:
a² + b² + c² = (a + b + c)² - 2(ab + bc + ca)
= 9² - 2(31) = 81 - 62 = 19।


প্রশ্ন 10. f(x) = x³ - 2x² + 4x - 8 কে (x - 2) দ্বারা ভাগ করলে ভাগশেষ কত হবে?
A. 0
B. 2
C. 4
D. 8
উত্তর: A
ব্যাখ্যা:
ভাগশেষ উপপাদ্য অনুযায়ী, x = 2 বসালে:
f(2) = 2³ - 2(2)² + 4(2) - 8 = 8 - 8 + 8 - 8 = 0। (অর্থাৎ, এটি একটি উৎপাদক)।


প্রশ্ন 11. x + 1/x = √3 হলে, x³ + 1/x³ এর মান কত?
A. 0
B. 3√3
C. 6√3
D. 9
উত্তর: A
ব্যাখ্যা:
x³ + 1/x³ = (x + 1/x)³ - 3(x + 1/x)
= (√3)³ - 3(√3) = 3√3 - 3√3 = 0।


প্রশ্ন 12. a - 1/a = 4 হলে, a³ - 1/a³ এর মান কত?
A. 52
B. 64
C. 76
D. 88
উত্তর: C
ব্যাখ্যা:
a³ - 1/a³ = (a - 1/a)³ + 3(a - 1/a)
= 4³ + 3(4) = 64 + 12 = 76।


প্রশ্ন 13. যদি 4x² - 12x + k একটি পূর্ণবর্গ রাশি হয়, তবে k এর মান কত?
A. 4
B. 9
C. 16
D. 36
উত্তর: B
ব্যাখ্যা:
পূর্ণবর্গ রাশির আকার (2x - a)² = 4x² - 4ax + a²।
এখানে 4ax = 12x, অর্থাৎ a = 3।
তাহলে k = a² = 3² = 9।


প্রশ্ন 14. a² + b² = 51 এবং ab = 15 হলে, (a - b)² এর মান কত?
A. 21
B. 36
C. 66
D. 81
উত্তর: A
ব্যাখ্যা:
(a - b)² = a² + b² - 2ab
= 51 - 2(15) = 51 - 30 = 21।


প্রশ্ন 15. x⁴ - y⁴ এর উৎপাদক বিশ্লেষিত রূপ কোনটি?
A. (x - y)⁴
B. (x² - y²)(x - y)
C. (x² + y²)(x + y)(x - y)
D. (x² + y²)(x² - y²)²
উত্তর: C
ব্যাখ্যা:
x⁴ - y⁴ = (x²)² - (y²)² = (x² + y²)(x² - y²)
= (x² + y²)(x + y)(x - y)।


প্রশ্ন 16. x = √5 + √4 হলে, x + 1/x এর মান কত?
A. 2√5
B. 2√4
C. 4
D. 2
উত্তর: A
ব্যাখ্যা:
x = √5 + 2।
1/x = 1/(√5 + 2) = √5 - 2 (লব ও হরকে অনুবন্ধী রাশি দ্বারা গুণ করে)।
তাহলে, x + 1/x = (√5 + 2) + (√5 - 2) = 2√5।


প্রশ্ন 17. 2x² - x - 3 এর উৎপাদক কোনটি?
A. (2x - 3)(x + 1)
B. (2x + 3)(x - 1)
C. (2x - 1)(x + 3)
D. (2x + 1)(x - 3)
উত্তর: A
ব্যাখ্যা:
2x² - 3x + 2x - 3 = x(2x - 3) + 1(2x - 3)
= (2x - 3)(x + 1)।


প্রশ্ন 18. a³ + b³ = 35 এবং a + b = 5 হলে, ab এর মান কত?
A. 4
B. 6
C. 8
D. 10
উত্তর: B
ব্যাখ্যা:
a³ + b³ = (a + b)³ - 3ab(a + b)
35 = 5³ - 3ab(5)
35 = 125 - 15ab
15ab = 90 => ab = 6।


প্রশ্ন 19. যদি x + y = a এবং x - y = b হয়, তবে 2(x² + y²) এর মান কত?
A. a² - b²
B. a² + b²
C. 2(a² + b²)
D. 4ab
উত্তর: B
ব্যাখ্যা:
সূত্রানুসারে, (x + y)² + (x - y)² = 2(x² + y²)।
সুতরাং, 2(x² + y²) = a² + b²।


প্রশ্ন 20. x² - 2x - 1 = 0 হলে, x + 1/x এর মান কত? (যেখানে x > 0)
A. √2
B. 2
C. 2√2
D. 4
উত্তর: C
ব্যাখ্যা:
x² - 1 = 2x => x - 1/x = 2।
(x + 1/x)² = (x - 1/x)² + 4 = 2² + 4 = 8।
সুতরাং, x + 1/x = √8 = 2√2।


প্রশ্ন 21. a + b + c = 0 হলে, a³ + b³ + c³ এর মান কত?
A. 0
B. abc
C. 3abc
D. (a+b+c)³
উত্তর: C
ব্যাখ্যা:
আমরা জানি, a³ + b³ + c³ - 3abc = (a+b+c)(a²+b²+c²-ab-bc-ca)।
যেহেতু a+b+c = 0, তাই ডানপক্ষ 0 হবে।
সুতরাং a³ + b³ + c³ = 3abc।


প্রশ্ন 22. 8x³ - 27y³ এর উৎপাদক কোনটি?
A. (2x - 3y)(4x² - 6xy + 9y²)
B. (2x - 3y)(4x² + 6xy + 9y²)
C. (2x + 3y)(4x² - 6xy + 9y²)
D. (2x + 3y)(4x² + 6xy + 9y²)
উত্তর: B
ব্যাখ্যা:
এটি a³ - b³ এর সূত্র।
(2x)³ - (3y)³ = (2x - 3y)((2x)² + 2x·3y + (3y)²) = (2x - 3y)(4x² + 6xy + 9y²)।


প্রশ্ন 23. f(x) = x³ - ax² + 5x - 6 বহুপদীর একটি উৎপাদক x - 3 হলে, a এর মান কত?
A. 2
B. 3
C. 4
D. 5
উত্তর: C
ব্যাখ্যা:
x - 3 উৎপাদক হওয়ায় f(3) = 0 হবে।
3³ - a(3)² + 5(3) - 6 = 0
27 - 9a + 15 - 6 = 0
36 - 9a = 0 => 9a = 36 => a = 4।


প্রশ্ন 24. x⁴ + x² + 1 এর উৎপাদক বিশ্লেষিত রূপ কোনটি?
A. (x² + x + 1)(x² - x + 1)
B. (x² + x - 1)(x² - x + 1)
C. (x² + x + 1)²
D. (x² - x - 1)²
উত্তর: A
ব্যাখ্যা:
x⁴ + 2x² + 1 - x² = (x² + 1)² - x²
= (x² + 1 + x)(x² + 1 - x) = (x² + x + 1)(x² - x + 1)।


প্রশ্ন 25. x - y = 2 এবং xy = 24 হলে, x + y এর মান কত? (যেখানে x, y ধনাত্মক)
A. 8
B. 10
C. 12
D. 14
উত্তর: B
ব্যাখ্যা:
(x + y)² = (x - y)² + 4xy = 2² + 4(24) = 4 + 96 = 100।
যেহেতু মান ধনাত্মক, তাই x + y = √100 = 10।


প্রশ্ন 26. a/b + b/a = 2 হলে, (a - b) এর মান কত?
A. -1
B. 0
C. 1
D. 2
উত্তর: B
ব্যাখ্যা:
a/b + b/a = 2
=> (a² + b²) / ab = 2
=> a² + b² = 2ab
=> a² - 2ab + b² = 0
=> (a - b)² = 0 => a - b = 0।


প্রশ্ন 27. x³ - 7x - 6 এর একটি উৎপাদক কোনটি?
A. x - 1
B. x + 2
C. x - 2
D. x + 3
উত্তর: B
ব্যাখ্যা:
ভাগশেষ উপপাদ্য (Vanishing method) প্রয়োগ করি।
x = -1 বসালে: -1 + 7 - 6 = 0। সুতরাং (x+1) একটি উৎপাদক।
x = -2 বসালে: -8 + 14 - 6 = 0। সুতরাং (x+2) একটি উৎপাদক।
x = 3 বসালে: 27 - 21 - 6 = 0। সুতরাং (x-3) একটি উৎপাদক।
অপশনগুলোর মধ্যে x+2 রয়েছে।


প্রশ্ন 28. x² + 1/x² = 38 হলে, x - 1/x এর মান কত? (x > 0)

উত্তর: B

প্রশ্ন 29. a² - 1 + 2b - b² এর উৎপাদক কোনটি?
A. (a + b - 1)(a - b + 1)
B. (a + b + 1)(a - b - 1)
C. (a - b - 1)(a + b - 1)
D. (a + b + 1)(a - b + 1)
উত্তর: A
ব্যাখ্যা:
a² - (b² - 2b + 1) = a² - (b - 1)²
= (a + b - 1)(a - b + 1)।


প্রশ্ন 30. যদি p + q = 7 এবং pq = 10 হয়, তবে (p-q)² এর মান কত?
A. 3
B. 9
C. 21
D. 29
উত্তর: B
ব্যাখ্যা:
(p-q)² = (p+q)² - 4pq = 7² - 4(10) = 49 - 40 = 9।


প্রশ্ন 31. x + 1/x = 3 হলে, x⁴ + 1/x⁴ এর মান কত?

ব্যাখ্যা:
x² + 1/x² = 3² - 2 = 7।
x⁴ + 1/x⁴ = (x² + 1/x²)² - 2 = 7² - 2 = 49 - 2 = 47।


প্রশ্ন 32. 3x² - 7x - 6 এর উৎপাদক কোনটি?

ব্যাখ্যা:
3x² - 9x + 2x - 6 = 3x(x - 3) + 2(x - 3) = (3x + 2)(x - 3)।


প্রশ্ন 33. a + b = √7 এবং a - b = √3 হলে, 8ab(a² + b²) এর মান কত?
A. 20
B. 24
C. 40
D. 50
উত্তর: C
ব্যাখ্যা:
8ab(a² + b²) = 4ab × 2(a² + b²)
4ab = (√7)² - (√3)² = 7 - 3 = 4।
2(a² + b²) = (√7)² + (√3)² = 7 + 3 = 10।
মান = 4 × 10 = 40।


প্রশ্ন 34. x³ + 3x² + 3x + 2 এর একটি উৎপাদক কত?
A. x - 1
B. x + 1
C. x + 2
D. x - 2
উত্তর: C
ব্যাখ্যা:
প্রদত্ত রাশি = (x³ + 3x² + 3x + 1) + 1 = (x + 1)³ + 1³
= (x + 1 + 1)((x+1)² - (x+1) + 1) = (x + 2)(x² + 2x + 1 - x - 1 + 1) = (x + 2)(x² + x + 1)।


প্রশ্ন 35. 9x² - 30xy + c একটি পূর্ণবর্গ হলে c এর মান কত?

B. 25y²
C. 36y²
D. 49y²

ব্যাখ্যা:

(3x)² - 2(3x)(5y) + (5y)² = 9x² - 30xy + 25y²।
সুতরাং c = 25y²।


প্রশ্ন 36. যদি x² - 3x + 1 = 0 হয়, তবে x³ + 1/x³ এর মান কত?
A. 18
B. 27
C. 36
D. 0
উত্তর: A
ব্যাখ্যা:
x² + 1 = 3x => x + 1/x = 3।

প্রশ্ন 37. a + b + c = 6 এবং a² + b² + c² = 14 হলে, (a - b)² + (b - c)² + (c - a)² এর মান কত?
A. 14
B. 12
C. 8
D. 6
উত্তর: D
ব্যাখ্যা:
ab + bc + ca = (6² - 14)/2 = 22/2 = 11।
(a - b)² + (b - c)² + (c - a)² = 2(a² + b² + c²) - 2(ab + bc + ca)
= 2(14) - 2(11) = 28 - 22 = 6।


প্রশ্ন 38. x - 1/x = √3 হলে, x³ - 1/x³ এর মান কত?
A. 0
B. 3√3

D. 9
উত্তর: C

x³ - 1/x³ = (x - 1/x)³ + 3(x - 1/x)
= (√3)³ + 3(√3) = 3√3 + 3√3 = 6√3।


প্রশ্ন 39. a³ - 21a - 20 এর একটি উৎপাদক কোনটি?

উত্তর: D

প্রশ্ন 40. x⁴ + 1/x⁴ = 119 হলে, x - 1/x এর মান কত? (যেখানে x > 1)
A. 3
B. 4
C. 5
D. 6
উত্তর: A
ব্যাখ্যা:
(x² + 1/x²)² - 2 = 119 => (x² + 1/x²)² = 121 => x² + 1/x² = 11।
(x - 1/x)² + 2 = 11 => (x - 1/x)² = 9 => x - 1/x = 3।


প্রশ্ন 41. (a+b) = 7 এবং a² + b² = 25 হলে, ab এর মান কত?
A. 10
B. 12
C. 14
D. 24
উত্তর: B
ব্যাখ্যা:
ab = ((a+b)² - (a²+b²))/2 = (49 - 25)/2 = 24/2 = 12।


প্রশ্ন 42. x² + 5x - 6 এর উৎপাদক কোনটি?

D. (x - 3)(x + 2)

প্রশ্ন 43. যদি x + y + z = 15 এবং xy + yz + zx = 71 হয়, তবে x² + y² + z² এর মান কত?

উত্তর: B
