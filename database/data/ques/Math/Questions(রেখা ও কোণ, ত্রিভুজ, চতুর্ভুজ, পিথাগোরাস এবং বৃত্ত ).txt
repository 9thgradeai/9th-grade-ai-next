প্রশ্ন ১. একটি কোণের মান তার পূরক কোণের মানের অর্ধেকের সমান। কোণটির মান কত?
A. ৩০°
B. ৪৫°
C. ৬০°
D. ৭৫°
উত্তর: A
ব্যাখ্যা:
ধরি, কোণটি = x। এর পূরক কোণ = (৯০° - x)।
শর্তমতে, x = (৯০° - x) / ২
=> ২x = ৯০° - x
=> ৩x = ৯০°
=> x = ৩০°।


প্রশ্ন ২. দুটি পূরক কোণের অনুপাত ২:৩ হলে, বৃহত্তর কোণটির মান কত?
A. ৩৬°
B. ৫৪°
C. ৭২°
D. ১০৮°
উত্তর: B
ব্যাখ্যা:
ধরি, কোণ দুটি ২x এবং ৩x। পূরক কোণের সমষ্টি সর্বদা ৯০°।
২x + ৩x = ৯০°
=> ৫x = ৯০°
=> x = ১৮°
বৃহত্তর কোণটি = ৩ × ১৮° = ৫৪°।


প্রশ্ন ৩. একটি কোণের মান তার সম্পূরক কোণের মানের চেয়ে ২৪° বেশি। কোণটির মান কত?
A. ৭৮°
B. ৯৬°
C. ১০২°
D. ১১৪°
উত্তর: C
ব্যাখ্যা:
ধরি, কোণটি = x। এর সম্পূরক কোণ = (১৮০° - x)।
শর্তমতে, x = (১৮০° - x) + ২৪°
=> ২x = ২০৪°
=> x = ১০২°।


প্রশ্ন ৪. দুটি সমান্তরাল রেখাকে একটি ছেদক ছেদ করলে, একান্তর কোণগুলোর সম্পর্ক কী রূপ হয়?
A. পরস্পর পূরক
B. পরস্পর সম্পূরক
C. পরস্পর সমান
D. একটি অপরটির দ্বিগুণ
উত্তর: C
ব্যাখ্যা:
জ্যামিতিক উপপাদ্য অনুযায়ী, দুটি সমান্তরাল সরলরেখাকে অপর একটি রেখা ছেদ করলে উৎপন্ন একান্তর কোণগুলো পরস্পর সমান হয়।


প্রশ্ন ৫. ঘড়িতে ৩টা ১৫ মিনিট বাজলে ঘণ্টা ও মিনিটের কাঁটার মধ্যবর্তী কোণ কত ডিগ্রি হবে?
A. ০°
B. ৭.৫°
C. ১৫°
D. ২২.৫°
উত্তর: B
ব্যাখ্যা:
ঘড়ি সংক্রান্ত কোণ নির্ণয়ের সূত্র: Angle = |(১১M - ৬০H) / ২|
এখানে H = ৩, M = ১৫।
কোণ = |(১১ × ১৫ - ৬০ × ৩) / ২| = |(১৬৫ - ১৮০) / ২| = |-১৫ / ২| = ৭.৫°।
Competitive Shortcut: ৩টায় কাঁটা দুটি মিলে যায় বলে মনে হলেও ঘণ্টার কাঁটা ১৫ মিনিটে কিছুটা এগিয়ে যায়। প্রতি মিনিটে ঘণ্টার কাঁটা ০.৫° ঘোরে। ১৫ মিনিটে ঘোরে ১৫ × ০.৫° = ৭.৫°।


প্রশ্ন ৬. ঘড়িতে ৪টা ৩০ মিনিট বাজলে ঘণ্টা ও মিনিটের কাঁটার মধ্যবর্তী কোণ কত?
A. ৩০°
B. ৪৫°
C. ৬০°
D. ৭৫°
উত্তর: B
ব্যাখ্যা:
সূত্র: Angle = |(১১ × ৩০ - ৬০ × ৪) / ২|
= |(৩৩০ - ২৪০) / ২|
= |৯০ / ২| = ৪৫°।


প্রশ্ন ৭. একটি সুষম ষড়ভুজের অন্তঃস্থ কোণগুলোর সমষ্টি কত?
A. ৫৪০°
B. ৭২০°
C. ৯০০°
D. ১০৮০°
উত্তর: B
ব্যাখ্যা:
যেকোনো বহুভুজের অন্তঃস্থ কোণের সমষ্টির সূত্র = (n - ২) × ১৮০°।
ষড়ভুজের ক্ষেত্রে n = ৬।
সমষ্টি = (৬ - ২) × ১৮০° = ৪ × ১৮০° = ৭২০°।


প্রশ্ন ৮. একটি সুষম বহুভুজের প্রত্যেকটি বহিঃস্থ কোণের মান ৩৬° হলে, এর বাহুর সংখ্যা কত?
A. ৮
B. ১০
C. ১২
D. ১৪
উত্তর: B
ব্যাখ্যা:
সুষম বহুভুজের বাহুর সংখ্যা, n = ৩৬০° / একটি বহিঃস্থ কোণ।
n = ৩৬০° / ৩৬° = ১০।


প্রশ্ন ৯. ২৫৩° কোণকে কী কোণ বলা হয়?
A. সূক্ষ্মকোণ
B. স্থূলকোণ
C. সরলকোণ
D. প্রবৃদ্ধ কোণ
উত্তর: D
ব্যাখ্যা:
যে কোণের মান ১৮০° এর চেয়ে বড় কিন্তু ৩৬০° এর চেয়ে ছোট, তাকে প্রবৃদ্ধ কোণ (Reflex angle) বলে।


প্রশ্ন ১০. দুটি রেখা পরস্পর ছেদ করলে যে চারটি কোণ উৎপন্ন হয়, তাদের সমষ্টি কত?
A. ১৮০°
B. ২৭০°
C. ৩৬০°
D. ৭২০°
উত্তর: C
ব্যাখ্যা:
দুটি রেখা একটি বিন্দুতে ছেদ করলে ওই বিন্দুতে মোট চার সমকোণ বা ৩৬০° কোণ উৎপন্ন হয়।


প্রশ্ন ১১. একটি সরলরেখার উপর অপর একটি রেখাংশ দণ্ডায়মান হলে যে দুটি সন্নিহিত কোণ উৎপন্ন হয়, তাদের সমষ্টি কত?
A. ৯০°
B. ১৮০°
C. ২৭০°
D. ৩৬০°
উত্তর: B
ব্যাখ্যা:
উপপাদ্য অনুযায়ী, একটি সরলরেখার উপর অপর একটি রেখাংশ মিলিত হলে উৎপন্ন সন্নিহিত কোণ দুটির সমষ্টি দুই সমকোণ বা ১৮০° হয়। এদের রৈখিক যুগল কোণও বলা হয়।


প্রশ্ন ১২. দুটি বিপ্রতীপ কোণের একটি ৬৫° হলে, অপরটি কত?
A. ২৫°
B. ৬৫°
C. ১১৫°
D. ১৩০°
উত্তর: B
ব্যাখ্যা:
দুটি সরলরেখা পরস্পর ছেদ করলে উৎপন্ন বিপ্রতীপ কোণগুলো পরস্পর সমান হয়। তাই অপর কোণটিও ৬৫° হবে।


প্রশ্ন ১৩. একটি সুষম পঞ্চভুজের প্রতিটি অন্তঃস্থ কোণের মান কত?
A. ৭২°
B. ১০৮°
C. ১২০°
D. ১৪৪°
উত্তর: B
ব্যাখ্যা:
পঞ্চভুজের বাহু n = ৫।
বহিঃস্থ কোণ = ৩৬০° / ৫ = ৭২°।
সুতরাং, প্রতিটি অন্তঃস্থ কোণ = ১৮০° - ৭২° = ১০৮°।


প্রশ্ন ১৪. একটি অষ্টভুজের কর্ণের সংখ্যা কত?
A. ১৪
B. ২০
C. ২৪
D. ২৮
উত্তর: B
ব্যাখ্যা:
বহুভুজের কর্ণের সংখ্যার সূত্র = n(n - ৩) / ২।
অষ্টভুজের ক্ষেত্রে n = ৮।
কর্ণ = ৮(৮ - ৩) / ২ = (৮ × ৫) / ২ = ২০টি।


প্রশ্ন ১৫. একটি কোণ তার সম্পূরক কোণের দ্বিগুণ হলে, কোণটির মান কত?
A. ৬০°
B. ৯০°
C. ১২০°
D. ১৫০°
উত্তর: C
ব্যাখ্যা:
ধরি, সম্পূরক কোণটি = x। তাহলে মূল কোণটি = ২x।
দুটি সম্পূরক কোণের সমষ্টি ১৮০°।
x + ২x = ১৮০°
=> ৩x = ১৮০°
=> x = ৬০°।
সুতরাং, মূল কোণটি = ২ × ৬০° = ১২০°।


প্রশ্ন ১৬. দুটি সমান্তরাল রেখাকে একটি ছেদক ছেদ করলে, ছেদকের একই পাশের অন্তঃস্থ কোণদ্বয়ের সমষ্টি কত?
A. ৯০°
B. ১৮০°
C. ২৭০°
D. ৩৬০°
উত্তর: B
ব্যাখ্যা:
উপপাদ্য অনুযায়ী, দুটি সমান্তরাল রেখাকে একটি ছেদক ছেদ করলে ছেদকের একই পাশের অন্তঃস্থ কোণদ্বয় পরস্পর সম্পূরক হয়, অর্থাৎ তাদের সমষ্টি ১৮০°।


প্রশ্ন ১৭. ৯১° কোণকে কী বলা হয়?
A. সূক্ষ্মকোণ
B. সমকোণ
C. স্থূলকোণ
D. প্রবৃদ্ধ কোণ
উত্তর: C
ব্যাখ্যা:
যে কোণের মান ৯০° এর চেয়ে বড় এবং ১৮০° এর চেয়ে ছোট, তাকে স্থূলকোণ বলে।


প্রশ্ন ১৮. দুটি সন্নিহিত কোণের সমষ্টি ৯০° হলে, তাদেরকে একে অপরের কী কোণ বলা হয়?
A. পূরক কোণ
B. সম্পূরক কোণ
C. বিপ্রতীপ কোণ
D. একান্তর কোণ
উত্তর: A
ব্যাখ্যা:
দুটি কোণের সমষ্টি এক সমকোণ বা ৯০° হলে, তাদেরকে পরস্পর পূরক কোণ (Complementary angles) বলে।


প্রশ্ন ১৯. একটি ঘড়ির মিনিটের কাঁটা ২০ মিনিটে কত ডিগ্রি কোণ ঘোরে?
A. ৬০°
B. ৯০°
C. ১২০°
D. ১৫০°
উত্তর: C
ব্যাখ্যা:
মিনিটের কাঁটা ৬০ মিনিটে ঘোরে ৩৬০°।
সুতরাং ১ মিনিটে ঘোরে ৩৬০° / ৬০ = ৬°।
২০ মিনিটে ঘুরবে ২০ × ৬° = ১২০°।


প্রশ্ন ২০. 'a' এবং 'b' দুটি একান্তর কোণ। 'a' এর মান ৭৫° হলে 'b' এর মান কত?
A. ১৫°
B. ৭৫°
C. ১০৫°
D. ১৮০°
উত্তর: B
ব্যাখ্যা:
সমান্তরাল রেখার ক্ষেত্রে একান্তর কোণগুলো পরস্পর সমান হয়। তাই a = b = ৭৫°।


প্রশ্ন ২১. ত্রিভুজের তিনটি কোণের অনুপাত ২:৩:৪ হলে, বৃহত্তম কোণটির মান কত?
A. ৪০°
B. ৬০°
C. ৮০°
D. ১০০°
উত্তর: C
ব্যাখ্যা:
ত্রিভুজের তিন কোণের সমষ্টি ১৮০°।
ধরি, কোণ তিনটি ২x, ৩x এবং ৪x।
২x + ৩x + ৪x = ১৮০°
=> ৯x = ১৮০°
=> x = ২০°।
বৃহত্তম কোণ = ৪ × ২০° = ৮০°।


প্রশ্ন ২২. একটি ত্রিভুজের যেকোনো এক বাহুকে বর্ধিত করলে উৎপন্ন বহিঃস্থ কোণটি অন্তস্থ বিপরীত কোণদ্বয়ের সমষ্টির—
A. অর্ধেক
B. সমান
C. দ্বিগুণ
D. সম্পূরক
উত্তর: B
ব্যাখ্যা:
জ্যামিতিক উপপাদ্য অনুযায়ী, ত্রিভুজের কোনো এক বাহু বর্ধিত করলে যে বহিঃস্থ কোণ উৎপন্ন হয়, তা এর অন্তস্থ বিপরীত কোণ দুটির সমষ্টির সমান।


প্রশ্ন ২৩. নিচের কোন তিনটি বাহুর দৈর্ঘ্য দ্বারা ত্রিভুজ গঠন করা সম্ভব?
A. ২, ৩, ৫
B. ৩, ৪, ৮
C. ৪, ৫, ৬
D. ১, ২, ৪
উত্তর: C
ব্যাখ্যা:
ত্রিভুজ গঠনের শর্ত হলো: যেকোনো দুই বাহুর যোগফল তৃতীয় বাহু অপেক্ষা বৃহত্তর হতে হবে (a + b > c)।
C অপশনে: ৪ + ৫ = ৯ > ৬ (শর্ত মানে)।
অন্যান্য অপশনে ছোট দুই বাহুর যোগফল তৃতীয় বাহুর সমান বা ছোট।


প্রশ্ন ২৪. সমদ্বিবাহু ত্রিভুজের শীর্ষকোণ ৮০° হলে, ভূমিসংলগ্ন কোণ দুটির প্রত্যেকটির মান কত?
A. ৪০°
B. ৫০°
C. ৬০°
D. ১০০°
উত্তর: B
ব্যাখ্যা:

শীর্ষকোণ ৮০° হলে, বাকি দুটি কোণের সমষ্টি = ১৮০° - ৮০° = ১০০°।

প্রশ্ন ২৮. সমকোণী ত্রিভুজের সূক্ষ্মকোণদ্বয়ের পার্থক্য ১০° হলে, ক্ষুদ্রতম কোণটির মান কত?

প্রশ্ন ৩০. একটি ত্রিভুজের তিনটি বাহুর দৈর্ঘ্য যথাক্রমে ৫, ১২ এবং ১৩ সেমি হলে, ত্রিভুজটির ক্ষেত্রফল কত?

প্রশ্ন ৩১. সমকোণী ত্রিভুজের অতিভুজের মধ্যবিন্দু থেকে এর শীর্ষগুলোর দূরত্ব কেমন হয়?

প্রশ্ন ৩২. একটি সমবাহু ত্রিভুজের ক্ষেত্রফল ৯√৩ বর্গ সেমি হলে, এর প্রতিটি বাহুর দৈর্ঘ্য কত?

প্রশ্ন ৩৫. একটি ত্রিভুজে সর্বোচ্চ কয়টি স্থূলকোণ থাকতে পারে?

ব্যাখ্যা:
বর্গক্ষেত্রটি দুটি সমকোণী ত্রিভুজে বিভক্ত হয় যার লম্ব ও ভূমি উভয়েই a। পিথাগোরাসের উপপাদ্য অনুযায়ী, কর্ণ = √(a² + a²) = √২a² = a√২।


প্রশ্ন ৪৬. আয়তক্ষেত্রের কর্ণদ্বয়ের সম্পর্ক কী রূপ?
A. অসমান ও সমকোণে ছেদ করে
B. সমান ও সমকোণে ছেদ করে
C. সমান এবং পরস্পরকে সমদ্বিখণ্ডিত করে
D. অসমান এবং পরস্পরকে সমদ্বিখণ্ডিত করে
উত্তর: C
ব্যাখ্যা:
আয়তক্ষেত্রের কর্ণ দুটি দৈর্ঘ্যে সমান এবং তারা পরস্পরকে সমদ্বিখণ্ডিত করে। তবে তারা সমকোণে ছেদ করে না (বর্গ ও রম্বসের ক্ষেত্রে সমকোণে ছেদ করে)।


প্রশ্ন ৪৭. ট্রাপিজিয়ামের সমান্তরাল বাহুদ্বয়ের দৈর্ঘ্য a ও b এবং এদের মধ্যবর্তী লম্ব দূরত্ব h হলে, ক্ষেত্রফল কত?
A. ah
B. ½(a + b)h
C. (a + b)h
D. ½(a - b)h
উত্তর: B
ব্যাখ্যা:
ট্রাপিজিয়ামের ক্ষেত্রফলের সূত্র: ১/২ × (সমান্তরাল বাহুদ্বয়ের যোগফল) × লম্ব দূরত্ব = ½(a + b)h।


প্রশ্ন ৪৮. একটি রম্বসের কর্ণদ্বয় যথাক্রমে ৮ সেমি ও ৬ সেমি হলে, এর ক্ষেত্রফল কত?
A. ১৪ বর্গ সেমি
B. ২৪ বর্গ সেমি
C. ৪৮ বর্গ সেমি
D. ৯৬ বর্গ সেমি
উত্তর: B
ব্যাখ্যা:
রম্বসের ক্ষেত্রফল = ১/২ × কর্ণদ্বয়ের গুণফল
= ১/২ × ৮ × ৬ = ২৪ বর্গ সেমি।


প্রশ্ন ৪৯. একটি সামান্তরিকের ভূমি ১০ সেমি এবং উচ্চতা ৫ সেমি হলে, এর ক্ষেত্রফল কত?
A. ২৫ বর্গ সেমি
B. ৫০ বর্গ সেমি
C. ১০০ বর্গ সেমি
D. ১২৫ বর্গ সেমি
উত্তর: B
ব্যাখ্যা:
সামান্তরিকের ক্ষেত্রফল = ভূমি × উচ্চতা
= ১০ × ৫ = ৫০ বর্গ সেমি।


প্রশ্ন ৫০. একটি রম্বসের কর্ণদ্বয় যথাক্রমে ১৬ সেমি এবং ১২ সেমি হলে, এর পরিসীমা কত?
A. ২৮ সেমি
B. ৪০ সেমি
C. ৫৬ সেমি
D. ৯৬ সেমি
উত্তর: B
ব্যাখ্যা:
রম্বসের কর্ণদ্বয় পরস্পরকে সমকোণে সমদ্বিখণ্ডিত করে।
সুতরাং সমকোণী ত্রিভুজের লম্ব = ১৬/২ = ৮ সেমি, ভূমি = ১২/২ = ৬ সেমি।
অতিভুজ (রম্বসের বাহু) = √(৮² + ৬²) = √(৬৪ + ৩৬) = √১০০ = ১০ সেমি।
পরিসীমা = ৪ × বাহু = ৪ × ১০ = ৪০ সেমি।


প্রশ্ন ৫১. যেকোনো চতুর্ভুজের বাহুগুলোর মধ্যবিন্দু পর্যায়ক্রমে যোগ করলে যে চিত্রটি উৎপন্ন হয়, তা সর্বদা কী হবে?
A. বর্গ
B. আয়তক্ষেত্র
C. রম্বস
D. সামান্তরিক
উত্তর: D
ব্যাখ্যা:
জ্যামিতিক উপপাদ্য (Varignon's Theorem) অনুযায়ী, যেকোনো চতুর্ভুজের সন্নিহিত বাহুগুলোর মধ্যবিন্দু যোগ করলে সর্বদা একটি সামান্তরিক উৎপন্ন হয়।


প্রশ্ন ৫২. আয়তক্ষেত্রের বাহুগুলোর মধ্যবিন্দু পর্যায়ক্রমে যোগ করলে কোন চিত্রটি গঠিত হয়?
A. বর্গ
B. আয়তক্ষেত্র
C. রম্বস
D. ট্রাপিজিয়াম
উত্তর: C
ব্যাখ্যা:
আয়তক্ষেত্রের কর্ণদ্বয় সমান হওয়ায়, এর মধ্যবিন্দুগুলো যোগ করে যে সামান্তরিক পাওয়া যায় তার সবগুলো বাহু সমান হয়। তাই এটি একটি রম্বস।


প্রশ্ন ৫৩. রম্বসের বাহুগুলোর মধ্যবিন্দু পর্যায়ক্রমে যোগ করলে কোন চিত্রটি গঠিত হয়?
A. বর্গ
B. আয়তক্ষেত্র
C. সামান্তরিক
D. কাইট
উত্তর: B
ব্যাখ্যা:
রম্বসের কর্ণদ্বয় পরস্পর লম্ব হওয়ায়, এর মধ্যবিন্দুগুলো যোগ করে যে চতুর্ভুজ পাওয়া যায় তার সন্নিহিত বাহুগুলো পরস্পর লম্ব হয়। তাই এটি একটি আয়তক্ষেত্র।


প্রশ্ন ৫৪. বৃত্তস্থ চতুর্ভুজের বিপরীত কোণগুলোর সমষ্টি কত?
A. ৯০°
B. ১৮০°
C. ২৭০°
D. ৩৬০°
উত্তর: B
ব্যাখ্যা:
উপপাদ্য: বৃত্তে অন্তর্লিখিত চতুর্ভুজের যেকোনো দুটি বিপরীত কোণের সমষ্টি সর্বদা দুই সমকোণ বা ১৮০°।


প্রশ্ন ৫৫. একটি বর্গক্ষেত্রের পরিসীমা ৩৬ সেমি হলে, এর কর্ণের দৈর্ঘ্য কত?
A. ৯ সেমি
B. ৯√২ সেমি
C. ১৮ সেমি
D. ১৮√২ সেমি
উত্তর: B
ব্যাখ্যা:
বর্গের পরিসীমা ৪a = ৩৬ => বাহু a = ৯ সেমি।
বর্গের কর্ণের দৈর্ঘ্য = a√২ = ৯√২ সেমি।


প্রশ্ন ৫৬. যে সামান্তরিকের কর্ণদ্বয় পরস্পর সমান, তাকে কী বলে?
A. রম্বস
B. ট্রাপিজিয়াম
C. আয়তক্ষেত্র
D. কাইট
উত্তর: C
ব্যাখ্যা:
সামান্তরিকের কর্ণ দুটি সমান হলে তার প্রতিটি কোণ সমকোণ হয়ে যায়। তাই সেটি একটি আয়তক্ষেত্র। (বর্গও আয়তক্ষেত্রের একটি বিশেষ রূপ)।


প্রশ্ন ৫৭. একটি রম্বসের একটি কোণ ১২০° হলে, এর বৃহত্তর কর্ণ ও ক্ষুদ্রতর কর্ণের সম্পর্ক কী? (Advanced)
A. বৃহত্তর কর্ণ ক্ষুদ্রতর কর্ণের √২ গুণ
B. বৃহত্তর কর্ণ ক্ষুদ্রতর কর্ণের √৩ গুণ
C. বৃহত্তর কর্ণ ক্ষুদ্রতর কর্ণের দ্বিগুণ
D. বৃহত্তর কর্ণ ক্ষুদ্রতর কর্ণের সমান
উত্তর: B
ব্যাখ্যা:
রম্বসের একটি কোণ ১২০° হলে, অপর কোণটি ৬০°। ক্ষুদ্রতর কর্ণটি রম্বসকে দুটি সমবাহু ত্রিভুজে ভাগ করে।
তাই ক্ষুদ্রতর কর্ণ (d₁) = বাহু (a)।
বৃহত্তর কর্ণ (d₂) = ২ × (a√৩/২) = a√৩।
অর্থাৎ, d₂ = d₁√৩।


প্রশ্ন ৫৮. ট্রাপিজিয়ামের সমান্তরাল বাহুদ্বয়ের মধ্যবিন্দুর সংযোজক রেখাকে কী বলে?
A. মধ্যমা
B. উচ্চতা
C. কর্ণ
D. সমান্তরাল রেখা
উত্তর: A (The median of a trapezium)
সংশোধিত প্রশ্ন: ট্রাপিজিয়ামের তীর্যক বাহুদ্বয়ের মধ্যবিন্দুর সংযোজক রেখাংশ সমান্তরাল বাহুদ্বয়ের—
A. সমান
B. সমান্তরাল ও তাদের যোগফলের অর্ধেক
C. সমান্তরাল ও তাদের বিয়োগফলের অর্ধেক
D. লম্ব
উত্তর: B
ব্যাখ্যা:
ট্রাপিজিয়ামের অসমান্তরাল (তীর্যক) বাহুদ্বয়ের মধ্যবিন্দুর সংযোজক সরলরেখা সমান্তরাল বাহুগুলোর সমান্তরাল এবং তাদের যোগফলের অর্ধেক হয়।


প্রশ্ন ৫৯. ঘুড়ির (Kite) কর্ণদ্বয়ের মধ্যে সম্পর্ক কী?
A. পরস্পর সমান
B. পরস্পরকে সমদ্বিখণ্ডিত করে
C. একটি কর্ণ অপর কর্ণকে লম্বভাবে সমদ্বিখণ্ডিত করে
D. পরস্পর সমান্তরাল
উত্তর: C
ব্যাখ্যা:
ঘুড়ি বা Kite-এর প্রধান কর্ণটি অপর কর্ণকে ৯০° কোণে সমদ্বিখণ্ডিত করে। তবে দুটি কর্ণ একে অপরকে সমদ্বিখণ্ডিত করে না (কেবল একটি করে)।


প্রশ্ন ৬০. একটি বর্গের পরিসীমা ও তার কর্ণের দৈর্ঘ্যের অনুপাত কত?
A. ২ : √২
B. ২√২ : ১
C. ৪ : ১
D. ৪ : √২ (বা ২√২ : ১)
উত্তর: B
ব্যাখ্যা:
পরিসীমা = ৪a। কর্ণ = a√২।
অনুপাত = ৪a : a√২ = ৪ : √২ = ২√২ : ১।


প্রশ্ন ৬১. সমকোণী ত্রিভুজের লম্ব ৩ সেমি এবং ভূমি ৪ সেমি হলে, অতিভুজ কত?
A. ৫ সেমি
B. ৬ সেমি
C. ৭ সেমি
D. ৮ সেমি
উত্তর: A
ব্যাখ্যা:
পিথাগোরাসের উপপাদ্য অনুযায়ী, অতিভুজ² = লম্ব² + ভূমি²
অতিভুজ = √(৩² + ৪²) = √(৯ + ১৬) = √২৫ = ৫ সেমি।


প্রশ্ন ৬২. একটি মই দেয়ালের সাথে হেলান দিয়ে আছে। মইটির দৈর্ঘ্য ১০ মিটার এবং দেয়ালের গোড়া থেকে মইয়ের দূরত্ব ৬ মিটার হলে, মইটি দেয়ালের কত উচ্চতায় স্পর্শ করবে?
A. ৬ মিটার
B. ৮ মিটার
C. ১০ মিটার
D. ১২ মিটার
উত্তর: B
ব্যাখ্যা:
এটি একটি সমকোণী ত্রিভুজ তৈরি করে, যেখানে অতিভুজ (মই) = ১০, ভূমি = ৬।
লম্ব (দেয়ালের উচ্চতা) = √(১০² - ৬²) = √(১০০ - ৩৬) = √৬৪ = ৮ মিটার।


প্রশ্ন ৬৩. নিচের কোন বাহুত্রয় দ্বারা সমকোণী ত্রিভুজ গঠন করা সম্ভব?
A. ২, ৩, ৪
B. ৫, ১২, ১৩
C. ৬, ৭, ৮
D. ৯, ১০, ১১
উত্তর: B
ব্যাখ্যা:
পিথাগোরাসের সূত্রানুযায়ী, ৫² + ১২² = ২৫ + ১৪৪ = ১৬৯ = ১৩²। তাই ৫, ১২, ১৩ একটি পিথাগোরীয় ট্রিপলেট।


প্রশ্ন ৬৪. ৮, ১৫ এবং ১৭ বাহুবিশিষ্ট ত্রিভুজটি কী ধরনের ত্রিভুজ?
A. সূক্ষ্মকোণী
B. স্থূলকোণী
C. সমকোণী
D. সমবাহু
উত্তর: C
ব্যাখ্যা:
৮² + ১৫² = ৬৪ + ২২৫ = ২৮৯ = ১৭²। যেহেতু লম্ব² + ভূমি² = অতিভুজ² শর্তটি পূরণ হয়, তাই এটি সমকোণী ত্রিভুজ।


প্রশ্ন ৬৫. দুটি খুঁটির উচ্চতা যথাক্রমে ১০ মিটার ও ১৫ মিটার। এদের মধ্যবর্তী দূরত্ব ১২ মিটার হলে, খুঁটি দুটির শীর্ষবিন্দুর মধ্যবর্তী দূরত্ব কত?
A. ১৩ মিটার
B. ১৪ মিটার
C. ১৫ মিটার
D. ১৭ মিটার
উত্তর: A
ব্যাখ্যা:
খুঁটি দুটির উচ্চতার পার্থক্য = ১৫ - ১০ = ৫ মিটার।
শীর্ষবিন্দুর দূরত্ব একটি সমকোণী ত্রিভুজের অতিভুজ তৈরি করে যার লম্ব ৫ মিটার এবং ভূমি ১২ মিটার।
অতিভুজ = √(৫² + ১২²) = √(২৫ + ১৪৪) = √১৬৯ = ১৩ মিটার।


প্রশ্ন ৬৬. একজন লোক উত্তর দিকে ১২ কিমি গিয়ে সেখান থেকে পূর্ব দিকে ৫ কিমি গেল। যাত্রাস্থান থেকে তার সোজাসুজি দূরত্ব কত?

সোজাসুজি দূরত্ব (অতিভুজ) = √(১২² + ৫²) = √(১৪৪ + ২৫) = √১৬৯ = ১৩ কিমি।


প্রশ্ন ৬৭. একটি আয়তক্ষেত্রের দৈর্ঘ্য ২৪ সেমি এবং প্রস্থ ৭ সেমি হলে, এর কর্ণের দৈর্ঘ্য কত?

আয়তক্ষেত্রের কর্ণ = √(দৈর্ঘ্য² + প্রস্থ²) = √(২৪² + ৭²) = √(৫৭৬ + ৪৯) = √৬২৫ = ২৫ সেমি।


প্রশ্ন ৬৮. একটি বর্গক্ষেত্রের কর্ণের দৈর্ঘ্য ১০√২ সেমি হলে, এর ক্ষেত্রফল কত?

ক্ষেত্রফল = a² = ১০² = ১০০ বর্গ সেমি।


প্রশ্ন ৬৯. একটি সমকোণী ত্রিভুজের অতিভুজ ২৫ সেমি এবং একটি বাহু ২৪ সেমি হলে, ত্রিভুজটির ক্ষেত্রফল কত?

অপর বাহু (লম্ব বা ভূমি) = √(২৫² - ২৪²) = √(৬২৫ - ৫৭৬) = √৪৯ = ৭ সেমি।
ক্ষেত্রফল = ১/২ × ভূমি × লম্ব = ১/২ × ২৪ × ৭ = ৮৪ বর্গ সেমি।


প্রশ্ন ৭০. একটি সমদ্বিবাহু সমকোণী ত্রিভুজের অতিভুজের দৈর্ঘ্য ১০ সেমি হলে, এর সমান বাহু দুটির প্রত্যেকটির দৈর্ঘ্য কত?

ধরি, সমান বাহু দুটি a।
পিথাগোরাসের সূত্রমতে, a² + a² = ১০²
=> ২a² = ১০০
=> a² = ৫০
=> a = √৫০ = ৫√২ সেমি।


প্রশ্ন ৭১. পিথাগোরাসের উপপাদ্যটি নিচের কোন জ্যামিতিক চিত্রের সাথে সরাসরি সম্পর্কিত?

প্রশ্ন ৭২. একটি ত্রিভুজের বাহুগুলোর অনুপাত ১ : ১ : √২ হলে, এর বৃহত্তম কোণটি কত ডিগ্রি?

যেহেতু এটি পিথাগোরাসের সূত্র মেনে চলে, তাই এটি একটি সমকোণী ত্রিভুজ এবং এর বৃহত্তম কোণ ৯০°।


প্রশ্ন ৭৩. একটি রম্বসের একটি বাহু ১৩ সেমি এবং একটি কর্ণ ২৪ সেমি হলে, অপর কর্ণটি কত?

একটি সমকোণী ত্রিভুজ গঠিত হয় যার অতিভুজ = ১৩, এবং লম্ব = ২৪/২ = ১২।

প্রশ্ন ৭৪. একটি আয়তাকার বাক্সের দৈর্ঘ্য, প্রস্থ ও উচ্চতা যথাক্রমে ৪ মি, ৩ মি ও ১২ মি হলে, এর ভেতরের কর্ণের দৈর্ঘ্য কত?

প্রশ্ন ৭৫. একটি আয়তাকার মাঠের দৈর্ঘ্য ১৬ মিটার এবং প্রস্থ ১২ মিটার। মাঠটির এক কোণ থেকে আড়াআড়িভাবে বিপরীত কোণে যেতে কত মিটার হাঁটতে হবে?

কর্ণ = √(১৬² + ১২²) = √(২৫৬ + ১৪৪) = √৪০০ = ২০ মিটার।


প্রশ্ন ৭৬. একটি সমবাহু ত্রিভুজের বাহুর দৈর্ঘ্য ৬ সেমি। পিথাগোরাসের উপপাদ্য প্রয়োগ করে এর উচ্চতা বের করলে কত হবে?

উচ্চতা (লম্ব) = √(৬² - ৩²) = √(৩৬ - ৯) = √২৭ = ৩√৩ সেমি।


প্রশ্ন ৭৭. একটি বৃত্তের ব্যাসার্ধ ১৩ সেমি। কেন্দ্র থেকে একটি জ্যা-এর লম্ব দূরত্ব ৫ সেমি হলে, জ্যা-এর দৈর্ঘ্য কত?

ভূমি (জ্যা-এর অর্ধেক) = √(১৩² - ৫²) = √(১৬৯ - ২৫) = √১৪৪ = ১২ সেমি।
সম্পূর্ণ জ্যা = ১২ × ২ = ২৪ সেমি।


প্রশ্ন ৭৮. একটি সমকোণী ত্রিভুজের অতিভুজ এবং অপর একটি বাহুর দৈর্ঘ্য যথাক্রমে ২৫ সেমি ও ৭ সেমি। ত্রিভুজটির পরিসীমা কত?

প্রশ্ন ৭৯. দুটি জাহাজ একই বন্দর থেকে একই সময়ে যাত্রা শুরু করল। একটি উত্তর দিকে ঘণ্টায় ১৫ কিমি বেগে এবং অপরটি পূর্ব দিকে ঘণ্টায় ২০ কিমি বেগে চলল। ২ ঘণ্টা পর তাদের মধ্যবর্তী দূরত্ব কত হবে?

প্রশ্ন ৮০. একটি গাছ ঝড়ে এমনভাবে ভেঙে গেল যে তার অবিচ্ছিন্ন ভাঙা অংশ দণ্ডায়মান অংশের সাথে ৩০° কোণ করে গাছের গোড়া থেকে ১০√৩ মিটার দূরে মাটি স্পর্শ করল। দণ্ডায়মান অংশের দৈর্ঘ্য কত?

tan(৩০°) = বিপরীত বাহু / সন্নিহিত বাহু = (১০√৩) / x
১/√৩ = ১০√৩ / x
=> x = ১০√৩ × √৩ = ১০ × ৩ = ৩০।
(Wait, this means x=30. Let's re-read: "দণ্ডায়মান অংশের সাথে ৩০° কোণ করে". This means the angle is at the top. So opposite side is the ground distance. tan(30) = ground / standing part = 10√3 / x => 1/√3 = 10√3 / x => x = 30.

সমকোণী ত্রিভুজে, tan(৩০°) = ভূমি (গোড়া থেকে দূরত্ব) / লম্ব (দণ্ডায়মান অংশ)
=> ১/√৩ = ১০√৩ / লম্ব
=> লম্ব = ১০√৩ × √৩ = ৩০ মিটার।

C. দ্বিগুণ দূরত্বে
D. অর্ধেক দূরত্বে
উত্তর: B
ব্যাখ্যা:
উপপাদ্য: বৃত্তের সকল সমান জ্যা কেন্দ্র থেকে সমদূরবর্তী।


প্রশ্ন ৮৪. একই চাপের উপর দণ্ডায়মান কেন্দ্রস্থ কোণ বৃত্তস্থ কোণের—
A. অর্ধেক
B. সমান
C. দ্বিগুণ
D. চারগুণ
উত্তর: C
ব্যাখ্যা:
বৃত্তের একই চাপের উপর দণ্ডায়মান কেন্দ্রস্থ কোণ সর্বদা পরিধিস্থ বা বৃত্তস্থ কোণের দ্বিগুণ হয়।


প্রশ্ন ৮৫. বৃত্তের একই চাপের উপর দণ্ডায়মান বৃত্তস্থ কোণগুলোর সম্পর্ক কী রূপ?
A. একটি অপরটির দ্বিগুণ
B. পরস্পর পূরক
C. পরস্পর সম্পূরক
D. পরস্পর সমান
উত্তর: D
ব্যাখ্যা:
উপপাদ্য অনুযায়ী, বৃত্তের একই চাপের উপর দণ্ডায়মান সকল বৃত্তস্থ কোণ পরস্পর সমান হয়।


প্রশ্ন ৮৬. বৃত্তের বৃহত্তম জ্যা কোনটি?
A. ব্যাসার্ধ
B. ব্যাস
C. স্পর্শক
D. ছেদক
উত্তর: B
ব্যাখ্যা:
বৃত্তের কেন্দ্রগামী জ্যা-ই হলো বৃত্তের বৃহত্তম জ্যা, যাকে ব্যাস (Diameter) বলা হয়।


প্রশ্ন ৮৭. বৃত্তের যেকোনো বিন্দুতে অঙ্কিত স্পর্শক স্পর্শবিন্দুগামী ব্যাসার্ধের সাথে কত ডিগ্রি কোণ উৎপন্ন করে?
A. ৪৫°
B. ৬০°
C. ৯০°
D. ১৮০°
উত্তর: C
ব্যাখ্যা:
বৃত্তের কোনো বিন্দুতে অঙ্কিত স্পর্শক এবং ওই বিন্দুগামী ব্যাসার্ধ পরস্পর লম্ব হয়, অর্থাৎ তাদের মধ্যবর্তী কোণ ৯০°।


প্রশ্ন ৮৮. বৃত্তের বহিঃস্থ কোনো বিন্দু থেকে বৃত্তে সর্বাধিক কয়টি স্পর্শক আঁকা যায়?
A. ১টি
B. ২টি
C. ৩টি
D. অসংখ্য
উত্তর: B
ব্যাখ্যা:
বৃত্তের বাইরের যেকোনো বিন্দু থেকে ওই বৃত্তে সর্বাধিক ২টি স্পর্শক অঙ্কন করা যায় এবং স্পর্শক দুটির দৈর্ঘ্য পরস্পর সমান হয়।


প্রশ্ন ৮৯. দুটি বৃত্ত পরস্পরকে বহিঃস্পর্শ করলে, তাদের কেন্দ্রদ্বয়ের মধ্যবর্তী দূরত্ব কত হবে?
A. তাদের ব্যাসার্ধের পার্থক্যের সমান
B. তাদের ব্যাসার্ধের গুণফলের সমান
C. তাদের ব্যাসার্ধের যোগফলের সমান
D. শূন্য
উত্তর: C
ব্যাখ্যা:
দুটি বৃত্ত পরস্পরকে বাইরের দিক থেকে স্পর্শ করলে কেন্দ্র দুটির মধ্যবর্তী দূরত্ব হবে তাদের নিজ নিজ ব্যাসার্ধের যোগফলের (R + r) সমান।


প্রশ্ন ৯০. দুটি বৃত্ত পরস্পরকে অন্তঃস্পর্শ করলে, তাদের কেন্দ্রদ্বয়ের মধ্যবর্তী দূরত্ব কত হবে?
A. ব্যাসার্ধের যোগফল
B. ব্যাসার্ধের বিয়োগফল
C. ব্যাসের যোগফল
D. ব্যাসের বিয়োগফল
উত্তর: B
ব্যাখ্যা:
দুটি বৃত্ত পরস্পরকে ভেতরের দিক থেকে স্পর্শ করলে তাদের কেন্দ্রদ্বয়ের মধ্যবর্তী দূরত্ব হবে তাদের ব্যাসার্ধের পার্থক্যের বা বিয়োগফলের (R - r) সমান।


প্রশ্ন ৯১. বৃত্তের অধিচাপে (Major arc) অন্তর্লিখিত কোণ কী ধরনের কোণ?
A. সূক্ষ্মকোণ
B. সমকোণ
C. স্থূলকোণ
D. প্রবৃদ্ধ কোণ
উত্তর: A
ব্যাখ্যা:
বৃত্তের বড় চাপ বা অধিচাপে অন্তর্লিখিত কোণ সর্বদা সূক্ষ্মকোণ (৯০° এর ছোট) হয়।


প্রশ্ন ৯২. বৃত্তের উপচাপে (Minor arc) অন্তর্লিখিত কোণ কী ধরনের কোণ?
A. সূক্ষ্মকোণ
B. সমকোণ
C. স্থূলকোণ
D. প্রবৃদ্ধ কোণ
উত্তর: C
ব্যাখ্যা:
বৃত্তের ছোট চাপ বা উপচাপে অন্তর্লিখিত কোণ সর্বদা স্থূলকোণ (৯০° এর বড়) হয়।


প্রশ্ন ৯৩. একটি বৃত্তের পরিধি ও ব্যাসের অনুপাত কত?
A. ২২/৭ (π)
B. ৭/২২
C. ৩.১৪
D. উপরের ক ও গ উভয়ই
উত্তর: D
ব্যাখ্যা:
বৃত্তের পরিধি (২πr) এবং ব্যাসের (২r) অনুপাত একটি ধ্রুবক, যাকে π (পাই) বলা হয়। এর মান ২২/৭ বা প্রায় ৩.১৪১৫৯...।


প্রশ্ন ৯৪. একটি বৃত্তের ক্ষেত্রফল ৩১৪ বর্গ সেমি হলে, এর ব্যাসার্ধ কত? (π = ৩.১৪ ধরে)
A. ৫ সেমি
B. ১০ সেমি
C. ১৫ সেমি
D. ২০ সেমি
উত্তর: B
ব্যাখ্যা:
ক্ষেত্রফল = πr²
৩.১৪ × r² = ৩১৪
=> r² = ১০০
=> r = ১০ সেমি।


প্রশ্ন ৯৫. একটি বৃত্তের ব্যাসার্ধ ৭ সেমি এবং একটি বৃত্তচাপ কেন্দ্রে ৬০° কোণ উৎপন্ন করলে, ওই বৃত্তকলার (Sector) ক্ষেত্রফল কত? (π = ২২/৭)
A. ১২.৮৩ বর্গ সেমি
B. ২৫.৬৬ বর্গ সেমি
C. ৫১.৩৩ বর্গ সেমি
D. ১৫৪ বর্গ সেমি
উত্তর: B
ব্যাখ্যা:
বৃত্তকলার ক্ষেত্রফল = (θ / ৩৬০°) × πr²
= (৬০° / ৩৬০°) × (২২/৭) × ৭²
= (১/৬) × ১৫৪ = ২৫.৬৬ বর্গ সেমি (প্রায়)।


প্রশ্ন ৯৬. কোনো বৃত্তের কেন্দ্র থেকে ১২ সেমি দূরে অবস্থিত জ্যা-এর দৈর্ঘ্য ১০ সেমি। বৃত্তটির ব্যাসার্ধ কত?
A. ১৩ সেমি
B. ১৪ সেমি
C. ১৫ সেমি
D. ১৭ সেমি
উত্তর: A
ব্যাখ্যা:
কেন্দ্র থেকে জ্যা-এর উপর লম্ব জ্যা-কে সমদ্বিখণ্ডিত করে। তাই সমকোণী ত্রিভুজের ভূমি = ১০/২ = ৫ সেমি, লম্ব = ১২ সেমি।
ব্যাসার্ধ (অতিভুজ) = √(১২² + ৫²) = √(১৪৪ + ২৫) = √১৬৯ = ১৩ সেমি।


প্রশ্ন ৯৭. একটি বৃত্তের দুটি জ্যা AB ও CD পরস্পরকে বৃত্তের অভ্যন্তরে P বিন্দুতে ছেদ করেছে। PA = ৪ সেমি, PB = ৬ সেমি এবং PC = ৩ সেমি হলে, PD এর দৈর্ঘ্য কত?
A. ৫ সেমি
B. ৬ সেমি
C. ৮ সেমি
D. ১২ সেমি
উত্তর: C
ব্যাখ্যা:
বৃত্তের দুটি জ্যা অভ্যন্তরে ছেদ করলে উপপাদ্য অনুযায়ী, PA × PB = PC × PD।
৪ × ৬ = ৩ × PD
=> ২৪ = ৩ × PD
=> PD = ৮ সেমি।


প্রশ্ন ৯৮. বৃত্তস্থ চতুর্ভুজের একটি কোণ ৬০° হলে, এর বিপরীত কোণটির মান কত?
A. ৩০°
B. ৬০°
C. ৯০°
D. ১২০°
উত্তর: D
ব্যাখ্যা:
বৃত্তস্থ চতুর্ভুজের বিপরীত কোণ দুটির সমষ্টি ১৮০°।
একটি কোণ ৬০° হলে বিপরীত কোণটি = ১৮০° - ৬০° = ১২০°।


প্রশ্ন ৯৯. একটি বৃত্তের ব্যাসার্ধ ৩ গুণ করা হলে এর ক্ষেত্রফল কত গুণ বৃদ্ধি পাবে?
A. ৩ গুণ
B. ৬ গুণ
C. ৮ গুণ
D. ৯ গুণ
উত্তর: C
ব্যাখ্যা:
প্রাথমিক ক্ষেত্রফল = πr²।
নতুন ব্যাসার্ধ = ৩r, নতুন ক্ষেত্রফল = π(৩r)² = ৯πr²।
ক্ষেত্রফল ৯ গুণ হবে। কিন্তু প্রশ্নে বলা হয়েছে "কত গুণ বৃদ্ধি পাবে?"
বৃদ্ধি পাবে = ৯ - ১ = ৮ গুণ।
Competitive Trap: অনেক সময় প্রশ্নে 'কত গুণ হবে' (৯ গুণ) এবং 'কত গুণ বৃদ্ধি পাবে' (৮ গুণ) এর মধ্যে পার্থক্য থাকে।


প্রশ্ন ১০০. কোনো বৃত্তের বহিঃস্থ বিন্দু P থেকে বৃত্তের উপর PA এবং PB দুটি স্পর্শক টানা হলো। ∠APB = ৪০° হলে, ∠PAB এর মান কত?
A. ৪০°
B. ৫০°
C. ৭০°
D. ১৪০°
উত্তর: C
ব্যাখ্যা:
বহিঃস্থ বিন্দু থেকে টানা স্পর্শক দুটির দৈর্ঘ্য সমান (PA = PB)।
তাহলে ত্রিভুজ PAB একটি সমদ্বিবাহু ত্রিভুজ, যার ∠PAB = ∠PBA।
ত্রিভুজের তিন কোণের সমষ্টি ১৮০°।
∠PAB + ∠PBA + ৪০° = ১৮০°
=> ২ × ∠PAB = ১৪০°
=> ∠PAB = ৭০°।


প্রশ্ন ১০১. একটি সমকোণের এক-তৃতীয়াংশের পূরক কোণ কত ডিগ্রি?
A. ৩০°
B. ৬০°
C. ৯০°
D. ১২০°
উত্তর: B
ব্যাখ্যা:
এক সমকোণ = ৯০°। এর এক-তৃতীয়াংশ = ৯০° / ৩ = ৩০°।
৩০° এর পূরক কোণ = (৯০° - ৩০°) = ৬০°।


প্রশ্ন ১০২. কোনো একটি কোণের সম্পূরক কোণ এবং পূরক কোণের অনুপাত ৩ : ১ হলে, কোণটির মান কত?
A. ৩০°
B. ৪৫°
C. ৬০°
D. ৭৫°
উত্তর: B
ব্যাখ্যা:
ধরি, কোণটি x। এর সম্পূরক কোণ = ১৮০° - x এবং পূরক কোণ = ৯০° - x।
শর্তমতে, (১৮০° - x) / (৯০° - x) = ৩ / ১
=> ১৮০° - x = ২৭০° - ৩x
=> ২x = ৯০°
=> x = ৪৫°।


প্রশ্ন ১০৩. দুটি সমান্তরাল রেখাকে একটি ছেদক ছেদ করলে, ছেদকের একই পাশের অন্তঃস্থ কোণদ্বয়ের অন্তর ২০° হলে কোণ দুটি কত?
A. ৫০° ও ৭০°
B. ৮০° ও ১০০°
C. ৭০° ও ১১০°
D. ৭৫° ও ৯৫°
উত্তর: B
ব্যাখ্যা:
সমান্তরাল রেখার ক্ষেত্রে ছেদকের একই পাশের অন্তঃস্থ কোণদ্বয়ের সমষ্টি ১৮০°।
ধরি, কোণ দুটি x এবং y।
x + y = ১৮০° এবং x - y = ২০°।
যোগ করে পাই, ২x = ২০০° => x = ১০০°।
সুতরাং, y = ১৮০° - ১০০° = ৮০°।


প্রশ্ন ১০৪. ঘড়িতে ২টা ২০ মিনিট বাজলে ঘণ্টা ও মিনিটের কাঁটার মধ্যবর্তী কোণ কত ডিগ্রি হবে?
A. ৪০°
B. ৫০°
C. ৬০°
D. ৭০°
উত্তর: B
ব্যাখ্যা:
কোণ নির্ণয়ের সূত্র = |(১১M - ৬০H) / ২|
এখানে, H = ২, M = ২০।
কোণ = |(১১ × ২০ - ৬০ × ২) / ২| = |(২২০ - ১২০) / ২| = ১০০ / ২ = ৫০°।


প্রশ্ন ১০৫. ঘড়িতে ১০টা ১০ মিনিট বাজলে ঘণ্টা ও মিনিটের কাঁটার মধ্যবর্তী ক্ষুদ্রতম কোণটি কত?
A. ১১৫°
B. ১২০°
C. ২৪৫°
D. ১১০°
উত্তর: A
ব্যাখ্যা:
কোণ = |(১১ × ১০ - ৬০ × ১০) / ২| = |(১১০ - ৬০০) / ২| = |-৪৯০ / ২| = ২৪৫°।
যেহেতু ২৪৫° প্রবৃদ্ধ কোণ (১৮০° এর চেয়ে বড়), তাই ক্ষুদ্রতম কোণ = ৩৬০° - ২৪৫° = ১১৫°।


প্রশ্ন ১০৬. একটি সুষম বহুভুজের অন্তঃস্থ কোণগুলোর সমষ্টি ১৪৪০° হলে, এর বাহুর সংখ্যা কত?
A. ৮
B. ১০
C. ১২
D. ১৪
উত্তর: B
ব্যাখ্যা:
বহুভুজের অন্তঃস্থ কোণের সমষ্টি = (n - ২) × ১৮০°।
শর্তমতে, (n - ২) × ১৮০° = ১৪৪০°
=> n - ২ = ১৪৪০ / ১৮০ = ৮
=> n = ১০।


প্রশ্ন ১০৭. একটি সুষম বহুভুজের প্রতিটি বহিঃস্থ কোণের মান ২৪° হলে, এর বাহুর সংখ্যা কত?
A. ১২
B. ১৫
C. ১৮
D. ২০
উত্তর: B
ব্যাখ্যা:
সুষম বহুভুজের বাহুর সংখ্যা (n) = ৩৬০° / একটি বহিঃস্থ কোণ।
n = ৩৬০° / ২৪° = ১৫টি।


প্রশ্ন ১০৮. একটি সুষম দশভুজের (Decagon) কর্ণের সংখ্যা কত?
A. ২০
B. ২৫
C. ৩৫
D. ৪০
উত্তর: C
ব্যাখ্যা:
কর্ণ নির্ণয়ের সূত্র = n(n - ৩) / ২।
দশভুজের ক্ষেত্রে n = ১০।
কর্ণের সংখ্যা = ১০(১০ - ৩) / ২ = (১০ × ৭) / ২ = ৭০ / ২ = ৩৫টি।


প্রশ্ন ১০۹. একটি বিন্দুর চারদিকে চারটি কোণ উৎপন্ন হলো যাদের অনুপাত ১ : ২ : ৩ : ৪। বৃহত্তম কোণটির মান কত?
A. ৭২°
B. ১০৮°
C. ১৪৪°
D. ১৮০°
উত্তর: C
ব্যাখ্যা:
বিন্দুর চারদিকে মোট কোণ ৩৬০°।
অনুপাতের সমষ্টি = ১ + ২ + ৩ + ৪ = ১০।
বৃহত্তম কোণ = (৪ / ১০) × ৩৬০° = ১৪৪°।


প্রশ্ন ১১০. 'A' এবং 'B' দুটি পূরক কোণ। যদি A এর মান B এর দ্বিগুণের চেয়ে ১৫° বেশি হয়, তবে A এর মান কত?
A. ২৫°
B. ৬৫°
C. ৭৫°
D. ১৫°
উত্তর: B
ব্যাখ্যা:
A + B = ৯০° (যেহেতু পূরক কোণ)।
দেওয়া আছে, A = ২B + ১৫°।
(২B + ১৫°) + B = ৯০° => ৩B = ৭৫° => B = ২৫°।
সুতরাং, A = ৯০° - ২৫° = ৬৫°।


প্রশ্ন ১১১. কোন কোণের মান তার পূরক কোণের মানের সমান?
A. ৩০°
B. ৪৫°
C. ৬০°
D. ৯০°
উত্তর: B
ব্যাখ্যা:
ধরি কোণটি x। শর্তমতে, x = ৯০° - x => ২x = ৯০° => x = ৪৫°।


প্রশ্ন ১১২. কোন কোণের মান তার সম্পূরক কোণের মানের সমান?
A. ৪৫°
B. ৯০°
C. ১৩৫°
D. ১৮০°
উত্তর: B
ব্যাখ্যা:
ধরি কোণটি x। শর্তমতে, x = ১৮০° - x => ২x = ১৮০° => x = ৯০°।


প্রশ্ন ১১৩. দুটি সরলরেখা পরস্পর ছেদ করলে উৎপন্ন বিপ্রতীপ কোণগুলো (৫x - ১০)° এবং (৩x + ৩০)°। x এর মান কত?
A. ১০
B. ১৫
C. ২০
D. ২৫
উত্তর: C
ব্যাখ্যা:
বিপ্রতীপ কোণগুলো পরস্পর সমান।
৫x - ১০ = ৩x + ৩০
=> ২x = ৪০
=> x = ২০।


প্রশ্ন ১১৪. একটি সরলরেখা AB এর উপর C একটি বিন্দু। C বিন্দুতে CD রেখাংশ দণ্ডায়মান হওয়ায় দুটি সন্নিহিত কোণ ∠ACD ও ∠DCB উৎপন্ন হলো। যদি ∠ACD = ৩x এবং ∠DCB = ২x হয়, তবে x এর মান কত?
A. ১৮
B. ৩৬
C. ৫৪
D. ৭২
উত্তর: B
ব্যাখ্যা:
সরলরেখার উপর অবস্থিত দুটি সন্নিহিত কোণের সমষ্টি ১৮০°।
৩x + ২x = ১৮০°
=> ৫x = ১৮০°
=> x = ৩৬।


প্রশ্ন ১১৫. একটি ত্রিভুজের তিনটি কোণের অনুপাত ৩ : ৪ : ৫ হলে, ক্ষুদ্রতম কোণটির মান কত?
A. ৩০°
B. ৪৫°
C. ৬০°
D. ৭৫°
উত্তর: B
ব্যাখ্যা:
কোণগুলোর সমষ্টি = ১৮০°।
অনুপাতের সমষ্টি = ৩ + ৪ + ৫ = ১২।
ক্ষুদ্রতম কোণ = (৩ / ১২) × ১৮০° = ৪৫°।


প্রশ্ন ১১৬. একটি ত্রিভুজের যেকোনো দুই বাহুর সমষ্টি সর্বদা তৃতীয় বাহু অপেক্ষা—
A. ক্ষুদ্রতর
B. বৃহত্তর
C. সমান
D. দ্বিগুণ
উত্তর: B
ব্যাখ্যা:
ত্রিভুজ গঠনের মৌলিক শর্ত হলো, যেকোনো দুটি বাহুর দৈর্ঘ্যের যোগফল তৃতীয় বাহুর দৈর্ঘ্য অপেক্ষা বৃহত্তর হতে হবে।


প্রশ্ন ১১৭. একটি ত্রিভুজের যেকোনো দুই বাহুর অন্তর সর্বদা তৃতীয় বাহু অপেক্ষা—
A. ক্ষুদ্রতর
B. বৃহত্তর
C. সমান
D. অর্ধেক
উত্তর: A
ব্যাখ্যা:
ত্রিভুজের উপপাদ্য অনুযায়ী, যেকোনো দুটি বাহুর দৈর্ঘ্যের অন্তর (বিয়োগফল) তৃতীয় বাহুর দৈর্ঘ্য অপেক্ষা ক্ষুদ্রতর হয়।


প্রশ্ন ১১৮. একটি সমকোণী ত্রিভুজের কোণগুলোর অনুপাত নিচের কোনটি হতে পারে?
A. ১ : ২ : ৩
B. ২ : ৩ : ৪
C. ৩ : ৪ : ৫
D. ১ : ১ : ৩
উত্তর: A
ব্যাখ্যা:
সমকোণী ত্রিভুজের একটি কোণ ৯০°। বাকি দুটির সমষ্টি ৯০°।
A অপশনে: অনুপাতের সমষ্টি = ৬। বৃহত্তম কোণ = (৩/৬) × ১৮০° = ৯০°। এটি একটি সমকোণী ত্রিভুজ। (বি.দ্র. C অপশনের ৩:৪:৫ হলো বাহুর অনুপাত, কোণের নয়)।


প্রশ্ন ১১৯. একটি ত্রিভুজের বহিঃস্থ কোণ ১১০° এবং এর বিপরীত একটি অন্তঃস্থ কোণ ৪০° হলে, অপর অন্তঃস্থ কোণটি কত?
A. ৪০°
B. ৫০°
C. ৭০°
D. ৮০°
উত্তর: C
ব্যাখ্যা:
ত্রিভুজের বহিঃস্থ কোণ বিপরীত অন্তঃস্থ কোণদ্বয়ের সমষ্টির সমান।
ধরি, অপর কোণটি x।
x + ৪০° = ১১০°
=> x = ৭০°।


প্রশ্ন ১২০. একটি সমদ্বিবাহু ত্রিভুজের ভূমিসংলগ্ন একটি কোণ শীর্ষকোণের এক-চতুর্থাংশ। ভূমিসংলগ্ন কোণটির মান কত?
A. ১৫°
B. ৩০°
C. ৪৫°
D. ৬০°
উত্তর: B
ব্যাখ্যা:
ধরি, শীর্ষকোণ = ৪x। ভূমিসংলগ্ন কোণ = x এবং x (যেহেতু সমদ্বিবাহু ত্রিভুজ)।
x + x + ৪x = ১৮০°
=> ৬x = ১৮০°
=> x = ৩০°।
সুতরাং, ভূমিসংলগ্ন কোণটি ৩০°।


প্রশ্ন ১২১. একটি সমবাহু ত্রিভুজের ক্ষেত্রফল ১৬√৩ বর্গ মিটার হলে, এর পরিসীমা কত?
A. ১২ মিটার
B. ২৪ মিটার
C. ৩৬ মিটার
D. ৪৮ মিটার
উত্তর: B
ব্যাখ্যা:
সমবাহু ত্রিভুজের ক্ষেত্রফল = (√৩ / ৪)a² = ১৬√৩
=> a² / ৪ = ১৬
=> a² = ৬৪
=> a = ৮ মিটার।
পরিসীমা = ৩a = ৩ × ৮ = ২৪ মিটার।


প্রশ্ন ১২২. একটি ত্রিভুজের তিনটি বাহুর দৈর্ঘ্য যথাক্রমে ৫ সেমি, ৬ সেমি ও ৭ সেমি। ত্রিভুজটির ক্ষেত্রফল কত?
A. ৬√৬ বর্গ সেমি
B. ১০√৬ বর্গ সেমি
C. ১২ বর্গ সেমি
D. ১৪.৭ বর্গ সেমি
উত্তর: A
ব্যাখ্যা:
অর্ধপরিসীমা, s = (৫ + ৬ + ৭) / ২ = ১৮ / ২ = ৯।
ক্ষেত্রফল = √[s(s-a)(s-b)(s-c)]
= √[৯ × (৯-৫) × (৯-৬) × (৯-৭)]
= √(৯ × ৪ × ৩ × ২) = √২১৬ = ৬√৬ বর্গ সেমি।


প্রশ্ন ১২৩. একটি সমকোণী ত্রিভুজের অতিভুজ ১৩ সেমি এবং একটি বাহু ১২ সেমি। ত্রিভুজটির ক্ষেত্রফল কত?
A. ৩০ বর্গ সেমি
B. ৬০ বর্গ সেমি
C. ৭৮ বর্গ সেমি
D. ১৫৬ বর্গ সেমি
উত্তর: A
ব্যাখ্যা:
অপর বাহু (লম্ব বা ভূমি) = √(১৩² - ১২²) = √(১৬৯ - ১৪৪) = √২৫ = ৫ সেমি।
ক্ষেত্রফল = ১/২ × ৫ × ১২ = ৩০ বর্গ সেমি।


প্রশ্ন ১২৪. একটি ত্রিভুজের দুটি কোণ যথাক্রমে ৩৫° ও ৫৫°। ত্রিভুজটির পরিকেন্দ্র কোথায় অবস্থান করবে?
A. ত্রিভুজের অভ্যন্তরে
B. ত্রিভুজের বাইরে
C. অতিভুজের মধ্যবিন্দুতে
D. যেকোনো বাহুর উপর
উত্তর: C
ব্যাখ্যা:
কোণ দুটির সমষ্টি ৩৫° + ৫৫° = ৯০°। সুতরাং তৃতীয় কোণটি ৯০° এবং এটি একটি সমকোণী ত্রিভুজ। সমকোণী ত্রিভুজের পরিকেন্দ্র সর্বদা তার অতিভুজের মধ্যবিন্দুতে অবস্থান করে।


প্রশ্ন ১২৫. একটি সমদ্বিবাহু ত্রিভুজের অসমান বাহুর দৈর্ঘ্য ৬ সেমি এবং সমান বাহুদ্বয়ের প্রতিটির দৈর্ঘ্য ৫ সেমি হলে, ত্রিভুজটির ক্ষেত্রফল কত?
A. ১০ বর্গ সেমি
B. ১২ বর্গ সেমি
C. ২৪ বর্গ সেমি
D. ৪৮ বর্গ সেমি
উত্তর: B
ব্যাখ্যা:
উচ্চতা, h = √(৫² - (৬/২)²) = √(২৫ - ৯) = √১৬ = ৪ সেমি।
ক্ষেত্রফল = ১/২ × ভূমি × উচ্চতা = ১/২ × ৬ × ৪ = ১২ বর্গ সেমি।


প্রশ্ন ১২৬. কোনো ত্রিভুজের পরিসীমা ২৪ সেমি এবং অন্তর্বৃত্তের ব্যাসার্ধ ৩ সেমি। ত্রিভুজটির ক্ষেত্রফল কত?
A. ৩৬ বর্গ সেমি
B. ৭২ বর্গ সেমি
C. ৪৮ বর্গ সেমি
D. ৫৪ বর্গ সেমি
উত্তর: A
ব্যাখ্যা:
ত্রিভুজের ক্ষেত্রফলের সূত্র: Area = r × s (যেখানে r = অন্তর্ব্যাসার্ধ, s = অর্ধপরিসীমা)।
s = ২৪ / ২ = ১২ সেমি।
ক্ষেত্রফল = ৩ × ১২ = ৩৬ বর্গ সেমি।


প্রশ্ন ১২৭. একটি সমবাহু ত্রিভুজের পরিসীমা ১২ সেমি হলে, এর ক্ষেত্রফল কত?
A. ৩√৩ বর্গ সেমি
B. ৪√৩ বর্গ সেমি
C. ৬√৩ বর্গ সেমি
D. ১২√৩ বর্গ সেমি
উত্তর: B
ব্যাখ্যা:
বাহুর দৈর্ঘ্য a = ১২ / ৩ = ৪ সেমি।
ক্ষেত্রফল = (√৩ / ৪) × a² = (√৩ / ৪) × ১৬ = ৪√৩ বর্গ সেমি।


প্রশ্ন ১২৮. ত্রিভুজের অন্তঃকেন্দ্র (Incenter) থেকে ত্রিভুজের বাহুগুলোর লম্ব দূরত্বকে কী বলা হয়?
A. পরিব্যাসার্ধ
B. অন্তর্ব্যাসার্ধ
C. মধ্যমা
D. লম্ববিন্দু
উত্তর: B
ব্যাখ্যা:
ত্রিভুজের অন্তঃকেন্দ্র থেকে বাহুগুলোর লম্ব দূরত্ব সবসময় সমান হয় এবং একে অন্তর্ব্যাসার্ধ (Inradius) বলা হয়। এই ব্যাসার্ধ নিয়ে আঁকা বৃত্ত ত্রিভুজের তিনটি বাহুকে ভেতর থেকে স্পর্শ করে।


প্রশ্ন ১২৯. একটি সামান্তরিকের ভূমি ১২ সেমি এবং উচ্চতা ৮ সেমি। এর ক্ষেত্রফল কত?
A. ৪৮ বর্গ সেমি
B. ৭২ বর্গ সেমি
C. ৯৬ বর্গ সেমি
D. ১৯২ বর্গ সেমি
উত্তর: C
ব্যাখ্যা:
সামান্তরিকের ক্ষেত্রফল = ভূমি × উচ্চতা = ১২ × ৮ = ৯৬ বর্গ সেমি।


প্রশ্ন ১৩০. একটি রম্বসের কর্ণদ্বয় ১০ সেমি ও ২৪ সেমি হলে, এর পরিসীমা কত?
A. ৩৪ সেমি
B. ৫২ সেমি
C. ৬০ সেমি
D. ৬৮ সেমি
উত্তর: B
ব্যাখ্যা:
রম্বসের কর্ণদ্বয় সমকোণে সমদ্বিখণ্ডিত করে।
সমকোণী ত্রিভুজের লম্ব = ১০/২ = ৫ সেমি, ভূমি = ২৪/২ = ১২ সেমি।
বাহু (অতিভুজ) = √(৫² + ১২²) = √(২৫ + ১৪৪) = √১৬৯ = ১৩ সেমি।
পরিসীমা = ৪ × ১৩ = ৫২ সেমি।


প্রশ্ন ১৩১. একটি ট্রাপিজিয়ামের সমান্তরাল বাহু দুটির দৈর্ঘ্য যথাক্রমে ১০ সেমি ও ১৪ সেমি এবং এদের মধ্যবর্তী লম্ব দূরত্ব ৫ সেমি। ট্রাপিজিয়ামের ক্ষেত্রফল কত?
A. ৬০ বর্গ সেমি
B. ৭০ বর্গ সেমি
C. ১২০ বর্গ সেমি
D. ২৪০ বর্গ সেমি
উত্তর: A
ব্যাখ্যা:
ক্ষেত্রফল = ১/২ × (সমান্তরাল বাহুদ্বয়ের যোগফল) × লম্ব দূরত্ব
= ১/২ × (১০ + ১৪) × ৫ = ১/২ × ২৪ × ৫ = ৬০ বর্গ সেমি।


প্রশ্ন ১৩২. একটি আয়তক্ষেত্রের দৈর্ঘ্য ১০% বৃদ্ধি এবং প্রস্থ ১০% হ্রাস পেলে এর ক্ষেত্রফলের কী পরিবর্তন হবে?
A. কোনো পরিবর্তন হবে না
B. ১% বৃদ্ধি পাবে
C. ১% হ্রাস পাবে
D. ২% হ্রাস পাবে
উত্তর: C
ব্যাখ্যা:
Competitive Shortcut: একই হারে বৃদ্ধি ও হ্রাস পেলে সর্বদা হ্রাস পায় এবং তার মান = (x² / ১০০)%।
হ্রাস = (১০² / ১০০)% = ১০০ / ১০০ = ১% হ্রাস।


প্রশ্ন ১৩৩. একটি বর্গের কর্ণের দৈর্ঘ্য ৮ সেমি হলে, এর ক্ষেত্রফল কত?
A. ১৬ বর্গ সেমি
B. ৩২ বর্গ সেমি
C. ৬৪ বর্গ সেমি
D. ১২৮ বর্গ সেমি
উত্তর: B
ব্যাখ্যা:
বর্গের ক্ষেত্রফল = (কর্ণ)² / ২
= ৮² / ২ = ৬৪ / ২ = ৩২ বর্গ সেমি।


প্রশ্ন ১৩৪. একটি রম্বসের ক্ষেত্রফল ৪৮ বর্গ সেমি এবং একটি কর্ণের দৈর্ঘ্য ১২ সেমি হলে, অপর কর্ণটির দৈর্ঘ্য কত?
A. ৬ সেমি
B. ৮ সেমি
C. ১০ সেমি
D. ১৬ সেমি
উত্তর: B
ব্যাখ্যা:
ক্ষেত্রফল = ১/২ × d₁ × d₂
৪৮ = ১/২ × ১২ × d₂
=> ৪৮ = ৬ × d₂
=> d₂ = ৪৮ / ৬ = ৮ সেমি।


প্রশ্ন ১৩৫. কোনো চতুর্ভুজের চারটি কোণের অনুপাত ১ : ২ : ৩ : ৪ হলে, বৃহত্তম কোণটির মান কত?
A. ৭২°
B. ১০৮°
C. ১৪৪°
D. ২১৬°
উত্তর: C
ব্যাখ্যা:
চতুর্ভুজের চার কোণের সমষ্টি ৩৬০°।
অনুপাতের সমষ্টি = ১ + ২ + ৩ + ৪ = ১০।
বৃহত্তম কোণ = (৪ / ১০) × ৩৬০° = ১৪৪°।


প্রশ্ন ১৩৬. সামান্তরিকের কর্ণদ্বয় পরস্পরকে সমকোণে সমদ্বিখণ্ডিত করলে তাকে কী বলে?

C. কাইট
D. আয়তক্ষেত্র

যে সামান্তরিকের কর্ণদ্বয় পরস্পরকে সমকোণে সমদ্বিখণ্ডিত করে, তাকে রম্বস বলে (বর্গও এক প্রকার রম্বস)।


প্রশ্ন ১৩৭. আয়তক্ষেত্রের কর্ণদ্বয়—
A. অসমান ও সমকোণে ছেদ করে

আয়তক্ষেত্রের কর্ণ দুটি দৈর্ঘ্যে সমান হয় এবং তারা পরস্পরকে সমদ্বিখণ্ডিত করে, কিন্তু সমকোণে ছেদ করে না।


প্রশ্ন ১৩৮. বৃত্তস্থ সামান্তরিক সর্বদা একটি—

ব্যাখ্যা:
বৃত্তস্থ চতুর্ভুজের বিপরীত কোণগুলোর সমষ্টি ১৮০°। সামান্তরিকের বিপরীত কোণগুলো সমান হয়।
তাই x + x = ১৮০° => ২x = ১৮০° => x = ৯০°।
যে সামান্তরিকের প্রতিটি কোণ ৯০°, তা একটি আয়তক্ষেত্র।


প্রশ্ন ১৩৯. বৃত্তস্থ রম্বস সর্বদা একটি—

ব্যাখ্যা:
বৃত্তস্থ রম্বসের প্রতিটি কোণ ৯০° হতে হয় (বৃত্তস্থ সামান্তরিকের নিয়মে)। আর যে রম্বসের প্রতিটি কোণ ৯০°, সেটি একটি বর্গ।


প্রশ্ন ১৪০. একটি আয়তক্ষেত্রের পরিসীমা ৪০ মিটার। এর দৈর্ঘ্য প্রস্থের ৩ গুণ হলে, ক্ষেত্রফল কত?
A. ৭৫ বর্গ মিটার
B. ১০০ বর্গ মিটার
C. ১৫০ বর্গ মিটার
D. ৩০০ বর্গ মিটার
উত্তর: A
ব্যাখ্যা:
ধরি, প্রস্থ = x, দৈর্ঘ্য = ৩x।
পরিসীমা = ২(৩x + x) = ৪০
=> ৮x = ৪০ => x = ৫।
প্রস্থ = ৫ মি, দৈর্ঘ্য = ১৫ মি।
ক্ষেত্রফল = ১৫ × ৫ = ৭৫ বর্গ মিটার।


প্রশ্ন ১৪১. একটি কাইটের (Kite) কর্ণদ্বয় ১০ সেমি এবং ১২ সেমি। কাইটটির ক্ষেত্রফল কত?
A. ৩০ বর্গ সেমি
B. ৬০ বর্গ সেমি
C. ১২০ বর্গ সেমি
D. ২৪০ বর্গ সেমি
উত্তর: B
ব্যাখ্যা:
কাইটের কর্ণদ্বয় পরস্পর লম্ব হওয়ায় এর ক্ষেত্রফল রম্বসের মতো নির্ণয় করা যায়।
ক্ষেত্রফল = ১/২ × কর্ণদ্বয়ের গুণফল = ১/২ × ১০ × ১২ = ৬০ বর্গ সেমি।


প্রশ্ন ১৪২. একটি আয়তক্ষেত্রের দৈর্ঘ্য ১২ সেমি এবং কর্ণের দৈর্ঘ্য ১৫ সেমি হলে, প্রস্থ কত?
A. ৮ সেমি
B. ৯ সেমি
C. ১০ সেমি
D. ১১ সেমি
উত্তর: B
ব্যাখ্যা:
পিথাগোরাসের সূত্রানুযায়ী, প্রস্থ = √(কর্ণ² - দৈর্ঘ্য²)
= √(১৫² - ১২²) = √(২২৫ - ১৪৪) = √৮১ = ৯ সেমি।


প্রশ্ন ১৪৩. নিচের কোনটি পিথাগোরীয় ট্রিপলেট (Pythagorean triplet) নয়?
A. ৩, ৪, ৫
B. ৫, ১২, ১৩
C. ৭, ২৪, ২৫
D. ৮, ১৫, ১৯
উত্তর: D
ব্যাখ্যা:
৮² + ১৫² = ৬৪ + ২২৫ = ২৮৯ = ১৭²।
কিন্তু অপশনে ১৯ দেওয়া আছে, তাই D পিথাগোরীয় ট্রিপলেট নয়।


প্রশ্ন ১৪৪. একটি মই ২০ মিটার দীর্ঘ, যা একটি দেয়ালের সাথে ঠেস দিয়ে রাখা আছে। মইটির গোড়া দেয়াল থেকে ১২ মিটার দূরে থাকলে, মইটি দেয়ালের কত উচ্চতায় স্পর্শ করবে?
A. ১৪ মিটার
B. ১৫ মিটার
C. ১৬ মিটার
D. ১৮ মিটার
উত্তর: C
ব্যাখ্যা:
উচ্চতা (লম্ব) = √(২০² - ১২²) = √(৪০০ - ১৪৪) = √২৫৬ = ১৬ মিটার।


প্রশ্ন ১৪৫. (০,০) বিন্দু থেকে (৬,৮) বিন্দুর সোজাসুজি দূরত্ব কত?
A. ১০
B. ১২
C. ১৪
D. ১০০
উত্তর: A
ব্যাখ্যা:
দূরত্ব = √((৬ - ০)² + (৮ - ০)²) = √(৩৬ + ৬৪) = √১০০ = ১০।


প্রশ্ন ১৪৬. একজন ব্যক্তি প্রথমে ৫ কিমি উত্তর দিকে, এরপর ১২ কিমি পূর্ব দিকে গেল। যাত্রাস্থান থেকে তার বর্তমান সোজাসুজি দূরত্ব কত?
A. ১৩ কিমি
B. ১৫ কিমি
C. ১৭ কিমি
D. ৬০ কিমি
উত্তর: A
ব্যাখ্যা:
পিথাগোরাসের সূত্রমতে, দূরত্ব = √(৫² + ১২²) = √(২৫ + ১৪৪) = √১৬৯ = ১৩ কিমি।


প্রশ্ন ۱۴৭. সমকোণী সমদ্বিবাহু ত্রিভুজের অতিভুজের দৈর্ঘ্য ১০ সেমি হলে, এর ক্ষেত্রফল কত?
A. ২৫ বর্গ সেমি
B. ৫০ বর্গ সেমি
C. ৭৫ বর্গ সেমি
D. ১০০ বর্গ সেমি
উত্তর: A
ব্যাখ্যা:
ধরি, সমান বাহু দুটি a। a² + a² = ১০² => ২a² = ১০০ => a² = ৫০।
ক্ষেত্রফল = ১/২ × ভূমি × লম্ব = ১/২ × a × a = ১/২ × a² = ১/২ × ৫০ = ২৫ বর্গ সেমি।


প্রশ্ন ১৪৮. একটি সমকোণী ত্রিভুজের পরিসীমা ৩০ সেমি এবং অতিভুজ ১৩ সেমি হলে, ত্রিভুজটির ক্ষেত্রফল কত?

প্রশ্ন ১৬১. একটি বৃত্তের পরিধি ও একটি বর্গের পরিসীমা সমান হলে, বৃত্তের ক্ষেত্রফল ও বর্গের ক্ষেত্রফলের অনুপাত কত? (π = ২২/৭)

অর্ধবৃত্তের ক্ষেত্রফল = ১/২ × πr²
= ১/২ × (২২/৭) × ১৪²
= ১/২ × (২২/৭) × ১৯৬
= ১/২ × ৬১৬ = ৩০৮ বর্গ সেমি।


প্রশ্ন ১৬৯. একটি সমকোণী ত্রিভুজ একটি বৃত্তে অন্তর্লিখিত (Inscribed)। ত্রিভুজটির অতিভুজ বৃত্তের কী হবে?
A. ব্যাসার্ধ
B. ব্যাস
C. স্পর্শক
D. সাধারণ জ্যা
উত্তর: B
ব্যাখ্যা:
উপপাদ্য: অর্ধবৃত্তস্থ কোণ এক সমকোণ। যেহেতু ত্রিভুজটি সমকোণী এবং বৃত্তে অন্তর্লিখিত, তাই এর অতিভুজ অবশ্যই বৃত্তের কেন্দ্র দিয়ে যাবে এবং এটি বৃত্তের ব্যাস হবে।


প্রশ্ন ১৭০. একটি বৃত্তে অন্তর্লিখিত সমকোণী ত্রিভুজের সমকোণ সংলগ্ন বাহুদ্বয় ৬ সেমি এবং ৮ সেমি হলে, বৃত্তটির ব্যাসার্ধ কত?
A. ৩ সেমি
B. ৪ সেমি
C. ৫ সেমি
D. ১০ সেমি
উত্তর: C
ব্যাখ্যা:
ত্রিভুজের অতিভুজ = √(৬² + ৮²) = √(৩৬ + ৬৪) = √১০০ = ১০ সেমি।
অন্তর্লিখিত সমকোণী ত্রিভুজের অতিভুজই বৃত্তের ব্যাস।
ব্যাস = ১০ সেমি, সুতরাং ব্যাসার্ধ = ১০ / ২ = ৫ সেমি।


প্রশ্ন ১৭১. একটি সুষম ষড়ভুজের (Regular Hexagon) বাহুর দৈর্ঘ্য a হলে, এর ক্ষেত্রফল কত?
A. (৩√৩/২)a²
B. (√৩/৪)a²
C. ৩√৩ a²
D. ৬a²
উত্তর: A
ব্যাখ্যা:
একটি সুষম ষড়ভুজ ৬টি সমবাহু ত্রিভুজে বিভক্ত হয়।
ক্ষেত্রফল = ৬ × (√৩ / ৪)a² = (৩√৩ / ২)a²।


প্রশ্ন ১৭২. একটি সমবাহু ত্রিভুজের ক্ষেত্রফল এবং তার অন্তর্বৃত্তের ক্ষেত্রফলের অনুপাত কত?
A. ৩√৩ : π
B. ৪√৩ : π
C. π : ৩√৩
D. π : ৪√৩
উত্তর: A
ব্যাখ্যা:
সমবাহু ত্রিভুজের বাহু a হলে ক্ষেত্রফল = (√৩/৪)a²।
অন্তর্ব্যাসার্ধ r = a / (২√৩)।
অন্তর্বৃত্তের ক্ষেত্রফল = π(a / ২√৩)² = πa² / ১২।
অনুপাত = (√৩/৪)a² : (πa²/১২) = √৩/৪ : π/১২ = ৩√৩ : π।


প্রশ্ন ১৭৩. একটি বৃত্তের ব্যাসার্ধ ২০% হ্রাস পেলে এর ক্ষেত্রফল কত শতাংশ হ্রাস পাবে?
A. ২০%
B. ৩৬%
C. ৪০%
D. ৪৪%
উত্তর: B
ব্যাখ্যা:
Shortcut: ক্ষেত্রফল হ্রাসের হার = ২x - (x²/১০০)
= ২(২০) - (৪০০/১০০) = ৪০ - ৪ = ৩৬%।


প্রশ্ন ১৭৪. একটি বর্গক্ষেত্রের বাহুর দৈর্ঘ্য এবং এর পরিবৃত্তের ব্যাসার্ধের অনুপাত কত?
A. ১ : √২
B. √২ : ১
C. ২ : √২
D. ১ : ২
উত্তর: B
ব্যাখ্যা:
বর্গের বাহু = a। বর্গের কর্ণ = a√২।
পরিবৃত্তের ব্যাস হলো বর্গের কর্ণ। তাই পরিব্যাসার্ধ = a√২ / ২ = a / √২।
বাহু ও ব্যাসার্ধের অনুপাত = a : (a/√২) = ১ : ১/√২ = √২ : ১।


প্রশ্ন ১৭৫. একটি চাকার ব্যাস ২.১ মিটার। চাকাটি ৩৩০ মিটার পথ অতিক্রম করতে কতবার ঘুরবে? (π = ২২/৭)
A. ২৫ বার
B. ৪০ বার
C. ৫০ বার
D. ৭৫ বার
উত্তর: C
ব্যাখ্যা:
চাকার পরিধি = πd = (২২/৭) × ২.১ = ৬.৬ মিটার।
একবার ঘুরলে ৬.৬ মিটার যায়।
মোট ঘূর্ণন সংখ্যা = মোট দূরত্ব / পরিধি = ৩৩০ / ৬.৬ = ৩৩০ / (৬৬/১০) = ৩৩০০ / ৬৬ = ৫০ বার।


প্রশ্ন ১৭৬. কোনো ত্রিভুজের তিনটি বাহু ৫, ১২ এবং ১৩ হলে, এর বৃহত্তম কোণটি কত?
A. ৬০°
B. ৯০°
C. ১২০°
D. ১৮০°
উত্তর: B
ব্যাখ্যা:
৫² + ১২² = ২৫ + ১৪৪ = ১৬৯ = ১৩²।
এটি পিথাগোরাসের সূত্র মেনে চলে, তাই এটি সমকোণী ত্রিভুজ। সমকোণী ত্রিভুজের বৃহত্তম কোণ ৯০°।


প্রশ্ন ১৭৭. একটি আয়তক্ষেত্রের ক্ষেত্রফল ১৯২ বর্গ সেমি এবং পরিসীমা ৫৬ সেমি হলে, এর কর্ণ কত?
A. ২০ সেমি
B. ২২ সেমি
C. ২৪ সেমি
D. ২৮ সেমি
উত্তর: A
ব্যাখ্যা:
ধরি, দৈর্ঘ্য = l, প্রস্থ = b।
২(l + b) = ৫৬ => l + b = ২৮।
lb = ১৯২।
কর্ণ = √(l² + b²) = √((l + b)² - ২lb)
= √(২৮² - ২ × ১৯২) = √(৭৮৪ - ৩৮৪) = √৪০০ = ২০ সেমি।


প্রশ্ন ১৭৮. দুটি ত্রিভুজ সদৃশ (Similar) হওয়ার জন্য নিচের কোন শর্তটি যথেষ্ট?
A. তাদের ক্ষেত্রফল সমান
B. তাদের পরিসীমা সমান
C. তাদের অনুরূপ কোণগুলো সমান
D. তাদের একটি বাহু সমান
উত্তর: C
ব্যাখ্যা:
সদৃশকোণী ত্রিভুজ সর্বদা সদৃশ (Similar) হয়। তাই অনুরূপ কোণগুলো সমান হওয়াই সদৃশ হওয়ার জন্য যথেষ্ট শর্ত (AAA Similarity)।


প্রশ্ন ১৭৯. একটি সমকোণী ত্রিভুজের সমকোণ সংলগ্ন বাহুদ্বয়ের দৈর্ঘ্য ৫ সেমি ও ১২ সেমি। অতিভুজের উপর অঙ্কিত লম্বের দৈর্ঘ্য কত?
A. ৪.৬ সেমি
B. ২.৪ সেমি
C. ৩.৬ সেমি
D. ৪.৬১ সেমি (প্রায়)
উত্তর: D
ব্যাখ্যা:
অতিভুজ = √(৫² + ১২²) = ১৩ সেমি।
সমকোণিক বিন্দু থেকে অতিভুজের উপর লম্ব (h) = (ভূমি × লম্ব) / অতিভুজ
h = (৫ × ১২) / ১৩ = ৬০ / ১৩ = ৪.৬১৫... সেমি।


প্রশ্ন ১৮০. একটি রম্বসের একটি কর্ণ অপরটির দ্বিগুণ। রম্বসের ক্ষেত্রফল ৩৬ বর্গ সেমি হলে, বৃহত্তর কর্ণটি কত?
A. ৬ সেমি
B. ৯ সেমি
C. ১২ সেমি
D. ১৮ সেমি
উত্তর: C
ব্যাখ্যা:
ধরি, ছোট কর্ণ x। বড় কর্ণ ২x।
ক্ষেত্রফল = ১/২ × x × ২x = x²।
x² = ৩৬ => x = ৬ সেমি।
বৃহত্তর কর্ণ = ২ × ৬ = ১২ সেমি।


প্রশ্ন ১৮১. একই সরলরেখায় অবস্থিত নয় এমন তিনটি বিন্দু দিয়ে কয়টি বৃত্ত আঁকা যায়?
A. ১টি
B. ২টি
C. ৩টি
D. অসংখ্য
উত্তর: A
ব্যাখ্যা:
জ্যামিতিক উপপাদ্য: সমরেখ নয় এমন তিনটি বিন্দু দিয়ে কেবল একটি এবং একটিমাত্র বৃত্ত অঙ্কন করা সম্ভব।


প্রশ্ন ১৮২. বৃত্তের কোনো জ্যা যদি বৃত্তের কেন্দ্রে সমকোণ উৎপন্ন করে, তবে ওই জ্যা এবং ব্যাসার্ধের অনুপাত কত?
A. ১ : ১
B. √২ : ১
C. ১ : √২
D. ২ : ১
উত্তর: B
ব্যাখ্যা:
কেন্দ্র থেকে জ্যা-এর দুই প্রান্ত যোগ করলে একটি সমকোণী সমদ্বিবাহু ত্রিভুজ তৈরি হয়, যার সমান বাহু দুটি হলো ব্যাসার্ধ (r)।
পিথাগোরাসের সূত্রানুযায়ী, জ্যা² = r² + r² = ২r² => জ্যা = r√২।
জ্যা : ব্যাসার্ধ = r√২ : r = √২ : ১।


প্রশ্ন ১৮৩. একটি সমকোণী ত্রিভুজের অতিভুজের দৈর্ঘ্য ১০ সেমি। এর পরিবৃত্তের ক্ষেত্রফল কত?
A. ১০π বর্গ সেমি
B. ২০π বর্গ সেমি
C. ২৫π বর্গ সেমি
D. ১০০π বর্গ সেমি
উত্তর: C
ব্যাখ্যা:
সমকোণী ত্রিভুজের অতিভুজই হলো তার পরিবৃত্তের ব্যাস।
ব্যাস = ১০ সেমি => পরিব্যাসার্ধ r = ৫ সেমি।
ক্ষেত্রফল = πr² = π(৫²) = ২৫π বর্গ সেমি।


প্রশ্ন ১৮৪. একটি বৃত্তের দুটি জ্যা AB এবং AC পরস্পর লম্ব। AB = ৬ সেমি এবং AC = ৮ সেমি হলে, বৃত্তটির ব্যাসার্ধ কত?
A. ৪ সেমি
B. ৫ সেমি
C. ৭ সেমি
D. ১০ সেমি
উত্তর: B
ব্যাখ্যা:
যেহেতু জ্যা দুটি লম্ব, A বিন্দুতে সমকোণ উৎপন্ন হয়েছে।
তাহলে BC হলো সমকোণী ত্রিভুজ ABC এর অতিভুজ এবং একইসাথে বৃত্তের ব্যাস (কারণ অর্ধবৃত্তস্থ কোণ এক সমকোণ)।
BC = √(৬² + ৮²) = ১০ সেমি।
ব্যাসার্ধ = ১০ / ২ = ৫ সেমি।


প্রশ্ন ১৮৫. একটি বৃত্তের দুটি সমান জ্যা পরস্পরকে ছেদ করলে, একটির অংশদ্বয় অপরটির অংশদ্বয়ের—
A. সমানুপাতিক
B. অর্ধেক
C. সমান
D. দ্বিগুণ
উত্তর: C
ব্যাখ্যা:
উপপাদ্য: বৃত্তের দুটি সমান জ্যা পরস্পরকে ছেদ করলে তাদের একটির অংশদ্বয় অপরটির সংশ্লিষ্ট অংশদ্বয়ের সমান হয়।


প্রশ্ন ১৮৬. বৃত্তের কোনো বিন্দুতে স্পর্শক এবং ওই বিন্দুগামী জ্যা-এর মধ্যবর্তী কোণ—
A. সর্বদা সমকোণ
B. সর্বদা সূক্ষ্মকোণ
C. ওই জ্যা দ্বারা ছিন্ন একান্তর চাপের ওপর অবস্থিত যেকোনো বৃত্তস্থ কোণের সমান
D. কেন্দ্রস্থ কোণের সমান
উত্তর: C
ব্যাখ্যা:
উপপাদ্য (Alternate Segment Theorem): বৃত্তের কোনো বিন্দুতে একটি স্পর্শক ও একটি জ্যা যে কোণ উৎপন্ন করে, তা একান্তর বৃত্তাংশস্থিত যেকোনো কোণের সমান।


প্রশ্ন ১৮৭. যদি দুটি বৃত্তের ব্যাসার্ধ যথাক্রমে ৪ সেমি ও ৩ সেমি হয় এবং তাদের কেন্দ্রদ্বয়ের দূরত্ব ১০ সেমি হয়, তবে তাদের মধ্যে কয়টি সাধারণ স্পর্শক আঁকা যাবে?
A. ১টি
B. ২টি
C. ৩টি
D. ৪টি
উত্তর: D
ব্যাখ্যা:
ব্যাসার্ধের যোগফল = ৪ + ৩ = ৭ সেমি।
কেন্দ্রদ্বয়ের দূরত্ব (১০) > ব্যাসার্ধের যোগফল (৭)। এর অর্থ বৃত্ত দুটি পরস্পরকে ছেদ বা স্পর্শ করেনি, দূরে অবস্থিত।
এক্ষেত্রে ৪টি সাধারণ স্পর্শক (২টি সরল, ২টি তীর্যক) আঁকা সম্ভব।


প্রশ্ন ১৮৮. একটি ট্রাপিজিয়ামের সমান্তরাল বাহুদ্বয়ের দৈর্ঘ্য ১২ সেমি ও ৮ সেমি এবং উচ্চতা ৫ সেমি। একে সমান ক্ষেত্রফলবিশিষ্ট একটি আয়তক্ষেত্রে রূপান্তর করলে, ওই আয়তক্ষেত্রের একটি বাহু ৫ সেমি হলে অপর বাহু কত?
A. ৮ সেমি
B. ১০ সেমি
C. ১২ সেমি
D. ২০ সেমি
উত্তর: B
ব্যাখ্যা:
ট্রাপিজিয়ামের ক্ষেত্রফল = ১/২ × (১২ + ৮) × ৫ = ১/২ × ২০ × ৫ = ৫০ বর্গ সেমি।
আয়তক্ষেত্রের ক্ষেত্রফল = দৈর্ঘ্য × ৫ = ৫০
=> দৈর্ঘ্য = ১০ সেমি।


প্রশ্ন ১৮৯. একটি বর্গের বাহুর দৈর্ঘ্য ১০% বৃদ্ধি পেলে, এর পরিসীমা কত শতাংশ বৃদ্ধি পাবে?
A. ১০%
B. ২০%
C. ২১%
D. ১০০%
উত্তর: A
ব্যাখ্যা:
বর্গের পরিসীমা (৪a) বাহুর সমানুপাতিক। বাহু ১০% বাড়লে পরিসীমাও ১০% বাড়বে। (ক্ষেত্রফল বাড়ত ২১%)।


প্রশ্ন ১৯০. একটি বৃত্তের পরিধি ১০০π হলে, বৃত্তটির অন্তর্লিখিত সর্বোচ্চ ক্ষেত্রফলবিশিষ্ট বর্গের ক্ষেত্রফল কত?
A. ১২৫০
B. ২৫০০
C. ৫০০০
D. ১০০০০
উত্তর: C
ব্যাখ্যা:
পরিধি ২πr = ১০০π => r = ৫০।
অন্তর্লিখিত সবচেয়ে বড় বর্গের কর্ণ হবে বৃত্তের ব্যাস (২r = ১০০)।
বর্গের ক্ষেত্রফল = (কর্ণ)² / ২ = ১০০² / ২ = ১০০০০ / ২ = ৫০০০।


প্রশ্ন ১৯১. একটি ঘড়িতে যখন ৫টা বাজে, তখন ঘণ্টা ও মিনিটের কাঁটার মধ্যবর্তী কোণ কত?
A. ১২০°
B. ১৩৫°
C. ১৫০°
D. ১৮০°
উত্তর: C
ব্যাখ্যা:
ঘড়ির ডায়ালে ১২টি ঘরের মোট কোণ ৩৬০°। প্রতি ঘরের ব্যবধান ৩০°।
৫টায় কাঁটা দুটি ৫ ঘর দূরে থাকে।
কোণ = ৫ × ৩০° = ১৫০°।


প্রশ্ন ১৯২. একটি সুষম অষ্টভুজের (Octagon) প্রতিটি অন্তঃস্থ কোণ কত ডিগ্রি?
A. ১২০°
B. ১৩৫°
C. ১৪০°
D. ১৫০°
উত্তর: B
ব্যাখ্যা:
বহিঃস্থ কোণ = ৩৬০° / ৮ = ৪৫°।
অন্তঃস্থ কোণ = ১৮০° - ৪৫° = ১৩৫°।


প্রশ্ন ১৯৩. কোনো ত্রিভুজের মধ্যমাত্রয় পরস্পর সমান হলে, ত্রিভুজটি কী ধরনের?
A. সমকোণী
B. সমদ্বিবাহু
C. সমবাহু
D. স্থূলকোণী
উত্তর: C
ব্যাখ্যা:
যে ত্রিভুজের তিনটি মধ্যমা পরস্পর সমান, তা সর্বদা একটি সমবাহু ত্রিভুজ।


প্রশ্ন ১৯৪. একটি রম্বসের পরিসীমা ২০ সেমি এবং একটি কর্ণ ৮ সেমি হলে, এর ক্ষেত্রফল কত?
A. ১২ বর্গ সেমি
B. ২৪ বর্গ সেমি
C. ৩৬ বর্গ সেমি
D. ৪৮ বর্গ সেমি
উত্তর: B
ব্যাখ্যা:
পরিসীমা ৪a = ২০ => a = ৫ সেমি।
রম্বসের কর্ণদ্বয় সমকোণে সমদ্বিখণ্ডিত করে।
একটি সমকোণী ত্রিভুজ গঠিত হয় যার অতিভুজ = ৫, লম্ব (অর্ধেক কর্ণ) = ৪।
ভূমি (অপর কর্ণের অর্ধেক) = √(৫² - ৪²) = √৯ = ৩ সেমি।
অপর কর্ণ = ৩ × ২ = ৬ সেমি।
ক্ষেত্রফল = ১/২ × ৮ × ৬ = ২৪ বর্গ সেমি।


প্রশ্ন ১৯৫. দুটি সদৃশ ত্রিভুজের অনুরূপ বাহুগুলোর অনুপাত ৩ : ৪ হলে, তাদের ক্ষেত্রফলের অনুপাত কত?
A. ৩ : ৪
B. √৩ : ২
C. ৬ : ৮
D. ৯ : ১৬
উত্তর: D
ব্যাখ্যা:
সদৃশ ত্রিভুজের ক্ষেত্রফলের অনুপাত তাদের অনুরূপ বাহুগুলোর বর্গের অনুপাতের সমান।
ক্ষেত্রফলের অনুপাত = ৩² : ৪² = ৯ : ১৬।


প্রশ্ন ১৯৬. একটি ত্রিভুজের লম্ববিন্দু (Orthocenter), ভরকেন্দ্র (Centroid) এবং পরিকেন্দ্র (Circumcenter) একই সরলরেখায় অবস্থান করে। এই রেখাকে কী বলা হয়?
A. অয়লার রেখা (Euler Line)
B. সিভিয়ান (Cevian)
C. প্যাস্কেল রেখা
D. সিম্পসন রেখা
উত্তর: A
ব্যাখ্যা:
যেকোনো ত্রিভুজের (সমবাহু ব্যতীত, যেখানে সব বিন্দু একই) লম্ববিন্দু, ভরকেন্দ্র এবং পরিকেন্দ্র একটি সরলরেখায় অবস্থান করে, যাকে অয়লার রেখা বলা হয়।


প্রশ্ন ১৯৭. একটি বৃত্তের ব্যাসার্ধ r। কেন্দ্র থেকে r/২ দূরত্বে অবস্থিত জ্যা-এর দৈর্ঘ্য কত?
A. r√২
B. r√৩
C. ২r/√৩
D. r
উত্তর: B
ব্যাখ্যা:
পিথাগোরাসের সূত্র: (জ্যা/২)² + (r/২)² = r²
=> (জ্যা/২)² = r² - r²/৪ = ৩r²/৪
=> জ্যা/২ = (r√৩) / ২
=> জ্যা = r√৩।


প্রশ্ন ১৯৮. একটি বৃত্তের ব্যাসার্ধ ও পরিধির অনুপাত কত?
A. ১ : π
B. ১ : ২π
C. ২π : ১
D. π : ১
উত্তর: B
ব্যাখ্যা:
ব্যাসার্ধ = r, পরিধি = ২πr।
অনুপাত = r : ২πr = ১ : ২π।


প্রশ্ন ১৯৯. পিথাগোরাসের উপপাদ্যের বিপরীত উপপাদ্যটি কী প্রমাণ করে?
A. অতিভুজের বর্গ সমান লম্ব ও ভূমির বর্গের সমষ্টি
B. যদি কোনো ত্রিভুজের এক বাহুর উপর অঙ্কিত বর্গক্ষেত্র অপর দুই বাহুর উপর অঙ্কিত বর্গক্ষেত্রদ্বয়ের সমষ্টির সমান হয়, তবে শেষোক্ত বাহুদ্বয়ের অন্তর্ভুক্ত কোণটি সমকোণ হবে
C. সমকোণী ত্রিভুজের ক্ষেত্রফল
D. মধ্যমার দৈর্ঘ্য
উত্তর: B
ব্যাখ্যা:
বিপরীত উপপাদ্যটি প্রমাণ করে যে, a² + b² = c² শর্ত পূরণ হলে ত্রিভুজটি অবশ্যই সমকোণী হবে।


প্রশ্ন ২০০. একটি আয়তাকার ঘরের মেঝের দৈর্ঘ্য এর প্রস্থের দ্বিগুণ। ঘরটির মেঝে কার্পেট দিয়ে ঢাকতে ৭২০০ টাকা খরচ হয়। প্রতি বর্গমিটারে ২৫ টাকা খরচ হলে, ঘরটির দৈর্ঘ্য কত?
A. ১২ মিটার
B. ২৪ মিটার
C. ৩৬ মিটার
D. ৪৮ মিটার
উত্তর: B
ব্যাখ্যা:
মেঝের মোট ক্ষেত্রফল = মোট খরচ / প্রতি বর্গমিটারে খরচ = ৭২০০ / ২৫ = ২৮৮ বর্গমিটার।
ধরি, প্রস্থ = x, দৈর্ঘ্য = ২x।
ক্ষেত্রফল = ২x² = ২৮৮
=> x² = ১৪৪
=> x = ১২ (প্রস্থ)।
দৈর্ঘ্য = ২ × ১২ = ২৪ মিটার।




প্রশ্ন ২০১. একটি কোণের মান তার সম্পূরক কোণের অর্ধেকের চেয়ে ৩০° কম। কোণটির মান কত?
A. ১০°
B. ২০°
C. ৩০°
D. ৪০°
উত্তর: D
ব্যাখ্যা:
ধরি, কোণটি x। সম্পূরক কোণ (১৮০° - x)।
শর্তমতে, x = (১৮০° - x)/২ - ৩০°
=> ২x = ১৮০° - x - ৬০°
=> ৩x = ১২০° => x = ৪০°।


প্রশ্ন ২০২. ৯০° কোণের সম্পূরক কোণ এবং পূরক কোণের পার্থক্য কত?
A. ৪৫°
B. ৯০°
C. ১৩৫°
D. ১৮০°
উত্তর: B
ব্যাখ্যা:
৯০° এর সম্পূরক কোণ = ১৮০° - ৯০° = ৯০°।
৯০° এর পূরক কোণ = ৯০° - ৯০° = ০°।
পার্থক্য = ৯০° - ০° = ৯০°।


প্রশ্ন ২০৩. দুটি সরলরেখা পরস্পর ছেদ করলে যে চারটি কোণ উৎপন্ন হয়, তাদের মধ্যে যেকোনো দুটি সন্নিহিত কোণের অনুপাত ৪ : ৫ হলে, ক্ষুদ্রতম কোণটির মান কত?
A. ৪০°
B. ৬০°
C. ৮০°
D. ১০০°
উত্তর: C
ব্যাখ্যা:
সন্নিহিত কোণের সমষ্টি ১৮০°।
৪x + ৫x = ১৮০° => ৯x = ১৮০° => x = ২০°।
ক্ষুদ্রতম কোণ = ৪ × ২০° = ৮০°।


প্রশ্ন ২০৪. ঘড়ির কাঁটায় ৯টা ১৫ মিনিট বাজলে ঘণ্টা ও মিনিটের কাঁটার মধ্যবর্তী কোণ কত?
A. ১৬০.৫°
B. ১৬৫°
C. ১৭২.৫°
D. ১৮০°
উত্তর: C
ব্যাখ্যা:
কোণ = |(১১ × ১৫ - ৬০ × ৯) / ২| = |(১৬৫ - ৫৪০) / ২| = |-৩৭৫ / ২| = ১৮৭.৫°।
যেহেতু এটি ১৮০° এর বড়, তাই ক্ষুদ্রতম কোণ = ৩৬০° - ১৮৭.৫° = ১৭২.৫°।


প্রশ্ন ২০৫. একটি সুষম বহুভুজের অন্তঃস্থ কোণ ও বহিঃস্থ কোণের অনুপাত ৩ : ১ হলে, বহুভুজটির বাহুর সংখ্যা কত?
A. ৬
B. ৮
C. ১০
D. ১২
উত্তর: B
ব্যাখ্যা:
অন্তঃস্থ + বহিঃস্থ = ১৮০°।
৩x + x = ১৮০° => ৪x = ১৮০° => x = ৪৫° (বহিঃস্থ কোণ)।
বাহুর সংখ্যা n = ৩৬০° / ৪৫° = ৮।


প্রশ্ন ২০৬. দুটি সমান্তরাল রেখাকে একটি ছেদক ছেদ করলে, অনুরূপ কোণগুলোর সম্পর্ক কী?

D. অসম

ব্যাখ্যা:
জ্যামিতিক উপপাদ্য অনুযায়ী, সমান্তরাল রেখাকে ছেদ করলে উৎপন্ন অনুরূপ কোণগুলো পরস্পর সমান হয়।


প্রশ্ন ২০৭. একটি ত্রিভুজের কোণগুলোর অনুপাত ১ : ২ : ৩। ত্রিভুজটি কী ধরনের?
A. সমবাহু
B. সমদ্বিবাহু
C. সমকোণী
D. স্থূলকোণী
উত্তর: C
ব্যাখ্যা:
১x + ২x + ৩x = ১৮০° => ৬x = ১৮০° => x = ৩০°।
কোণগুলো: ৩০°, ৬০°, ৯০°। একটি কোণ ৯০° হওয়ায় এটি সমকোণী ত্রিভুজ।


প্রশ্ন ২০৮. একটি সমদ্বিবাহু ত্রিভুজের শীর্ষকোণ ১২০°। এর সমান সমান বাহুদ্বয়ের বিপরীত কোণগুলোর প্রত্যেকটি কত ডিগ্রি?
A. ৩০°
B. ৪৫°
C. ৬০°
D. ৭৫°
উত্তর: A
ব্যাখ্যা:
শীর্ষকোণ ১২০° হলে বাকি দুই কোণের সমষ্টি = ১৮০° - ১২০° = ৬০°।
যেহেতু ত্রিভুজটি সমদ্বিবাহু, তাই কোণ দুটি সমান = ৬০° / ২ = ৩০°।


প্রশ্ন ২০৯. ত্রিভুজের তিনটি বাহুর লম্বদ্বিখণ্ডক যে বিন্দুতে মিলিত হয়, তাকে কী বলে?

প্রশ্ন ২১০. কোনো ত্রিভুজের শীর্ষবিন্দু থেকে বিপরীত বাহুর উপর অঙ্কিত লম্ব তিনটি যে বিন্দুতে ছেদ করে, তাকে কী বলে?

ব্যাখ্যা:
শীর্ষবিন্দু থেকে বিপরীত বাহুর উপর অঙ্কিত লম্বগুলোর ছেদবিন্দুকে লম্ববিন্দু বা Orthocenter বলা হয়।


প্রশ্ন ২১১. একটি সমবাহু ত্রিভুজের বাহুর দৈর্ঘ্য ২ সেমি হলে, এর ক্ষেত্রফল কত?
A. √৩ বর্গ সেমি
B. ২√৩ বর্গ সেমি
C. ৩√৩ বর্গ সেমি
D. ৪√৩ বর্গ সেমি
উত্তর: A
ব্যাখ্যা:
সমবাহু ত্রিভুজের ক্ষেত্রফল = (√৩/৪)a² = (√৩/৪) × ২² = √৩ বর্গ সেমি।


প্রশ্ন ২১২. যদি একটি ত্রিভুজের ক্ষেত্রফল ৩৬ বর্গ সেমি এবং এর ভূমি ১২ সেমি হয়, তবে এর উচ্চতা কত?
A. ৩ সেমি
B. ৪ সেমি
C. ৬ সেমি
D. ৮ সেমি
উত্তর: C
ব্যাখ্যা:
ক্ষেত্রফল = ১/২ × ভূমি × উচ্চতা
৩৬ = ১/২ × ১২ × উচ্চতা => ৭২ = ১২ × উচ্চতা => উচ্চতা = ৬ সেমি।


প্রশ্ন ২১৩. একটি বিষমবাহু ত্রিভুজের বাহুগুলোর দৈর্ঘ্য ৫, ৬ ও ৭ সেমি। ত্রিভুজটির পরিসীমা কত?
A. ৯ সেমি
B. ১৫ সেমি
C. ১৮ সেমি
D. ২১ সেমি
উত্তর: C
ব্যাখ্যা:
পরিসীমা = তিন বাহুর যোগফল = ৫ + ৬ + ৭ = ১৮ সেমি।


প্রশ্ন ২১৪. একটি সমকোণী ত্রিভুজের অতিভুজের দৈর্ঘ্য ৫ সেমি এবং অপর দুটি বাহুর একটি ৩ সেমি হলে, ত্রিভুজটির ক্ষেত্রফল কত?
A. ৬ বর্গ সেমি
B. ১০ বর্গ সেমি
C. ১২ বর্গ সেমি
D. ১৫ বর্গ সেমি
উত্তর: A
ব্যাখ্যা:
অপর বাহু = √(৫² - ৩²) = √১৬ = ৪ সেমি।
ক্ষেত্রফল = ১/২ × ৩ × ৪ = ৬ বর্গ সেমি।


প্রশ্ন ২১৫. একটি ত্রিভুজের দুটি বাহুর দৈর্ঘ্য যথাক্রমে ৭ সেমি ও ৮ সেমি। তৃতীয় বাহুর দৈর্ঘ্য নিচের কোনটি হতে পারে না?
A. ২ সেমি
B. ১৪ সেমি
C. ১৫ সেমি
D. ১০ সেমি
উত্তর: C
ব্যাখ্যা:
ত্রিভুজের যেকোনো দুই বাহুর যোগফল তৃতীয় বাহু অপেক্ষা বৃহত্তর। ৭ + ৮ = ১৫। তৃতীয় বাহু অবশ্যই ১৫ এর চেয়ে ছোট হতে হবে। তাই ১৫ হতে পারবে না।


প্রশ্ন ২১৬. একটি আয়তক্ষেত্রের পরিসীমা ১০০ মিটার এবং দৈর্ঘ্য প্রস্থের ৪ গুণ। আয়তক্ষেত্রটির ক্ষেত্রফল কত?
A. ৪০০ বর্গমিটার
B. ৫০০ বর্গমিটার
C. ৬০০ বর্গমিটার
D. ৮০০ বর্গমিটার
উত্তর: A
ব্যাখ্যা:
ধরি, প্রস্থ = x, দৈর্ঘ্য = ৪x। পরিসীমা = ২(৪x + x) = ১০০ => ১০x = ১০০ => x = ১০।
প্রস্থ = ১০ মি, দৈর্ঘ্য = ৪০ মি। ক্ষেত্রফল = ৪০ × ১০ = ৪০০ বর্গমিটার।


প্রশ্ন ২১৭. একটি বর্গের ক্ষেত্রফল ১৬৯ বর্গ সেমি। এর পরিসীমা কত?
A. ২৬ সেমি
B. ৩৯ সেমি
C. ৫২ সেমি
D. ৬৮ সেমি
উত্তর: C
ব্যাখ্যা:
বর্গের ক্ষেত্রফল a² = ১৬৯ => a = ১৩ সেমি।
পরিসীমা = ৪a = ৪ × ১৩ = ৫২ সেমি।


প্রশ্ন ২১৮. রম্বসের কর্ণদ্বয় পরস্পরকে কী কোণে ছেদ করে?

প্রশ্ন ২১৯. একটি ট্রাপিজিয়ামের সমান্তরাল বাহুদ্বয়ের দৈর্ঘ্য ১৫ সেমি ও ২৫ সেমি এবং উচ্চতা ৮ সেমি। ট্রাপিজিয়ামটির ক্ষেত্রফল কত?
A. ১৬০ বর্গ সেমি

C. ৩০০ বর্গ সেমি

উত্তর: A
ব্যাখ্যা:
ক্ষেত্রফল = ১/২ × (১৫ + ২৫) × ৮ = ১/২ × ৪০ × ৮ = ১৬০ বর্গ সেমি।


প্রশ্ন ২২০. একটি সামান্তরিকের ক্ষেত্রফল ১২০ বর্গ সেমি এবং এর ভূমি ১৫ সেমি হলে, উচ্চতা কত?
A. ৬ সেমি
B. ৮ সেমি

D. ১২ সেমি

ব্যাখ্যা:
সামান্তরিকের ক্ষেত্রফল = ভূমি × উচ্চতা।
১২০ = ১৫ × উচ্চতা => উচ্চতা = ১২০ / ১৫ = ৮ সেমি।


প্রশ্ন ২২১. কোনো চতুর্ভুজের চারটি কোণের সমষ্টি কত?

প্রশ্ন ২২২. একটি বর্গের কর্ণ ৪√২ সেমি হলে, বর্গের পরিসীমা কত?

প্রশ্ন ২২৩. একটি রম্বসের ক্ষেত্রফল ৯৬ বর্গ সেমি এবং একটি কর্ণ ১৬ সেমি হলে, অপর কর্ণটির দৈর্ঘ্য কত?

ব্যাখ্যা:
ক্ষেত্রফল = ১/২ × d₁ × d₂
৯৬ = ১/২ × ১৬ × d₂ => ৯৬ = ৮ × d₂ => d₂ = ১২ সেমি।


প্রশ্ন ২২৪. পিথাগোরাসের উপপাদ্য অনুযায়ী, একটি সমকোণী ত্রিভুজের অতিভুজের বর্গ অপর দুই বাহুর বর্গের—
A. গুণফলের সমান
B. পার্থক্যের সমান
C. সমষ্টির সমান
D. অনুপাতের সমান
উত্তর: C
ব্যাখ্যা:
পিথাগোরাসের উপপাদ্যের বিবৃতি হলো: অতিভুজ² = লম্ব² + ভূমি² (বর্গের সমষ্টির সমান)।


প্রশ্ন ২২৫. একটি ত্রিভুজের বাহুগুলোর দৈর্ঘ্য ৯, ৪০ এবং ৪১। ত্রিভুজটি কী ধরনের?
A. সূক্ষ্মকোণী
B. সমকোণী
C. স্থূলকোণী
D. সমদ্বিবাহু
উত্তর: B
ব্যাখ্যা:
৯² + ৪০² = ৮১ + ১৬০০ = ১৬৮১ = ৪১²। এটি পিথাগোরীয় ট্রিপলেট মেনে চলে, তাই এটি সমকোণী ত্রিভুজ।


প্রশ্ন ২২৬. একটি খুঁটি এমনভাবে ভেঙে গেল যে, ভাঙা অংশটি অবিচ্ছিন্ন থেকে ভূমির সাথে ৪৫° কোণ উৎপন্ন করে খুঁটির গোড়া থেকে ১০ মিটার দূরে মাটি স্পর্শ করে। খুঁটিটির ভাঙা অংশের দৈর্ঘ্য কত?
A. ১০ মিটার
B. ১০√২ মিটার
C. ১০√৩ মিটার
D. ২০ মিটার
উত্তর: B
ব্যাখ্যা:
এখানে ভূমি = ১০ মিটার, কোণ = ৪৫°। ভাঙা অংশটি অতিভুজ।
cos(৪৫°) = ভূমি / অতিভুজ => ১/√২ = ১০ / অতিভুজ => অতিভুজ = ১০√২ মিটার।


প্রশ্ন ২২৭. একটি সমকোণী ত্রিভুজের লম্ব ও ভূমির অনুপাত ৩ : ৪ এবং এর ক্ষেত্রফল ৫৪ বর্গ সেমি হলে, অতিভুজ কত?
A. ৯ সেমি
B. ১২ সেমি
C. ১৫ সেমি
D. ১৮ সেমি
উত্তর: C
ব্যাখ্যা:
ধরি লম্ব = ৩x, ভূমি = ৪x। ক্ষেত্রফল = ১/২ × ৩x × ৪x = ৬x² = ৫৪ => x² = ৯ => x = ৩।
লম্ব = ৯, ভূমি = ১২।
অতিভুজ = √(৯² + ১২²) = √(৮১ + ১৪৪) = √২২৫ = ১৫ সেমি।


প্রশ্ন ২২৮. একটি আয়তাকার মাঠের দৈর্ঘ্য ও প্রস্থ যথাক্রমে ৬০ মিটার ও ৪৫ মিটার। এর কর্ণ বরাবর আড়াআড়ি যেতে কত মিটার পথ অতিক্রম করতে হবে?

কর্ণ = √(৬০² + ৪৫²) = √(৩৬০০ + ২০২৫) = √৫৬২৫ = ৭৫ মিটার। (এটি ৩:৪:৫ অনুপাতের ১৫ গুণ; ১৫×৩=৪৫, ১৫×৪=৬০, ১৫×৫=৭৫)।

প্রশ্ন ২৫৫. একটি সমকোণী ত্রিভুজের লম্ব ভূমির চেয়ে ২ সেমি ছোট এবং অতিভুজ ভূমির চেয়ে ২ সেমি বড়। অতিভুজের দৈর্ঘ্য কত?

প্রশ্ন ২৭৫. একটি আয়তক্ষেত্রের ক্ষেত্রফল ২০০ বর্গ মিটার। যদি দৈর্ঘ্য ১০ মিটার কমানো হয় এবং প্রস্থ ৫ মিটার বাড়ানো হয়, তবে এটি একটি বর্গক্ষেত্র হয়। আয়তক্ষেত্রটির দৈর্ঘ্য কত?

প্রশ্ন ৩০৫. একটি সমকোণী ত্রিভুজের অতিভুজ ২৫ সেমি এবং একটি বাহু ২৪ সেমি। অপর বাহুটির দৈর্ঘ্য কত?
A. ৭ সেমি
B. ৯ সেমি
C. ১১ সেমি
D. ১৪ সেমি
উত্তর: A
ব্যাখ্যা:
অপর বাহু = √(২৫² - ২৪²) = √(৬২৫ - ৫৭৬) = √৪৯ = ৭ সেমি।


প্রশ্ন ৩০৬. কোনো ট্রাপিজিয়ামের সমান্তরাল বাহুদ্বয় ১২ সেমি ও ৮ সেমি এবং ক্ষেত্রফল ৫০ বর্গ সেমি। এর উচ্চতা কত?

C. ৬ সেমি
D. ১০ সেমি

ব্যাখ্যা:
১/২ × (১২ + ৮) × h = ৫০ => ১/২ × ২০ × h = ৫০ => ১০h = ৫০ => h = ৫ সেমি।


প্রশ্ন ৩০৭. একটি রম্বসের কর্ণদ্বয় ৬ সেমি ও ৮ সেমি হলে, এর বাহুর দৈর্ঘ্য কত?

অতিভুজ (বাহু) = √(৩² + ৪²) = √(৯ + ১৬) = √২৫ = ৫ সেমি।


প্রশ্ন ৩০৮. একটি বর্গের পরিসীমা ২৪ সেমি। এর কর্ণের দৈর্ঘ্য কত?

প্রশ্ন ৩০৯. দুটি বৃত্ত পরস্পরকে ছেদ করলে, তাদের কেন্দ্রদ্বয়ের দূরত্ব—

ব্যাখ্যা:
দুটি বৃত্ত ছেদ করার শর্ত হলো: কেন্দ্রদ্বয়ের দূরত্ব (d), ব্যাসার্ধের যোগফলের (R+r) চেয়ে ছোট এবং তাদের পার্থক্যের (R-r) চেয়ে বড় হতে হবে।


প্রশ্ন ৩১০. বৃত্তস্থ সামান্তরিকের একটি কোণ কত ডিগ্রি?

ব্যাখ্যা:
বৃত্তস্থ সামান্তরিক সর্বদা একটি আয়তক্ষেত্র। তাই এর প্রতিটি কোণ ৯০°।


প্রশ্ন ৩১১. একটি ঘড়িতে ৮টা বাজলে ঘণ্টা ও মিনিটের কাঁটার মধ্যকার কোণ কত ডিগ্রি?

B. ১৫০°
C. ২১০°
D. ২৪০°
উত্তর: A
ব্যাখ্যা:
৮টার সময় কাঁটা দুটি ৮ ঘর দূরে থাকে (১২ থেকে ৮)। অথবা ৪ ঘর দূরে। ৪ × ৩০° = ১২০°।
প্রবৃদ্ধ কোণ চাইলে তা ২৪০° হতো।


প্রশ্ন ৩১২. একটি সমদ্বিবাহু ত্রিভুজের সমান বাহুদ্বয় ৫ সেমি এবং ভূমি ৬ সেমি হলে, এর ক্ষেত্রফল কত?
A. ১০ বর্গ সেমি
B. ১২ বর্গ সেমি
C. ১৫ বর্গ সেমি
D. ২৪ বর্গ সেমি
উত্তর: B
ব্যাখ্যা:
উচ্চতা h = √(৫² - (৬/২)²) = √(২৫ - ৯) = √১৬ = ৪ সেমি।
ক্ষেত্রফল = ১/২ × ৬ × ৪ = ১২ বর্গ সেমি।


প্রশ্ন ৩১৩. কোনো আয়তক্ষেত্রের দৈর্ঘ্য ২০% বৃদ্ধি এবং প্রস্থ ১০% হ্রাস পেলে ক্ষেত্রফল কত শতাংশ বৃদ্ধি পাবে?
A. ৮%
B. ১০%
C. ১২%
D. ১৫%
উত্তর: A
ব্যাখ্যা:
শর্টকাট: x + y + (xy/১০০)। এখানে x = ২০, y = -১০।
২০ - ১০ + (২০ × -১০) / ১০০ = ১০ - ২ = ৮% বৃদ্ধি।


প্রশ্ন ৩১৪. একটি বৃত্তের ব্যাসার্ধ ৫ সেমি। এর কেন্দ্রে একটি বৃত্তচাপ ৭২° কোণ উৎপন্ন করলে, বৃত্তচাপটির দৈর্ঘ্য কত? (π = ৩.১৪)
A. ৩.১৪ সেমি
B. ৬.২৮ সেমি
C. ১৫.৭ সেমি
D. ৩১.৪ সেমি

ব্যাখ্যা:
চাপের দৈর্ঘ্য s = (θ / ৩৬০°) × ২πr
= (৭২° / ৩৬০°) × ২ × ৩.১৪ × ৫
= (১/৫) × ৩১.৪ = ৬.২৮ সেমি।


প্রশ্ন ৩১৫. একটি কাইটের (Kite) কর্ণদ্বয়ের গুণফল ৮০ বর্গ সেমি। এর ক্ষেত্রফল কত?

প্রশ্ন ৩১৬. কোনো ত্রিভুজের ভরকেন্দ্র এর প্রতিটি মধ্যমাকে কী অনুপাতে অন্তর্বিভক্ত করে?

প্রশ্ন ৩১৭. একটি রম্বসের ক্ষেত্রফল একটি বর্গের ক্ষেত্রফলের অর্ধেক। বর্গের কর্ণ ৮ সেমি হলে, রম্বসের ক্ষেত্রফল কত?

রম্বসের ক্ষেত্রফল বর্গের অর্ধেক = ৩২ / ২ = ১৬ বর্গ সেমি।


প্রশ্ন ৩১৮. ১০ মিটার লম্বা একটি মই দেয়ালের সাথে ঠেস দিয়ে রাখা আছে। দেয়ালের গোড়া থেকে মইয়ের দূরত্ব ৬ মিটার। মইটি দেয়ালের উপর কত উচ্চতায় স্পর্শ করবে?

প্রশ্ন ৩১৯. কোনো বহুভুজের অন্তঃস্থ ও বহিঃস্থ কোণের সমষ্টি কত?

প্রশ্ন ৩২০. একটি বৃত্তে অন্তর্লিখিত সুষম ষড়ভুজের বাহুর দৈর্ঘ্য এবং বৃত্তের ব্যাসার্ধের সম্পর্ক কী?

সুষম ষড়ভুজ ৬টি সমবাহু ত্রিভুজে বিভক্ত হয়, যাদের শীর্ষবিন্দু বৃত্তের কেন্দ্রে থাকে। তাই ষড়ভুজের বাহুর দৈর্ঘ্য বৃত্তের ব্যাসার্ধের সমান হয়।


প্রশ্ন ৩২১. দুটি সমান্তরাল রেখাকে একটি ছেদক ছেদ করলে, একান্তর কোণগুলো পরস্পর সমান। এই কোণগুলো ইংরেজি কোন অক্ষরের মতো আকৃতি গঠন করে?

B. F
C. Z

একান্তর কোণগুলো (Alternate angles) ছেদক এবং সমান্তরাল রেখার মাঝে ইংরেজি 'Z' অক্ষরের মতো আকৃতি গঠন করে। (অনুরূপ কোণগুলো 'F' এর মতো হয়)।


প্রশ্ন ৩২২. একটি সামান্তরিকের ভূমি উচ্চতার দ্বিগুণ। এর ক্ষেত্রফল ৯৮ বর্গ সেমি হলে, উচ্চতা কত?

C. ২১ সেমি

ক্ষেত্রফল = h × ২h = ২h² = ৯৮ => h² = ৪৯ => h = ৭ সেমি।


প্রশ্ন ৩২৩. একটি সমকোণী ত্রিভুজের লম্ব ৩ সেমি এবং ভূমি ৪ সেমি। ত্রিভুজটিকে ভূমির সাপেক্ষে ঘোরালে যে ঘনবস্তু উৎপন্ন হয়, তার নাম কী?

সমকোণী ত্রিভুজকে এর লম্ব বা ভূমির সাপেক্ষে ঘোরালে একটি লম্ব বৃত্তাকার কোণক (Right Circular Cone) উৎপন্ন হয়।


প্রশ্ন ৩২৪. বৃত্তের দুটি জ্যা পরস্পরকে সমদ্বিখণ্ডিত করলে তাদের ছেদবিন্দুটি কোথায় অবস্থিত হবে?

কেবলমাত্র বৃত্তের ব্যাসগুলোই (যা বৃহত্তম জ্যা) একে অপরকে সমদ্বিখণ্ডিত করে এবং তাদের ছেদবিন্দুটি সর্বদা বৃত্তের কেন্দ্র হয়।


প্রশ্ন ৩২৫. একটি বর্গের প্রতিটি বাহু ২০% বৃদ্ধি পেলে, এর ক্ষেত্রফল কত শতাংশ বৃদ্ধি পাবে?
A. ২০%
B. ৪০%
C. ৪৪%
D. ১০০%
উত্তর: C
ব্যাখ্যা:
শর্টকাট: (২x + x²/১০০)% = ২(২০) + (৪০০/১০০) = ৪০ + ৪ = ৪৪%।


প্রশ্ন ৩২৬. একটি ত্রিভুজের তিনটি বাহু ৬, ৮ এবং ১০। ত্রিভুজটির পরিবৃত্তের ব্যাসার্ধ কত?
A. ৩
B. ৪
C. ৫
D. ৬
উত্তর: C
ব্যাখ্যা:
৬² + ৮² = ৩৬ + ৬৪ = ১০০ = ১০²। এটি সমকোণী ত্রিভুজ।
সমকোণী ত্রিভুজের পরিব্যাসার্ধ = অতিভুজ / ২ = ১০ / ২ = ৫।


প্রশ্ন ৩২৭. রম্বসের কর্ণদ্বয় ৬ সেমি ও ৮ সেমি। রম্বসটির পরিসীমা কত?

B. ২৪ সেমি
C. ২৮ সেমি
D. ৩২ সেমি
উত্তর: A
ব্যাখ্যা:
সমকোণী ত্রিভুজের লম্ব ও ভূমি ৩ ও ৪। অতিভুজ (রম্বসের বাহু) = √(৩² + ৪²) = ৫।
পরিসীমা = ৪ × ৫ = ২০ সেমি।


প্রশ্ন ৩২৮. একটি আয়তক্ষেত্রের পরিসীমা ৩৬ সেমি। দৈর্ঘ্য ও প্রস্থের অনুপাত ৫ : ৪ হলে, এর ক্ষেত্রফল কত?

প্রশ্ন ৩২৯. একটি বৃত্তের ব্যাসার্ধ ৫ সেমি। কেন্দ্র থেকে ৪ সেমি দূরে অবস্থিত জ্যা-এর দৈর্ঘ্য কত?

প্রশ্ন ৩৩২. একটি ত্রিভুজের ক্ষেত্রফল ২৪ বর্গ সেমি এবং ভূমি ৮ সেমি। উচ্চতা কত?

প্রশ্ন ৩৩৪. সমবাহু ত্রিভুজের বাহু ২ সেমি হলে, এর মধ্যমার দৈর্ঘ্য কত?

প্রশ্ন ৩৩৫. একটি সুষম ষড়ভুজের প্রতিটি অন্তঃস্থ কোণ কত ডিগ্রি?

প্রশ্ন ৩৩৬. একটি সমদ্বিবাহু সমকোণী ত্রিভুজের অতিভুজ ৮√২ সেমি হলে, এর ক্ষেত্রফল কত?

ধরি সমান বাহু a। a² + a² = (৮√২)² = ১২৮ => ২a² = ১২৮ => a² = ৬৪ => a = ৮।
ক্ষেত্রফল = ১/২ × a × a = ১/২ × ৬৪ = ৩২ বর্গ সেমি।


প্রশ্ন ৩৩৭. দুটি বৃত্ত পরস্পরকে বহিঃস্পর্শ করলে তাদের কয়টি সাধারণ স্পর্শক থাকে?

প্রশ্ন ৩৩৮. বৃত্তের কোনো বিন্দুতে স্পর্শকের ওপর লম্ব সর্বদা কোন বিন্দুগামী হয়?

প্রশ্ন ৩৩৯. একটি বর্গের কর্ণ ৬√২ সেমি। এর ভেতরে অঙ্কিত সবচেয়ে বড় বৃত্তের ক্ষেত্রফল কত?

ক্ষেত্রফল = πr² = π(৩²) = ৯π বর্গ সেমি।


প্রশ্ন ৩৪০. একটি আয়তক্ষেত্রের দৈর্ঘ্য প্রস্থের ৩ গুণ। এর পরিসীমা ৪৮ সেমি হলে, ক্ষেত্রফল কত?

প্রশ্ন ৩৪১. ১৩, ১৪ এবং ১৫ সেমি বাহুবিশিষ্ট ত্রিভুজের ক্ষেত্রফল কত?

ক্ষেত্রফল = √(২১(২১-১৩)(২১-১৪)(২১-১৫)) = √(২১ × ৮ × ৭ × ৬)
= √(৩×৭ × ২×২×২ × ৭ × ২×৩) = √(৩² × ৭² × ২⁴) = ৩ × ৭ × ৪ = ৮৪ বর্গ সেমি।

প্রশ্ন ৩৪৫. কোনো ত্রিভুজের দুটি কোণ পরস্পর পূরক হলে, ত্রিভুজটি কী ধরনের?

প্রশ্ন ৩৪৬. একটি বৃত্তের ক্ষেত্রফল ১৬π বর্গ সেমি হলে, এর পরিধি কত?

প্রশ্ন ৩৬৩. একটি রম্বসের বাহুর দৈর্ঘ্য ১৩ সেমি এবং একটি কর্ণ ১০ সেমি হলে, অপর কর্ণটি কত?

প্রশ্ন ৩৬৪. একটি আয়তক্ষেত্রের পরিসীমা ২০ সেমি এবং ক্ষেত্রফল ২৪ বর্গ সেমি। এর দৈর্ঘ্য ও প্রস্থের পার্থক্য কত?

প্রশ্ন ৩৬৫. একটি বৃত্তের পরিধি ২২ সেমি হলে, এর ক্ষেত্রফল কত? (π = ২২/৭)

প্রশ্ন ৩৮২. একটি ত্রিভুজের দুটি কোণ ৬০° ও ৮০°। তৃতীয় কোণটি কত?

উত্তর: C
ব্যাখ্যা:
১৮০° - (৬০° + ৮০°) = ৪০°।


প্রশ্ন ৩৮৩. একটি আয়তক্ষেত্রের ক্ষেত্রফল ১০০ বর্গ সেমি এবং দৈর্ঘ্য ২০ সেমি হলে, পরিসীমা কত?

B. ৫০ সেমি
C. ৬০ সেমি
D. ৮০ সেমি
উত্তর: B
ব্যাখ্যা:
প্রস্থ = ১০০ / ২০ = ৫।
পরিসীমা = ২(২০ + ৫) = ২ × ২৫ = ৫০ সেমি।


প্রশ্ন ৩৮৪. একটি চাকার পরিধি ৪৪ মিটার। এটি ১০ বার ঘুরলে কত দূরত্ব অতিক্রম করবে?

উত্তর: A
ব্যাখ্যা:
দূরত্ব = পরিধি × ঘূর্ণন সংখ্যা = ৪৪ × ১০ = ৪৪০ মিটার।


প্রশ্ন ৩৮৫. একটি সমকোণী ত্রিভুজের লম্ব ও ভূমির পার্থক্য ২ সেমি এবং অতিভুজ ১০ সেমি। লম্ব ও ভূমির যোগফল কত?

ব্যাখ্যা:
অতিভুজ ১০ হলে লম্ব ও ভূমি ৬ ও ৮। পার্থক্য ২ (শর্ত মিলেছে)। যোগফল = ৬ + ৮ = ১৪ সেমি।


প্রশ্ন ৩৮৬. একটি বৃত্তের ক্ষেত্রফল এবং পরিধির সাংখ্যিক মান সমান হলে, ব্যাস কত?
A. ২
B. ৪
C. ৬
D. ৮
উত্তর: B
ব্যাখ্যা:
πr² = ২πr => r = ২। ব্যাস = ২r = ৪।


প্রশ্ন ৩৮৭. একটি রম্বসের পরিসীমা ৪০ সেমি এবং একটি কর্ণ ১৬ সেমি। ক্ষেত্রফল কত?
A. ৪৮ বর্গ সেমি
B. ৯৬ বর্গ সেমি
C. ১৯২ বর্গ সেমি
D. ৩৮৪ বর্গ সেমি
উত্তর: B
ব্যাখ্যা:
বাহু = ১০। লম্ব (অর্ধেক কর্ণ) = ৮।
ভূমি = √(১০² - ৮²) = ৬। অপর কর্ণ = ১২।
ক্ষেত্রফল = ১/২ × ১৬ × ১২ = ৯৬ বর্গ সেমি।


প্রশ্ন ৩৮৮. একটি ত্রিভুজের তিনটি বাহু ৯, ১২ এবং ১৫। ত্রিভুজটির ক্ষেত্রফল কত?
A. ২৭ বর্গ সেমি
B. ৩৬ বর্গ সেমি

ব্যাখ্যা:
এটি সমকোণী ত্রিভুজ (৯² + ১২² = ১৫²)। ক্ষেত্রফল = ১/২ × ৯ × ১২ = ৫৪ বর্গ সেমি।


প্রশ্ন ৩৮৯. একটি সুষম ষড়ভুজের প্রতিটি বহিঃস্থ কোণ কত?

প্রশ্ন ৩৯০. একটি ঘড়িতে ৯টা বাজলে কাঁটা দুটির মধ্যকার কোণ কত?

প্রশ্ন ৩৯১. একটি বর্গের ক্ষেত্রফল ২৫ বর্গ সেমি হলে, এর কর্ণ কত?

প্রশ্ন ৩৯২. একটি ট্রাপিজিয়ামের সমান্তরাল বাহুদ্বয় ১০ সেমি ও ২০ সেমি এবং ক্ষেত্রফল ৬০ বর্গ সেমি হলে, উচ্চতা কত?

প্রশ্ন ৩৯৩. একটি বৃত্তের ব্যাসার্ধ ১৪ সেমি হলে, এর পরিধি কত? (π = ২২/৭)

প্রশ্ন ৩৯৪. একটি সমবাহু ত্রিভুজের বাহুর দৈর্ঘ্য ২ সেমি হলে, এর ক্ষেত্রফল কত?

প্রশ্ন ৩৯৫. একটি আয়তক্ষেত্রের কর্ণ ১০ সেমি এবং দৈর্ঘ্য ৮ সেমি হলে, ক্ষেত্রফল কত?

প্রশ্ন ৩৯৬. একটি বৃত্তের ব্যাস ১৪ সেমি হলে, এর ক্ষেত্রফল কত? (π = ২২/৭)

প্রশ্ন ৩৯৭. একটি রম্বসের ক্ষেত্রফল ২৪ বর্গ সেমি এবং একটি কর্ণ ৮ সেমি। অপর কর্ণটি কত?

প্রশ্ন ৩৯৮. একটি সমকোণী ত্রিভুজের লম্ব ৪ সেমি এবং ভূমি ৩ সেমি। অতিভুজ কত?

প্রশ্ন ৩৯৯. একটি বর্গের পরিসীমা ২০ সেমি। এর ক্ষেত্রফল কত?

প্রশ্ন ৪০০. একটি ত্রিভুজের তিনটি কোণ যথাক্রমে ৪০°, ৬০° এবং x। x এর মান কত?
