প্রশ্ন ১. x + y = ১২ এবং x - y = ২ হলে, x এর মান কত?
A. ৫
B. ৬
C. ৭
D. ৮
উত্তর: C
ব্যাখ্যা:
সমীকরণ দুটি যোগ করলে পাই, ২x = ১৪। অতএব, x = ৭।


প্রশ্ন ২. ২x + y = ৮ এবং x - y = ১ হলে, y এর মান কত?
A. ২
B. ৩
C. ৪
D. ৫
উত্তর: A
ব্যাখ্যা:
যোগ করলে, ৩x = ৯ => x = ৩। x এর মান প্রথম সমীকরণে বসালে, ৬ + y = ৮ => y = ২।


প্রশ্ন ৩. ৩x - ২y = ৫ এবং ২x + ৩y = ১২ হলে, x + y এর মান কত?
A. ৩
B. ৪
C. ৫
D. ৬
উত্তর: C
ব্যাখ্যা:
প্রথমটিকে ৩ দ্বারা এবং দ্বিতীয়টিকে ২ দ্বারা গুণ করে যোগ করলে: ৯x + ৪x = ১৫ + ২৪ => ১৩x = ৩৯ => x = ৩। ২(৩) + ৩y = ১২ => ৩y = ৬ => y = ২। সুতরাং, x + y = ৩ + ২ = ৫।


প্রশ্ন ৪. x/২ + y/৩ = ৫ এবং x/৩ + y/২ = ৫ হলে, x এবং y এর মান কত?
A. x=৪, y=৬
B. x=৬, y=৬
C. x=৩, y=২
D. x=৬, y=৪
উত্তর: B
ব্যাখ্যা:
সমীকরণ দুটি যোগ করলে: (৫/৬)(x + y) = ১০ => x + y = ১২। বিয়োগ করলে: (১/৬)(x - y) = ০ => x = y। সুতরাং, ২x = ১২ => x = ৬, y = ৬।


প্রশ্ন ৫. ৫x + ৩y = ২১ এবং ৩x + ৫y = ১৯ হলে, x - y এর মান কত?
A. ১
B. ২
C. ৩
D. ৪
উত্তর: A
ব্যাখ্যা:
প্রথম সমীকরণ থেকে দ্বিতীয়টি বিয়োগ করলে: ২x - ২y = ২ => x - y = ১।


প্রশ্ন ৬. x + ২y = ১০ এবং ২x - y = ৫ হলে, x এর মান কত?
A. ২
B. ৩
C. ৪
D. ৫
উত্তর: C
ব্যাখ্যা:
দ্বিতীয় সমীকরণকে ২ দ্বারা গুণ করে যোগ করলে: x + ৪x = ১০ + ১০ => ৫x = ২০ => x = ৪।


প্রশ্ন ৭. ৭x - ২y = ১১ এবং ৩x + y = ১৪ হলে, x এর মান কত?
A. ২
B. ৩
C. ৪
D. ৫
উত্তর: B
ব্যাখ্যা:
দ্বিতীয় সমীকরণকে ২ দ্বারা গুণ করে যোগ করলে: ৭x + ৬x = ১১ + ২৮ => ১৩x = ৩৯ => x = ৩।


প্রশ্ন ৮. x - y = a এবং x + y = b হলে, x এর মান কোনটি?
A. a+b
B. (a+b)/২
C. (a-b)/২
D. ab
উত্তর: B
ব্যাখ্যা:
সমীকরণ দুটি যোগ করলে: ২x = a + b => x = (a + b)/২।


প্রশ্ন ৯. x/a + y/b = ২ এবং ax - by = a² - b² হলে, (x, y) এর মান কত?
A. (a, b)
B. (b, a)
C. (a², b²)
D. (১, ১)
উত্তর: A
ব্যাখ্যা:
x = a এবং y = b বসালে উভয় সমীকরণ সিদ্ধ হয়। a/a + b/b = ১ + ১ = ২ এবং a(a) - b(b) = a² - b²।


প্রশ্ন ১০. ১/x + ১/y = ৫ এবং ১/x - ১/y = ১ হলে, x এর মান কত?
A. ১/২
B. ১/৩
C. ২
D. ৩
উত্তর: B
ব্যাখ্যা:
যোগ করলে: ২/x = ৬ => x = ২/৬ = ১/৩।


প্রশ্ন ১১. ৩x + y = ১১ এবং x - y = ১ হলে, x² + y² এর মান কত?
A. ১০
B. ১৩
C. ২৫
D. ২৯
উত্তর: B
ব্যাখ্যা:
যোগ করলে: ৪x = ১২ => x = ৩। x - y = ১ => ৩ - y = ১ => y = ২। x² + y² = ৩² + ২² = ৯ + ৪ = ১৩।


প্রশ্ন ১২. ২x - ৩y = ৭ এবং ৩x + ২y = ১৭ হলে, xy এর মান কত?
A. ৫
B. ৬
C. ১০
D. ১৫
উত্তর: C
ব্যাখ্যা:
প্রথমটিকে ২ এবং দ্বিতীয়টিকে ৩ দ্বারা গুণ করে যোগ করলে: ৪x + ৯x = ১৪ + ৫১ => ১৩x = ৬৫ => x = ৫। ১০ - ৩y = ৭ => ৩y = ৩ => y = ১। xy = ৫ × ১ = ৫।


প্রশ্ন ১৩. ৫x - y = ৯ এবং x + y = ৩ হলে, ২x + ৩y এর মান কত?
A. ৩
B. ৫
C. ৭
D. ৯
উত্তর: C
ব্যাখ্যা:
যোগ করলে: ৬x = ১২ => x = ২। ২ + y = ৩ => y = ১। সুতরাং, ২x + ৩y = ২(২) + ৩(১) = ৪ + ৩ = ৭।


প্রশ্ন ১৪. ২/x + ৩/y = ১৩ এবং ৫/x - ৪/y = -২ হলে, y এর মান কত?
A. ১/২
B. ১/৩
C. ২
D. ৩
উত্তর: B
ব্যাখ্যা:
ধরি ১/x = u, ১/y = v। ২u + ৩v = ১৩ এবং ৫u - ৪v = -২। সমাধান করলে u = ২, v = ৩। ১/y = ৩ => y = ১/৩।


প্রশ্ন ১৫. ০.২x + ০.৩y = ১.৩ এবং ০.৪x + ০.৫y = ২.৩ হলে, x এর মান কত?

B. ৩
C. ৪
D. ৫
উত্তর: A
ব্যাখ্যা:
সমীকরণগুলোকে ১০ দ্বারা গুণ করলে: ২x + ৩y = ১৩ এবং ৪x + ৫y = ২৩। প্রথমটিকে ২ দ্বারা গুণ করে বিয়োগ করলে: ৬y - ৫y = ২৬ - ২৩ => y = ৩। ২x + ৯ = ১৩ => x = ২।


প্রশ্ন ১৬. x + y = ৫ এবং ২x + ২y = ১০ সমীকরণ জোটের কয়টি সমাধান আছে?
A. একটি
B. দুটি
C. অসংখ্য
D. কোনো সমাধান নেই
উত্তর: C
ব্যাখ্যা:
এখানে a₁/a₂ = ১/২, b₁/b₂ = ১/২, c₁/c₂ = ৫/১০ = ১/২। তিনটি অনুপাত সমান হওয়ায় এর অসংখ্য সমাধান আছে।


প্রশ্ন ১৭. ২x - ৫y = ৮ এবং ৪x - ১০y = ১৬ সমীকরণ জোটটি কীরূপ?
A. সমঞ্জস ও নির্ভরশীল
B. সমঞ্জস ও অনির্ভরশীল
C. অসমঞ্জস ও নির্ভরশীল
D. অসমঞ্জস ও অনির্ভরশীল
উত্তর: A
ব্যাখ্যা:
a₁/a₂ = ২/৪ = ১/২; b₁/b₂ = -৫/-১০ = ১/২; c₁/c₂ = ৮/১৬ = ১/২। অনুপাতগুলো সমান হওয়ায় এটি সমঞ্জস, নির্ভরশীল এবং অসংখ্য সমাধান রয়েছে।


প্রশ্ন ১৮. ৩x + ২y = ৫ এবং ৩x + ২y = ১০ সমীকরণ জোটের কয়টি সমাধান আছে?
A. একটি
B. দুটি
C. অসংখ্য
D. কোনো সমাধান নেই
উত্তর: D
ব্যাখ্যা:
a₁/a₂ = ৩/৩ = ১; b₁/b₂ = ২/২ = ১; c₁/c₂ = ৫/১০ = ১/২। যেহেতু a₁/a₂ = b₁/b₂ ≠ c₁/c₂, তাই এর কোনো সমাধান নেই (সমান্তরাল রেখা)।


প্রশ্ন ১৯. k এর কোন মানের জন্য kx + ২y = ৪ এবং ৩x + y = ১ সমীকরণ জোটের একটি অদ্বিতীয় সমাধান থাকবে?
A. k = ৬
B. k ≠ ৬
C. k = ৩
D. k ≠ ৩
উত্তর: B
ব্যাখ্যা:
অদ্বিতীয় সমাধানের শর্ত: a₁/a₂ ≠ b₁/b₂। সুতরাং k/৩ ≠ ২/১ => k ≠ ৬।


প্রশ্ন ২০. k এর কোন মানের জন্য ২x + ৩y = ৫ এবং ৪x + ky = ১০ সমীকরণ জোটের অসংখ্য সমাধান থাকবে?
A. ৪
B. ৫
C. ৬
D. ৮
উত্তর: C
ব্যাখ্যা:
অসংখ্য সমাধানের শর্ত: a₁/a₂ = b₁/b₂ = c₁/c₂। ২/৪ = ৩/k = ৫/১০। অর্থাৎ ১/২ = ৩/k => k = ৬।


প্রশ্ন ২১. ৩x - y = ৫ এবং ৬x - ২y = k সমীকরণ জোটের কোনো সমাধান না থাকলে k এর মান কোনটি হতে পারবে না?
A. ৫
B. ১০
C. ১৫
D. ২০
উত্তর: B
ব্যাখ্যা:
কোনো সমাধান না থাকার শর্ত: a₁/a₂ = b₁/b₂ ≠ c₁/c₂। ৩/৬ = -১/-২ ≠ ৫/k। অর্থাৎ ১/২ ≠ ৫/k => k ≠ ১০।


প্রশ্ন ২২. দুটি সরলরেখা পরস্পর সমান্তরাল হলে, তাদের সমীকরণ জোটের কয়টি সমাধান থাকে?
A. একটি
B. দুটি

D. কোনো সমাধান নেই
উত্তর: D
ব্যাখ্যা:
সমান্তরাল রেখাগুলো কখনোই একে অপরকে ছেদ করে না। তাই এদের কোনো সমাধান থাকে না।


প্রশ্ন ২৩. ax + by = c এবং dx + ey = f সমীকরণ জোটের অনন্য (unique) সমাধান থাকার শর্ত কী?
A. ae = bd
B. ae ≠ bd
C. af = cd
D. bf = ce
উত্তর: B
ব্যাখ্যা:
অনন্য সমাধানের শর্ত: a/d ≠ b/e => ae ≠ bd।


প্রশ্ন ২৪. x - y = ২ এবং x + y = ৪ সমীকরণ নির্দেশক সরলরেখাদ্বয়ের ছেদবিন্দু কোনটি?
A. (৩, ১)
B. (১, ৩)
C. (২, ২)
D. (৪, ২)
উত্তর: A
ব্যাখ্যা:
যোগ করলে ২x = ৬ => x = ৩। x - y = ২ => ৩ - y = ২ => y = ১। ছেদবিন্দু (৩, ১)।


প্রশ্ন ২৫. ৩x + ৪y = ১২ রেখাটি x-অক্ষকে কোন বিন্দুতে ছেদ করে?
A. (০, ৩)
B. (৪, ০)
C. (০, ৪)
D. (৩, ০)
উত্তর: B
ব্যাখ্যা:
x-অক্ষকে ছেদ করলে y = ০ হবে। ৩x + ৪(০) = ১২ => ৩x = ১২ => x = ৪। বিন্দুটি (৪, ০)।


প্রশ্ন ২৬. y = ২x + ৩ এবং y = ২x - ৫ রেখাদ্বয় পরস্পর কীরূপ?
A. লম্ব
B. সমান্তরাল
C. ছেদক
D. সমাপতিত (একই রেখা)
উত্তর: B
ব্যাখ্যা:
উভয় রেখার ঢাল (m) সমান (m = ২)। ঢাল সমান হলে রেখাদ্বয় সমান্তরাল হয়।


প্রশ্ন ২৭. x = ৫ এবং y = -৩ রেখাদ্বয়ের ছেদবিন্দু কোনটি?
A. (-৩, ৫)
B. (৫, ০)
C. (০, -৩)
D. (৫, -৩)
উত্তর: D
ব্যাখ্যা:
x এর মান সর্বদা ৫ এবং y এর মান সর্বদা -৩, তাই ছেদবিন্দু সরাসরি (৫, -৩)।


প্রশ্ন ২৮. a₁x + b₁y = c₁ এবং a₂x + b₂y = c₂ সমীকরণ জোট অসমঞ্জস (inconsistent) হওয়ার শর্ত কোনটি?
A. a₁/a₂ ≠ b₁/b₂
B. a₁/a₂ = b₁/b₂ = c₁/c₂
C. a₁/a₂ = b₁/b₂ ≠ c₁/c₂
D. a₁/a₂ ≠ b₁/b₂ ≠ c₁/c₂
উত্তর: C
ব্যাখ্যা:
অসমঞ্জস বা সমাধানবিহীন হওয়ার শর্ত হলো x ও y এর সহগের অনুপাত সমান কিন্তু ধ্রুবক পদের অনুপাত অসমান।


প্রশ্ন ২৯. ৫x + ৪y = ২০ রেখাটি দ্বারা x ও y অক্ষের সাথে গঠিত ত্রিভুজের ক্ষেত্রফল কত?
A. ১০
B. ২০
C. ৪০
D. ৮০
উত্তর: A
ব্যাখ্যা:
x-অক্ষের ছেদাংশ a = ২০/৫ = ৪। y-অক্ষের ছেদাংশ b = ২০/৪ = ৫। ত্রিভুজের ক্ষেত্রফল = ১/২ × |a| × |b| = ১/২ × ৪ × ৫ = ১০ বর্গ একক।


প্রশ্ন ৩০. (k-১)x - y = ৫ এবং (k+১)x + (১-k)y = ৩ সমীকরণ জোটের কোনো সমাধান না থাকলে k এর মান কত?
A. ০, ৩
B. ১, -১
C. ২, ৪
D. ০, -৩
উত্তর: A
ব্যাখ্যা:
শর্ত: (k-১)/(k+১) = -১/(১-k)। => (k-১)² = k+১ => k² - ২k + ১ = k + ১ => k² - ৩k = ০ => k(k - ৩) = ০। সুতরাং, k = ০ বা ৩।


প্রশ্ন ৩১. দুটি সংখ্যার যোগফল ৬০ এবং বিয়োগফল ১২। ছোট সংখ্যাটি কত?
A. ২৪

প্রশ্ন ১৫০. p⁴ - q⁴ কে p - q দ্বারা ভাগ করলে ভাগফল কত হবে?
A. p³ - q³
B. p³ + q³
C. (p + q)(p² + q²)
D. (p - q)(p² + q²)
উত্তর: C
ব্যাখ্যা:
p⁴ - q⁴ = (p - q)(p + q)(p² + q²)। p - q দিয়ে ভাগ করলে থাকে (p + q)(p² + q²)।
