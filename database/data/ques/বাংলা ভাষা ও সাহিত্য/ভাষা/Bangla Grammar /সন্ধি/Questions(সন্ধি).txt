১. 'সন্ধি' শব্দের অর্থ কী? ক. মিলন খ. বন্ধুত্ব গ. বিচ্ছেদ ঘ. সংযোগ Ans. ক. মিলন ব্যাখ্যা: 'সন্ধি' শব্দের আক্ষরিক অর্থ মিলন, অর্থাৎ দুটি ধ্বনির মিলন।
২. পরস্পর কাছাকাছি ধ্বনি বা বর্ণের মিলনকে বলে- ক. সন্ধি খ. কারক গ. সমাস ঘ. প্রত্যয় Ans. ক. সন্ধি ব্যাখ্যা: পাশাপাশি বা পরস্পর কাছাকাছি দুটি বর্ণ বা ধ্বনির মিলনকে সন্ধি বলে।
৩. কোনটিকে সন্ধির সংজ্ঞা বলা হয়? ক. পদে পদে মিলকে খ. ধ্বনিতে ধ্বনিতে মিলকে গ. শব্দে শব্দে মিলকে ঘ. উপসর্গে শব্দে মিলকে Ans. খ. ধ্বনিতে ধ্বনিতে মিলকে ব্যাখ্যা: ব্যাকরণ অনুযায়ী ধ্বনিতে ধ্বনিতে মিলনই হলো সন্ধি।
৪. উচ্চারণে সুবিধা হলেও ধ্বনিমাধুর্যতা থাকে না, সেখানে কী করতে নেই? ক. সন্ধি খ. সমাস গ. প্রত্যয় ঘ. ণত্ব ও ষত্ব বিধান Ans. ক. সন্ধি ব্যাখ্যা: যেখানে ধ্বনিমাধুর্যতা নষ্ট হয়, সেখানে সন্ধি করা উচিত নয়।
৫. সন্ধির প্রধান সুবিধা কী? ক. উচ্চারণের সুবিধা খ. শোনার সুবিধা গ. লেখার সুবিধা ঘ. পড়ার সুবিধা Ans. ক. উচ্চারণের সুবিধা ব্যাখ্যা: সন্ধির মূল উদ্দেশ্য বা প্রধান সুবিধা হলো দ্রুত ও সহজে উচ্চারণ করা।
৬. সন্ধির উদ্দেশ্য কোনটি? ক. শব্দের মিলন খ. শব্দগত মাধুর্য সৃষ্টি গ. ধ্বনিগত মাধুর্য সৃষ্টি ঘ. বর্ণের মিল Ans. গ. ধ্বনিগত মাধুর্য সৃষ্টি ব্যাখ্যা: উচ্চারণের স্বাচ্ছন্দ্য ও ধ্বনিগত মাধুর্য আনয়ন করা সন্ধির অন্যতম উদ্দেশ্য।
৭. কোন বাংলা পদের সাথে সন্ধি হয় না? ক. বিশেষ্য খ. বিশেষণ গ. ক্রিয়া ঘ. অব্যয় Ans. ঘ. অব্যয় ব্যাখ্যা: বাংলা অব্যয় পদের সাথে সাধারণত সন্ধি হয় না।
৮. 'বক + কচ্ছপ = বকচ্ছপ' এই রীতিতে গঠিত শব্দকে বলা হয়- ক. সন্ধিবদ্ধ শব্দ খ. জোড়কলম শব্দ গ. মিশ্র শব্দ ঘ. নিপাতনে সিদ্ধ শব্দ Ans. খ. জোড়কলম শব্দ ব্যাখ্যা: 'বকচ্ছপ' (বক + কচ্ছপ) রূপকথা বা সুকুমার রায়ের সাহিত্যরীতিতে দুটি স্বতন্ত্র শব্দের অংশ বিশেষ জোড়া দিয়ে গঠিত 'জোড়কলম শব্দ' (Portmanteau Word), এটি সাধারণ সন্ধিসাধিত শব্দ নয়।
৯. ব্যাকরণ অনুযায়ী খাঁটি বাংলা সন্ধি কয় প্রকার? ক. ৩ প্রকার খ. ৪ প্রকার গ. ২ প্রকার ঘ. ৭ প্রকার Ans. গ. ২ প্রকার। ব্যাখ্যা: খাঁটি বাংলা সন্ধি ২ প্রকার (বাংলা স্বরসন্ধি ও বাংলা ব্যঞ্জনসন্ধি)।
১০. সন্ধি কত প্রকার? ক. ২ খ. ৩ গ. ৪ ঘ. ৫ Ans. খ. ৩। ব্যাখ্যা: সাধারণ সন্ধি ৩ প্রকার (স্বরসন্ধি, ব্যঞ্জনসন্ধি ও বিসর্গসন্ধি)।
১১. 'অত্যধিক'-এর সন্ধি বিচ্ছেদ করুন : ক. অতি + ধিক খ. অত্যাগ + অধিক গ. অতি + অধিক ঘ. অ + তাধিক Ans. গ ব্যাখ্যা: ই-কার/ঈ-কারের পর ই/ঈ ভিন্ন অন্য স্বরধ্বনি থাকলে ই/ঈ স্থানে 'য' (বা 'য'-ফলা) হয়, তাই অতি + অধিক = অত্যধিক।
১২. অতি + অধিক = ক. অত্যাধিক খ. অতো্যধিক গ. অত্যধিক ঘ. ওত্যোধিক Ans. গ ব্যাখ্যা: ই + অ = য + অ (য-ফলা), ফলে অতি + অধিক = অত্যধিক।
১৩. 'অত্যন্ত' এর সন্ধি বিচ্ছেদ কোনটি? ক. অতি + অন্ত খ. অতী + অন্ত গ. অতৎ + অন্ত ঘ. অত + অন্ত Ans. ক ব্যাখ্যা: অতি + অন্ত = অত্যন্ত (ই + অ = য-ফলা)।
১৪. 'অন্বেষণ' এর সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. অম্বে + ষণ খ. অনেঃ + এষণ গ. অনু + এষন ঘ. অনু + এষণ Ans. ঘ ব্যাখ্যা: উ-কার/ঊ-কারের পর উ/ঊ ভিন্ন অন্য স্বরধ্বনি থাকলে উ/ঊ স্থানে 'ব' (ব-ফলা) হয়, ফলে অনু + এষণ = অন্বেষণ।
১৫. কোনটি শুদ্ধ বানান? ক. অন্বেষণ খ. অন্বেষন গ. অন্বৈষণ ঘ. অন্বেশন Ans. ক. অন্বেষণ ব্যাখ্যা: অনু + এষণ = অন্বেষণ, এটিই মূর্ধন্য-ণ যুক্ত সঠিক শব্দরূপ।
১৬. 'অন্বিত' শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি হবে? ক. অনু + ইত খ. অনু + নিত গ. অনু + ঈত ঘ. অনু + বিত Ans. ক ব্যাখ্যা: অনু + ইত = অন্বিত (উ + ই = ব-ফলা + ই)।
১৭. 'অভীষ্ট' এর সন্ধি বিচ্ছেদ কি? ক. অভি + ইষ্ট খ. অভি + রিষ্ট গ. অভী + ইষ্ট ঘ. অভি + রিষ্ট Ans. ক ব্যাখ্যা: ই-কার + ই-কার মিলে দীর্ঘ ঈ-কার হয় (ই + ই = ঈ), তাই অভি + ইষ্ট = অভীষ্ট।
১৮. সন্ধি বিচ্ছেদ করুন : অর্ধেক = ক. আধা + এক খ. অর্ধ + এক গ. অর্ধ্বে + এক ঘ. অর্ধ + ক Ans. ক. আধা + এক ব্যাখ্যা: এটি খাঁটি বাংলা স্বরসন্ধির নিয়ম। আ-কার + এ-কার মিলে এ-কার হয় (পূর্ববর্তী 'আ' লোপ পায়), তাই আধা + এক = অর্ধেক।
১৯. সন্ধি বিচ্ছেদ করুন : ইত্যাদি। ক. ইতি + দি খ. ইতি + আদি গ. ইত + তাদি ঘ. ইতি + অদি Ans. খ ব্যাখ্যা: ই + আ = য-ফলা + আ, তাই ইতি + আদি = ইত্যাদি।
২০. 'উপর্যুক্ত' - এর সন্ধি বিচ্ছেদ কোনটি শুদ্ধ? ক. উপরি + উক্ত খ. উপর + উক্তি গ. উপ + যুতে ঘ. উপর + যুক্ত Ans. ক ব্যাখ্যা: উপরি + উক্ত = উপর্যুক্ত (ই + উ = য-ফলা + উ)।
২১. 'উপরি + উক্ত' মিলে কোন শব্দ গঠিত হয়? ক. উপরিক্ত খ. উপর্যুক্ত গ. উপরুক্ত ঘ. উপরোক্ত Ans. খ ব্যাখ্যা: উপরি + উক্ত মিলে উপর্যুক্ত গঠিত হয় (ই + উ = য-ফলা + উ)।
২২. সন্ধি বিচ্ছেদ কর : উপর্যুপরি ক. উপরি + উপরি খ. উপর্য + পরি গ. উপ + র্যুপরি ঘ. উপ + উপরি Ans. ক ব্যাখ্যা: উপরি + উপরি = উপর্যুপরি (ই + উ = য-ফলা + উ)।
২৩. 'কটাক্ষ' শব্দের সন্ধি বিচ্ছেদ - ক. কটু + অক্ষ খ. কটা + অক্ষ গ. কট + ক্ষ ঘ. কট + অক্ষ Ans. ঘ ব্যাখ্যা: অ-কার + অ-কার মিলে আ-কার হয় (অ + অ = আ), ফলে কট + অক্ষ = কটাক্ষ।
২৪. 'কথোপকথন' শব্দটি কি রীতিতে গঠিত? ক. উপসর্গযোগে খ. সন্ধিযোগে গ. প্রত্যয়যোগে ঘ. সমাসযোগে Ans. খ ব্যাখ্যা: কথা + উপকথন = কথোপকথন (আ + উ = ও-কার), তাই এটি সন্ধিযোগে গঠিত।
২৫. কোনটি 'ক্ষুধার্ত' শব্দের সন্ধি বিচ্ছেদ? ক. ক্ষুৎ + আর্ত খ. ক্ষুধা + আর্ত গ. ক্ষুধা + ঋত ঘ. ক্ষুধ + আর্ত Ans. গ ব্যাখ্যা: ঋত শব্দ পরে থাকলে অ/আ এর স্থানে 'আর' হয়, ফলে ক্ষুধা + ঋত = ক্ষুধার্ত।
২৬. 'গতানুগতিক' এর সন্ধি বিচ্ছেদ কোনটি? ক. গত + আনুগতিক খ. গতা + অনুগতিক গ. গত + অনুগতিক ঘ. গতানু + গতিক ঙ. গতা + আনুগতিক Ans. গ ব্যাখ্যা: অ-কার + অ-কার মিলে আ-কার হয় (অ + অ = আ), তাই গত + অনুগতিক = গতানুগতিক।
২৭. 'গবেষণা' শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. গব + এষণা খ. গবেষ + এষণা গ. গৌ + এষণা ঘ. গো + এষণা Ans. ঘ ব্যাখ্যা: ও-কারের পর অন্য স্বরধ্বনি থাকলে ও-কারের স্থানে 'অব' হয়, তাই গো + এষণা = গবেষণা।
২৮. 'গবাদি' শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. গবা + আদি খ. গো + আবাদি গ. গো + আদি ঘ. গবা + দি Ans. গ ব্যাখ্যা: গো + আদি = গবাদি (ও-কার + অন্য স্বরধ্বনি = অব)।
২৯. 'গায়ক' শব্দের সন্ধি বিচ্ছেদ - ক. গা + অক খ. গায় + অক গ. গৈ + অক ঘ. গৌ + অক Ans. গ ব্যাখ্যা: ঐ-কারের পর অন্য স্বরধ্বনি থাকলে ঐ-কারের স্থানে 'আয়' হয়, তাই গৈ + অক = গায়ক।
৩০. 'গুরূক্তি' এর সন্ধি বিচ্ছেদ কোনটি? ক. গুরু + যুক্তি খ. গুরূ + উক্তি গ. গুরু + উক্তি ঘ. গুরু + ঊক্তি Ans. গ. গুরু + উক্তি ব্যাখ্যা: হ্রস্ব উ-কার + হ্রস্ব উ-কার মিলে দীর্ঘ ঊ-কার হয় (উ + উ = ঊ), তাই গুরু + উক্তি = গুরূক্তি।
৩১. কোনটি শুদ্ধ? ক. মরু + উদ্যান = মরুদ্যান খ. পরি + পরীক্ষা = পরীক্ষা গ. গঙ্গা + ঊর্মি = গঙ্গোর্মি ঘ. প্রতি + উষ = প্রত্যুষ Ans. গ ব্যাখ্যা: আ-কার + ঊ-কার মিলে ও-কার হয় (আ + ঊ = ও), তাই গঙ্গা + ঊর্মি = গঙ্গোর্মি।
৩২. 'ঘ্রাণ' শব্দটির সঠিক প্রকৃতি-প্রত্যয় বিচ্ছেদ কোনটি? ক. ঘ্রাণ + অ খ. ঘ্রা + অন গ. ঘ্রৃ + আ + ন ঘ. ঘৃ + অন Ans. খ. ঘ্রা + অন ব্যাখ্যা: 'ঘ্রাণ' শব্দটি কোনো সাধারণ সন্ধিসাধিত শব্দ নয়; এটি কৃৎ প্রত্যয়সাধিত শব্দ (ধাতু 'ঘ্রা' + প্রত্যয় 'অন')।
৩৩. 'ছেলেমি' শব্দের সঠিক সন্ধি বিচ্ছেদ করুন : ক. ছে + লেমি খ. ছেলে + মি গ. ছেলে + আমি ঘ. ছে + এলেমি Ans. গ ব্যাখ্যা: এটি খাঁটি বাংলা স্বরসন্ধি, ছেলে + আমি = ছেলেমি।
৩৪. 'জনৈক' শব্দের সন্ধি বিচ্ছেদ - ক. জন + ঐক খ. জন + এক গ. জনে + এক ঘ. জন + অক Ans. খ ব্যাখ্যা: অ-কার + এ-কার মিলে ঐ-কার হয় (অ + এ = ঐ), তাই জন + এক = জনৈক।
৩৫. 'জলৌকা' শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. জল + একা খ. জলো + ঐকা গ. জল + ওকা ঘ. জল + ঔকা Ans. গ ব্যাখ্যা: অ-কার + ও-কার মিলে ঔ-কার হয় (অ + ও = ঔ), তাই জল + ওকা = জলৌকা।
৩৬. জাতি + অভিমান - ক. জাত্যাভিমান খ. জাত্যভিমান গ. জাতিভিমান ঘ. জাতভিমান Ans. খ ব্যাখ্যা: ই + অ = য-ফলা, তাই জাতি + অভিমান = জাত্যভিমান।
৩৭. 'জমানো' শব্দটির সঠিক বিশ্লেষণ কোনটি? ক. জমান + ও খ. জমা + ন গ. জমা + নো ঘ. জম্ + আনো Ans. ঘ. জম্ + আনো ব্যাখ্যা: 'জমানো' শব্দটি সন্ধিসাধিত নয়; এটি প্রযোজক ধাতু বা নামধাতু থেকে উৎপন্ন কৃৎ প্রত্যয়সাধিত শব্দ (ধাতু 'জম্' + প্রত্যয় 'আনো')।
৩৮. ঢাকা + ঈশ্বরী = ঢাকেশ্বরী - কোন নিয়মে এ সন্ধি হয়েছে? ক. আ + ঈ = এ খ. অ + ঈ = এ গ. আ + ই = এ ঘ. অ + ই = এ Ans. ক ব্যাখ্যা: ঢাকা (আ) + ঈশ্বরী (ঈ) = ঢাকেশ্বরী (এ), অর্থাৎ আ + ঈ = এ নিয়ম।
৩৯. তৃষ্ণার্ত - এর সন্ধি বিচ্ছেদ কোনটি? ক. তৃষ্ণা + আর্ত খ. তৃষ্ণা + ঋত গ. তৃষ্ণা + ঘর্ত ঘ. তৃষ্ণা + রিত Ans. খ ব্যাখ্যা: ঋত শব্দ পরে থাকলে অ/আ এর স্থানে 'আর' হয়, তাই তৃষ্ণা + ঋত = তৃষ্ণার্ত।
৪০. 'তন্বী' শব্দের কোনটি সঠিক সন্ধি বিচ্ছেদ? ক. তন্ + ঈ খ. তন্ব + ই গ. তনু + ই ঘ. তনু + ঈ Ans. ঘ ব্যাখ্যা: উ + ঈ = ব-ফলা + ঈ, তাই তনু + ঈ = তন্বী।
৪১. দেবালয়ের সন্ধি বিচ্ছেদ কোনটি? ক. দেব + আলয় খ. দেবা + আলয় গ. দেবা + লয় ঘ. দেব + লয় Ans. ক ব্যাখ্যা: অ-কার + আ-কার মিলে আ-কার হয় (অ + আ = আ), তাই দেব + আলয় = দেবালয়।
৪২. 'দৃষ্টান্ত' শব্দটির সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. দৃষ্টি + অন্ত খ. দৃষ্টি + আন্ত গ. দৃষ্ট + আন্ত ঘ. দৃষ্ট + অন্ত Ans. ঘ. দৃষ্ট + অন্ত ব্যাখ্যা: অ-কার + অ-কার মিলে আ-কার হয় (অ + অ = আ)। তাই দৃষ্ট + অন্ত = দৃষ্টান্ত। ('দৃষ্টি + অন্ত' হলে তা হতো 'দৃষ্ট্যন্ত')।
৪৩. 'দ্বৈপায়ন' শব্দের শুদ্ধ সন্ধি বিচ্ছেদ কোনটি? ক. দ্বীপ + আয়ণ খ. দ্বীপ + অয়ন গ. দ্বিপ + অনট ঘ. দ্বীপ + অনট Ans. খ. দ্বীপ + অয়ন ব্যাখ্যা: দ্বীপ + অয়ন = দ্বৈপায়ন; এটি নিপাতনে সিদ্ধ স্বরসন্ধির উদাহরণ।
৪৪. 'দৈনিক' শব্দটির সঠিক বিশ্লেষণ কোনটি? ক. দৈ + নিক খ. দে + নিক গ. দৈঃ + এক ঘ. দিন + ইক Ans. ঘ. দিন + ইক ব্যাখ্যা: 'দৈনিক' (দিন + ইক) শব্দটি মূল প্রাকৃতি ও তদ্ধিত প্রত্যয়সাধিত শব্দ, এটি সাধারণ সন্ধিসাধিত শব্দ নয়।
৪৫. ' ধর্মাধর্ম' শব্দটির সন্ধি বিচ্ছেদ হলো - ক. ধর্ম + অধর্ম খ. ধর্মা + ধর্ম গ. ধর্ম + আ + ধর্ম ঘ. ধর্ম + অদধর্ম Ans. ক ব্যাখ্যা: অ-কার + অ-কার মিলে আ-কার হয় (অ + অ = আ), তাই ধর্ম + অধর্ম = ধর্মাধর্ম।
৪৬. 'নাবিক' শব্দের সন্ধি বিচ্ছেদ - ক. ন + ইক খ. নবৌ + ইক গ. নৌ + ইক ঘ. নবো + ইক Ans. গ ব্যাখ্যা: ঔ-কারের পর অন্য স্বরধ্বনি থাকলে ঔ-কারের স্থানে 'আব' হয়, তাই নৌ + ইক = নাবিক।
৪৭. 'নায়ক' এর সন্ধি বিচ্ছেদ কোনটি? ক. না + যক খ. নৈ + অক গ. নৌ + অক ঘ. নৈ + আক Ans. খ ব্যাখ্যা: ঐ-কারের পর অন্য স্বরধ্বনি থাকলে ঐ-কারের স্থানে 'আয়' হয়, তাই নৈ + অক = নায়ক।
৪৮. সন্ধি বিচ্ছেদ করুন : 'নরাধম' - ক. নর + আধম খ. নর + অধম গ. নর + ধম ঘ. নরধ + ম Ans. খ ব্যাখ্যা: অ-কার + অ-কার মিলে আ-কার হয় (অ + অ = আ), তাই নর + অধম = নরাধম।
৪৯. 'নবোঢ়া' শব্দের সন্ধি বিচ্ছেদ - ক. নব + উঢ়া খ. নব + ঊঢ়া গ. নবো + উঢ়া ঘ. নবো + উড়া Ans. খ ব্যাখ্যা: অ-কার + ঊ-কার মিলে ও-কার হয় (অ + ঊ = ও), তাই নব + ঊঢ়া = নবোঢ়া।
৫০. সন্ধিযোগে গঠিত শব্দ - ক. নীলোৎপল খ. বিপদাপন্ন গ. ফুলেল ঘ. পরাজয় Ans. ক ব্যাখ্যা: নীল + উৎপল = নীলোৎপল (অ + উ = ও-কার), এটি স্বরসন্ধিযোগে গঠিত।
৫১. 'পানির' শব্দটির খাঁটি বাংলা সন্ধি বিচ্ছেদ কোনটি? ক. পানি + এর খ. পানি + র গ. পন + ইর ঘ. পানি + আর Ans. ক. পানি + এর ব্যাখ্যা: খাঁটি বাংলা স্বরসন্ধির নিয়মে ই-কারের পর এ-কার থাকলে ই-কার বহাল থাকে এবং এ-কার লোপ পেয়ে 'র' যুক্ত হয় (পানি + এর = পানির)।
৫২. 'পবিত্র' শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. প + বিত্র খ. প + অবিত্র গ. পো + ইত্র ঘ. পো + অবিত্র Ans. গ ব্যাখ্যা: ও-কারের পর অন্য স্বরধ্বনি থাকলে ও-কারের স্থানে 'অব' হয়, তাই পো + ইত্র = পবিত্র।
৫৩. 'পাগলামি' শব্দের সন্ধি বিচ্ছেদ করলে পাওয়া যায় - ক. পাগল + লামি খ. পাগল + মি গ. পাগল + আমি ঘ. পাগল + মি Ans. গ ব্যাখ্যা: এটি খাঁটি বাংলা স্বরসন্ধি, পাগল + আমি = পাগলামি।
৫৪. 'পাবক' কোন সন্ধির উদাহরণ? ক. স্বরসন্ধি খ. ব্যঞ্জন সন্ধি গ. বিসর্গ সন্ধি ঘ. নিপাতনে সিদ্ধ Ans. ক ব্যাখ্যা: পৌ + অক = পাবক (ঔ + অ = আব), এটি স্বরসন্ধির উদাহরণ।
৫৫. 'পর্যন্ত' শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. পর্য + ন্ত খ. পরি + অন্ত গ. পর্চ + অন্ত ঘ. প + যন্ত Ans. খ ব্যাখ্যা: ই + অ = য-ফলা, তাই পরি + অন্ত = পর্যন্ত।
৫৬. 'ব্যর্থ' শব্দটির সন্ধি বিচ্ছেদ হলো - ক. বি + আর্থ খ. ব্য + অর্থ গ. বি + অর্থ ঘ. ব্যা + অর্থ Ans. গ ব্যাখ্যা: ই + অ = য-ফলা, তাই বি + অর্থ = ব্যর্থ।
৫৭. 'বহ্ন্যুৎসব' শব্দটির সন্ধি বিচ্ছেদ করলে পাই - ক. বহ্ন্যু + উৎসব খ. বহ্ন্য + উৎসব গ. বহ্য + উৎসব ঘ. বহ্নি + উৎসব Ans. ঘ ব্যাখ্যা: ই + উ = য-ফলা + উ, তাই বহ্নি + উৎসব = বহ্ন্যুৎসব।
৫৮. 'বিদ্যালয়' এর সন্ধি বিচ্ছেদ - ক. বিদ্যা + আলয় খ. বিদ্য + আলয় গ. বিদ্যা + লয় ঘ. বিদ + আলয় Ans. ক ব্যাখ্যা: আ-কার + আ-কার মিলে আ-কার হয় (আ + আ = আ), তাই বিদ্যা + আলয় = বিদ্যালয়।
৫৯. কোনটি স্বরসন্ধির উদাহরণ? ক. গিজন্ত খ. অহরহ গ. বিদ্যালয় ঘ. দুশ্চিন্তা Ans. গ ব্যাখ্যা: বিদ্যা + আলয় = বিদ্যালয় (আ + আ = আ), এটি স্বরসন্ধির উদাহরণ।
৬০. 'বনৌষধি' শব্দের সঠিক সন্ধি বিচ্ছেদ - ক. বন + ওষধি খ. বন্ + ওষধি গ. বন + ঔষধি ঘ. বনঃ + ওষধি Ans. ক ব্যাখ্যা: অ-কার + ও-কার মিলে ঔ-কার হয় (অ + ও = ঔ), তাই বন + ওষধি = বনৌষধি।
৬১. 'ভূর্ধ্ব' এর সন্ধি বিচ্ছেদ কি? ক. ভূ + উর্ধ্ব খ. ভূ + ঊর্ধ্ব গ. ভূ + র্ধ ঘ. ভূদ + ঊর্ধ্ব Ans. খ. ভূ + ঊর্ধ্ব ব্যাখ্যা: ঊ-কার + ঊ-কার মিলে দীর্ঘ ঊ-কার হয় (ঊ + ঊ = ঊ), তাই ভূ + ঊর্ধ্ব = ভূর্ধ্ব।
৬২. 'ভাবুক' শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. ভৌ + উক খ. ভো + উক গ. ভাব + উক ঘ. ভৌ + অক Ans. ক ব্যাখ্যা: ঔ-কারের পর অন্য স্বরধ্বনি থাকলে ঔ-কারের স্থানে 'আব' হয়, তাই ভৌ + উক = ভাবুক।
৬৩. 'মহৌষধি' শব্দের সঠিক সন্ধি কোনটি? ক. মহা + ঔষধি খ. মহ + ঔষধি গ. মহাঃ + ঔষধি ঘ. মহা + ওষধি Ans. ঘ ব্যাখ্যা: আ-কার + ও-কার মিলে ঔ-কার হয় (আ + ও = ঔ), তাই মহা + ওষধি = মহৌষধি।
৬৪. 'মরূদ্যান' শব্দের সন্ধি বিচ্ছেদ - ক. মরু + দ্যান খ. মরু + উদ্যান গ. মরূ + উদ্যান ঘ. মরু + ঊদ্যান Ans. খ. মরু + উদ্যান ব্যাখ্যা: হ্রস্ব উ-কার + হ্রস্ব উ-কার মিলে দীর্ঘ ঊ-কার হয় (উ + উ = ঊ), তাই মরু + উদ্যান = মরূদ্যান।
৬৫. 'মাত্রাধিক্য' শব্দটির সন্ধি বিচ্ছেদ কী রকম? ক. মাতৃ + আধিক্য খ. মাত্র + অধিক গ. মাত্র + আধিক্য ঘ. মাত্রা + আধিক্য Ans. ঘ ব্যাখ্যা: আ-কার + আ-কার মিলে আ-কার হয় (আ + আ = আ), তাই মাত্রা + আধিক্য = মাত্রাধিক্য।
৬৬. 'মহৈশ্বর্য' এর সন্ধি বিচ্ছেদ কোনটি? ক. মহা + ঐশ্বর্য খ. মহ + ঐশ্বর্য গ. মহৈ + ঐশ্বর্য ঘ. মহো + ঐশ্বর্য Ans. ক ব্যাখ্যা: আ-কার + ঐ-কার মিলে ঐ-কার হয় (আ + ঐ = ঐ), তাই মহা + ঐশ্বর্য = মহৈশ্বর্য।
৬৭. 'মতৈক্য' শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. মতঃ + এক খ. মতঃ + ঐক্য গ. মত + এক ঘ. মত + ঐক্য Ans. ঘ ব্যাখ্যা: অ-কার + ঐ-কার মিলে ঐ-কার হয় (অ + ঐ = ঐ), তাই মত + ঐক্য = মতৈক্য।
৬৮. 'মন্বন্তর' শব্দের সন্ধি বিচ্ছেদ - ক. মন + অন্তর খ. মনন + তর গ. মনু + অন্তর ঘ. মন্বণ + তর Ans. গ ব্যাখ্যা: উ + অ = ব-ফলা, তাই মনু + অন্তর = মন্বন্তর।
৬৯. 'মাথায়' শব্দটির সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. মাথা + আয় খ. মাথা + য় গ. মাথা + অয় ঘ. মাথা + এ Ans. ঘ ব্যাখ্যা: এটি খাঁটি বাংলা সন্ধির নিয়ম, মাথা + এ = মাথায়।
৭০. 'মস্যাধার' শব্দের সন্ধি বিচ্ছেদ কর - ক. মস্যা + আধার খ. মসা + আধার গ. মসী + আধার ঘ. মসিয় + আধার Ans. গ ব্যাখ্যা: ঈ + আ = য-ফলা + আ, তাই মসী + আধার = মস্যাধার।
৭১. 'যদ্যপি' শব্দটির সন্ধি বিচ্ছেদ - ক. যদ + পি খ. যদি + অপি গ. যদ + অপি ঘ. যদ্য + অপি Ans. খ ব্যাখ্যা: ই + অ = য-ফলা, তাই যদি + অপি = যদ্যপি।
৭২. 'যাচ্ছেতাই' শব্দটির সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. যাহা + ইচ্ছা + তাহা খ. যাচ্ছে + তাই গ. যা + ইচ্ছা + তাই ঘ. কোনোটিই নয় Ans. গ ব্যাখ্যা: এটি খাঁটি বাংলা সন্ধির রূপ, যা + ইচ্ছা + তাই = যাচ্ছেতাই।
৭৩. নিচের কোন সন্ধি বিচ্ছেদটি সঠিক নয়? ক. মহা + ঋষি = মহর্ষি খ. শীত + ঋত = শীতার্ত গ. যথা + ইষ্ট = যথেস্ট ঘ. যথা + উচিত = যথোচিত Ans. গ ব্যাখ্যা: যথা + ইষ্ট = যথেষ্ট (যথেস্ট বানানটি অশুদ্ধ)।
৭৪. 'রত্নাকর' শব্দটির সন্ধি বিচ্ছেদ - ক. রত্ন + কর খ. রত্ন + অাকর গ. রত্না + আকর ঘ. রত্ন + আকর Ans. ঘ. রত্ন + আকর ব্যাখ্যা: অ-কার + আ-কার মিলে আ-কার হয় (অ + অ = আ), তাই রত্ন + আকর = রত্নাকর।
৭৫. 'রূপালি' এর সন্ধি বিচ্ছেদ - ক. রূপা + আলি খ. রূপ + আলি গ. রূপা + লি ঘ. রূপ + লি Ans. ক ব্যাখ্যা: এটি খাঁটি বাংলা সন্ধির নিয়ম, রূপা + আলি = রূপালি।
৭৬. 'রবীন্দ্র' এর সন্ধি বিচ্ছেদ কি? ক. রবী + ইন্দ্র খ. রবি + ঈন্দ্র গ. রবি + ইন্দ্র ঘ. রব + ইন্দ্র Ans. গ. রবি + ইন্দ্র ব্যাখ্যা: ই-কার + ই-কার মিলে দীর্ঘ ঈ-কার হয় (ই + ই = ঈ), তাই রবি + ইন্দ্র = রবীন্দ্র।
৭৭. কোনটি 'লবণ' এর সন্ধি বিচ্ছেদ? ক. লো + অন খ. ল + অন গ. লে + অন ঘ. ল + বন Ans. ক ব্যাখ্যা: ও-কারের পর অন্য স্বরধ্বনি থাকলে ও-কারের স্থানে 'অব' হয়, তাই লো + অন = লবণ।
৭৮. শীতার্ত - এর সন্ধি বিচ্ছেদ কোনটি? ক. শী + তার্ত খ. শীত + আর্ত গ. শীত + আরত ঘ. শীত + ঋত Ans. ঘ ব্যাখ্যা: ঋত শব্দ পরে থাকলে অ/আ এর স্থানে 'আর' হয়, তাই শীত + ঋত = শীতার্ত।
৭৯. 'শশাঙ্ক' শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. শশ + অঙ্ক খ. শস + অঙ্ক গ. শশা + অঙ্ক ঘ. শম + অঙ্ক Ans. ক ব্যাখ্যা: অ-কার + অ-কার মিলে আ-কার হয় (অ + অ = আ), তাই শশ + অঙ্ক = শশাঙ্ক।
৮০. 'শতেক' শব্দটি কোন ধরনের সন্ধি? ক. বিসর্গ সন্ধি খ. ব্যঞ্জন সন্ধি গ. স্বরসন্ধি ঘ. খাঁটি বাংলা স্বরসন্ধি Ans. ঘ. খাঁটি বাংলা স্বরসন্ধি ব্যাখ্যা: শত + এক = শতেক (অ + এ = এ)। এটি বাংলা সংখ্যাবাচক শব্দের সাথে গঠিত সুনির্দিষ্ট 'খাঁটি বাংলা স্বরসন্ধি'-র উদাহরণ।
৮১. 'শুভেচ্ছা'র সন্ধি বিচ্ছেদ - ক. শু + বেচ্ছা খ. শুভ + ইচ্ছা গ. শুভ + চ্ছা ঘ. শু + ইচ্ছা Ans. খ ব্যাখ্যা: অ-কার + ই-কার মিলে এ-কার হয় (অ + ই = এ), তাই শুভ + ইচ্ছা = শুভেচ্ছা।
৮২. নিচের কোনটি স্বরসন্ধির উদাহরণ? ক. শিক্ষালয় খ. অহরহ গ. দিগন্ত ঘ. ইত্যাদি Ans. ক ব্যাখ্যা: শিক্ষা + আলয় = শিক্ষালয় (আ + আ = আ), যা স্বরসন্ধির একটি স্পষ্ট উদাহরণ।
৮৩. 'সতীশ' শব্দটির সন্ধি বিচ্ছেদ কোনটি? ক. সতি + ইশ খ. সতীশ + অ গ. সতি + ঈশ ঘ. সতী + ঈশ Ans. ঘ ব্যাখ্যা: ঈ-কার + ঈ-কার মিলে দীর্ঘ ঈ-কার হয় (ঈ + ঈ = ঈ), তাই সতী + ঈশ = সতীশ।
৮৪. সন্ধি বিচ্ছেদ করুন : 'সূর্যোদয়' ক. সূর্য + দয় খ. সূর্য + উদয় গ. সূর্যো + দয় ঘ. সূর্যো + উদয় Ans. খ ব্যাখ্যা: অ-কার + উ-কার মিলে ও-কার হয় (অ + উ = ও), তাই সূর্য + উদয় = সূর্যোদয়।
৮৫. 'সুধীন্দ্র' এর সন্ধি বিচ্ছেদ কি? ক. সুধি + ইন্দ্র খ. সুধী + ঈন্দ্র গ. সুধী + ইন্দ্র ঘ. সুধ + ইন্দ্র Ans. গ. সুধী + ইন্দ্র ব্যাখ্যা: ঈ-কার + ই-কার মিলে দীর্ঘ ঈ-কার হয় (ঈ + ই = ঈ), তাই সুধী + ইন্দ্র = সুধীন্দ্র।
৮৬. 'সতীন্দ্র' শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি হবে? ক. সতি + ইন্দ্র খ. সতী + ঈন্দ্র গ. সতী + ইন্দ্র ঘ. সতী + ন্দ্র Ans. গ. সতী + ইন্দ্র ব্যাখ্যা: ঈ-কার + ই-কার মিলে দীর্ঘ ঈ-কার হয় (ঈ + ই = ঈ), তাই সতী + ইন্দ্র = সতীন্দ্র।
৮৭. 'স্বেচ্ছা' শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. সে + চ্ছা খ. স্ব + ঈচ্ছা গ. স্ব + ইচ্ছা ঘ. স্বৈ + চ্ছা Ans. গ. স্ব + ইচ্ছা ব্যাখ্যা: অ-কার + ই-কার মিলে এ-কার হয় (অ + ই = এ), তাই স্ব + ইচ্ছা = স্বেচ্ছা।
৮৮. 'স্বাগত' এর সন্ধি বিচ্ছেদ কি? ক. সু + আগত খ. স্বা + গত গ. সু + গত ঘ. সা + আগত Ans. ক ব্যাখ্যা: উ + আ = ব-ফলা + আ, তাই সু + আগত = স্বাগত।
৮৯. 'স্বাধীন' শব্দটির সন্ধি বিচ্ছেদ কোনটি? ক. স + অধিন খ. শ + অধিন গ. স্ব + অধিন ঘ. স্ব + অধীন Ans. ঘ ব্যাখ্যা: অ-কার + অ-কার মিলে আ-কার হয় (অ + অ = আ), তাই স্ব + অধীন = স্বাধীন।
৯০. 'হিতৈষী' শব্দের সন্ধি-বিচ্ছেদ? ক. হিতেঃ + ষী খ. হিত + এষী গ. হিতঃ + এষী ঘ. হিত + ঐষী Ans. খ. হিত + এষী ব্যাখ্যা: অ-কারের পর এ-কার থাকলে উভয়ে মিলে ঐ-কার হয় (অ + এ = ঐ)। তাই হিত + এষী = হিতৈষী।
৯১. কোনটি স্বরসন্ধির উদাহরণ? ক. হিমালয় খ. অহরহ গ. সংসার ঘ. বনস্পতি Ans. ক ব্যাখ্যা: হিম + আলয় = হিমালয় (অ + আ = আ), এটি স্বরসন্ধি।
৯২. 'হিমাচল' শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. হিমা + আচল খ. হিম + আচল গ. হিম + আঁচল ঘ. হিমা + আচঁল ঙ. হিম + অচল Ans. ঙ. হিম + অচল ব্যাখ্যা: হিম + অচল = হিমাচল (অ + অ = আ)।
৯৩. নিচের কোনটি ভুল সন্ধি বিচ্ছেদ? ক. স্ব + অল্প = স্বল্প খ. রবি + ইন্দ্র = রবীন্দ্র গ. পরি + পরীক্ষা = পরীক্ষা ঘ. ইত + আদি = ইত্যাদি Ans. ক ব্যাখ্যা: সু + অল্প = স্বল্প হয় (উ + অ = ব-ফলা), তাই 'স্ব + অল্প' বিচ্ছেদটি ভুল।
৯৪. নিচের কোন সন্ধি শুদ্ধ নয়? ক. জ্যোতিঃ + ইন্দ্র = জ্যোতিরিন্দ্র খ. বি + ছেদ = বিচ্ছেদ গ. উপরি + উক্ত = উপরোক্ত ঘ. মহা + একত্ব = মহৈকত্ব Ans. গ ব্যাখ্যা: উপরি + উক্ত = উপর্যুক্ত শুদ্ধ; উপরোক্ত শব্দটি ব্যাকরণগতভাবে অসিদ্ধ।
৯৫. নিচের কোন স্বরসন্ধি অশুদ্ধ? ক. পূর্ণ + বিন্দু = পূর্ণেন্দু খ. প্রতি + আগমন = প্রত্যাগমন গ. কটু + উক্তি = কটুক্তি ঘ. তথা + এব = তথৈব Ans. গ ব্যাখ্যা: কটু + উক্তি = কটূক্তি (উ + উ = দীর্ঘ ঊ-কার), তাই কটুক্তি বানানটি অশুদ্ধ।
৯৬. নিচের কোন সন্ধি বিচ্ছেদ অশুদ্ধ? ক. হিম + অচল = হিমাচল খ. এক + এক = একেক গ. কথা + উপকথন = কথোপকথন ঘ. মন + অন্তর = মন্বন্তর Ans. ঘ ব্যাখ্যা: মনু + অন্তর = মন্বন্তর, তাই মন + অন্তর বিচ্ছেদটি অশুদ্ধ।
৯৭. 'অলংকার' শব্দের সঠিক সন্ধিজাত বিশ্লেষণ কোনটি? ক. অলম্ + কার খ. অলং + কার গ. অ + লঙ্কার ঘ. অলঙ্ক + কার Ans. ক ব্যাখ্যা: সম্‌/অলమ్‌-এর পর ক-বর্গীয় ধ্বনি থাকলে ম্ স্থানে ঙ বা অনুস্বার হয়, তাই অলম্ + কার = অলংকার।
৯৮. 'অহংকার' শব্দের সন্ধি বিচ্ছেদ - ক. আহঃ + কার খ. অহম্ + কার গ. অহং + কার ঘ. আহ + কার Ans. খ. অহম্ + কার ব্যাখ্যা: অহম্ + কার = অহংকার (ম্-এর পর ক-বর্গীয় ধ্বনি থাকলে ম্ স্থানে অনুস্বার হয়)।
৯৯. কোনটি সঠিক সন্ধি বিচ্ছেদ? ক. উৎ + শ্বাস = উচ্ছ্বাস খ. উৎ + ডীন = উড্ডীন গ. বৃহৎ + ঢক্কা = হক্কা ঘ. বল্ + ধ = লব্ধ Ans. খ ব্যাখ্যা: উৎ + ডীন = উড্ডীন (ত্-এর পর ড্ থাকলে ত্ স্থানে ড্ হয়)।
১০০. 'উচ্ছেদ'- শব্দটির সন্ধি বিচ্ছেদ কোনটি? ক. উছ + ছেদ খ. উৎ + ছেদ গ. উদ + ছেদ ঘ. উত + ছেদ Ans. খ ব্যাখ্যা: ত্/দ্-এর পর ছ্ থাকলে ত্/দ্ স্থানে চ্ হয়, তাই উৎ + ছেদ = উচ্ছেদ।




১০১. নিচের কোনটি ব্যঞ্জনসন্ধির উদাহরণ? ক. ভবন খ. উচ্ছেদ গ. অতএব ঘ. দুস্তর Ans. খ ব্যাখ্যা: উৎ + ছেদ = উচ্ছেদ, এটি ব্যঞ্জনবর্ণ ও ব্যঞ্জনবর্ণের মিলনে গঠিত ব্যঞ্জনসন্ধি।
১০২. 'উল্লাস' এর সন্ধি বিচ্ছেদ - ক. উদ + লাস খ. উদ্ + লাস গ. উল + লাস ঘ. উৎ + লাস Ans. ঘ ব্যাখ্যা: ত্-এর পর ল্ থাকলে ত্ স্থানে ল্ হয়, তাই উৎ + লাস = উল্লাস।
১০৩. উৎ + শ্বাস - এটি কোন সন্ধি? ক. জটিল সন্ধি খ. স্বরসন্ধি গ. ব্যঞ্জন সন্ধি ঘ. নিপাতনে সিদ্ধ Ans. গ ব্যাখ্যা: উৎ + শ্বাস = উচ্ছ্বাস (ত্ + শ্ = চ্ছ), এটি ব্যঞ্জনসন্ধি।
১০৪. 'উজ্জ্বল' শব্দটির সন্ধি বিচ্ছেদ কোনটি? ক. উজ + জ্বল খ. উদ + জল গ. উদ + জল ঘ. উজ্জ + বল ঙ. উৎ + জ্বল Ans. ঙ ব্যাখ্যা: ত্/দ্-এর পর জ্ থাকলে ত্/দ্ স্থানে জ্ হয়, তাই উৎ + জ্বল = উজ্জ্বল।
১০৫. 'উচ্ছ্বাস' শব্দের সন্ধি বিচ্ছেদ হচ্ছে - ক. উত + ছ্বাস খ. উৎ + ছাস গ. উৎ + শ্বাস ঘ. উৎ + চ্ছাস Ans. গ ব্যাখ্যা: ত্-এর পর শ্ থাকলে ত্ স্থানে চ্ এবং শ্ স্থানে ছ্ হয়, তাই উৎ + শ্বাস = উচ্ছ্বাস।
১০৬. 'উচ্ছৃংখল' শব্দটির সন্ধি বিচ্ছেদ - ক. উৎ + শৃঙ্খল খ. উচ + শৃঙ্খল গ. উচ্চ + খল ঘ. উৎ + সৃংখল Ans. ক ব্যাখ্যা: ত্ + শ্ = চ্ছ এবং পরে ঋ-কার যুক্ত হয়ে উচ্ছৃংখল।
১০৭. 'উত্থাপন' শব্দটির সন্ধি বিচ্ছেদ - ক. উৎ + থাপন খ. উৎ + স্থাপন গ. উঃ + স্থাপন ঘ. উঃ + থাপন Ans. খ ব্যাখ্যা: উৎ-উপসর্গের পর স্থাপন শব্দের স্ লোপ পায়, তাই উৎ + স্থাপন = উত্থাপন।
১০৮. 'উত্তমর্ণ'-কে সন্ধি বিচ্ছেদ করলে হয় - ক. উত্তর + মণ খ. উত্তম + ঋণ গ. উত্তর + মর্ণ ঘ. উত্তরম + ণ Ans. খ ব্যাখ্যা: অ-কারের পর ঋণ থাকলে উভয়ে মিলে 'অর্' হয়, তাই উত্তম + ঋণ = উত্তমর্ণ।
১০৯. 'উদ্ধৃত' এর সন্ধি বিচ্ছেদ - ক. উৎ + হৃত খ. উৎ + হত গ. উদ + হত ঘ. উৎ + ঋত Ans. ক ব্যাখ্যা: ত্-এর পর হ্ থাকলে ত্ স্থানে দ্ এবং হ্ স্থানে ধ্ হয়, তাই উৎ + হৃত = উদ্ধৃত।
১১০. 'উদ্ধার' শব্দটির সন্ধি বিচ্ছেদ হবে - ক. উঃ + ধার খ. উৎ + দার গ. উৎ + ধার ঘ. উৎ + হার Ans. ঘ ব্যাখ্যা: ত্ + হ্ = দ্ধ, তাই উৎ + হার = উদ্ধার।
১১১. 'উদ্যোগ' শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. উদ + যোগ খ. উৎ + যোগ গ. উদ্দো + গ ঘ. উত + যোগ Ans. খ ব্যাখ্যা: ত্ + য্ (য-ফলা) মিলে দ্-য বা উদ্যোগ রূপ নেয়, তাই উৎ + যোগ = উদ্যোগ।
১১২. 'উন্নত' শব্দের সন্ধি বিচ্ছেদ হচ্ছে - ক. উৎ + নীত খ. উৎ + নত গ. উন্নী + ত ঘ. উন + নত Ans. খ ব্যাখ্যা: ত্-এর পর ন্ থাকলে ত্ স্থানে ন্ হয়, তাই উৎ + নত = উন্নত।
১১৩. 'উন্নয়ন' এর সন্ধি বিচ্ছেদ - ক. উৎ + নয়ন খ. উন্ন + য়ন গ. উৎ + য়ন ঘ. উৎ + অন Ans. ক ব্যাখ্যা: ত্-এর পর ন্ থাকলে ত্ স্থানে ন্ হয়, তাই উৎ + নয়ন = উন্নয়ন।
১১৪. সন্ধিজাত শব্দ - ক. উন্মনা খ. দখিনা গ. ফাল্গুন ঘ. মিনতি Ans. ক ব্যাখ্যা: উৎ + মনা = উন্মনা (ব্যঞ্জনসন্ধিজাত শব্দ)।
১১৫. বিশেষ নিয়মে সাধিত সন্ধির উদাহরণ - ক. আশ্চর্য খ. উত্থান গ. পরস্পর ঘ. ষষ্ঠ ঙ. বিদ্যালয় Ans. খ ব্যাখ্যা: উৎ + স্থান = উত্থান, এটি বিশেষ নিয়মে সাধিত ব্যঞ্জনসন্ধি।
১১৬. কোনটি 'এদ্দূর' এর সন্ধি বিচ্ছেদ? ক. এ + দূর খ. এত + দূর গ. এৎ + দূর ঘ. এ + দূর Ans. খ ব্যাখ্যা: ত্ + দ্ = দ্দ, তাই এত + দূর = এদ্দূর (বা এতদূর)।
১১৭. সন্ধি বিচ্ছেদ করুন - 'কথাচ্ছলে' ক. কথা + ছলে খ. কোনোটিই নয় গ. কথা + ছদ্ম ঘ. কথা + ছাল Ans. ক ব্যাখ্যা: স্বরবর্ণের পর ছ্ থাকলে ছ্ স্থানে চ্ছ হয়, তাই কথা + ছলে = কথাচ্ছলে।
১১৮. 'কিংবদন্তি' শব্দের সন্ধি বিচ্ছেদ হলো - ক. কিম + দন্তী খ. কিম্ + বদন্তি গ. কিংস + দন্তী ঘ. কিং + বদন্তী Ans. খ ব্যাখ্যা: ম্-এর পর ব্ থাকলে ম্ স্থানে অনুস্বার হয়, তাই কিম্ + বদন্তি = কিংবদন্তি।
১১৯. 'কিন্নর' এর সন্ধি বিচ্ছেদ হলো - ক. কিম + নর খ. কিম + ণর গ. কিম্ + নর ঘ. কিম + ণর Ans. গ ব্যাখ্যা: ম্-এর পর ন্ থাকলে ম্ স্থানে ন্ হয়, তাই কিম্ + নর = কিন্নর।
১২০. কুঞ্ঝটিকা-এর সন্ধি বিচ্ছেদ - ক. কুত + ঝটিকা খ. কুদ + ঝটিকা গ. কুৎ + ঝটিকা ঘ. কুজ + ঝটিকা Ans. গ ব্যাখ্যা: ত্ + ঝ্ = জ্ঝ (বা ঞ্ঝ), তাই কুৎ + ঝটিকা = কুঞ্ঝটিকা।
১২১. কোন বানানটি শুদ্ধ? ক. কুজ্বটিকা খ. কুজ্জটিকা গ. কুঞ্জটিকা ঘ. কুজ্বটীকা Ans. খ ব্যাখ্যা: উৎ/কুৎ + ঝটিকা = কুজ্জটিকা (বা কুঞ্ঝটিকা)। ত্-এর পর ঝ্ থাকলে ত্ স্থানে জ্ হয়。
১২২. 'কৃষ্টি' শব্দটির সন্ধি বিচ্ছেদ - ক. কূস + তি খ. কৃষ + টি গ. কৃষ্ + তি ঘ. কৃষঃ + তি Ans. গ ব্যাখ্যা: ষ্-এর পর ত্ থাকলে ত্ স্থানে ট্ হয়, তাই কৃষ্ + তি = কৃষ্টি। (উল্লেখ্য, এটি মূলগতভাবে √কৃষ্ + তি কৃৎ প্রত্যয়সাধিত শব্দ)।
১২৩. 'কাঁদুনি' শব্দের সন্ধি বিচ্ছেদ হবে - ক. কাঁদ + নি খ. কাঁদো + উনি গ. কাঁদ + ইনি ঘ. কাঁদ্ + উনি Ans. ঘ ব্যাখ্যা: এটি খাঁটি বাংলা শব্দগঠন (কৃৎ প্রত্যয়), কাঁদ্ + উনি = কাঁদুনি।
১২৪. 'কাঁদ্ + না' - এটি কোন সন্ধি? ক. স্বরসন্ধি খ. ব্যঞ্জন সন্ধি গ. খাঁটি বাংলা সন্ধি ঘ. বিসর্গ সন্ধি Ans. খ ব্যাখ্যা: কাঁদ্ + না = কান্না (দ্ + ন্ = ন্ন), এটি ব্যঞ্জনসন্ধির উদাহরণ।
১২৫. 'ক্ষুন্নিবৃত্তি' শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. ক্ষুধা + নিবৃত্তি খ. ক্ষুণ + নিবৃত্তি গ. ক্ষুন্নি + বৃত্তি ঘ. ক্ষুধ্ + নিবৃত্তি Ans. ঘ ব্যাখ্যা: ক্ষুধ্ + নিবৃত্তি = ক্ষুন্নিবৃত্তি (ধ্ + ন্ = ন্ন)।
১২৬. 'ক্ষুৎপিপাসা' শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. ক্ষুধা + পিপাসা খ. ক্ষুত্ + পিপাসা গ. ক্ষুদ্ + পিপাসা ঘ. ক্ষুধ্ + পিপাসা Ans. ঘ ব্যাখ্যা: ক্ষুধ্ + পিপাসা = ক্ষুৎপিপাসা (ঘোষধ্বনি 'ধ্' অঘোষ 'প্'-এর পূর্বে অঘোষ 'ত্/ৎ' রূপ নেয়)।
১২৭. 'চিরুনি' শব্দটির সন্ধি বিচ্ছেদ হচ্ছে - ক. চিরু + নি খ. চির্ + উনি গ. চিরুন + ই ঘ. চিরু + অনি Ans. খ ব্যাখ্যা: এটি খাঁটি বাংলা কৃৎ প্রত্যয়সাধিত শব্দ, চির্ + উনি = চিরুনি।
১২৮. 'চলচ্চিত্র'-এর সন্ধি বিচ্ছেদ - ক. চল + চিত্র খ. চলত + চিত্র গ. চলৎ + চিত্র ঘ. চল + চিত্র Ans. গ ব্যাখ্যা: ত্ + চ্ = চ্চ, তাই চলৎ + চিত্র = চলচ্চিত্র।
১২৯. 'চার্বাক'-এর সন্ধি বিচ্ছেদ কোনটি? ক. চার + বাক খ. চর + বাক গ. চর্ব + বাক ঘ. চারু + বাক্ Ans. ঘ ব্যাখ্যা: উ-কার + স্বরধ্বনিতে চারু + বাক্ = চার্বাক (উ + আ = ব্ + আ)।
১৩০. সন্ধি বিচ্ছেদ কোনটি ঠিক? জগদীশ - ক. জগ + দীশ খ. জগ + ঈশ গ. জগৎ + দীশ ঘ. জগৎ + ঈশ Ans. ঘ ব্যাখ্যা: ত্-এর পর স্বরধ্বনি থাকলে ত্ স্থানে দ্ হয়, তাই জগৎ + ঈশ = জগদীশ।
১৩১. 'জগন্মোহন' এর সন্ধি বিচ্ছেদ - ক. জাদ + মোহন খ. জগৎ + মোহন গ. জাগ + মোহন ঘ. জগম + অহন Ans. খ ব্যাখ্যা: ত্-এর পর ম্ থাকলে ত্ স্থানে ন্ হয়, তাই জগৎ + মোহন = জগন্মোহন।
১৩২. 'জগন্নাথ' শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. জগৎ + নাথ খ. জগম + নাথ গ. জগন + নাথ ঘ. জগদ + নাথ Ans. ক ব্যাখ্যা: ত্-এর পর ন্ থাকলে ত্ স্থানে ন্ হয়, তাই জগৎ + নাথ = জগন্নাথ।
১৩৩. 'ণিজন্ত' - এর সন্ধি বিচ্ছেদ হবে - ক. গিজ + অন্ত খ. ণিচ্ + অন্ত গ. ণিঃ + অন্ত ঘ. ণিথ + অন্ত Ans. খ ব্যাখ্যা: চ্-এর পর স্বরধ্বনি থাকলে চ্ স্থানে জ্ হয়, তাই ণিচ্ + অন্ত = ণিজন্ত।
১৩৪. 'তন্ময়' - এর সন্ধি বিচ্ছেদ কী? ক. তৎ + ময় খ. তন + ময় গ. তিম + ময় ঘ. তহ্ + ময় Ans. ক ব্যাখ্যা: ত্-এর পর ম্ থাকলে ত্ স্থানে ন্ হয়, তাই তৎ + ময় = তন্ময়।
১৩৫. সন্ধি বিচ্ছেদ করুন : 'তদবধি' ক. তদ + বধি খ. তদ + অবধি গ. তদো + বধি ঘ. তৎ + অবধি Ans. ঘ ব্যাখ্যা: ত্-এর পর স্বরধ্বনি থাকলে ত্ স্থানে দ্ হয়, তাই তৎ + অবধি = তদবধি।
১৩৬. সন্ধি বিচ্ছেদ কোনটি ঠিক? তদ্ধিত = ক. তত + হিত খ. তৎ + হিত গ. তৎ + হৃত ঘ. তদ্ + ধিত Ans. খ ব্যাখ্যা: ত্-এর পর হ্ থাকলে ত্ স্থানে দ্ এবং হ্ স্থানে ধ্ হয় (ত্ + হ্ = দ্ধ), তাই তৎ + হিত = তদ্ধিত।
১৩৭. 'তুষ্ট' শব্দটির সন্ধি বিচ্ছেদ - ক. তুষ + ট খ. তুষ্ + ত গ. তুষ + থ ঘ. কোনোটিই নয় Ans. খ ব্যাখ্যা: ষ্-এর পর ত্ থাকলে ত্ স্থানে ট্ হয়, তাই তুষ্ + ত = তুষ্ট। (উল্লেখ্য, এটি মূলগতভাবে √তুষ্ + ত/ক্ত কৃৎ প্রত্যয়)।
১৩৮. 'তাৎক্ষণিক' শব্দের সঠিক বিচ্ছেদ কোনটি? ক. তৎ + ক্ষণিক খ. তাৎ + ক্ষণিক গ. তৎক্ষণ + ইক ঘ. ততক্ষণ + ইক Ans. গ ব্যাখ্যা: 'তাৎক্ষণিক' কোনো সন্ধিসাধিত শব্দ নয়, এটি তদ্ধিত প্রত্যয়সাধিত শব্দ। 'তৎক্ষণ' শব্দের সাথে 'ইক' (ষ্ণিক) প্রত্যয় যুক্ত হয়ে আদি স্বরের বৃদ্ধিতে 'তাৎক্ষণিক' গঠিত হয় (তৎক্ষণ + ইক = তাৎক্ষণিক)।
১৩৯. 'দিগন্ত' - এর সন্ধি বিশ্লেষণ - ক. দিক্ + অন্ত খ. দিগ্ + অন্ত গ. দি + অন্ত ঘ. দিথ্ + অন্ত Ans. ক ব্যাখ্যা: ক্-এর পর স্বরধ্বনি থাকলে ক্ স্থানে গ্ হয়, তাই দিক্ + অন্ত = দিগন্ত।
১৪০. 'দুশ্চার' শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. দুচ + ছার খ. দুৎ + চার গ. দুই + চার ঘ. দুঃ + চার Ans. ঘ ব্যাখ্যা: বিসর্গের পর চ্ থাকলে বিসর্গ স্থানে 'শ্' হয়, তাই দুঃ + চার = দুশ্চার।
১৪১. 'দংশন'-এর সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. দম্ + শন খ. দন্ + শন গ. দং + শন ঘ. দম + শণ Ans. ক ব্যাখ্যা: ম্-এর পর তালব্য 'শ্' থাকলে ম্ স্থানে অনুস্বার (ং) হয়, তাই দম্ + শন = দংশন।
১৪২. 'দর্শক' শব্দের সঠিক সন্ধি বিচ্ছেদ - ক. দ্ + অক খ. দৃষ্ + ঋক গ. দৃশ্ + অক ঘ. দ্ + শক্ Ans. গ ব্যাখ্যা: দৃশ্ + অক = দর্শক। (উল্লেখ্য, এটি √দৃশ্ + অক/ণ্বুল কৃৎ প্রত্যয়সাধিত শব্দ)।
১৪৩. 'দৃশ্য' শব্দের সন্ধি বিচ্ছেদ হলো - ক. দৃশ্ + য খ. দৃশঃ + য গ. দৃশ + ত ঘ. দৃশ + ট Ans. ক ব্যাখ্যা: দৃশ্ + য = দৃশ্য। (উল্লেখ্য, এটি √দৃশ্ + য/ক্যপ্ কৃৎ প্রত্যয়সাধিত শব্দ)।
১৪৪. 'নিরবধি' শব্দটির সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. নির্ + অবধি খ. নির্ + বধি গ. নিঃ + অবধি ঘ. নিঃ + বধি Ans. গ ব্যাখ্যা: বিসর্গসন্ধির নিয়ম অনুসারে অ-কারান্ত বিসর্গের পর স্বরধ্বনি থাকলে বিসর্গ স্থানে 'র্' হয়, তাই নিঃ + অবধি = নিরবধি।
১৪৫. 'নাজ্জামাই' শব্দের যথার্থ সন্ধি বিচ্ছেদ কোনটি? ক. নাতি + জামাই খ. নাত + জামাই গ. নাজ + জামাই ঘ. নাতিম + জামাই Ans. খ ব্যাখ্যা: ত্ + জ্ = জ্জ, তাই নাত + জামাই = নাজ্জামাই।
১৪৬. 'নশ্বর' এর সন্ধি বিচ্ছেদ - ক. ন + শ্বর খ. নশ্ + বর গ. নশ্ব + র ঘ. নঃ + বর Ans. খ ব্যাখ্যা: নশ্ + বর = নশ্বর। (উল্লেখ্য, এটি √নশ্ + বর/ক্বরপ্ কৃৎ প্রত্যয়সাধিত শব্দ)।
১৪৭. 'পদ্ধতি' শব্দের সন্ধি বিচ্ছেদ করলে পাওয়া যায় - ক. পদ + ধতি খ. পৎ + ধতি গ. পথ + ধতি ঘ. পদ্‌ + হতি Ans. ঘ ব্যাখ্যা: দ্ + হ্ = দ্ধ, তাই পদ্ + হতি = পদ্ধতি।
১৪৭.১. 'পদ্ধতি' শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. পদ + ধতি খ. পৎ + ধতি গ. পথ + ধতি ঘ. পদ্ + হতি Ans. ঘ ব্যাখ্যা: দ্ + হ্ = দ্ধ, তাই পদ্ + হতি = পদ্ধতি।
১৪৭.২. 'পদ্ধতি' শব্দে কোন কোন ধ্বনি সংযুক্ত হয়েছে? ক. দ + ধ খ. দ + হ গ. ত + ধ ঘ. ত + হ Ans. খ ব্যাখ্যা: দ্ ধ্বনির সাথে হ্ ধ্বনির সন্ধি হয়ে 'দ্ধ' রূপ গঠিত হয়।
১৪৭.৩. 'পদ্ধতি' কোন প্রকারের সন্ধির উদাহরণ? ক. স্বরসন্ধি খ. ব্যঞ্জনসন্ধি গ. বিসর্গসন্ধি ঘ. নিপাতনে সিদ্ধ Ans. খ ব্যাখ্যা: ব্যঞ্জন ধ্বনির সাথে ব্যঞ্জন ধ্বনির মিলনে গঠিত হওয়ায় এটি ব্যঞ্জনসন্ধি।
১৪৭.৪. 'পদ্ + হতি = পদ্ধতি' - এখানে বিচ্ছেদের 'হ' ধ্বনিটি সন্ধিবদ্ধ হয়ে কী রূপ নেয়? ক. ধ খ. দ্ধ গ. থ ঘ. দ Ans. ক ব্যাখ্যা: দ্-এর পর হ্ থাকলে হ্-এর স্থানে 'ধ' হয় এবং দ্ + ধ = দ্ধ গঠিত হয়।
১৪৭.৫. 'পদ্ধতি' শব্দটির প্রাক-সন্ধি রূপের দ্বিতীয় অংশ কোনটি? ক. ধতি খ. হতি গ. থি ঘ. হতিঃ Ans. খ ব্যাখ্যা: পদ্ধতি শব্দের ব্যাকরণগত বিচ্ছেদ হলো পদ্ + হতি।
১৪৭.৬. 'পদ্ধতি' শব্দের মূল ধাতু বা ব্যাকরণিক ভিত্তি কোনটি? ক. পথ খ. পদ্ গ. পত্ ঘ. পদ Ans. খ ব্যাখ্যা: পদ্ধতি শব্দ বিচ্ছেদের প্রথম অংশ হলো 'পদ্'।
১৪৭.৭. 'পদ্ধতি' শব্দের সমার্থক শব্দ কোনটি? ক. নিয়ম খ. পথ গ. গ্রন্থ ঘ. ধারণা Ans. ক ব্যাখ্যা: পদ্ধতি শব্দের অর্থ প্রণালী, উপায় বা নিয়ম।
১৪৭.৮. ব্যঞ্জনসন্ধির নিয়ম অনুসারে দ্ + হ্ = ? ক. দ্ধ খ. ধ্ গ. ত্থ ঘ. দ্ঘ Ans. ক ব্যাখ্যা: ত্ বা দ্-এর পর হ্ থাকলে ত্/দ্ স্থানে দ্ এবং হ্ স্থানে ধ্ হয়ে যুক্তরূপ 'দ্ধ' হয়।
১৪৮. 'প্রিয়ংবদা' শব্দটির সন্ধি বিচ্ছেদ কোনটি? ক. প্রিয়ম্ + বদা খ. প্রিয়ং + বদা গ. পিয়ম + বদা ঘ. প্রিয়াং + বদা Ans. ক ব্যাখ্যা: ম্-এর পর ব্ থাকলে ম্ স্থানে অনুস্বার হয়, তাই প্রিয়ম্ + বদা = প্রিয়ংবদা।
১৪৯. 'বৈঠক' শব্দের সন্ধি বিচ্ছেদ হচ্ছে - ক. বৈঠ + অক খ. বৈ + ঠক গ. বৈঠ + ক ঘ. বি + ঠক Ans. গ ব্যাখ্যা: বৈঠ + ক = বৈঠক। (উল্লেখ্য, এটি মূলত শব্দগঠন প্রক্রিয়ার প্রত্যয়জাত রূপ)।
১৫০. 'বর্জন' এর সন্ধি বিচ্ছেদ কোনটি? ক. বৃজ্ + অন খ. ব + অর্জন গ. বুজ + অর্জন ঘ. বর + জন Ans. ক ব্যাখ্যা: বৃজ্ + অন = বর্জন। (উল্লেখ্য, এটি √বৃজ্ + অন/অনট্ কৃৎ প্রত্যয়সাধিত শব্দ)।
১৫১. 'বজ্জাত' শব্দের সঠিক সন্ধি বিচ্ছেদ করুন : ক. সৎ + জাত খ. বদ্ + জাত গ. বজ + জাত ঘ. ব + জাত Ans. খ ব্যাখ্যা: দ্ + জ্ = জ্জ, তাই বদ্ + জাত = বজ্জাত।
১৫২. 'বাগাড়ম্বর' শব্দের সন্ধি বিচ্ছেদ - ক. বাগ + আম্বর খ. বাগ + আড়ম্বর গ. বাক + অম্বর ঘ. বাক্ + আড়ম্বর Ans. ঘ ব্যাখ্যা: ক্-এর পর স্বরধ্বনি থাকলে ক্ স্থানে গ্ হয়, তাই বাক্ + আড়ম্বর = বাগাড়ম্বর।
১৫৩. 'বাগদান' শব্দের সঠিক সন্ধি বিচ্ছেদ করুন : ক. বাক্ + দান খ. বাগ + দান গ. বাঃ + দান ঘ. কোনোটিই নয় Ans. ক ব্যাখ্যা: ক্ + দ্ = গ্দ, তাই বাক্ + দান = বাগদান।
১৫৪. 'বিচ্ছেদ' শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. বিঃ + ছেদ খ. বি + ছেদ গ. বিং + ছেদ ঘ. বিচ্ + ছেদ Ans. খ ব্যাখ্যা: স্বরবর্ণের পর ছ্ থাকলে চ্ছ হয়, তাই বি + ছেদ = বিচ্ছেদ।
১৫৫. 'বিচ্ছিন্ন' শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. বিচ + ছিন্ন খ. বি + ছিন্ন গ. বিং + ছিন্ন ঘ. বিচ্ছ + ছিন্ন Ans. খ ব্যাখ্যা: স্বরবর্ণের পর ছ্ থাকলে চ্ছ হয়, তাই বি + ছিন্ন = বিচ্ছিন্ন।
১৫৬. 'বৃষ্টি' এর সন্ধি বিচ্ছেদ কি হবে? ক. বৃষ + টি খ. বৃশ + টি গ. বৃ + টি ঘ. বৃষ্ + তি Ans. ঘ ব্যাখ্যা: ষ্-এর পর 'ত' থাকলে 'ত' স্থানে 'ট' হয়, তাই বৃষ্ + তি = বৃষ্টি। (উল্লেখ্য, এটি √বৃষ্ + তি কৃৎ প্রত্যয়সাধিত শব্দ)।
১৫৭. কোনটি সঠিক সন্ধি বিচ্ছেদ? ক. উৎ + শ্বাস = উচ্ছ্বাস খ. উৎ + ডীন = উড্ডীন গ. বৃহৎ + ঢক্কা = বৃহড্ডক্কা ঘ. লভ্ + ত = লব্ধ Ans. ক ব্যাখ্যা: ত্-এর পর 'শ্' থাকলে ত্ স্থানে 'চ্' এবং 'শ্' স্থানে 'ছ্' হয় (ত্ + শ্ = চ্ছ), তাই উৎ + শ্বাস = উচ্ছ্বাস।
১৫৮. 'ভজ্ + ত' এর সন্ধি বিচ্ছেদ হলো - ক. ভজত খ. ভোজ্য গ. ভক্ত ঘ. ভজ্য Ans. গ ব্যাখ্যা: ভজ্ + ত = ভক্ত। (উল্লেখ্য, এটি √ভজ্ + ত/ক্ত কৃৎ প্রত্যয়সাধিত শব্দ)।
১৫৯. 'ভক্তি'-এর সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. ভজ্ + তি খ. ভক্ + তি গ. ভজ + তি ঘ. ভদ্ + উক্তি Ans. ক ব্যাখ্যা: ভজ্ + তি = ভক্তি। (উল্লেখ্য, এটি √ভজ্ + তি/ক্তি কৃৎ প্রত্যয়সাধিত শব্দ)।
১৬০. 'সংগীত' এর শুদ্ধ সন্ধি বিচ্ছেদ কোনটি? ক. সং + গীত খ. সং + গিত গ. সম্ + গিত ঘ. সম্ + গীত Ans. ঘ ব্যাখ্যা: ম্-এর পর গ্ থাকলে ম্ স্থানে অনুস্বার/ঙ হয়, তাই সম্ + গীত = সংগীত।
১৬১. 'সংসার' এর সন্ধি বিচ্ছেদ - ক. সং + সার খ. সাং + সার গ. সম + সার ঘ. সম্ + সার Ans. ঘ ব্যাখ্যা: ম্-এর পর স্ থাকলে ম্ স্থানে অনুস্বার হয়, তাই সম্ + সার = সংসার।
১৬২. সন্ধি নির্ণয় কর: সংসার = সম্ + সার ক. স্বরসন্ধি খ. খাঁটি বাংলা সন্ধি গ. বিসর্গসন্ধি ঘ. ব্যঞ্জনসন্ধি Ans. ঘ ব্যাখ্যা: ম্ ব্যঞ্জনবর্ণের পরিবর্তনে গঠিত বলে এটি ব্যঞ্জনসন্ধি।
১৬৩. 'সংযম'-এর সন্ধি বিচ্ছেদ হচ্ছে - ক. সং + যম খ. সম + যম গ. সম্ + যম ঘ. সংঙ + যম Ans. গ ব্যাখ্যা: ম্-এর পর য্ থাকলে ম্ স্থানে অনুস্বার হয়, তাই সম্ + যম = সংযম।
১৬৪. 'সন্তাপ' শব্দটির সন্ধি বিচ্ছেদ কোনটি? ক. সন + তাপ খ. সম্ + তাপ গ. সপ + তাপ ঘ. সমংস্ + তাপ Ans. খ ব্যাখ্যা: ম্-এর পর ত্ থাকলে ম্ স্থানে ন্ বা অনুস্বার হয়, তাই সম্ + তাপ = সন্তাপ।
১৬৫. কোনটি সঠিক? ক. সম + তান = সন্তান খ. সন + তান = সন্তান গ. সম্ + তান = সন্তান ঘ. সম্ + তন্ = সন্তান Ans. গ ব্যাখ্যা: ম্-এর পর 'ত' থাকলে ম্ স্থানে বর্গীয় পঞ্চম বর্ণ 'ন' (বা অনুস্বার) হয়, তাই সম্ + তান = সন্তান।
১৬৬. 'সংস্কৃত' এর সন্ধি বিচ্ছেদ কোনটি? ক. সং + স্কৃত খ. সং + কৃত গ. সম + স্কৃত ঘ. সম্ + কৃত Ans. ঘ ব্যাখ্যা: সম্-এর পর কৃ-ধাতু থাকলে স্ আগম হয়, তাই সম্ + কৃত = সংস্কৃত।
১৬৭. 'সংশপ্তক' শব্দের সন্ধি বিচ্ছেদ - ক. সম্ + শপ্তক খ. সৎ + শপ্তক গ. সম + শপ্ত + ক ঘ. সং + শপ্ত + এক Ans. ক ব্যাখ্যা: সম্ + শপ্তক = সংশপ্তক।
১৬৮. কোন বানানটি শুদ্ধ? ক. সংসপ্তক খ. সংশপ্তক গ. শংসপ্তক ঘ. শংশপ্তক Ans. খ ব্যাখ্যা: সম্ + শপ্তক = সংশপ্তক, এটিই সঠিক বানান।
১৬৯. 'সংবিধান' শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. সং + বিধান খ. সং + অবিধান গ. সম্ + বিধান ঘ. সম + ধান Ans. গ ব্যাখ্যা: ম্-এর পর ব্/ভ্/বর্গীয় ধ্বনি থাকলে অনুস্বার হয়, তাই সম্ + বিধান = সংবিধান।
১৭০. 'সংশয়' এর সন্ধি বিচ্ছেদ - ক. সৎ + শয় খ. সন + শয় গ. সম্ + শয় ঘ. সম + শয় Ans. গ ব্যাখ্যা: ম্-এর পর শ্ থাকলে অনুস্বার হয়, তাই সম্ + শয় = সংশয়।
১৭১. 'সংলাপ' শব্দের সন্ধি বিচ্ছেদ: ক. সম্ + লাপ খ. সং + লাপ গ. স + আলাপ ঘ. সু + আলাপ ঙ. সম্ঃ + লাপ Ans. ক ব্যাখ্যা: ম্-এর পর ল্ থাকলে অনুস্বার হয়, তাই সম্ + লাপ = সংলাপ।
১৭২. 'সন্ধান' শব্দের সঠিক সন্ধি বিচ্ছেদ করুন : ক. সম্ + ধান খ. সন + ধান গ. সংঃ + ধান ঘ. কোনোটিই নয় Ans. ক ব্যাখ্যা: ম্-এর পর ধ্ থাকলে ম্ স্থানে ন্ বা অনুস্বার হয়, তাই সম্ + ধান = সন্ধান।
১৭৩. 'সন্ধি' শব্দটি গঠিত হয়েছে কোন প্রক্রিয়ায়? ক. উপসর্গ খ. সন্ধি গ. সমাস ঘ. প্রত্যয় Ans. ঘ ব্যাখ্যা: 'সন্ধি' শব্দটি মূলত প্রত্যয় (সম্ + √ধা + ই) ও উপসর্গ সহযোগে গঠিত কৃদন্ত শব্দ।
১৭৪. 'সন্ধি' শব্দটির সন্ধি বিচ্ছেদ করলে হবে - ক. সন + ধি খ. সম + ধি গ. সম্ + ধি ঘ. সং + ধি Ans. গ ব্যাখ্যা: সম্ + ধি = সন্ধি।
১৭৫. কোনটি সন্ধিজাত শব্দ? ক. শীতল খ. সংখ্যা গ. অধিকার ঘ. তোমার Ans. খ ব্যাখ্যা: সম্ + খ্যা = সংখ্যা (ব্যঞ্জনসন্ধিজাত শব্দ)।
১৭৬. কোনটি ব্যঞ্জন সন্ধির উদাহরণ? ক. শুভেচ্ছা খ. প্রত্যেক গ. সংবাদ ঘ. ইত্যাদি Ans. গ ব্যাখ্যা: সম্ + বাদ = সংবাদ, এটি ব্যঞ্জনসন্ধির উদাহরণ।
১৭৭. 'সংবাদ' এর সন্ধি বিচ্ছেদ কি? ক. সৎ + বাদ খ. সম্ + বাদ গ. সুম + বাদ ঘ. সু + আবাদ Ans. খ ব্যাখ্যা: সম্ + বাদ = সংবাদ।
১৭৮. 'সঞ্চয়' এর সন্ধি বিচ্ছেদ কি হবে? ক. সন + চয় খ. সম্ + চয় গ. সংএ + চয় ঘ. সনচ্ + য় Ans. খ ব্যাখ্যা: ম্-এর পর চ্ থাকলে ম্ স্থানে ঞ হয়, তাই সম্ + চয় = সঞ্চয়।
১৭৯. কোনটি সঠিক সন্ধি বিচ্ছেদ? ক. সম্ + চয় = সঞ্চয় খ. রাজ + জ্ঞী = রাজ্ঞী গ. শ + অন = শয়ন ঘ. মনো + কষ্ট = মনঃকষ্ট Ans. ক ব্যাখ্যা: সম্ + চয় = সঞ্চয় (ব্যঞ্জনসন্ধির শুদ্ধ রূপ)।
১৮০. সম্ + চয় = সঞ্চয়, এটি কোন সন্ধি? ক. বিসর্গ খ. স্বর গ. ব্যঞ্জন ঘ. কোনোটিই নয় Ans. গ ব্যাখ্যা: ম্ ব্যঞ্জনবর্ণ থাকায় এটি ব্যঞ্জনসন্ধি।
১৮১. সম্ + হার এর সন্ধি কোনটি? ক. সমহার খ. সংহার গ. সঙগার ঘ. সঙহার Ans. খ ব্যাখ্যা: সম্ + হার = সংহার (ম্ + হ্ = অনুস্বার)।
১৮২. 'সদাশয়' শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. সদ + আশয় খ. সদা + শয় গ. সৎ + আশয় ঘ. সৎ + শয় Ans. গ ব্যাখ্যা: ত্ + আ = দ্ + আ, তাই সৎ + আশয় = সদাশয়।
১৮৩. 'সদানন্দ' সন্ধি বিচ্ছেদ হলো - ক. সদ + আনন্দ খ. সদা + নন্দ গ. সৎ + আনন্দ ঘ. সদ + অ + নন্দ Ans. গ ব্যাখ্যা: ত্-এর পর স্বরধ্বনি থাকলে ত্ স্থানে দ্ হয়, তাই সৎ + আনন্দ = সদানন্দ।
১৮৪. 'সন্নিহিত' শব্দের সন্ধি বিচ্ছেদ - ক. সৎ + নিহিত খ. সম্ + নিহিত গ. সং + নিহিত ঘ. সন্ + নিহিত Ans. খ ব্যাখ্যা: সম্ + নিহিত = সন্নিহিত (ম্ + ন্ = ন্ন)।
১৮৫. 'সার্বভৌম' শব্দের সঠিক বিচ্ছেদ কোনটি? ক. ঋ + সর্বভূমি খ. সার্ব + ভৌম গ. সর্বভূমি + ষ্ণ ঘ. সার্বভৌম + ম Ans. গ ব্যাখ্যা: সর্বভূমি + ষ্ণ (অ) = সার্বভৌম। (উল্লেখ্য, এটি কোনো সন্ধি নয়, এটি তদ্ধিত প্রত্যয়সাধিত শব্দ)।
১৮৬. 'সুবন্ত' এর সন্ধি বিচ্ছেদ - ক. সুব + অন্ত খ. সুপ্‌ + অন্ত গ. সুভ + অন্ত ঘ. সু + অন্ত Ans. খ ব্যাখ্যা: প্-এর পর স্বরধ্বনি থাকলে প্ স্থানে ব্ হয়, তাই সুপ্ + অন্ত = সুবন্ত।
১৮৭. ভুল সন্ধি বিচ্ছেদ - ক. ইতঃ + পূর্বে = ইতঃপূর্বে খ. উৎ + হত = উদ্ধত গ. চমক + ইত = চমকিত ঘ. গণ + অ = গণ্য Ans. ঘ ব্যাখ্যা: গণ্ + য = গণ্য, তাই 'গণ + অ' বিচ্ছেদটি ভুল।
১৮৮. ভুল সন্ধি বিচ্ছেদ কোনটি? ক. মনঃ + কষ্ট খ. ইতঃ + পূর্বে গ. সিং + হ = সিংহ ঘ. শ্রু + অন Ans. গ ব্যাখ্যা: 'সিংহ' শব্দটি নিপাতনে সিদ্ধ, 'সিং + হ' বিচ্ছেদটি সম্পূর্ণ ভুল।
১৮৯. নিচের কোন ব্যঞ্জন সন্ধিটি অশুদ্ধ? ক. দিক্ + দর্শন = দিগ্দর্শন খ. চিত্ + ময় = চিন্ময় গ. সং + গীত = সংগীত ঘ. শরৎ + চন্দ্র = শরচ্চন্দ্র Ans. গ ব্যাখ্যা: সম্ + গীত = সংগীত (তাই 'সং + গীত' বিচ্ছেদটি অশুদ্ধ)।
১৮৯.১. 'দিক্ + দর্শন' সন্ধিবদ্ধ হয়ে কী হয়? ক. দিকদর্শন খ. দিগ্দর্শন গ. দিঘদর্শন ঘ. দিচ্ছদর্শন Ans. খ ব্যাখ্যা: ক্-এর পর ঘোষ ধ্বনি 'দ' থাকায় ক্ স্থানে গ্ হয়, ফলে দিক্ + দর্শন = দিগ্দর্শন।
১৮৯.২. 'চিত্ + ময়' এর সঠিক সন্ধিবদ্ধ রূপ কোনটি? ক. চিটময় খ. চিন্ময় গ. চিদ্ময় ঘ. চিত্তময় Ans. খ ব্যাখ্যা: ত্-এর পর অনুনাসিক 'ম' থাকায় ত্ স্থানে 'ন' হয়, ফলে চিত্ + ময় = চিন্ময়।
১৮৯.৩. 'সংগীত' শব্দের শুদ্ধ সন্ধি বিচ্ছেদ কোনটি? ক. সং + গীত খ. সম্ + গীত গ. সং + ইত ঘ. সম্ + ইত Ans. খ ব্যাখ্যা: ম্-এর পর ক-বর্গীয় ধ্বনি 'গ' থাকায় ম্ স্থানে অনুস্বার হয়, তাই সম্ + গীত = সংগীত।
১৮৯.৪. 'শরচ্চন্দ্র' শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. শরৎ + চন্দ্র খ. শর + চন্দ্র গ. শরদ্ + চন্দ্র ঘ. শর চ্ + চন্দ্র Ans. ক ব্যাখ্যা: ত্-এর পর চ্ থাকলে ত্ স্থানে চ্ হয়, তাই শরৎ + চন্দ্র = শরচ্চন্দ্র।
১৮৯.৫. ক্-এর পর বর্গীয় ঘোষধ্বনি থাকলে ক্ স্থানে কী হয়? ক. খ খ. গ গ. ঘ ঘ. ঙ Ans. খ ব্যাখ্যা: স্পর্শ বর্ণ বা বর্গীয় ঘোষধ্বনি পরে থাকলে প্রথমাংশের অঘোষ ধ্বনি সঘোষ ধ্বনিতে রূপান্তরিত হয় (ক্ -> গ্)।
১৮৯.৬. 'সংগীত' শব্দে ব্যবহৃত 'সম্' কী নির্দেশ করে? ক. প্রত্যয় খ. উপসর্গ গ. অনুসর্গ ঘ. অব্যয় Ans. খ ব্যাখ্যা: 'সম্' একটি সংস্কৃত উপসর্গ যা গীত শব্দের পূর্বে বসে সংগীত তৈরি করেছে।
১৮৯.৭. ত্ + চ্ সন্ধিবদ্ধ হলে কী রূপ ধারণ করে? ক. চ্চ খ. চ্ছ গ. জ্জ ঘ. ত্চ Ans. ক ব্যাখ্যা: ত্ ধ্বনির পর চ্ ধ্বনি এলে ত্ বিলুপ্ত হয়ে 'চ্চ' যুক্তবর্ণ গঠন করে।
১৮৯.৮. 'চিন্ময়' শব্দের অর্থ কী? ক. জ্ঞানময় খ. মৃত্তিকাময় গ. স্বর্ণময় ঘ. প্রজ্ঞাহীন Ans. ক ব্যাখ্যা: 'চিত্' অর্থ জ্ঞান বা চেতনা, সুতরাং 'চিন্ময়' অর্থ জ্ঞানময় বা চেতনাময়।
১৮৯.৯. ব্যঞ্জনবর্ণের সাথে ব্যঞ্জনবর্ণের মিলনে যে সন্ধি হয় তাকে কী বলে? ক. স্বরসন্ধি খ. ব্যঞ্জনসন্ধি গ. বিসর্গসন্ধি ঘ. খাঁটি বাংলা সন্ধি Ans. খ ব্যাখ্যা: ব্যঞ্জনে-ব্যঞ্জনে বা স্বরে-ব্যঞ্জনে মিলনে গঠিত সন্ধিই হলো ব্যঞ্জনসন্ধি।
১৯০. কোন বানানটি শুদ্ধ? ক. অধগতি খ. অধোগতি গ. অধংগতি ঘ. অধোঃগতি Ans. খ ব্যাখ্যা: অধঃ + গতি = অধোগতি (বিসর্গ ও অ-কার মিলে ও-কার হয়)।
১৯১. কোনটি ‘অন্তরঙ্গ’ এর সঠিক সন্ধি বিচ্ছেদ? ক. অন্তঃ + অঙ্গ খ. অন্তর + অঙ্গ গ. অন্তর্রম + গ ঘ. অন্তররণ + গ Ans. ক ব্যাখ্যা: অ-ঘোষ বিসর্গের পর স্বরধ্বনি থাকলে বিসর্গ স্থানে 'র্' হয়, তাই অন্তঃ + অঙ্গ = অন্তরঙ্গ।
১৯২. ‘অন্তরীপ’ শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. অন্তর + ঈপ খ. অন্তর + ঈশ গ. অন্ত + রীপ ঘ. অন্ততঃ + রীপ ঙ. অন্তঃ + ঈপ Ans. ঙ ব্যাখ্যা: অন্তঃ + ঈপ = অন্তরীপ (বিসর্গ স্থানে 'র্' আগম)।
১৯৩. কোনটি শুদ্ধ? ক. অতঃপর বিচ্ছেদ: অতঃপর/অতঃ + এব = অতএব খ. পরিঃ + কার = পরিষ্কার গ. এক + ছত্র = একচ্ছত্র ঘ. পরিঃ + ছদ = পরিচ্ছদ Ans. ক ব্যাখ্যা: অ-কারান্ত বিসর্গের পর এ-কার থাকলে বিসর্গ লোপ পায়, তাই অতঃপর বা অতঃপর বিচ্ছেদ হিসেবে অতঃপর/অতঃ + এব = অতএব।
১৯৪. ‘আবিষ্কার’ শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. আবি + কার খ. আবিঃ + কার গ. আবিষ + কার ঘ. আবি + ষকার Ans. খ ব্যাখ্যা: ই-কারান্ত বিসর্গের পর ক্ থাকলে বিসর্গ স্থানে ষ হয়, তাই আবিঃ + কার = আবিষ্কার।
১৯৫. ‘আবির্ভাব’ শব্দটি গঠিত হয়েছে - ক. প্রত্যয় দ্বারা খ. উপসর্গ দ্বারা গ. সন্ধি দ্বারা ঘ. বিভক্তি দ্বারা Ans. গ ব্যাখ্যা: আবিঃ + ভাব = আবির্ভাব (বিসর্গসন্ধি দ্বারা গঠিত)।
১৯৬. ‘ইতস্তত’ শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. ইত + তত খ. ইতঃ + তত গ. ইতস্ + তত ঘ. ইত + স্তত Ans. খ ব্যাখ্যা: অ-কারান্ত বিসর্গের পর ত্ থাকলে বিসর্গ স্থানে স্ হয়, তাই ইতঃ + তত = ইতস্তত।
১৯৭. উৎ + লিখিত - এর সন্ধি হবে? ক. উল্লেখিত খ. উল্লিখিত গ. উথলিখিত ঘ. উল্লেখিত Ans. খ ব্যাখ্যা: ত্ + ল্ = ল্ল, তাই উৎ + লিখিত = উল্লিখিত।
১৯৮. ‘চতুরঙ্গ’ এর সন্ধি বিচ্ছেদ করুন: ক. চতু + অঙ্গ খ. চতুঃ + অঙ্গ গ. চতুর + অঙ্গ ঘ. চার + অঙ্গ Ans. খ ব্যাখ্যা: বিসর্গ স্থানে 'র্' হয়ে চতুঃ + অঙ্গ = চতুরঙ্গ।
১৯৯. সন্ধিঘটিত শুদ্ধ শব্দ - ক. অতি + অধিক = অত্যাধিক খ. অগ্নি + উৎপাত = অগ্নপাত গ. প্রশ্ন + আবলি = প্রশ্নাবলী ঘ. চতুঃ + অঙ্গ = চতুরঙ্গ Ans. ঘ ব্যাখ্যা: চতুঃ + অঙ্গ = চতুরঙ্গ (বিসর্গসন্ধির নির্ভুল রূপ)।
২০০. ‘চতুষ্পদ’ শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. চতুর + পদ খ. চতুর্ব + পদ গ. চতু + পদ ঘ. চতুঃ + পদ Ans. ঘ ব্যাখ্যা: উ-কারান্ত বিসর্গের পর প্ থাকলে বিসর্গ স্থানে ষ হয়, তাই চতুঃ + পদ = চতুষ্পদ।








২০১. বিসর্গ সন্ধির একটি উদাহরণ হলো - ক. সংস্কৃত খ. আচ্ছন্ন গ. জ্যোতিরিন্দ্র ঘ. গোস্পদ Ans. গ ব্যাখ্যা: জ্যোতিঃ + ইন্দ্র = জ্যোতিরিন্দ্র (বিসর্গসন্ধির উদাহরণ)।
২০২. ‘ততোধিক’ শব্দের সন্ধি বিচ্ছেদ করলে পাওয়া যায়? ক. তত + অধিক খ. তত + ধিক গ. ততো + ধিক ঘ. ততঃ + অধিক Ans. ঘ ব্যাখ্যা: বিসর্গ + অ-কার মিলে ও-কার হয়, তাই ততঃ + অধিক = ততোধিক।
২০৩. ‘তপোবন’ এর সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. তপ + বন খ. তপঃ + বন গ. তপো + বন ঘ. তপ + উবন Ans. খ ব্যাখ্যা: তপঃ + বন = তপোবন (বিসর্গ স্থানে ও-কার)।
২০৪. সন্ধি বিচ্ছেদ করুন : ‘তিরস্কার’ - ক. তিরস + কার খ. তির + স্কার গ. তিরঃ + কার ঘ. তিরসংঃ + কার ঙ. কোনোটিই নয় Ans. গ ব্যাখ্যা: অ-কারান্ত বিসর্গের পর ক্ থাকলে বিসর্গ স্থানে স্ হয়, তাই তিরঃ + কার = তিরস্কার।
২০৫. ‘দুর্নীতি’ শব্দের সন্ধি বিচ্ছেদ হবে - ক. দুর + নীতি খ. দুঃ + নীতো গ. দুঃ + নীতি ঘ. দুরো + নীতি Ans. গ ব্যাখ্যা: দুঃ + নীতি = দুর্নীতি (বিসর্গ স্থানে 'র্' বা রেফ হয়)।
২০৬. কোনটি সন্ধিগঠিত নির্ভুল শব্দ? ক. দুঃ + নীতি = দুর্নীতি খ. দূর + নীতি = দুর্নীতি গ. দুর + নীতি = দুর্নীতি ঘ. দুতঃ + নীতি = দুর্নীতি Ans. ক ব্যাখ্যা: বিসর্গযুক্ত দুঃ + নীতি = দুর্নীতি নির্ভুল রূপ।
২০৭. ‘দুর্ঘটনা’ শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. দুঃ + ঘটনা খ. দূর + ঘটনা গ. দুর + ঘটনা ঘ. দর্ + ঘটনা Ans. ক ব্যাখ্যা: দুঃ + ঘটনা = দুর্ঘটনা (বিসর্গ স্থানে 'র্' বা রেফ হয়)।
২০৮. কোনটি নির্ভুল? ক. দুতঃ + ঘটনা = দুর্ঘটনা খ. দুর + ঘটনা = দুর্ঘটনা গ. দুংঃ + ঘটনা = দুর্ঘটনা ঘ. দুঃ + ঘটনা = দুর্ঘটনা Ans. ঘ ব্যাখ্যা: দুঃ + ঘটনা = দুর্ঘটনা বিসর্গসন্ধির সঠিক রূপ।
২০৯. ‘দুর্বার’ শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. দূর + বার খ. দুর + বার গ. দুঃ + বার ঘ. দু + বার Ans. গ ব্যাখ্যা: দুঃ + বার = দুর্বার (বিসর্গ স্থানে 'র্' বা রেফ হয়)।
২১০. ‘দুর্যোগ’ এর সন্ধি বিচ্ছেদ কী? ক. দুহঃ + যোগ খ. দুর + যোগ গ. দুঃ + যোগ ঘ. দুহ + যোগ Ans. গ ব্যাখ্যা: দুঃ + যোগ = দুর্যোগ (বিসর্গ স্থানে 'র্' বা রেফ হয়)।
২১১. ‘দুর্গতি’ এর সন্ধি বিচ্ছেদ কোনটি? ক. দুর + গতি খ. দূর + গতি গ. দুঃ + গতি ঘ. দু + গতি Ans. গ ব্যাখ্যা: দুঃ + গতি = দুর্গতি (বিসর্গ স্থানে 'র্' বা রেফ হয়)।
২১২. ‘দুরূহ’ শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. দুঃ + ঊহ খ. দুঃ + রুহ গ. দুর + উহ ঘ. দূর + ঊহ Ans. ক ব্যাখ্যা: দুঃ + ঊহ = দুরূহ (বিসর্গ স্থানে 'র্' এবং পরে 'ঊ' মিলে 'রূ' হয়, দুঃ + ঊহ = দুরূহ)।
২১৩. ‘দুরবস্থা’ শব্দটির সন্ধি বিচ্ছেদ কোনটি? ক. দুঃ + অবস্থা খ. দুর + অবস্থা গ. দুদ্ + অবস্থা ঘ. দূর + অবস্থা Ans. ক ব্যাখ্যা: দুঃ + অবস্থা = দুরবস্থা (বিসর্গ স্থানে 'র্' হয়; ব্যাকরণে 'দুর্বস্থা' রূপটি অশুদ্ধ)।
২১৪. ‘দুরাপনেয়’ এর সন্ধি বিচ্ছেদ হলো - ক. দূর + অপনেয় খ. দুর + অপনেয় গ. দুঃ + অপনেয় ঘ. দু + অপনেয় Ans. গ ব্যাখ্যা: দুঃ + অপনেয় = দুরাপনেয় (বিসর্গ স্থানে 'র্' হয়)।
২১৫. 'দুঃস্থ' শব্দের সন্ধি বিচ্ছেদ - ক. দুস্ + থ খ. দুঃ + থ গ. দুঃ + স্থ ঘ. দুস্ + স্থ Ans. গ ব্যাখ্যা: দুঃ + স্থ = দুঃস্থ (বিসর্গসন্ধির নিয়ম অনুযায়ী বিসর্গের পর স্ত/স্থ থাকলে বিসর্গ অবিকৃত থাকে)।
২১৬. সন্ধি নির্ণয় কর: দুশ্চিন্তা = দুঃ + চিন্তা ক. বিসর্গসন্ধি খ. খাঁটি বাংলা সন্ধি গ. ব্যঞ্জন সন্ধি ঘ. স্বরসন্ধি Ans. ক ব্যাখ্যা: বিসর্গের পর চ্ থাকলে বিসর্গ স্থানে শ্ হয়, তাই দুঃ + চিন্তা = দুশ্চিন্তা (বিসর্গসন্ধি)।
২১৭. ‘দুর্লভ’ শব্দের সন্ধি বিচ্ছেদ - ক. দুঃ + লভ খ. দুর + লভ গ. দুর + লোভ ঘ. দূর + লভ Ans. ক ব্যাখ্যা: দুঃ + লভ = দুর্লভ (বিসর্গ স্থানে 'র্' বা রেফ হয়)।
২১৮. ‘দুশ্চরিত্র’ এর সন্ধি বিচ্ছেদ - ক. দুশ্চ + চিত্র খ. দুঃ + চরিত্র গ. দু + চরিত্র ঘ. দুস্ + চরিত্র Ans. খ ব্যাখ্যা: বিসর্গের পর চ্ থাকলে বিসর্গ স্থানে শ্ হয়, তাই দুঃ + চরিত্র = দুশ্চরিত্র।
২১৯. ‘দুচ্ছেদ্য’ শব্দটির সন্ধি বিচ্ছেদ - ক. দুশ + ছেদ্য খ. দুষ + ছেদ্য গ. দুঃ + ছেদ্য ঘ. দু + ছেদ্য Ans. গ ব্যাখ্যা: বিসর্গের পর ছ্ থাকলে বিসর্গ স্থানে শ্ হয়, তাই দুঃ + ছেদ্য = দুচ্ছেদ্য।
২২০. ‘ধনুষ্টংকার’ - এর সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. ধনুয + টঙ্কার খ. ধনুঃ + টঙ্কার গ. ধনু + টঙ্কার ঘ. ধনুট + ঙ্কার Ans. খ ব্যাখ্যা: বিসর্গের পর ট্ থাকলে বিসর্গ স্থানে ষ হয়, তাই ধনুঃ + টঙ্কার = ধনুষ্টংকার।
২২১. কোনটি শুদ্ধ সন্ধি বিচ্ছেদ? ক. ধনু + বিদ্যা খ. ধনুঃ + বিদ্যা গ. ধনুর্ + বিদ্যা ঘ. ধনুঞ্জঃ + বিদ্যা Ans. খ ব্যাখ্যা: ধনুঃ + বিদ্যা = ধনুর্বিদ্যা (বিসর্গ স্থানে 'র্')।
২২২. ‘নীরোগ’ শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. নিংঃ + রোগ খ. নিঃ + রোগ গ. নি + রোগ ঘ. নির্ + রোগ Ans. খ ব্যাখ্যা: র-কারের পূর্বে বিসর্গ থাকলে বিসর্গ লোপ পায় এবং পূর্বের হ্রস্ব স্বর 'ই' দীর্ঘ 'ঈ'-তে পরিণত হয়, তাই নিঃ + রোগ = নীরোগ (বিচ্ছেদে মূল উপসর্গ 'নিঃ' হ্রস্ব ই-কারযুক্ত)।
২২৩. ‘নীরস’ শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. নি + রস খ. নী + রস গ. নিঃ + রস ঘ. নির্ + রস Ans. গ ব্যাখ্যা: নিঃ + রস = নীরস (বিসর্গ লোপ পেয়ে পূর্ববর্তী হ্রস্ব ই-কার দীর্ঘ ঈ-কার হয়)।
২২৪. নিচের কোন বানানটি শুদ্ধ? ক. নিঃশোষিত খ. নীরস গ. মাধুরিয়া ঘ. অধীনী Ans. খ ব্যাখ্যা: নিঃ + রস = নীরস (দীর্ঘ ঈ-কারযুক্ত বানানটিই শুদ্ধ)।
২২৫. ‘নিরাকার’ শব্দের সন্ধি বিচ্ছেদ করলে পাওয়া যায় - ক. নির্ + আকার খ. নিরা + আকার গ. নি + আকার ঘ. নিঃ + আকার Ans. ঘ ব্যাখ্যা: নিঃ + আকার = নিরাকার (বিসর্গ স্থানে 'র্' হয়)।
২২৬. ‘নীরব’ শব্দের সন্ধি বিচ্ছেদ - ক. নী + রব খ. নিঃ + রব গ. নির্ + রব ঘ. নির্ + ব Ans. খ ব্যাখ্যা: নিঃ + রব = নীরব (বিসর্গ লোপ পেয়ে হ্রস্ব ই-কার দীর্ঘ ঈ-কার হয়; সন্ধি বিচ্ছেদে 'নিঃ' হ্রস্ব ই-কারযুক্ত)।
২২৭. ‘নিরন্ন’ শব্দের সন্ধি বিচ্ছেদ - ক. নি + অন্ন খ. নির্ + অন্ন গ. নিঃ + অন্ন ঘ. নির্ + ন্ন Ans. গ ব্যাখ্যা: নিঃ + অন্ন = নিরন্ন (বিসর্গ স্থানে 'র্' হয়)।
২২৮. ‘নিষ্পত্তি’ শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. নিঃ + পত্তি খ. নিস্ + পত্তি গ. নিষ্ম + পত্তি ঘ. নিস্ + পতি Ans. ক ব্যাখ্যা: ই-কারান্ত বিসর্গের পর প্ থাকলে বিসর্গ স্থানে ষ হয়, তাই নিঃ + পত্তি = নিষ্পত্তি।
২২৯. ‘নিশ্চয়’ এর সন্ধি বিচ্ছেদ কোনটি? ক. নিশ্চয় + য খ. নি + চয় গ. নিশ + চয় ঘ. নিঃ + চয় Ans. ঘ ব্যাখ্যা: বিসর্গের পর চ্ থাকলে শ্ হয়, তাই নিঃ + চয় = নিশ্চয়।
২৩০. ‘নিষ্ঠা’ শব্দের সঠিক সন্ধি বিচ্ছেদ করুন : ক. নিস্ + ঠা খ. নি + ঠা গ. নিঃ + স্থা ঘ. নির্ + ঠা Ans. গ ব্যাখ্যা: নিঃ + স্থা = নিষ্ঠা (ই-কারান্ত বিসর্গের পর 'স্থা' ধাতুর 'স্থ' থাকলে বিসর্গ লোপ পেয়ে 'ষ্ঠ' হয়)।
২৩১. কোনটি ‘নিরাময়’ শব্দের সন্ধি বিচ্ছেদ? ক. নিঃ + আময় খ. নিরা + ময় গ. নির্ + ময় ঘ. নির্ + আময় Ans. ক ব্যাখ্যা: নিঃ + আময় = নিরাময় (বিসর্গ স্থানে 'র্' হয়)।
২৩২. কোনটি ‘নিরাময়’ শব্দের সন্ধি বিচ্ছেদ? ক. নিরা + ময় খ. নিঃ + আময় গ. নির্ + ময় ঘ. নি + আময় Ans. খ ব্যাখ্যা: নিঃ + আময় = নিরাময় (বিসর্গ সন্ধির নিয়ম অনুযায়ী)।
২৩৩. ‘নিরাকরণ’ শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. নিঃ + আকরণ খ. নির্ + আকরণ গ. নি + করণ ঘ. নিরা + করণ Ans. ক ব্যাখ্যা: নিঃ + আকরণ = নিরাকরণ (বিসর্গ স্থানে 'র্' হয়)।
২৩৪. সন্ধি বিচ্ছেদ করুন : ‘পুরস্কার’। ক. পুরস্ + কার খ. পুর + কার গ. পুরঃ + কার ঘ. পুরসংঃ + কার Ans. গ ব্যাখ্যা: অ-কারান্ত বিসর্গের পর ক্ থাকলে বিসর্গ স্থানে স্ হয়, তাই পুরঃ + কার = পুরস্কার।
২৩৫. ‘পুনরুক্ত’ এর সন্ধি বিচ্ছেদ কী? ক. পুন + উক্ত খ. পুনঃ + উক্ত গ. পুন + রক্ত ঘ. পুনঃ + রক্ত Ans. খ ব্যাখ্যা: পুনঃ + উক্ত = পুনরুক্ত (বিসর্গ স্থানে 'র্' হয়)।
২৩৬. ‘প্রাতরাশ’ শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. প্রাতঃ + আস খ. প্রাতঃ + রাশ গ. প্রাতঃ + আশ ঘ. প্রাত + রাশ Ans. গ ব্যাখ্যা: প্রাতঃ + আশ = প্রাতরাশ (বিসর্গ স্থানে 'র্')।
২৩৭. ‘বাচস্পতি’ - শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. বাচ + পতি খ. বাচঃ + পতি গ. বাচ্‌স্‌ + পতি ঘ. বাচস্‌‌ + পতি ঙ. কোনোটিই নয় Ans. খ ব্যাখ্যা: বাচঃ + পতি = বাচস্পতি (নিপাতনে সিদ্ধ বিসর্গসন্ধি)।
২৩৮. ‘ভ্রাতুষ্পুত্র’ সন্ধি বিচ্ছেদ করলে পাওয়া যায় - ক. ভ্রাত + পুত্র খ. ভ্রাতুস্ + পুত্র গ. ভ্রাতুঃ + পুত্র ঘ. ভ্রাতু + পুত্র Ans. গ ব্যাখ্যা: ভ্রাতুঃ + পুত্র = ভ্রাতুষ্পুত্র (বিসর্গের পর প্ থাকলে বিসর্গ স্থানে ষ হয়)।
২৩৯. 'ভাস্কর' - এর সন্ধি বিচ্ছেদ কী? ক. ভাস + কর খ. ভাঃ + কর গ. ভাস্থ্য + সর ঘ. ভা + স্বর Ans. খ ব্যাখ্যা: ভাঃ + কর = ভাস্কর (এটি নিপাতনে সিদ্ধ বিসর্গসন্ধি)।
২৪০. ‘মনোনয়ন’ এর সন্ধি বিচ্ছেদ কোনটি? ক. মনন + অয়ন খ. মন + নয়ন গ. মনঃ + নয়ন ঘ. মনো + নয়ন Ans. গ ব্যাখ্যা: মনঃ + নয়ন = মনোনয়ন (বিসর্গ স্থানে ও-কার হয়)।
২৪১. ‘মনোযোগ’ শব্দটি কোন সন্ধিতে গঠিত? ক. স্বরসন্ধি খ. ব্যঞ্জন সন্ধি গ. বিসর্গ সন্ধি ঘ. নিপাতনে সিদ্ধ Ans. গ ব্যাখ্যা: মনঃ + যোগ = মনোযোগ (বিসর্গসন্ধি)।
২৪২. ‘মনোযোগ’ শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. মন + যোগ খ. মন + উৎ + যোগ গ. মনঃ + যোগ ঘ. মনো + যোগ Ans. গ ব্যাখ্যা: বিসর্গ স্থানে ও-কার হয়ে মনঃ + যোগ = মনোযোগ।
২৪৩. ‘মনস্তাপ’ এর সন্ধি বিচ্ছেদ কোনটি? ক. মনঃ + তাপ খ. মন + তাপ গ. মনস্ + তাপ ঘ. মনো + তাপ Ans. ক ব্যাখ্যা: বিসর্গের পর ত্ থাকলে স্ হয়, তাই মনঃ + তাপ = মনস্তাপ।
২৪৪. ‘যশোলাভ’ এর সন্ধি বিচ্ছেদ - ক. যশঃ + লাভ খ. যশ + লাভ গ. যশো + লাভ ঘ. যশ + অ + লাভ Ans. ক ব্যাখ্যা: যশঃ + লাভ = যশোলাভ (বিসর্গ স্থানে ও-কার)।
২৪৫. সন্ধির নিয়মে কোনটি ঠিক? ক. শির + ছদ = শিরোনাম খ. শিরঃ + ছেদ = শিরোনাম গ. শিরো + ছেদ = শিরোনাম ঘ. শিরঃ + ছেদ = শিরোচ্ছেদ Ans. ঘ ব্যাখ্যা: শিরঃ + ছেদ = শিরোচ্ছেদ (বিসর্গের পর ছ্ থাকলে শ্ হয়)।
২৪৬. কোনটি শুদ্ধ বানান? ক. শিরেচ্ছেদ খ. শিরনাম গ. শিরোচ্ছেদ ঘ. শিরাচ্ছেদ Ans. গ ব্যাখ্যা: শিরঃ + ছেদ = শিরোচ্ছেদ (শিরঃ + নাম = শিরোনামও শুদ্ধ, তাই বিকল্প দ্ব্যর্থতা দূর করতে 'খ' বিকল্প পরিমার্জন করা হয়েছে)।
২৪৭. নির্ভুল সন্ধি বিচ্ছেদ - ক. ক্ষুধা + আর্ত খ. উছ + শ্বাস গ. শিরঃ + ছেদ ঘ. আশী + বাদ ঙ. দুষ্টা + অন্ত Ans. গ ব্যাখ্যা: শিরঃ + ছেদ = শিরোচ্ছেদ (শুদ্ধ সন্ধি বিচ্ছেদ)।
২৪৮. বিসর্গ সন্ধির উদাহরণ নয় কোনটি? ক. ইতোমধ্যে খ. নীরব গ. যশোলাভ ঘ. অত্যন্ত Ans. ঘ ব্যাখ্যা: 'অত্যন্ত' (অতি + অন্ত) স্বরসন্ধির উদাহরণ; বাকিগুলো বিসর্গসন্ধিসাধিত (ইতঃ + মধ্যে = ইতোমধ্যে, নিঃ + রব = নীরব, যশঃ + লাভ = যশোলাভ)।
২৪৯. ‘সদ্যোজাত’ শব্দের সন্ধি বিচ্ছেদ - ক. সদ্য + জাত খ. সদ্যঃ + জাত গ. সদ্যা + জাত ঘ. সদা + জাত Ans. খ ব্যাখ্যা: সদ্যঃ + জাত = সদ্যোজাত (বিসর্গ স্থানে ও-কার)।
২৪৯.১. 'সদ্যঃ + জাত' বিচ্ছেদে বিসর্গ স্থানে কী তৈরি হয়? ক. র-কার খ. ও-কার গ. স-কার ঘ. শ-কার Ans. খ ব্যাখ্যা: অ-কারান্ত বিসর্গের পর ঘোষ ধ্বনি 'জ' থাকায় বিসর্গ ও অ-কার মিলে ও-কার হয়, ফলে সদ্যোজাত রূপ পায়।
২৪৯.২. 'সদ্যোজাত' শব্দের অর্থ কী? ক. সদ্য জন্ম নেওয়া খ. প্রাচীন গ. মৃত ঘ. দীর্ঘজীবী Ans. ক ব্যাখ্যা: 'সদ্যঃ' মানে অবিলম্বে বা সম্প্রতি, আর 'জাত' মানে জন্মপ্রাপ্ত; সুতরাং সদ্যোজাত অর্থ সদ্য জন্ম নেওয়া।
২৪৯.৩. 'সদ্যোজাত' শব্দটি কোন সন্ধির অন্তর্ভুক্ত? ক. স্বরসন্ধি খ. ব্যঞ্জনসন্ধি গ. বিসর্গসন্ধি ঘ. নিপাতনে সিদ্ধ Ans. গ ব্যাখ্যা: বিসর্গের পরিবর্তনের মাধ্যমে গঠিত হওয়ায় এটি বিসর্গসন্ধি।
২৪৯.৪. 'সদ্যোজাত' শব্দের শুদ্ধ বানান কোনটি? ক. সদ্যজাত খ. সদ্যোজাত গ. সধ্যজাত ঘ. সদ্যজাতঃ Ans. খ ব্যাখ্যা: বিসর্গসন্ধির নিয়ম অনুযায়ী ও-কার যুক্ত হয়ে 'সদ্যোজাত' বানানটিই শুদ্ধ।
২৫০. যেসব ক্ষেত্রে সন্ধি নিয়মানুসারে হয় না তাকে বলে - ক. স্বরসন্ধি খ. ব্যঞ্জন সন্ধি গ. নিপাতনে সিদ্ধ সন্ধি ঘ. বিসর্গ সন্ধি Ans. গ ব্যাখ্যা: নিয়ম বহির্ভূতভাবে গঠিত সন্ধিকে নিপাতনে সিদ্ধ সন্ধি বলে।
২৫১. ব্যাকরণে নিয়ম বহির্ভূত প্রচলিত বিষয় বা দৃষ্টান্তকে বলা হয় - ক. ব্যতিক্রম খ. নিপাতন গ. অনিয়ম ঘ. নিপাতনে সিদ্ধ Ans. ঘ ব্যাখ্যা: সাধারণ ব্যাকরণগত নিয়মের বাইরে থাকা সিদ্ধ রূপ হলো নিপাতনে সিদ্ধ।
২৫২. ‘অন্যান্য’ শব্দের সন্ধি রূপ কোনটি? ক. অন্য + আন্যা খ. অন + অন্য গ. অন্য + অন্য ঘ. অন্ন + অন্ন Ans. গ ব্যাখ্যা: অন্য + অন্য = অন্যান্য (অ + অ = আ)।
২৫৩. সন্ধি নির্ণয় কর: অন্যান্য = অন্য + অন্য ক. ব্যঞ্জন সন্ধি খ. স্বরসন্ধি গ. খাঁটি বাংলা সন্ধি ঘ. বিসর্গসন্ধি Ans. খ ব্যাখ্যা: দুই স্বরবর্ণের মিলনে তৈরি বলে এটি স্বরসন্ধি।
২৫৪. ‘অহর্নিশ’ শব্দের সন্ধি বিচ্ছেদ - ক. অহঃ + নিশা খ. অহঃ + নিশ গ. অহর + নিশ ঘ. অহ + নিশ Ans. ক ব্যাখ্যা: অহঃ + নিশা = অহর্নিশ (নিপাতনে সিদ্ধ বা বিশেষ বিসর্গসন্ধি)।
২৫৫. ‘অহরহ’ শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. অহ + রহ খ. অহঃ + রহ গ. অহ + অহ ঘ. অহঃ + অহ Ans. ঘ ব্যাখ্যা: অহঃ + অহ = অহরহ (বিসর্গ স্থানে 'র্')।
২৫৬. ‘আশ্চর্য’ এর সন্ধি বিচ্ছেদ - ক. অ + আচর্ খ. অতি + চর্য গ. আশ + চর্য ঘ. আ + চর্য Ans. ঘ (সঠিক উত্তর: আ + চর্য = আশ্চর্য) ব্যাখ্যা: এটি নিপাতনে সিদ্ধ ব্যঞ্জনসন্ধির উদাহরণ।
২৫৭. কোনটি নিপাতনে সিদ্ধ সন্ধির উদাহরণ? ক. আ + চর্য খ. জল + আশয় গ. মত + ঐক্য ঘ. ইতি + আদি Ans. ক ব্যাখ্যা: আ + চর্য = আশ্চর্য, এটি নিপাতনে সিদ্ধ।
২৫৮. নিপাতনে সিদ্ধ সন্ধি কোনটি? ক. একাদশ খ. পুনরায় গ. পরিষ্কার ঘ. মনোহর Ans. ক ব্যাখ্যা: এক + দশ = একাদশ (নিয়ম বহির্ভূত নিপাতনে সিদ্ধ সন্ধি)।
২৫৯. কোনটি নিয়মানুসারে সন্ধি হয় না? ক. কুলটা খ. পঞ্চাধর গ. নদ্যম্ব ঘ. দেশান্তর Ans. ক ব্যাখ্যা: কুল + অটা = কুলটা (নিয়মানুসারে কুলাটা হওয়া উচিত ছিল, তাই নিপাতনে সিদ্ধ)।
২৬০. নিচের কোনটি নিপাতনে সিদ্ধ সন্ধি? ক. কুলটা খ. সংস্কার গ. গবেষণা ঘ. ভাবুক Ans. ক ব্যাখ্যা: কুল + অটা = কুলটা।
২৬১. কোনটি সন্ধির নিপাতনে সিদ্ধ হয়েছে? ক. যদ্যপি খ. লবণ গ. গবাক্স ঘ. সংসার Ans. গ ব্যাখ্যা: গো + অক্ষ = গবাক্স (নিপাতনে সিদ্ধ সন্ধি)।
২৬২. গো + অক্ষ = গবাক্স। এটি কোন ধরনের সন্ধি বিচ্ছেদ? ক. স্বরসন্ধি খ. স্বর ব্যঞ্জন সন্ধি গ. বিসর্গ সন্ধি ঘ. নিপাতনে সিদ্ধ সন্ধি Ans. ঘ ব্যাখ্যা: স্বাভাবিক স্বরসন্ধির নিয়ম না মেনে গঠিত বলে এটি নিপাতনে সিদ্ধ।
২৬৩. ‘গোস্পদ’ এর সন্ধি বিচ্ছেদ কোনটি? ক. পোঃ + পদ খ. গো + পদ গ. গৌ + পদ ঘ. গৈ + পদ Ans. খ ব্যাখ্যা: গো + পদ = গোস্পদ (নিপাতনে সিদ্ধ ব্যঞ্জনসন্ধি)।
২৬৪. নিপাতনে সিদ্ধ সন্ধি কোনটি? ক. অন্তঃ + ধান = অন্তর্ধান খ. তৎ + কাল = তৎকাল গ. সম + তান = সন্তান ঘ. গো + পদ = গোস্পদ Ans. ঘ ব্যাখ্যা: গো + পদ = গোস্পদ।
২৬৫. নিচের কোনটি ‘তস্কর’ শব্দের শুদ্ধ সন্ধি বিচ্ছেদ? ক. তূস্ + কর খ. তৎ + কর গ. তসঃ + কর ঘ. তদ্ + কর Ans. খ ব্যাখ্যা: তৎ + কর = তস্কর (এটি নিপাতনে সিদ্ধ ব্যঞ্জনসন্ধি)।
২৬৬. ‘দ্যুলোক’ শব্দের যথার্থ সন্ধি বিচ্ছেদ কোনটি? ক. দুঃ + লোক খ. দিব্ + লোক গ. দ্বি + লোক ঘ. দ্বিঃ + লোক Ans. খ ব্যাখ্যা: দিব্ + লোক = দ্যুলোক (বিশেষ ব্যঞ্জনসন্ধি)।
২৬৭. ‘পরস্পর’ শব্দটির সন্ধি বিচ্ছেদ কোনটি? ক. পরঃ + পর খ. পরস্ + পর গ. পর + পর ঘ. পরো + পর ঙ. পরসঃ + পর Ans. গ ব্যাখ্যা: পর + পর = পরস্পর (নিপাতনে সিদ্ধ ব্যঞ্জনসন্ধি)।
২৬৮. কোন সন্ধিটি নিপাতনে সিদ্ধ? ক. পর + পর = পরস্পর খ. বাক্ + দান = বাগদান গ. উৎ + ছেদ = উচ্ছেদ ঘ. সম্ + সার = সংসার Ans. ক ব্যাখ্যা: পর + পর = পরস্পর নিপাতনে সিদ্ধ।
২৬৯. ‘পতঞ্জলি’ শব্দের সন্ধি বিচ্ছেদ - ক. পত + অঞ্জলি খ. পতঃ + অঞ্জলি গ. পত্ + অঞ্জলি ঘ. পতৎ + অঞ্জলি Ans. ঘ ব্যাখ্যা: পতৎ + অঞ্জলি = পতঞ্জলি (নিপাতনে সিদ্ধ ব্যঞ্জনসন্ধি)।
২৭০. ‘বৃহস্পতি’-একটি সন্ধিবদ্ধ শব্দ। এর সন্ধি বিচ্ছেদ করলে পাওয়া যায় - ক. বৃহস্ + পতি খ. বৃহৎ + পতি গ. বৃহঃ + পতি ঘ. বৃহম্পত + ই Ans. খ ব্যাখ্যা: বৃহৎ + পতি = বৃহস্পতি (নিপাতনে সিদ্ধ ব্যঞ্জনসন্ধি)।
২৭১. ‘বৃহৎ + পতি = বৃহস্পতি’- এটি কোন নিয়মের দৃষ্টান্ত? ক. বিসর্গ সন্ধি খ. ব্যঞ্জন সন্ধি গ. নিপাতনে সিদ্ধ ঘ. স্বরসন্ধি Ans. গ ব্যাখ্যা: এটি নিয়মের বাইরে গঠিত নিপাতনে সিদ্ধ সন্ধি।
২৭২. নিপাতনে সিদ্ধ হয়ে সন্ধিবদ্ধ হয়েছে কোনটি? ক. মৃন্ময় খ. বৃহস্পতি গ. বৃহর্থ ঘ. আদ্যন্ত Ans. খ ব্যাখ্যা: বৃহৎ + পতি = বৃহস্পতি।
২৭৩. ‘মনীষা’-এর সন্ধি বিচ্ছেদ কোনটি? ক. মন + ইষা খ. মনস্ + ঈষা গ. মন + ঈষা ঘ. মনস + ইষা Ans. খ ব্যাখ্যা: মনস্ + ঈষা = মনীষা (নিপাতনে সিদ্ধ স্বরসন্ধি)।
২৭৪. ‘মনঃকষ্ট’ এর সন্ধি বিচ্ছেদ - ক. মনস + কষ্ট খ. মনো + কষ্ট গ. মনোহ + কষ্ট ঘ. মনঃ + কষ্ট Ans. ঘ ব্যাখ্যা: ক্-এর পূর্বে বিসর্গ থাকলে তা বহাল থাকে, তাই মনঃ + কষ্ট = মনঃকষ্ট।
২৭৫. ‘শুদ্ধোদন’ শব্দের সন্ধি বিচ্ছেদ - ক. শুদ্ধ + উদন খ. শুদ্ধ + উদান গ. শুদ্ধ + ওদন ঘ. শুদ্‌ + উদন Ans. গ ব্যাখ্যা: শুদ্ধ + ওদন = শুদ্ধোদন।
২৭৬. ‘ষোড়শ’ শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. ষট্ + দশ খ. ষড়্ + শ গ. ষোড় + অশ ঘ. ষোড় + শ Ans. ক ব্যাখ্যা: ষট্ + দশ = ষোড়শ (নিপাতনে সিদ্ধ ব্যঞ্জনসন্ধি)।
২৭৭. নিপাতনে সিদ্ধ সন্ধি কোনটি? ক. বাক্ + দান = বাগদান খ. জল + ওকা = জলৌকা গ. নিঃ + রব = নীরব ঘ. ষট্ + দশ = ষোড়শ ঙ. কোনোটিই নয় Ans. ঘ ব্যাখ্যা: ষট্ + দশ = ষোড়শ।
২৭৮. ‘সীমান্ত’ শব্দটির সন্ধি বিচ্ছেদ - ক. সীমা + অন্ত খ. সী + অন্ত গ. সীম + অন্ত ঘ. সীমন + অন্ত Ans. ক ব্যাখ্যা: সীমা + অন্ত = সীমান্ত (আ + অ = আ-কার, এটি স্বরসন্ধির উদাহরণ)।
২৭৯. কোনটি নিপাতনে সিদ্ধ সন্ধি নয়? ক. মস্যাধার খ. গবাক্স গ. মার্তণ্ড ঘ. কুলটা Ans. ক ব্যাখ্যা: মসী + আধার = মস্যাধার (ই + আ = য-ফলা + আ) স্বাভাবিক স্বরসন্ধি; কিন্তু গবাক্স, মার্তণ্ড ও কুলটা নিপাতনে সিদ্ধ সন্ধি।
২৮০. কোন সন্ধি বিচ্ছেদটি ভুল? ক. গৈ + অক খ. সু + অল্প গ. আ + চর্য ঘ. দু + লোক Ans. ঘ ব্যাখ্যা: দিব্ + লোক = দ্যুলোক সঠিক, তাই 'দু + লোক' ভুল বিচ্ছেদ।
২৮১. কোনটি অশুদ্ধ সন্ধি বিচ্ছেদ? ক. মনঃ + কষ্ট = মনঃকষ্ট খ. প্রাতঃ + কাল = প্রতঃকাল গ. মনঃ + কামনা = মনঃকামনা ঘ. অন্তঃ + কারণ = অন্তঃকরণ Ans. খ ব্যাখ্যা: প্রাতঃ + কাল = প্রাতঃকাল (ক, খ, গ, ঘ পরে থাকলে অ-কারান্ত বিসর্গ অপরিবর্তিত থাকে, তাই 'প্রতঃকাল' রূপটি অশুদ্ধ)।
২৮২. নিচের অশুদ্ধ সন্ধি বিচ্ছেদ কোনটি? ক. সু + অল্প = স্বল্প খ. অনু + এষণ = অন্বেষণ গ. আদ্য + আন্ত = আদ্যন্ত ঘ. ভৌ + উক = ভাবুক Ans. গ ব্যাখ্যা: আদি + অন্ত = আদ্যন্ত হয়, তাই 'আদ্য + আন্ত' অশুদ্ধ।
