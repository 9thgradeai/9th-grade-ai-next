সন্ধি
০১. 'সন্ধি' শব্দের অর্থ কী? ক. সংক্ষেপণ খ. মিলন গ. বিশ্লেষণ ঘ. সংযোজন Ans. খ. মিলন ব্যাখ্যা: পাশাপাশি অবস্থিত দুটি ধ্বনির দ্রুত উচ্চারণের ফলে যে মিলন ঘটে, তাকে সন্ধি বলে। তাই সন্ধি শব্দের অর্থ মিলন।
০২. সন্ধির প্রধান উদ্দেশ্য কী? ক. শব্দের অর্থ স্পষ্ট করা খ. উচ্চারণের সুবিধা ও শ্রুতিমধুরতা গ. শব্দকে সংকুচিত করা ঘ. নতুন শব্দ তৈরি করা Ans. খ. উচ্চারণের সুবিধা ও শ্রুতিমধুরতা ব্যাখ্যা: স্বাভাবিক উচ্চারণের সাবলীলতা এবং ভাষাকে শ্রুতিমধুর করাই সন্ধির প্রধান উদ্দেশ্য।
০৩. সন্ধি ব্যাকরণের কোন অংশে আলোচিত হয়? ক. ধ্বনিতত্ত্বে খ. রূপতত্ত্বে গ. বাক্যতত্ত্বে ঘ. অর্থতত্ত্বে Ans. ক. ধ্বনিতত্ত্বে ব্যাখ্যা: সন্ধি মূলত ধ্বনির মিলন, পরিবর্তন বা বিলোপের প্রক্রিয়া, তাই এটি ব্যাকরণের ধ্বনিতত্ত্বে আলোচিত হয়।
০৪. বাংলা সন্ধি প্রধানত কয় প্রকার? ক. ২ প্রকার খ. ৩ প্রকার গ. ৪ প্রকার ঘ. ৫ প্রকার Ans. ক. ২ প্রকার ব্যাখ্যা: খাঁটি বাংলা সন্ধি প্রধানত ২ প্রকার: স্বরসন্ধি ও ব্যঞ্জনসন্ধি।
০৫. তৎসম বা সংস্কৃত সন্ধি কয় প্রকার? ক. ২ প্রকার খ. ৩ প্রকার গ. ৪ প্রকার ঘ. ৫ প্রকার Ans. খ. ৩ প্রকার ব্যাখ্যা: সংস্কৃত নিয়মে সন্ধি ৩ প্রকার: স্বরসন্ধি, ব্যঞ্জনসন্ধি ও বিসর্গ সন্ধি।
০৬. 'নবান্ন' শব্দটির সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. নব + অন্ন খ. নবা + অন্ন গ. নব + আন্ন ঘ. নবো + অন্ন Ans. ক. নব + অন্ন ব্যাখ্যা: অ-কার কিংবা আ-কারের পর অ-কার কিংবা আ-কার থাকলে উভয়ে মিলে আ-কার হয় (অ+অ=আ)।
০৭. 'বিদ্যালয়' শব্দটির সন্ধি বিচ্ছেদ কী হবে? ক. বিদ্য + আলয় খ. বিদ্যা + লয় গ. বিদ্যা + আলয় ঘ. বিদ্য + লয় Ans. গ. বিদ্যা + আলয় ব্যাখ্যা: আ-কারের পর আ-কার থাকলে উভয়ে মিলে আ-কার হয় (আ+আ=আ)।
০৮. 'যথেষ্ট' শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. যথ + ইষ্ট খ. যথা + ইষ্ট গ. যথা + ঈষ্ট ঘ. যথে + ষ্ট Ans. খ. যথা + ইষ্ট ব্যাখ্যা: অ-কার বা আ-কারের পর ই-কার বা ঈ-কার থাকলে উভয়ে মিলে এ-কার হয় (আ+ই=এ)।
০৯. 'সূর্যোদয়' শব্দটির সন্ধি বিচ্ছেদ কোনটি? ক. সূর্য + উদয় খ. সূর্য + দয় গ. সূর্যো + উদয় ঘ. সূর্যা + উদয় Ans. ক. সূর্য + উদয় ব্যাখ্যা: অ-কার বা আ-কারের পর উ-কার বা ঊ-কার থাকলে উভয়ে মিলে ও-কার হয় (অ+উ=ও)।
১০. 'মহর্ষি' শব্দের সঠিক সন্ধি বিচ্ছেদ কী? ক. মহ + ঋষি খ. মহা + ঋষি গ. মহো + ঋষি ঘ. মহর + ষি Ans. খ. মহা + ঋষি ব্যাখ্যা: অ-কার বা আ-কারের পর 'ঋ' থাকলে উভয়ে মিলে 'অর' হয় এবং তা রেফ হয়ে পরবর্তী বর্ণে যুক্ত হয় (আ+ঋ=অর)।
১১. 'শীতার্ত' শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. শীত + ঋত খ. শীত + আর্ত গ. শীতা + ঋত ঘ. শীত + রত Ans. ক. শীত + ঋত ব্যাখ্যা: অ-কার বা আ-কারের পর 'ঋত' শব্দ থাকলে উভয়ে মিলে 'আর' হয় (অ+ঋত=আর)।
১২. 'জনৈক' শব্দের সঠিক সন্ধি বিচ্ছেদ কী? ক. জন + এক খ. জন + ঐক গ. জনা + এক ঘ. জনো + এক Ans. ক. জন + এক ব্যাখ্যা: অ-কার বা আ-কারের পর এ-কার বা ঐ-কার থাকলে উভয়ে মিলে ঐ-কার হয় (অ+এ=ঐ)।
১৩. 'মহৌষধি' শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. মহা + ঔষধি খ. মহা + ওষধি গ. মহ + ঔষধি ঘ. মহো + ওষধি Ans. খ. মহা + ওষধি ব্যাখ্যা: আ-কারের পর ও-কার বা ঔ-কার থাকলে উভয়ে মিলে ঔ-কার হয়। (মহা+ওষধি=মহৌষধি)।
১৪. 'পরীক্ষা' শব্দটির সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. পরি + ইক্ষা খ. পরী + ঈক্ষা গ. পরি + ঈক্ষা ঘ. পরী + ইক্ষা Ans. গ. পরি + ঈক্ষা ব্যাখ্যা: ই-কার বা ঈ-কারের পর ই-কার বা ঈ-কার থাকলে উভয়ে মিলে দীর্ঘ ঈ-কার হয় (ই+ঈ=ঈ)।
১৫. 'সুক্ + উক্তি' মিলে কোন সন্ধিবদ্ধ শব্দটি তৈরি হয়? ক. সুউক্তি খ. সুযুক্তি গ. সূক্তি ঘ. সুক্তি Ans. গ. সূক্তি ব্যাখ্যা: উ-কারের পর উ-কার থাকলে উভয়ে মিলে দীর্ঘ ঊ-কার হয় (সু + উক্তি = সূক্তি)।
১৬. 'যদ্যপি' শব্দের সঠিক সন্ধি বিচ্ছেদ কী? ক. যদি + অপি খ. যদ্য + অপি গ. যদো + অপি ঘ. যদি + আপি Ans. ক. যদি + অপি ব্যাখ্যা: ই-কার বা ঈ-কারের পর ই/ঈ ভিন্ন অন্য স্বর থাকলে ই/ঈ স্থানে য-ফলা হয়।
১৭. 'অন্বেষণ' শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. অন্ব + এষণ খ. অনু + এষণ গ. অনু + এষন ঘ. অনো + এষণ Ans. খ. অনু + এষণ ব্যাখ্যা: উ-কার বা ঊ-কারের পর ভিন্ন স্বর থাকলে উ/ঊ স্থানে ব-ফলা হয়।
১৮. 'স্বাগত' শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. স্বা + গত খ. সু + আগত গ. স্ব + আগত ঘ. সু + গত Ans. খ. সু + আগত ব্যাখ্যা: উ-কারের পর ভিন্ন স্বর 'আ' থাকায় উ-কার স্থানে ব-ফলা হয়েছে (সু+আগত=স্বাগত)।
১৯. 'পিত্রালয়' শব্দের সন্ধি বিচ্ছেদ কী? ক. পিতা + আলয় খ. পিতৃ + আলয় গ. পিত্র + আলয় ঘ. পিতর + আলয় Ans. খ. পিতৃ + আলয় ব্যাখ্যা: ঋ-কারের পর ভিন্ন স্বর থাকলে ঋ স্থানে 'র' (র-ফলা) হয়। (পিতৃ+আলয়=পিত্রালয়)।
২০. 'নয়ন' শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. ন + অন খ. নে + অন গ. নৈ + অন ঘ. নী + অন Ans. খ. নে + অন ব্যাখ্যা: এ-কারের পর অ-কার থাকলে 'এ' স্থানে 'অয়' হয় (নে+অন=নয়ন)।
২১. 'গায়ক' শব্দটির সন্ধি বিচ্ছেদ কোনটি? ক. গা + অক খ. গৈ + অক গ. গে + অক ঘ. গায় + অক Ans. খ. গৈ + অক ব্যাখ্যা: ঐ-কারের পর ভিন্ন স্বর থাকলে 'ঐ' স্থানে 'আয়' হয় (গৈ+অক=গায়ক)।
২২. 'পবন' শব্দের সঠিক সন্ধি বিচ্ছেদ কী? ক. প + বন খ. প + অন গ. পো + অন ঘ. পৌ + অন Ans. গ. পো + অন ব্যাখ্যা: ও-কারের পর ভিন্ন স্বর থাকলে 'ও' স্থানে 'অব' হয় (পো+অন=পবন)।
২৩. 'নাবিক' শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. না + বিক খ. নে + ইক গ. নো + ইক ঘ. নৌ + ইক Ans. ঘ. নৌ + ইক ব্যাখ্যা: ঔ-কারের পর ভিন্ন স্বর থাকলে 'ঔ' স্থানে 'আব' হয় (নৌ+ইক=নাবিক)।
২৪. 'গবাক্ষ' শব্দটির সঠিক সন্ধি বিচ্ছেদ কী? ক. গো + অক্ষ খ. গো + আক্ষ গ. গবা + অক্ষ ঘ. গোব + অক্ষ Ans. ক. গো + অক্ষ ব্যাখ্যা: এটি নিপাতনে সিদ্ধ স্বরসন্ধি, সাধারণ নিয়মের বাইরে গঠিত।
২৫. নিচের কোনটি নিপাতনে সিদ্ধ স্বরসন্ধির উদাহরণ? ক. বিদ্যালয় খ. মহর্ষি গ. প্রৌঢ় ঘ. সূর্যোদয় Ans. গ. প্রৌঢ় ব্যাখ্যা: 'প্রৌঢ়' (প্র + ঊঢ়) নিপাতনে সিদ্ধ স্বরসন্ধির একটি প্রচলিত উদাহরণ।
২৬. 'মার্তণ্ড' শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. মার্ত + অণ্ড খ. মার্ত + ওণ্ড গ. মার্তা + অণ্ড ঘ. মার্তু + অণ্ড Ans. ক. মার্ত + অণ্ড ব্যাখ্যা: এটি নিপাতনে সিদ্ধ স্বরসন্ধি, যা সাধারণ স্বরসন্ধির নিয়ম মানে না।
২৭. 'স্বৈর' শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. স্ব + ইর খ. স্ব + ঈর গ. স্বৈ + র ঘ. সু + ঐর Ans. খ. স্ব + ঈর ব্যাখ্যা: এটিও নিপাতনে সিদ্ধ স্বরসন্ধি। নিয়ম অনুযায়ী অ+ঈ=এ হওয়ার কথা, কিন্তু এখানে ঐ হয়েছে।
২৮. 'দিগন্ত' শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. দিগ + অন্ত খ. দিক + অন্ত গ. দিক্ + অন্ত ঘ. দিগ্ + অন্ত Ans. গ. দিক্ + অন্ত ব্যাখ্যা: ক্, চ্, ট্, ত্, প্ -এর পর স্বরধ্বনি থাকলে সেগুলো স্ববর্গের ৩য় ধ্বনি (গ, জ, ড, দ, ব) হয়।
২৯. 'ষড়দর্শন' শব্দের সন্ধি বিচ্ছেদ কী? ক. ষড় + দর্শন খ. ষট + দর্শন গ. ষট্ + দর্শন ঘ. ষড়্ + দর্শন Ans. গ. ষট্ + দর্শন ব্যাখ্যা: ট্-এর পর দ থাকলে ট্ স্থানে ড় হয় (ষট্+দর্শন=ষড়দর্শন)।
৩০. 'পরিচ্ছদ' শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. পরি + ছদ খ. পরিচ্ + ছদ গ. পরি + চ্ছদ ঘ. পরী + ছদ Ans. ক. পরি + ছদ ব্যাখ্যা: স্বরধ্বনির পর 'ছ' থাকলে তা 'চ্ছ' হয় (পরি+ছদ=পরিচ্ছদ)।
৩১. 'উচ্চারণ' শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. উৎ + চারণ খ. উদ্ + চারণ গ. উচ্চ + আরণ ঘ. উ + চারণ Ans. ক. উৎ + চারণ ব্যাখ্যা: ত্ বা দ্-এর পর চ বা ছ থাকলে ত্/দ্ স্থানে 'চ' হয়।
৩২. 'সজ্জন' শব্দের সঠিক সন্ধি বিচ্ছেদ কী? ক. সৎ + জন খ. সজ + জন গ. সদ + জন ঘ. সদ্ + জন Ans. ক. সৎ + জন ব্যাখ্যা: ত্ বা দ্-এর পর জ বা ঝ থাকলে ত্/দ্ স্থানে 'জ' হয়।
৩৩. 'কুজ্ঝটিকা' শব্দের সন্ধি বিচ্ছেদ কোনটি? ক. কুত্ + ঝটিকা খ. কুদ্ + ঝটিকা গ. কুত + ঝটিকা ঘ. কুজ্ + ঝটিকা Ans. ক. কুত্ + ঝটিকা ব্যাখ্যা: ত্ বা দ্-এর পর ঝ থাকলে ত্/দ্ স্থানে 'জ' হয়।

৯৮. 'স্বেচ্ছা' শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. স্ব + ইচ্ছা খ. সু + ইচ্ছা গ. স্বে + চ্ছা ঘ. স্বৈ + চ্ছা Ans. ক. স্ব + ইচ্ছা ব্যাখ্যা: অ-কারের পর ই-কার থাকলে উভয়ে মিলে এ-কার হয় (স্ব+ইচ্ছা=স্বেচ্ছা)।
৯৯. 'রমেশ' শব্দের সন্ধি বিচ্ছেদ কী? ক. রম + ঈশ খ. রমা + ইশ গ. রমা + ঈশ ঘ. রম + ইশ Ans. গ. রমা + ঈশ ব্যাখ্যা: আ-কারের পর দীর্ঘ ঈ-কার থাকলে উভয়ে মিলে এ-কার হয়।
১০০. 'বাগাড়ম্বর' শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি? ক. বাক + আড়ম্বর খ. বাঘ + আড়ম্বর গ. বাক্ + আড়ম্বর ঘ. বাগ্ + আড়ম্বর Ans. গ. বাক্ + আড়ম্বর ব্যাখ্যা: ক্-এর পর স্বরধ্বনি থাকলে ক্ স্থানে বর্গের ৩য় ধ্বনি গ হয় (বাক্+আড়ম্বর=বাগাড়ম্বর)।
