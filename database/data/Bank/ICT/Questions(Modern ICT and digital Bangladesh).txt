Section A: Artificial Intelligence, Machine Learning and Generative AI
1. What is Artificial Intelligence (AI)?
A. A method of storing files permanently B. The ability of machines to perform tasks associated with human intelligence C. A type of computer network D. A system used exclusively for numerical calculations
Correct Answer: B. The ability of machines to perform tasks associated with human intelligence Explanation: AI enables machines to perform tasks such as reasoning, language understanding, pattern recognition, and decision-making. It is a broad field that includes machine learning and natural language processing.
2. Which statement best describes Machine Learning (ML)?
A. Computers execute only explicitly programmed rules B. Computers learn patterns from data to make predictions or decisions C. Computers operate without algorithms D. Computers convert all data into printed documents
Correct Answer: B. Computers learn patterns from data to make predictions or decisions Explanation: Machine learning is a subset of AI in which models learn statistical patterns from data. For example, a bank can train a model to identify potentially fraudulent transactions.
3. Which of the following is a generative AI application?
A. A calculator that performs addition B. A conventional file-compression utility C. A tool that creates a new image from a text prompt D. A switch that forwards network packets
Correct Answer: C. A tool that creates a new image from a text prompt Explanation: Generative AI produces new content, including text, images, audio, video, and code. It differs from systems designed only to classify or retrieve existing information.
4. Which relationship among AI, ML, and deep learning is correct?
A. AI is a subset of ML, which is a subset of deep learning B. ML and AI are unrelated fields C. Deep learning includes all forms of AI D. Deep learning is a subset of ML, which is a subset of AI
Correct Answer: D. Deep learning is a subset of ML, which is a subset of AI Explanation: AI is the broadest field. Machine learning is a subset of AI, and deep learning uses multilayer neural networks as a specialized approach to machine learning.
5. A bank trains a system using historical transactions labelled “fraudulent” or “legitimate.” Which learning approach is being used?
A. Supervised learning B. Unsupervised learning C. Reinforcement learning D. Manual data entry
Correct Answer: A. Supervised learning Explanation: Supervised learning uses labelled training examples containing inputs and known target outputs. The labels allow the model to learn how to classify new transactions.
6. Which machine-learning approach is most suitable for grouping customers according to purchasing patterns when no group labels are provided?
A. Supervised classification B. Unsupervised learning C. Reinforcement learning D. Rule-based encryption
Correct Answer: B. Unsupervised learning Explanation: Unsupervised learning discovers structures or patterns in unlabelled data. Clustering is commonly used for customer segmentation.
7. In reinforcement learning, an agent primarily learns through:
A. Memorising a fixed list of answers B. Receiving only labelled examples C. Interacting with an environment and receiving rewards or penalties D. Converting source code into machine code
Correct Answer: C. Interacting with an environment and receiving rewards or penalties Explanation: Reinforcement learning improves an agent's behaviour through actions and feedback. Its objective is generally to maximise cumulative reward over time.
8. Which technology is most closely associated with understanding and generating human language?
A. Optical disc technology B. DNS C. RAID D. Natural Language Processing (NLP)
Correct Answer: D. Natural Language Processing (NLP) Explanation: NLP enables computers to process human language in text or speech. Applications include chatbots, translation, sentiment analysis, and document summarisation.
9. A bank uses AI to estimate whether a loan applicant may default. This is an example of:
A. Predictive analytics B. Disk defragmentation C. Data encryption alone D. Optical character printing
Correct Answer: A. Predictive analytics Explanation: Predictive analytics uses historical data and statistical or machine-learning models to estimate future outcomes. Such predictions support credit-risk assessment but should not replace appropriate governance and human oversight.
10. What is a major function of a large language model (LLM)?
A. Physically repairing computer hardware B. Predicting and generating language sequences from learned patterns C. Regulating mobile network spectrum D. Replacing every database with a spreadsheet
Correct Answer: B. Predicting and generating language sequences from learned patterns Explanation: LLMs are trained on large collections of data to model language and generate contextually relevant outputs. They can perform tasks such as drafting, summarisation, translation, and question answering.
11. What is a common limitation of generative AI systems?
A. They can process only printed documents B. They cannot generate text C. They may produce plausible-sounding but factually incorrect information D. They always retrieve verified facts from official databases
Correct Answer: C. They may produce plausible-sounding but factually incorrect information Explanation: This behaviour is commonly called a hallucination. Important outputs, especially legal, financial, and factual claims, should be verified against reliable sources.
12. What does a prompt mean in generative AI?
A. A physical component of the CPU B. A permanent backup copy of a model C. A network cable connecting two computers D. An instruction or input provided to guide the model's response
Correct Answer: D. An instruction or input provided to guide the model's response Explanation: A prompt can contain a question, task, context, examples, or output-format requirements. Clear prompts generally help guide the system toward more relevant responses.
13. Which technology is commonly used to extract printed or handwritten text from images or scanned documents?
A. Optical Character Recognition (OCR) B. File Transfer Protocol (FTP) C. Simple Mail Transfer Protocol (SMTP) D. Dynamic Host Configuration Protocol (DHCP)
Correct Answer: A. Optical Character Recognition (OCR) Explanation: OCR converts text images into machine-readable text. AI-enhanced OCR can help banks digitise forms, invoices, and identity documents, although results require quality checks.
14. Which of the following is an example of computer vision?
A. Assigning an IP address automatically B. Detecting a person's face in an image C. Compressing a database backup D. Translating a domain name into an IP address
Correct Answer: B. Detecting a person's face in an image Explanation: Computer vision enables machines to interpret visual information from images and videos. Applications include image classification, object detection, and facial recognition.
15. A model performs extremely well on training data but poorly on new data. What is this problem called?
A. Normalisation B. Encryption C. Overfitting D. Data transmission
Correct Answer: C. Overfitting Explanation: Overfitting occurs when a model learns training-specific details, including noise, rather than patterns that generalise well. Proper validation, regularisation, and suitable training data can reduce the problem.
16. In machine learning, what is the purpose of a test dataset?
A. To replace all training data B. To store the model's source code C. To provide labels only after deployment D. To evaluate performance on data withheld from model training
Correct Answer: D. To evaluate performance on data withheld from model training Explanation: A test set estimates how well a model performs on unseen examples. It should not be repeatedly used to tune the model, as this can undermine an unbiased evaluation.
17. Which metric measures the proportion of all predictions that are correct?
A. Accuracy B. Latency C. Bandwidth D. Throughput
Correct Answer: A. Accuracy Explanation: Accuracy is the number of correct predictions divided by the total number of predictions. In highly imbalanced fraud datasets, accuracy alone can be misleading because fraudulent cases may be rare.
18. Which term describes unfair or systematically skewed outcomes produced by an AI system?
A. Data compression B. Algorithmic bias C. Load balancing D. Packet switching
Correct Answer: B. Algorithmic bias Explanation: AI bias can result from unrepresentative training data, historical inequalities, or flawed model design. Banks should test models for fairness and monitor their effects on different groups.
19. Which AI capability is most directly used by a chatbot that answers customers' banking questions in conversational language?
A. Disk partitioning B. Network routing C. Natural Language Processing D. Data deduplication
Correct Answer: C. Natural Language Processing Explanation: NLP supports understanding user queries and producing language-based responses. Modern conversational assistants may combine NLP with large language models and information retrieval.
20. What is a deepfake?
A. A database that contains duplicated records B. A method for encrypting a hard drive C. A type of optical fibre D. Synthetic or manipulated media created using AI or other digital techniques to imitate real people or events
Correct Answer: D. Synthetic or manipulated media created using AI or other digital techniques to imitate real people or events Explanation: Deepfakes can imitate voices, faces, or movements and may be used in fraud or misinformation. Banks should not rely solely on voice or video appearance to authenticate high-risk transactions.
21. Which statement best distinguishes generative AI from traditional discriminative AI?
A. Generative AI can create new content, while discriminative models commonly classify or predict labels B. Generative AI can only store data, while discriminative AI can only delete it C. Discriminative AI never uses training data D. Generative AI cannot use neural networks
Correct Answer: A. Generative AI can create new content, while discriminative models commonly classify or predict labels Explanation: A generative model may create text or images, whereas a discriminative model may determine whether a transaction is fraudulent. This is a useful conceptual distinction, although some modern models can perform both kinds of tasks.
22. What is the primary purpose of a recommendation system used by an e-commerce website?
A. To allocate IP addresses B. To suggest products based on relevant user or item information C. To issue digital certificates D. To replace the payment gateway
Correct Answer: B. To suggest products based on relevant user or item information Explanation: Recommendation systems may use collaborative filtering, content-based methods, or hybrid approaches. They help personalise product suggestions based on preferences and behaviour.
23. Which of the following is an example of predictive maintenance using AI?
A. Printing a monthly salary sheet B. Manually switching off a computer C. Analysing sensor data to predict when equipment may fail D. Formatting a word-processing document
Correct Answer: C. Analysing sensor data to predict when equipment may fail Explanation: Predictive maintenance uses data and analytical models to estimate equipment failure before it occurs. This can reduce unexpected downtime and maintenance costs.
24. What does the term “training data” refer to in machine learning?
A. Data created only after a model has been retired B. A computer's electrical power supply C. A list of internet domain names D. Data used by a learning algorithm to fit a model
Correct Answer: D. Data used by a learning algorithm to fit a model Explanation: Training data provides examples from which the model learns patterns or relationships. The quality, relevance, and representativeness of this data strongly influence model performance.
25. Which is the most appropriate practice when using a public generative AI service for banking work?
A. Avoid submitting confidential customer information unless the service is explicitly approved and appropriate safeguards are in place B. Upload customer passwords to improve response quality C. Treat every generated answer as an official bank decision D. Disable all verification of generated financial information
Correct Answer: A. Avoid submitting confidential customer information unless the service is explicitly approved and appropriate safeguards are in place Explanation: Sensitive information can create privacy, confidentiality, and compliance risks when submitted to external systems. Approved tools, access controls, data minimisation, and human verification are essential.
26. Which technique allows an AI application to retrieve relevant external documents before generating a response?
A. RAID B. Retrieval-Augmented Generation (RAG) C. Packet fragmentation D. Disk mirroring
Correct Answer: B. Retrieval-Augmented Generation (RAG) Explanation: RAG combines information retrieval with generative AI. It can help a model answer questions using relevant documents, although retrieval quality and source verification remain important.
27. Which of the following best describes a neural network?
A. A physical arrangement of internet cables B. A database containing only numerical values C. A computational model consisting of interconnected processing units arranged in layers D. A protocol for sending email
Correct Answer: C. A computational model consisting of interconnected processing units arranged in layers Explanation: Artificial neural networks contain connected units that transform input data using learned parameters. Deep neural networks contain multiple processing layers.
28. What is an AI model's inference stage?
A. Constructing the physical computer B. Collecting electricity for the server C. Deleting all training examples D. Using a trained model to produce a prediction or output
Correct Answer: D. Using a trained model to produce a prediction or output Explanation: Training adjusts model parameters using data. Inference occurs when the trained model is applied to new inputs, such as estimating transaction risk or generating text.
29. A bank uses a model to flag suspicious transactions for further review. Which approach is most appropriate?
A. Combine model outputs with risk-based controls and suitable human review B. Automatically assume every flagged transaction is criminal C. Remove all audit records D. Ignore false positives and false negatives
Correct Answer: A. Combine model outputs with risk-based controls and suitable human review Explanation: Fraud-detection systems can make errors in both directions. Appropriate review, auditability, monitoring, and escalation help reduce the consequences of incorrect predictions.
30. Which statement about Artificial General Intelligence (AGI) is most accurate?
A. It is another name for a spreadsheet B. It refers to a hypothetical or debated form of AI with broad, general-purpose cognitive capabilities C. It is a standard banking payment protocol D. It is a device used only to connect printers
Correct Answer: B. It refers to a hypothetical or debated form of AI with broad, general-purpose cognitive capabilities Explanation: AGI is generally used for AI that can perform a broad range of intellectual tasks rather than a narrow set of specialised tasks. It should not be confused with today's task-specific AI applications.
31. Which technology enables a system to convert spoken language into written text?
A. Image segmentation B. Data warehousing C. Automatic Speech Recognition (ASR) D. Blockchain mining
Correct Answer: C. Automatic Speech Recognition (ASR) Explanation: ASR converts audio speech into text. It can support voice assistants, call-centre transcription, and accessibility features, but accuracy varies with accent, noise, and language.
32. Which of the following is an example of unsupervised anomaly detection?
A. Teaching a system using only labelled examples of known fraud B. Sorting files alphabetically C. Encrypting every database record D. Identifying unusual transaction patterns without relying entirely on pre-labelled fraud examples
Correct Answer: D. Identifying unusual transaction patterns without relying entirely on pre-labelled fraud examples Explanation: Unsupervised anomaly detection identifies observations that differ substantially from learned patterns. Unusual transactions may warrant review, but an anomaly is not necessarily fraudulent.
33. In an AI system, what is a feature?
A. An input variable used by a model to make predictions B. A physical keyboard key C. A completed paper report D. A type of cloud subscription
Correct Answer: A. An input variable used by a model to make predictions Explanation: Features may include transaction amount, time, location, or other relevant attributes. Poorly selected or inappropriate features can reduce accuracy and introduce bias.
34. What is the main purpose of validation data during model development?
A. To replace the operating system B. To help select models and tune their settings C. To act as the bank's payment network D. To store only encrypted passwords
Correct Answer: B. To help select models and tune their settings Explanation: Validation data supports model selection and hyperparameter tuning. Training data fits the model, while a separate test dataset is used for final performance evaluation.
35. A text-generating AI produces different responses to the same prompt on different attempts. What is the best explanation?
A. Every AI response must be retrieved from a fixed webpage B. The computer's MAC address has necessarily changed C. Generation may involve probabilistic sampling and configurable decoding settings D. The system has stopped using algorithms
Correct Answer: C. Generation may involve probabilistic sampling and configurable decoding settings Explanation: Some generative models sample from possible next tokens, so their outputs can vary. Even with deterministic settings, differences in context or system implementation can affect results.
36. Which of the following is the strongest example of responsible AI governance in a bank?
A. Deploying a model without testing B. Allowing any employee to change its parameters C. Hiding all automated decisions from auditors D. Establishing accountability, risk assessment, testing, monitoring, and appropriate oversight
Correct Answer: D. Establishing accountability, risk assessment, testing, monitoring, and appropriate oversight Explanation: AI governance addresses reliability, fairness, privacy, accountability, and operational risks throughout the model lifecycle. Governance is especially important when automated outputs influence lending or customer access to financial services.
37. Which AI application is most suitable for translating a Bangla document into English?
A. Machine translation using NLP B. Network address translation alone C. Data deduplication D. Disk encryption
Correct Answer: A. Machine translation using NLP Explanation: Machine translation applies computational language models to translate between languages. Human review may be necessary for legal, technical, or financial documents where subtle errors matter.
38. What is a major risk of relying on biased historical data to train a recruitment or lending model?
A. It automatically increases internet bandwidth B. It may reproduce or amplify existing discriminatory patterns C. It guarantees equal treatment D. It eliminates the need for data quality checks
Correct Answer: B. It may reproduce or amplify existing discriminatory patterns Explanation: Historical data can reflect unequal treatment or underrepresentation. Testing for disparate outcomes and evaluating data quality are important safeguards.
39. Which statement correctly describes the relationship between an AI algorithm and an AI model?
A. They always mean exactly the same thing B. A model is a physical network cable C. An algorithm specifies a computational procedure, while a trained model contains learned parameters or a fitted representation D. An algorithm can never process data
Correct Answer: C. An algorithm specifies a computational procedure, while a trained model contains learned parameters or a fitted representation Explanation: A learning algorithm is used to fit a model from data. Once trained, the model can be applied to new inputs during inference.
40. A bank wants to use AI to summarise long internal policy documents. Which safeguard is especially important?
A. Permit the system to invent missing policy clauses B. Remove document dates and version numbers C. Assume summaries are always legally authoritative D. Check the summary against the original, current policy and protect confidential information
Correct Answer: D. Check the summary against the original, current policy and protect confidential information Explanation: AI summaries can omit qualifications or introduce inaccuracies. Source checking and version control help ensure that employees rely on the correct policy.
Section B: Cloud Computing — IaaS, PaaS and SaaS
41. What is cloud computing?
A. Delivering computing resources and services over a network, usually the internet B. Storing all files exclusively on paper C. Using a computer without any software D. Connecting computers only through Bluetooth
Correct Answer: A. Delivering computing resources and services over a network, usually the internet Explanation: Cloud computing provides resources such as servers, storage, databases, and applications on demand. It can reduce the need to purchase and maintain all infrastructure locally.
42. What does IaaS stand for?
A. Internet as an Application Service B. Infrastructure as a Service C. Information as a Security Standard D. Integration as a Software System
Correct Answer: B. Infrastructure as a Service Explanation: IaaS provides virtualised computing infrastructure, such as virtual machines, storage, and networking. Customers generally manage the operating systems and applications they deploy.
43. Which cloud service model typically provides a ready-to-use application accessed through a web browser?
A. IaaS B. PaaS C. SaaS D. On-premises hardware
Correct Answer: C. SaaS Explanation: Software as a Service delivers applications managed by a provider. Users typically access the application without managing its underlying servers or operating system.
44. A developer wants a managed environment for building, testing, and deploying applications without managing the underlying server infrastructure. Which model is most suitable?
A. SaaS B. IaaS only C. Personal computer hosting D. PaaS
Correct Answer: D. PaaS Explanation: Platform as a Service provides application-development and deployment environments. The provider manages much of the underlying infrastructure and platform, allowing developers to focus on application code.
45. Which of the following is the clearest example of SaaS?
A. A web-based email application managed by a provider B. A raw virtual machine rented from a cloud provider C. A physical server owned and operated entirely by a bank D. A processor installed on a motherboard
Correct Answer: A. A web-based email application managed by a provider Explanation: SaaS supplies a complete application as a service. A user generally does not manage its operating system, runtime, or server infrastructure.
46. Under a typical IaaS arrangement, which responsibility usually remains primarily with the customer?
A. Maintaining the provider's physical data-centre building B. Configuring the guest operating system and deployed applications C. Replacing the provider's physical network switches D. Repairing the cloud provider's power generators
Correct Answer: B. Configuring the guest operating system and deployed applications Explanation: IaaS customers normally control virtual machines and software running inside them. The provider manages physical infrastructure, although exact responsibilities depend on the service agreement.
47. What is a public cloud?
A. A network that must be disconnected from the internet B. A computer accessible only to one employee C. Cloud infrastructure offered for use by multiple customers through a provider D. A paper-based filing system
Correct Answer: C. Cloud infrastructure offered for use by multiple customers through a provider Explanation: Public-cloud services are provided by organisations that operate shared infrastructure for many customers. Logical isolation and security controls separate customer environments.
48. What best describes a private cloud?
A. A free public website B. A social media account C. A shared computer without access controls D. Cloud infrastructure dedicated to a single organisation's use
Correct Answer: D. Cloud infrastructure dedicated to a single organisation's use Explanation: A private cloud is dedicated to one organisation and may be hosted internally or by a third party. It can offer greater control, but it still requires appropriate management and security.
49. What is a hybrid cloud?
A. An arrangement combining private-cloud infrastructure with public-cloud services B. A computer containing both RAM and ROM C. A network that uses only wired connections D. A system that cannot exchange data
Correct Answer: A. An arrangement combining private-cloud infrastructure with public-cloud services Explanation: Hybrid cloud integrates distinct cloud environments, often to balance control, flexibility, and scalability. Workloads and data can be placed according to operational and regulatory needs.
50. What is a major advantage of cloud elasticity?
A. It permanently fixes computing capacity at one level B. Resources can expand or contract as demand changes C. It removes the need for authentication D. It guarantees that outages never occur
Correct Answer: B. Resources can expand or contract as demand changes Explanation: Elasticity allows computing resources to adjust to changing workloads. It can improve resource utilisation, but costs still require monitoring.
51. What does the term “scalability” mean in cloud computing?
A. Encrypting a file with a password B. Printing documents from a server C. Increasing or decreasing capacity to meet workload requirements D. Removing all application users
Correct Answer: C. Increasing or decreasing capacity to meet workload requirements Explanation: Scalability is the ability to accommodate changes in workload. Vertical scaling increases the resources of an existing system, while horizontal scaling adds more instances or machines.
52. Which cloud deployment model is generally most appropriate when an organisation needs a dedicated environment and extensive control over infrastructure?
A. Public social networking B. Open guest Wi-Fi C. Consumer email D. Private cloud
Correct Answer: D. Private cloud Explanation: A private cloud can provide dedicated resources and more control over configuration. However, the organisation must still assess costs, security, compliance, and operational capability.
53. Which of the following is an example of cloud storage?
A. Saving files to a remotely hosted storage service accessed over the internet B. Printing a document on paper C. Saving a file only in a computer's CPU register D. Writing data on a classroom whiteboard
Correct Answer: A. Saving files to a remotely hosted storage service accessed over the internet Explanation: Cloud storage keeps data on provider-managed remote infrastructure. Availability, privacy, backup, access control, and data-retention arrangements should be reviewed.
54. What is a Service Level Agreement (SLA) in cloud computing?
A. A programming language B. An agreement defining service expectations and measurable commitments C. A device for encrypting a keyboard D. A type of database key
Correct Answer: B. An agreement defining service expectations and measurable commitments Explanation: An SLA may specify availability targets, support response times, and remedies for service failures. An availability commitment does not guarantee that outages will never occur.
55. Which cloud feature allows a customer to be charged according to measured resource consumption?
A. Fixed manual filing B. Permanent offline storage C. Metered, pay-as-you-go usage D. Unrestricted free hardware replacement
Correct Answer: C. Metered, pay-as-you-go usage Explanation: Cloud providers often measure usage such as storage, processing time, or data transfer. This can make costs more flexible, but poorly controlled workloads can produce unexpected bills.
56. What is serverless computing?
A. Computing without any physical servers anywhere B. A service that never executes code C. A computer with its processor removed D. A model in which the provider manages server infrastructure and executes code or services on demand
Correct Answer: D. A model in which the provider manages server infrastructure and executes code or services on demand Explanation: Serverless computing hides much of the infrastructure management from developers. Servers still exist, but the provider manages provisioning and much of the scaling.
57. Which statement about cloud security is correct?
A. Security responsibilities are shared between the provider and the customer, depending on the service model B. The provider is always responsible for every customer security setting C. Cloud data cannot be stolen D. Moving to the cloud automatically guarantees regulatory compliance
Correct Answer: A. Security responsibilities are shared between the provider and the customer, depending on the service model Explanation: Providers typically secure the underlying infrastructure, while customers remain responsible for areas such as identities, data, and configurations. The precise division depends on the service and agreement.
58. What is a major purpose of a cloud backup?
A. To increase the physical size of a monitor B. To help restore data after deletion, corruption, or other loss C. To eliminate the need for access controls D. To prevent all network delays
Correct Answer: B. To help restore data after deletion, corruption, or other loss Explanation: Backups preserve recoverable copies of data. Organisations should test restoration procedures and protect backups against unauthorised access and ransomware.
59. A bank wants to move an existing operating system and custom application to a virtual machine while retaining considerable control over the software environment. Which model is most appropriate?
A. SaaS B. PaaS exclusively C. IaaS D. A search engine
Correct Answer: C. IaaS Explanation: IaaS offers virtualised infrastructure on which customers can install and manage operating systems and applications. PaaS usually abstracts more of the underlying system.
60. What is a cloud region?
A. A user's password B. A spreadsheet worksheet C. A single software function D. A geographic area containing cloud-provider infrastructure
Correct Answer: D. A geographic area containing cloud-provider infrastructure Explanation: Providers organise infrastructure into geographic regions, often with multiple availability zones. Region selection can affect latency, resilience, and data-residency obligations.
61. What is an availability zone in many cloud platforms?
A. An isolated location or group of data-centre facilities within a region B. A public internet search result C. A user-account password D. A software licence number
Correct Answer: A. An isolated location or group of data-centre facilities within a region Explanation: Availability zones are designed to reduce the effect of certain local failures. Deploying across zones can improve resilience when configured appropriately.
62. Which of the following is a potential disadvantage of cloud computing?
A. It always requires no internet connection B. Dependence on connectivity and possible provider lock-in C. It cannot store digital files D. It cannot support remote access
Correct Answer: B. Dependence on connectivity and possible provider lock-in Explanation: Cloud applications may be difficult to access during network disruptions, and moving between providers can be costly. Portability planning and contingency arrangements help manage these risks.
63. What is vendor lock-in?
A. A method of locking a physical office door B. A form of data compression C. Difficulty moving from one provider because of technical, contractual, or cost barriers D. A technique for generating random passwords
Correct Answer: C. Difficulty moving from one provider because of technical, contractual, or cost barriers Explanation: Proprietary interfaces, data formats, and dependencies can make migration difficult. Open standards and exit planning can reduce lock-in risk.
64. Which is the best example of PaaS?
A. Purchasing a desktop monitor B. Using a finished online word processor C. Renting a physical office D. Using a managed application platform to deploy code without managing the underlying operating system
Correct Answer: D. Using a managed application platform to deploy code without managing the underlying operating system Explanation: PaaS provides a managed environment for application development and deployment. A finished online word processor is more characteristic of SaaS.
65. What does “multi-tenancy” commonly mean in public-cloud services?
A. Multiple customers use shared underlying resources while their environments are logically separated B. Each customer must own a separate data centre C. A single person operates multiple keyboards D. Data is always stored in plain text
Correct Answer: A. Multiple customers use shared underlying resources while their environments are logically separated Explanation: Multi-tenancy improves resource utilisation, but isolation and access controls are essential. Shared infrastructure does not mean that one customer should be able to access another's data.
66. Which cloud-related technology provides a packaged application with its dependencies in an isolated, portable environment?
A. Optical character recognition B. Containerisation C. Domain registration D. Analog transmission
Correct Answer: B. Containerisation Explanation: Containers package applications and their dependencies while sharing the host operating-system kernel. They can improve consistency across development and deployment environments.
67. What is the primary purpose of a virtual machine?
A. To convert every website into a printed book B. To replace all data with images C. To emulate a computing environment that can run its own operating system D. To regulate national telecommunications tariffs
Correct Answer: C. To emulate a computing environment that can run its own operating system Explanation: Virtual machines allow multiple isolated computing environments to run on physical hardware. A hypervisor manages their execution and resource allocation.
68. Which practice is most important before migrating a bank's critical application to the cloud?
A. Deleting all audit logs B. Ignoring data-residency requirements C. Assuming migration automatically reduces every cost D. Assessing security, compliance, availability, dependencies, costs, and recovery requirements
Correct Answer: D. Assessing security, compliance, availability, dependencies, costs, and recovery requirements Explanation: A structured migration assessment identifies operational and regulatory risks before deployment. Critical banking systems also require testing, rollback planning, and appropriate business continuity measures.
69. What is the main difference between vertical and horizontal scaling?
A. Vertical scaling increases the resources of one machine; horizontal scaling adds more machines or instances B. Vertical scaling means deleting all servers C. Horizontal scaling means increasing screen brightness D. They are two names for data encryption
Correct Answer: A. Vertical scaling increases the resources of one machine; horizontal scaling adds more machines or instances Explanation: Vertical scaling may increase CPU or RAM on an instance. Horizontal scaling distributes workloads across additional instances and can improve resilience when properly designed.
70. Which is the most appropriate approach to protect cloud-hosted banking data?
A. Share administrator passwords with all employees B. Apply least-privilege access, strong authentication, encryption, monitoring, and tested recovery controls C. Disable security logs D. Make every storage bucket publicly accessible
Correct Answer: B. Apply least-privilege access, strong authentication, encryption, monitoring, and tested recovery controls Explanation: Cloud security depends on layered controls rather than a single feature. Access should be limited to authorised users and monitored for suspicious activity.
Section C: Internet of Things (IoT), Big Data and Blockchain
71. What is the Internet of Things (IoT)?
A. A system used exclusively for browsing websites B. A collection of offline word-processing applications C. A network of physical objects equipped with sensors, software, and connectivity D. A method of printing digital documents
Correct Answer: C. A network of physical objects equipped with sensors, software, and connectivity Explanation: IoT connects physical devices so they can collect, exchange, and sometimes act on data. Examples include smart electricity meters, connected vehicles, and industrial sensors.
72. Which component of an IoT device detects physical conditions such as temperature or humidity?
A. Search engine B. Firewall rule C. Database index D. Sensor
Correct Answer: D. Sensor Explanation: Sensors measure physical conditions and convert them into data that a system can process. Actuators perform actions, such as opening a valve or switching a motor on.
73. In an IoT system, what is the primary function of an actuator?
A. To perform a physical action in response to a control signal B. To translate a domain name into an IP address C. To generate a digital certificate D. To store website bookmarks
Correct Answer: A. To perform a physical action in response to a control signal Explanation: An actuator converts a control signal into a physical effect, such as movement or switching. Sensors measure conditions; actuators act on them.
74. A smart electricity meter sends usage readings automatically to a utility company. Which technology is most directly involved?
A. Desktop publishing B. Internet of Things C. Optical disc burning D. Spreadsheet formatting
Correct Answer: B. Internet of Things Explanation: A connected smart meter measures consumption and transmits readings electronically. Automated metering can reduce manual reading and help detect unusual usage patterns.
75. What does M2M stand for in connected-device systems?
A. Memory-to-Memory B. Machine-to-Monitor C. Machine-to-Machine D. Manual-to-Manual
Correct Answer: C. Machine-to-Machine Explanation: M2M refers to communication between devices with limited or no direct human intervention. IoT commonly incorporates M2M communication along with internet connectivity and data services.
76. What is edge computing?
A. Storing every file on the edge of a computer screen B. Computing exclusively in a central government office C. A method of physically cutting network cables D. Processing data near its source instead of sending everything to a distant central system
Correct Answer: D. Processing data near its source instead of sending everything to a distant central system Explanation: Edge computing can reduce latency and bandwidth usage. For example, an industrial sensor system may detect a dangerous condition locally without waiting for a remote cloud response.
77. Which is a major security risk associated with IoT devices?
A. Devices with weak passwords or unpatched firmware may be compromised B. Sensors cannot collect information C. Every IoT device is automatically immune to malware D. Connected devices never communicate over networks
Correct Answer: A. Devices with weak passwords or unpatched firmware may be compromised Explanation: Poorly secured IoT devices can be used to steal data or participate in botnets. Strong authentication, updates, network segmentation, and secure configuration help reduce these risks.
78. What is big data?

Section E: Digital Signatures and Electronic Transactions
131. What is a digital signature?
A. A scanned image of a handwritten signature in every case B. A password typed at the end of an email C. A cryptographic mechanism used to help verify authenticity and integrity D. A method of compressing electronic documents
Correct Answer: C. A cryptographic mechanism used to help verify authenticity and integrity Explanation: A digital signature commonly uses public-key cryptography and a hash of the signed data. It helps detect changes and verify that the signature corresponds to a particular signing key.
132. Which key is normally used to create a digital signature in a public-key cryptography system?
A. The recipient's public key B. A shared database key available to everyone C. The recipient's password D. The signer's private key
Correct Answer: D. The signer's private key Explanation: The signing operation uses the signer's private key, while verification generally uses the corresponding public key. The private key must remain protected from unauthorised use.
133. Which key is normally used to verify a digital signature?
A. The signer's corresponding public key B. Any unrelated private key C. The recipient's ATM PIN D. A randomly selected encryption key
Correct Answer: A. The signer's corresponding public key Explanation: A verifier uses the public key associated with the signing key to validate the signature. A valid signature supports integrity and key-based authenticity, but identity assurance also depends on how the public key is associated with the signer.
134. What is the principal purpose of a cryptographic hash in a digital-signature system?
A. To increase the file's physical size B. To create a fixed-length digest representing the signed data C. To reveal the signer's private key D. To convert the document into a paper copy
Correct Answer: B. To create a fixed-length digest representing the signed data Explanation: The signing process typically incorporates a hash of the document. If the document changes, its hash will ordinarily change, causing signature verification to fail.
135. Which statement best distinguishes an electronic signature from a digital signature?

Correct Answer: C. An electronic signature is a broad category, while a digital signature generally refers to a cryptographic technique Explanation: Electronic signatures may include typed names, click-to-sign actions, or other electronic methods, depending on the applicable legal framework. Digital signatures use cryptographic mechanisms and are one technical approach to electronic signing.
136. What is the role of a digital certificate in a public-key infrastructure (PKI)?

To bind a public key to an identified subject through a trusted certification process Explanation: A digital certificate typically contains a public key and identity information and is digitally signed by a certification authority. Certificate validation includes checking its trust chain, validity period, and revocation status where applicable.
137. What does PKI stand for?

Correct Answer: A. Public Key Infrastructure Explanation: PKI comprises technologies, policies, roles, and processes used to manage public-key cryptography and digital certificates. It supports applications such as digital signatures and secure authentication.
138. What is the main function of a Certification Authority (CA)?
A. To repair computer processors B. To issue and manage digital certificates under defined trust procedures C. To provide electricity to a data centre D. To operate every bank's core banking system

139. Which of the following best describes non-repudiation in electronic transactions?

140. What is the purpose of encryption in electronic transactions?

142. Which statement correctly describes asymmetric cryptography?

143. Which security property means that information has not been altered in an unauthorised manner?

144. Which security property ensures that information is accessible to authorised users when required?
A. Confidentiality B. Obfuscation C. Compression D. Availability
