Section 1: Operating System Fundamentals
1. Which of the following best describes an operating system?
A. A device used exclusively for data storage B. System software that manages hardware and provides services to applications C. An application used only for word processing D. A programming language used to develop websites
Correct Answer: B. System software that manages hardware and provides services to applications
Explanation: An operating system (OS) manages resources such as the CPU, memory, storage, and input/output devices. It also provides an environment in which application software runs.
2. Which of the following is NOT an operating system?
A. Linux B. Microsoft Windows C. Microsoft Excel D. macOS
Correct Answer: C. Microsoft Excel
Explanation: Excel is spreadsheet application software, not an operating system. Windows, Linux, and macOS are operating systems that manage computer resources and support applications.
3. Which component of an operating system interacts most directly with the hardware and manages core system resources?
A. Spreadsheet B. Web browser C. Word processor D. Kernel
Correct Answer: D. Kernel
Explanation: The kernel is the core of an operating system. It manages CPU scheduling, memory, device communication, and other fundamental operations.
4. Which type of software acts as an intermediary between computer hardware and application programs?
A. System software B. Presentation software C. Database content D. Desktop publishing documents
Correct Answer: A. System software
Explanation: System software includes operating systems, device drivers, and utilities. It helps applications use hardware resources without requiring each application to control the hardware independently.
5. Which of the following is an example of application software?
A. Linux kernel B. Device driver C. Microsoft Word D. UEFI firmware
Correct Answer: C. Microsoft Word
Explanation: Microsoft Word is application software designed for creating and editing documents. A kernel, device driver, and firmware serve system-level functions.
6. What is the primary function of a device driver?
A. To create presentation slides B. To enable the operating system to communicate with a hardware device C. To convert every document into a PDF automatically D. To replace the computer's processor
Correct Answer: B. To enable the operating system to communicate with a hardware device
Explanation: A device driver provides software instructions that allow the operating system to control or communicate with hardware such as printers, graphics adapters, and network interfaces.
7. Which operating-system function is primarily responsible for allocating CPU time to competing processes?
A. File compression B. Page formatting C. Spell checking D. Process scheduling
Correct Answer: D. Process scheduling
Explanation: Process scheduling determines which process or thread receives CPU time and when. It supports efficient resource utilization and responsive multitasking.
8. Virtual memory allows an operating system to:
A. Use secondary storage to supplement physical RAM B. Increase the physical size of the CPU C. eliminate the need for permanent storage D. execute programs without any memory
Correct Answer: A. Use secondary storage to supplement physical RAM
Explanation: Virtual memory allows the OS to keep some memory contents on secondary storage and bring them into RAM when needed. It does not make storage as fast as physical RAM, and excessive paging can reduce performance.
9. Which of the following is a key responsibility of an operating system's file-management system?
A. Designing presentation themes B. Calculating spreadsheet averages C. Organizing files and directories and controlling file access D. Translating every high-level program into machine code
Correct Answer: C. Organizing files and directories and controlling file access
Explanation: File management includes creating, naming, organizing, storing, retrieving, and protecting files. The exact features depend on the operating system and file system.
10. Which of the following best distinguishes a process from a program?
A. A process is always a hardware device, while a program is software. B. A program is a set of instructions; a process is a program in execution. C. A program must be online, while a process must be offline. D. A process is a file extension, while a program is a folder.
Correct Answer: B. A program is a set of instructions; a process is a program in execution.
Explanation: A program is a stored set of instructions, whereas a process is an executing instance with associated resources and state. One program may have multiple running instances.
11. Which operating-system capability prevents one ordinary application from freely accessing another application's protected memory?
A. Slide transition B. Mail merge C. Cell referencing D. Memory protection
Correct Answer: D. Memory protection
Explanation: Memory protection restricts processes from accessing memory regions they are not permitted to use. It helps improve system stability and security.
12. What is the principal purpose of a user account in a multiuser operating system?
A. To identify a user and associate access rights and settings with that user B. To increase the processor's clock speed C. To convert all files into executable programs D. To eliminate the need for authentication
Correct Answer: A. To identify a user and associate access rights and settings with that user
Explanation: User accounts help the OS distinguish users, manage permissions, and maintain separate settings and files. Authentication may use passwords, security keys, biometrics, or other mechanisms.
13. Which of the following is an example of a command-line interface (CLI)?
A. A graphical desktop containing icons only B. A slide-show view in PowerPoint C. A terminal in which users enter text commands D. A spreadsheet displayed as a grid
Correct Answer: C. A terminal in which users enter text commands
Explanation: A CLI accepts textual commands, commonly through a terminal or shell. A graphical user interface (GUI), by contrast, uses visual elements such as windows, menus, and icons.
14. Which statement about open-source operating systems is correct?
A. They can never be used commercially. B. Their source code is made available under a license that permits specified forms of use, inspection, or modification. C. They cannot support graphical interfaces. D. They are necessarily free of security vulnerabilities.
Correct Answer: B. Their source code is made available under a license that permits specified forms of use, inspection, or modification.
Explanation: Open-source software is governed by a license that grants particular rights concerning source code. Open source does not automatically mean that all services are free or that vulnerabilities cannot occur.
15. Which of the following is most directly associated with managing files, folders, and storage locations through a graphical Windows environment?
A. Windows File Explorer B. Microsoft PowerPoint Slide Show C. Excel Formula Bar D. Word Mail Merge Wizard
Correct Answer: A. Windows File Explorer
Explanation: File Explorer is the Windows file-management application used to browse drives and folders, copy or move files, rename items, and inspect file properties.
16. Which of the following is an example of a real-time operating system (RTOS)?
A. An OS designed to guarantee responses within specified timing constraints B. An OS that can run only one program per day C. An OS used exclusively for creating spreadsheets D. An OS that does not manage memory
Correct Answer: A. An OS designed to guarantee responses within specified timing constraints
Explanation: An RTOS is designed to respond to events within defined timing requirements. It is used in embedded control systems, industrial automation, and other time-sensitive applications.
17. Which of the following is a primary function of a file system?
A. Increasing the physical capacity of RAM B. Determining the monitor's refresh rate C. Organizing and tracking files on a storage device D. Replacing the operating system kernel
Correct Answer: C. Organizing and tracking files on a storage device
Explanation: A file system defines how files and directories are organized and how storage locations and metadata are managed. Examples include NTFS, FAT32, ext4, and APFS.
18. What is the main purpose of a user interface in an operating system?
A. To manufacture hardware components B. To provide a means for users to interact with the computer C. To guarantee unlimited storage capacity D. To eliminate all application software
Correct Answer: B. To provide a means for users to interact with the computer
Explanation: A user interface enables users to issue commands, access applications, and manage system resources. Common forms include graphical and command-line interfaces.
19. Which of the following is a utility program rather than a general-purpose application?
A. Microsoft Word B. Microsoft PowerPoint C. A presentation editor D. A disk-cleanup utility
Correct Answer: D. A disk-cleanup utility
Explanation: Utility software performs maintenance, diagnostic, security, or optimization tasks. Word and PowerPoint are productivity applications used to create documents and presentations.
20. Which statement about an operating system and application software is correct?
A. Application software commonly relies on OS services to access hardware and system resources. B. Every application must contain its own operating system. C. An operating system is always a spreadsheet program. D. Application software cannot use files.
Correct Answer: A. Application software commonly relies on OS services to access hardware and system resources.
Explanation: Applications normally request services through operating-system interfaces and libraries. The OS manages access to hardware, files, memory, and other resources.
Section 2: Windows, Linux, Android and macOS
21. Which company develops Microsoft Windows?
A. Apple B. Google C. Microsoft D. Canonical
Correct Answer: C. Microsoft
Explanation: Microsoft develops the Windows operating-system family for personal computers and other devices. Apple develops macOS, Google develops Android with contributions from the broader Android ecosystem, and Canonical publishes Ubuntu Linux.
22. Which of the following is a Linux distribution?
A. Microsoft Excel B. Ubuntu C. macOS Finder D. Android Studio
Correct Answer: B. Ubuntu
Explanation: Ubuntu is a Linux distribution based on the Linux kernel. Other examples include Debian, Fedora, and Linux Mint.
23. Android is primarily built around which operating-system kernel?
A. Windows NT kernel B. XNU kernel C. FreeBSD kernel exclusively D. Linux kernel
Correct Answer: D. Linux kernel
Explanation: Android uses the Linux kernel, together with Android-specific system components and application frameworks. Android is not simply a conventional desktop Linux distribution.
24. Which operating system is developed by Apple for its Mac computers?
A. macOS B. Ubuntu C. Android D. ChromeOS Flex only
Correct Answer: A. macOS
Explanation: macOS is Apple's desktop operating system for Mac computers. It provides a graphical environment and includes system services, security mechanisms, and application support.
25. Which statement best describes Linux?
A. It is exclusively a spreadsheet application. B. It cannot operate on servers. C. It is an open-source kernel used by many operating-system distributions. D. It can be installed only on smartphones.
Correct Answer: C. It is an open-source kernel used by many operating-system distributions.
Explanation: The Linux kernel is the core of numerous operating systems used on servers, desktops, embedded systems, and other devices. Linux distributions combine the kernel with utilities, libraries, package managers, and often a desktop environment.
26. Which Windows feature provides a graphical area containing application icons, open windows, and the taskbar?
A. BIOS setup B. Desktop C. Command interpreter only D. CPU cache
Correct Answer: B. Desktop
Explanation: The Windows desktop is the primary graphical workspace. Users can launch applications, access files, and switch between open windows using desktop elements and the taskbar.
27. Which Windows tool is commonly used to view running processes and end an unresponsive application?
A. Character Map B. WordPad C. Paint D. Task Manager
Correct Answer: D. Task Manager
Explanation: Task Manager displays information about running applications, processes, resource usage, and startup apps. It can be used to end a frozen task, although unsaved work may be lost.
28. In a typical Linux command-line environment, which command lists files and directories?
A. ls B. dirword C. showppt D. listxls
Correct Answer: A. ls
Explanation: The ls command lists directory contents in common Linux shells. Commands such as cd, pwd, and mkdir are used to change directories, display the current directory, and create directories, respectively.
29. Which Linux command is commonly used to change the current working directory?
A. rm B. grep C. cd D. chmod
Correct Answer: C. cd
Explanation: The cd command changes the current working directory. By contrast, rm removes files or directories, grep searches text, and chmod changes file permissions.
30. Which of the following is commonly used as a graphical file manager in many Linux desktop environments?
A. Microsoft Access B. GNOME Files C. Excel Formula Bar D. Windows Registry Editor
Correct Answer: B. GNOME Files
Explanation: GNOME Files, also known as Nautilus, is a graphical file manager associated with the GNOME desktop environment. Other Linux desktop environments have their own file managers.
31. What is the name of the graphical file-management application commonly used in macOS?
A. Task Manager B. File Explorer C. Control Panel D. Finder
Correct Answer: D. Finder
Explanation: Finder allows macOS users to browse files and folders, access storage locations, and manage documents. File Explorer performs a comparable role in Windows.
32. Which statement correctly distinguishes Android from iOS?
A. Android is associated with Google's mobile OS ecosystem, whereas iOS is Apple's mobile operating system for iPhones. B. Android is a desktop word processor, whereas iOS is a spreadsheet. C. Android cannot run mobile applications. D. iOS is a Linux distribution maintained by Canonical.
Correct Answer: A. Android is associated with Google's mobile OS ecosystem, whereas iOS is Apple's mobile operating system for iPhones.
Explanation: Android and iOS are major mobile operating-system platforms. They differ in system architecture, application distribution, development frameworks, and device ecosystems.
33. Which macOS feature is commonly used to search for applications, files, and other information on a Mac?
A. Disk Defragmenter B. Task View only C. Spotlight D. Mail Merge
Correct Answer: C. Spotlight
Explanation: Spotlight is macOS's system-wide search feature. It can locate files and applications and provide results from other supported sources.
34. Which statement about Windows and Linux is correct?
A. Both are exclusively mobile operating systems. B. Both can support multitasking and multiple user accounts. C. Neither supports networking. D. Linux cannot use a graphical user interface.
Correct Answer: B. Both can support multitasking and multiple user accounts.
Explanation: Modern Windows and Linux systems support multitasking, networking, and user accounts. Linux can be operated through a CLI, a GUI, or both.
35. Which of the following is a common characteristic of Android devices?
A. They can never connect to wireless networks. B. They cannot run applications. C. They are designed exclusively for desktop towers. D. They commonly support touch-based interaction and mobile applications.
Correct Answer: D. They commonly support touch-based interaction and mobile applications.
Explanation: Android is widely used on smartphones, tablets, and other embedded devices. Touch interaction and application-based functionality are common, although Android also supports devices with other input methods.
36. What is a key distinction between macOS and most Linux distributions?
A. macOS is developed by Apple, while Linux distributions are built around the Linux kernel by various organizations and communities. B. macOS cannot manage files. C. Linux distributions cannot run applications. D. macOS is a Microsoft Office application.
Correct Answer: A. macOS is developed by Apple, while Linux distributions are built around the Linux kernel by various organizations and communities.
Explanation: macOS is Apple's proprietary operating system. Linux distributions use the Linux kernel and combine it with other software under their respective licensing arrangements.
37. Which operating system is most closely associated with the Windows Registry?
A. Android B. Ubuntu C. Microsoft Windows D. macOS
Correct Answer: C. Microsoft Windows
Explanation: The Windows Registry is a hierarchical database that stores configuration information for Windows and many installed applications. It should be modified carefully because incorrect changes can cause system problems.
38. In Windows, what is the primary purpose of the Recycle Bin?
A. To permanently increase disk capacity B. To temporarily hold many deleted files so they can potentially be restored C. To run antivirus scans exclusively D. To store CPU instructions permanently
Correct Answer: B. To temporarily hold many deleted files so they can potentially be restored
Explanation: Files deleted through supported Windows operations are often moved to the Recycle Bin, from which they can be restored or permanently deleted. Some deletions, removable-drive operations, and other actions bypass it.
39. Which of the following is a package-management tool commonly associated with Debian-based Linux distributions?
A. PowerPoint Designer B. Windows Registry C. macOS Spotlight D. APT
Correct Answer: D. APT
Explanation: APT, or Advanced Package Tool, manages software packages on Debian-based systems such as Ubuntu. It can install, update, and remove software while handling dependencies.
40. Which statement about operating-system updates is most accurate?
A. Updates may provide security fixes, bug fixes, and feature improvements. B. Updates always double the physical RAM. C. Updates permanently eliminate every possible vulnerability. D. Updates are used only to change document extensions.
Correct Answer: A. Updates may provide security fixes, bug fixes, and feature improvements.
Explanation: Operating-system updates can address known vulnerabilities, improve compatibility, and fix defects. They reduce risk but cannot guarantee that a system will never be compromised.
Section 3: Booting, Multitasking and File Management
41. What is booting?
A. Formatting a document B. Sorting spreadsheet data C. Starting a computer and loading the operating system D. Printing a presentation
Correct Answer: C. Starting a computer and loading the operating system
Explanation: Booting is the startup process in which the computer initializes hardware and loads the OS. A computer may undergo a cold boot after being powered off or a warm boot when restarted.
42. Which type of booting occurs when a computer is started from a powered-off state?
A. Warm boot B. Cold boot C. Safe formatting D. Multitasking boot
Correct Answer: B. Cold boot
Explanation: A cold boot begins from a powered-off state. A warm boot generally refers to restarting a computer without fully powering it off first.
43. Which firmware standard is commonly used on modern computers to initialize hardware and start the operating-system boot process?
A. SMTP B. HTML C. JPEG D. UEFI
Correct Answer: D. UEFI
Explanation: UEFI stands for Unified Extensible Firmware Interface. It provides firmware interfaces and boot services, and it commonly replaces or modernizes the role historically associated with traditional BIOS firmware.
44. What is the principal role of a bootloader?
A. To help load the operating system or its kernel during startup B. To calculate the average of spreadsheet values C. To merge mailing lists into letters D. To create slide transitions
Correct Answer: A. To help load the operating system or its kernel during startup
Explanation: A bootloader helps transfer control to the operating system during startup. Depending on the system, it may also offer boot options or allow selection among multiple operating systems.
45. What is multitasking in an operating system?
A. Connecting multiple monitors without software B. Using several keyboards to type one letter C. Managing the execution of multiple tasks so they can make progress concurrently D. Storing several extensions in one filename
Correct Answer: C. Managing the execution of multiple tasks so they can make progress concurrently
Explanation: Multitasking allows multiple tasks to progress through CPU scheduling and, on suitable hardware, parallel execution. On a single CPU core, tasks often share processor time through rapid switching.
46. Which statement best describes multiprocessing?
A. A method of changing a file extension B. The use of multiple processing units or CPU cores to execute work C. A method of formatting paragraphs D. A process for combining spreadsheet cells
Correct Answer: B. The use of multiple processing units or CPU cores to execute work
Explanation: Multiprocessing uses more than one processing unit or core to execute tasks, potentially in parallel. Multitasking refers to managing multiple tasks and can occur even on a single-core processor.
47. A computer has a single CPU core and rapidly switches between a browser and a word processor. This is an example of:
A. Multiprocessing necessarily involving two CPUs B. File compression C. Mail merge D. Multitasking through time-sharing
Correct Answer: D. Multitasking through time-sharing
Explanation: A single core can execute different tasks in alternating time slices, making them appear to run simultaneously. True parallel execution of separate CPU instructions requires multiple processing resources.
48. Which of the following is a primary function of memory management?
A. Allocating and tracking memory used by processes B. Changing slide backgrounds C. Correcting spelling in documents D. Sorting names alphabetically in a worksheet
Correct Answer: A. Allocating and tracking memory used by processes
Explanation: Memory management controls the allocation, use, and protection of memory. It also supports mechanisms such as virtual memory where provided by the operating system.
49. What is a file path?
A. The speed of a processor B. The number of worksheet rows C. The location of a file or directory within a file-system hierarchy D. The duration of a slide transition
Correct Answer: C. The location of a file or directory within a file-system hierarchy
Explanation: A file path identifies a file or directory's location. For example, C:\Reports\Annual.docx is a typical Windows-style path.
50. Which of the following is an example of an absolute path in a typical Linux file system?
A. ../reports B. /home/user/reports/report.txt C. reports/report.txt D. ./report.txt
Correct Answer: B. /home/user/reports/report.txt
Explanation: An absolute Linux path begins at the root directory, represented by /. Paths such as ../reports and ./report.txt are relative to the current working directory.
51. Which statement about a file and a folder is correct?
A. A folder can contain only one file. B. A file is always an operating system. C. A folder cannot contain subfolders. D. A folder can organize files and other folders.
Correct Answer: D. A folder can organize files and other folders.
Explanation: Folders, also called directories, organize files in a hierarchical structure. A folder can contain multiple files and subfolders, subject to file-system limitations.
52. What is the primary purpose of a file extension?
A. To indicate a file's format or type, commonly through its suffix B. To guarantee that a file is free of malware C. To specify the physical size of the hard disk D. To identify the computer's processor manufacturer
Correct Answer: A. To indicate a file's format or type, commonly through its suffix
Explanation: Extensions such as .docx, .xlsx, and .pptx help identify file formats and associate files with applications. Renaming an extension does not necessarily convert the file's actual format.
53. Which of the following is an example of a hidden file on many Unix-like systems?
A. report.docx B. image.png C. .config D. budget.xlsx
Correct Answer: C. .config
Explanation: In Unix-like systems, a filename beginning with a period is conventionally treated as hidden by many tools and file managers. This naming convention does not itself provide security or encryption.
54. Which file-system permission is commonly associated with the ability to modify a file's contents?
A. Execute only B. Write C. Read only D. Search only
Correct Answer: B. Write
Explanation: In conventional Unix/Linux permissions, read permits reading, write permits modification, and execute permits execution or, for directories, traversal. Effective access also depends on ownership, directory permissions, and other security rules.
55. What happens when a user creates a shortcut to an application in Windows?
A. The application must be duplicated in full. B. The operating system is reinstalled. C. The original application is automatically deleted. D. A link is created that provides convenient access to the target.
Correct Answer: D. A link is created that provides convenient access to the target.
Explanation: A Windows shortcut normally points to a target file, folder, or application. Deleting the shortcut generally does not delete the original target.
56. Which key combination commonly opens Task Manager directly in modern Windows versions?
A. Ctrl + Shift + Esc B. Ctrl + P C. Alt + F4 D. Ctrl + S
Correct Answer: A. Ctrl + Shift + Esc
Explanation: Ctrl + Shift + Esc opens Task Manager directly. Ctrl + P commonly invokes printing, Alt + F4 closes the active window, and Ctrl + S saves the current document.
57. Which Windows key combination locks the computer?
A. Windows + E B. Windows + R C. Windows + L D. Windows + P
Correct Answer: C. Windows + L
Explanation: Windows + L locks the current session. Windows + E opens File Explorer, Windows + R opens the Run dialog, and Windows + P opens display-projection options.
58. Which Windows shortcut opens File Explorer?
A. Windows + D B. Windows + E C. Windows + I D. Windows + Tab
Correct Answer: B. Windows + E
Explanation: Windows + E opens File Explorer. Windows + D shows or hides the desktop, Windows + I opens Settings, and Windows + Tab opens Task View.
59. In a typical Linux shell, which command creates a new directory?
A. pwd B. cat C. whoami D. mkdir
Correct Answer: D. mkdir
Explanation: The mkdir command creates directories. pwd prints the current working directory, cat displays or concatenates file contents, and whoami displays the current effective username.
60. Which Linux command is commonly used to display the current working directory?
A. pwd B. cd C. touch D. mv
Correct Answer: A. pwd
Explanation: pwd stands for “print working directory.” The cd command changes the current directory, while mv moves or renames files and directories.
Section 4: GUI, CLI and Common File Operations
61. What does GUI stand for?
A. General Utility Instruction B. Graphical Universal Internet C. Graphical User Interface D. General User Integration
Correct Answer: C. Graphical User Interface
Explanation: A GUI allows users to interact through graphical elements such as windows, icons, buttons, and menus. It is designed to make many operations accessible without memorizing commands.
62. Which is a major advantage of a command-line interface?
A. It always requires more memory than a GUI. B. It can support efficient automation through scripts and commands. C. It cannot operate remotely. D. It prevents users from managing files.
Correct Answer: B. It can support efficient automation through scripts and commands.
Explanation: CLIs are useful for repetitive operations, administration, scripting, and remote management. They may require familiarity with commands and syntax.
63. Which interface is generally most suitable for a novice user who wants to move a file by dragging its icon into another folder?
A. Machine-code interface B. CPU instruction interface C. Binary-only interface D. GUI
Correct Answer: D. GUI
Explanation: A graphical interface supports direct manipulation through visual elements. Drag-and-drop file management is a common GUI operation, although exact behavior depends on the operating system and context.
64. Which of the following is a command-line shell commonly used on modern Windows systems?
A. PowerShell B. Microsoft Word C. Microsoft Excel D. Finder
Correct Answer: A. PowerShell
Explanation: PowerShell is a command-line shell and scripting environment used for administration and automation. Windows also supports Command Prompt and other terminal-based environments.
65. What is the function of the clipboard in a computer operating system?
A. To permanently store every file on the computer B. To execute the computer's bootloader C. To hold content temporarily for operations such as copying and pasting D. To replace RAM completely
Correct Answer: C. To hold content temporarily for operations such as copying and pasting
Explanation: The clipboard holds copied or cut content so that it can be pasted elsewhere. Depending on the operating system, it may support text, images, files, and clipboard history.
66. Which keyboard shortcut is commonly used to copy selected content?
A. Ctrl + X B. Ctrl + C C. Ctrl + V D. Ctrl + Z
Correct Answer: B. Ctrl + C
Explanation: Ctrl + C copies selected content in many Windows applications. Ctrl + X cuts, Ctrl + V pastes, and Ctrl + Z undoes a recent action.
67. Which keyboard shortcut is commonly used to cut selected content?
A. Ctrl + A B. Ctrl + P C. Ctrl + Y D. Ctrl + X
Correct Answer: D. Ctrl + X
Explanation: Ctrl + X cuts selected content for subsequent pasting. For files, the operation typically marks the selected items for moving when pasted into another location.
68. Which shortcut selects all selectable content in many Windows applications?
A. Ctrl + A B. Ctrl + D C. Ctrl + F D. Ctrl + N
Correct Answer: A. Ctrl + A
Explanation: Ctrl + A commonly selects all content in the current document, field, or list. The exact scope of selection depends on the application and the active control.
69. Which shortcut generally reverses the most recent undoable action?
A. Ctrl + S B. Ctrl + F C. Ctrl + Y D. Ctrl + Z
Correct Answer: C. Ctrl + Y
Explanation: In many Windows applications, Ctrl + Y performs Redo, reversing an earlier Undo. Ctrl + Z normally performs Undo, although shortcut behavior may vary between applications.
70. What is the usual effect of pressing F2 on a selected file in Windows File Explorer?
A. Open the print dialog B. Rename the selected file or folder C. Lock the computer D. Open the spreadsheet formula bar
Correct Answer: B. Rename the selected file or folder
Explanation: F2 is the standard rename shortcut in Windows File Explorer. Users should take care not to change the extension unintentionally when file extensions are visible.
71. Which shortcut commonly opens the Find or Search function in many desktop applications?
A. Ctrl + H only B. Ctrl + E only C. Ctrl + F D. Ctrl + W only
Correct Answer: C. Ctrl + F
Explanation: Ctrl + F commonly opens a search field for locating text or other content. Ctrl + H is often used for Replace or History, depending on the application.
72. Which keyboard shortcut commonly closes the active application window in Windows?
A. Alt + F4 B. Ctrl + C C. Windows + E D. Ctrl + Home
Correct Answer: A. Alt + F4
Explanation: Alt + F4 closes the active window or application, depending on the context. If a document contains unsaved changes, the application may prompt the user to save them.
73. Which operation creates a second copy of a file while leaving the original in its existing location?
A. Rename B. Delete C. Cut and move D. Copy and paste
Correct Answer: D. Copy and paste
Explanation: Copying and pasting creates a duplicate at the destination while retaining the source. Moving a file changes its location rather than creating an independent copy in the usual case.
74. What is the purpose of file compression?
A. To guarantee that all files become encrypted B. To reduce storage requirements or transmission size when possible C. To increase the physical capacity of RAM D. To convert every file into an executable program
Correct Answer: B. To reduce storage requirements or transmission size when possible
Explanation: Compression represents data more efficiently or uses encoding methods that reduce file size. Lossless compression preserves the original data; lossy compression discards some information to achieve greater reduction.
75. Which file extension commonly identifies a ZIP archive?
A. .xlsx B. .pptx C. .zip D. .exe
Correct Answer: C. .zip
Explanation: ZIP is a widely used archive format that can package multiple files and directories and may compress their contents. It does not inherently guarantee encryption or malware-free content.
Section 5: Microsoft Word
76. Microsoft Word is primarily used for:
A. Word processing and document creation B. Managing the CPU scheduler C. Operating a computer's firmware D. Designing network routing protocols
Correct Answer: A. Word processing and document creation
Explanation: Word is a word-processing application used to create, edit, format, and print documents. Typical uses include letters, reports, applications, and official correspondence.
77. Which extension is the default modern Word document format?
A. .xlsx B. .pptx C. .txt D. .docx
Correct Answer: D. .docx
Explanation: .docx is the standard modern Word document extension based on Office Open XML. The older .doc extension is associated with earlier binary Word document formats.
78. Which keyboard shortcut saves a document in Microsoft Word?
A. Ctrl + P B. Ctrl + S C. Ctrl + B D. Ctrl + L
Correct Answer: B. Ctrl + S
Explanation: Ctrl + S saves the current document. Ctrl + P opens printing options, Ctrl + B toggles bold formatting, and Ctrl + L commonly aligns a paragraph to the left.
79. Which shortcut makes selected text bold in Microsoft Word?
A. Ctrl + U B. Ctrl + I C. Ctrl + B D. Ctrl + E
Correct Answer: C. Ctrl + B
Explanation: Ctrl + B toggles bold formatting. Ctrl + I toggles italics, while Ctrl + U toggles underlining.
80. Which shortcut applies italics to selected text in Word?
A. Ctrl + I B. Ctrl + B C. Ctrl + P D. Ctrl + J
Correct Answer: A. Ctrl + I
Explanation: Ctrl + I toggles italic formatting. It changes the appearance of text without changing the underlying words.
81. Which shortcut commonly underlines selected text in Microsoft Word?
A. Ctrl + M B. Ctrl + K C. Ctrl + R D. Ctrl + U
Correct Answer: D. Ctrl + U
Explanation: Ctrl + U toggles underlining in Word. Ctrl + K commonly inserts a hyperlink, while Ctrl + R aligns a paragraph to the right.
82. Which Word feature is used to produce many personalized letters from one template and a recipient list?
A. Track Changes B. Mail Merge C. Word Count D. Page Color
Correct Answer: B. Mail Merge
Explanation: Mail Merge combines a main document with a data source containing recipient-specific fields. It can generate personalized letters, labels, envelopes, and similar documents efficiently.
83. In a mail-merge operation, what is the role of the data source?
A. It determines the monitor resolution. B. It stores the operating system kernel. C. It supplies recipient-specific information such as names and addresses. D. It automatically corrects every grammatical error.
Correct Answer: C. It supplies recipient-specific information such as names and addresses.
Explanation: The data source contains records and fields that are inserted into the main document. For example, a bank could use a recipient list to generate personalized customer letters.
84. Which Word feature controls paper size, page orientation, and page margins?

Correct Answer: D. Alt + Tab
Explanation: Alt + Tab displays a switcher for moving between open windows. It is useful when working with several applications, such as Excel, Word, and a web browser.
176. Which shortcut commonly closes the current browser tab in many desktop browsers?
A. Ctrl + W B. Ctrl + A C. Ctrl + C D. Ctrl + Z
Correct Answer: A. Ctrl + W
Explanation: Ctrl + W closes the active tab or document window in many applications. In a browser, it normally closes the current tab rather than the entire browser process.
177. Which shortcut commonly reopens a recently closed browser tab in many desktop browsers?
A. Ctrl + Shift + P B. Ctrl + Alt + Delete C. Ctrl + Shift + T D. Ctrl + Shift + N
Correct Answer: C. Ctrl + Shift + T
Explanation: Ctrl + Shift + T commonly restores the most recently closed browser tab. Repeated use can often restore additional recently closed tabs.
178. Which shortcut commonly selects the address bar in many desktop web browsers?
A. Ctrl + B B. Ctrl + L C. Ctrl + U D. Ctrl + J
Correct Answer: B. Ctrl + L
Explanation: Ctrl + L moves focus to the browser's address bar in many desktop browsers. Users can then enter a website address or a search query.
179. Which keyboard shortcut commonly refreshes a web page in Windows browsers?
A. Ctrl + S B. Ctrl + P C. Ctrl + D D. F5
Correct Answer: D. F5
Explanation: F5 commonly reloads the current webpage. Ctrl + R also commonly reloads a page in desktop browsers.
180. Which shortcut commonly creates a new folder in Windows File Explorer?
A. Ctrl + Shift + N B. Ctrl + Shift + S C. Alt + Shift + F D. Windows + Ctrl + F
Correct Answer: A. Ctrl + Shift + N
Explanation: Ctrl + Shift + N creates a new folder in Windows File Explorer. It is a convenient way to organize files without using the context menu.
Section 10: File Extensions, Formats and Integrated Applications
181. Which file extension is associated with a modern Excel workbook?
A. .docx B. .pptx C. .xlsx D. .accdb
Correct Answer: C. .xlsx
Explanation: .xlsx is the modern Excel workbook format. It stores worksheets, formulas, formatting, and other workbook information using Office Open XML.
182. Which Excel extension is specifically associated with a macro-enabled workbook?
A. .xlsx B. .xlsm C. .xltx D. .csv
Correct Answer: B. .xlsm
Explanation: .xlsm is a macro-enabled Excel workbook format that can store VBA macros. Macro-enabled files should be treated cautiously when obtained from untrusted sources.
183. Which extension is associated with an Excel template in the modern Office format?
A. .pptx B. .docm C. .xlsx D. .xltx
Correct Answer: D. .xltx
Explanation: .xltx identifies an Excel Open XML template. Templates provide reusable worksheet layouts, formatting, and formulas for new workbooks.
184. Which extension commonly represents a plain-text file?
A. .txt B. .pptx C. .xlsx D. .exe
Correct Answer: A. .txt
Explanation: A plain-text file stores text without the rich formatting and embedded structures typical of Word documents. Its appearance depends on the encoding and the application used to open it.
185. Which extension is commonly associated with a comma-separated values file?
A. .docx B. .pptx C. .csv D. .dll
Correct Answer: C. .csv
Explanation: CSV stands for Comma-Separated Values. It is commonly used to exchange tabular data between spreadsheets, databases, and other applications, but it does not preserve all workbook features such as formulas and formatting.
186. Which extension identifies a Portable Network Graphics image?
A. .gif B. .png C. .mp3 D. .wav
Correct Answer: B. .png
Explanation: PNG is a raster image format that supports lossless compression and transparency. JPEG is also a common image format but typically uses lossy compression.
187. Which extension is commonly associated with a JPEG image?
A. .mp4 B. .docx C. .zip D. .jpg
Correct Answer: D. .jpg
Explanation: .jpg and .jpeg commonly identify JPEG images. JPEG typically uses lossy compression and is widely used for photographs.
188. Which file extension is commonly associated with an executable program in Windows?
A. .exe B. .txt C. .jpg D. .csv
Correct Answer: A. .exe
Explanation: .exe is a common Windows executable extension. An executable file can run code, so files from unknown or untrusted sources should not be launched without appropriate safety checks.
189. Which extension commonly identifies a Windows batch file?
A. .docx B. .xlsx C. .bat D. .png
Correct Answer: C. .bat
Explanation: A .bat file contains commands intended for execution by the Windows command interpreter. Batch files can automate tasks but may also execute harmful commands.
190. Which extension is commonly associated with a Windows dynamic-link library?
A. .pptx B. .dll C. .csv D. .pdf
Correct Answer: B. .dll
Explanation: DLL stands for Dynamic-Link Library. It contains code or resources that can be used by compatible programs, allowing software components to be shared.
191. Which file extension commonly identifies a PDF document?
A. .psd B. .pptx C. .xlsx D. .pdf
Correct Answer: D. .pdf
Explanation: PDF stands for Portable Document Format. It is commonly used to distribute documents while preserving their intended layout across compatible viewers.
192. Which extension is commonly associated with an MP3 audio file?
A. .mp3 B. .mp4 C. .mkv D. .html
Correct Answer: A. .mp3
Explanation: MP3 is a widely used digital audio format that typically employs lossy compression. MP4 is a multimedia container format commonly used for video and audio.
193. Which extension commonly identifies an MP4 multimedia file?
A. .xlsx B. .docx C. .mp4 D. .ini
Correct Answer: C. .mp4
Explanation: MP4 is a multimedia container format that can contain video, audio, subtitles, and related data. The actual codecs used inside an MP4 file can vary.
194. Which extension commonly identifies an HTML document?
A. .sys B. .html C. .dll D. .xlsx
Correct Answer: B. .html
Explanation: HTML stands for HyperText Markup Language. It defines the structure of web content, which web browsers interpret and display.
195. Which extension commonly identifies a Cascading Style Sheets file?
A. .js B. .py C. .xml D. .css
Correct Answer: D. .css
Explanation: CSS controls the presentation and styling of web documents, including colors, spacing, typography, and layout. HTML provides document structure, while JavaScript commonly supplies interactive behavior.
196. Which extension commonly identifies a JavaScript source file?
A. .js B. .css C. .docx D. .xlsx
Correct Answer: A. .js
Explanation: .js is the conventional extension for JavaScript source files. JavaScript is widely used for web development and can also run in server-side and other environments.
197. Which of the following is a correct match between an application and its primary file extension?
A. Word — .xlsx B. PowerPoint — .docx C. Excel — .xlsx D. Windows — .pptx
Correct Answer: C. Excel — .xlsx
Explanation: .xlsx is the standard modern Excel workbook extension. Word normally uses .docx, while PowerPoint normally uses .pptx.
198. A bank employee needs to send a spreadsheet's tabular data to another system that supports simple text-based data exchange. Which format is particularly appropriate?
A. .ppsx B. .csv C. .exe D. .dll
Correct Answer: B. .csv
Explanation: CSV is widely used for exchanging rows and columns of data between systems. It generally does not preserve Excel-specific formulas, multiple worksheets, formatting, or macros.
199. A user renames report.docx to report.pdf using only the file-renaming command. What is the most accurate statement?
A. The file is automatically converted into a valid PDF. B. The file becomes encrypted automatically. C. All formatting is guaranteed to remain identical in every application. D. The extension changes, but the file's underlying format is not necessarily converted.
Correct Answer: D. The extension changes, but the file's underlying format is not necessarily converted.
Explanation: Renaming a file changes its name, not necessarily its internal structure. Proper conversion requires exporting, saving, or converting the document to the target format using suitable software.
200. A bank officer prepares a report in Word, analyzes transaction figures in Excel, and presents the findings in PowerPoint. Which statement best describes this workflow?
A. The three applications serve complementary purposes: document creation, numerical analysis, and presentation. B. All three applications are operating systems. C. Excel is the only application capable of storing files. D. PowerPoint replaces the need for an operating system.
Correct Answer: A. The three applications serve complementary purposes: document creation, numerical analysis, and presentation.
Explanation: Word is designed primarily for document creation, Excel for spreadsheets and numerical analysis, and PowerPoint for slide-based presentations. Together, they support a typical office workflow in which data is analyzed, documented, and communicated.
