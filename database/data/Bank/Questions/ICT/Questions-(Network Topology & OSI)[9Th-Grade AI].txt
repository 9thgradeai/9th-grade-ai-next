1. A BB branch connects 6 ATMs in a full mesh topology for redundancy. How many dedicated cables are required?
A) 12
B) 15
C) 30
D) 36
Ans: B | Speed Solution: Full Mesh formula is N(N-1)/2. For N=6: (6×5)/2 = 15.
2. A clearinghouse connects 10 servers. If 45 cables are used, what topology is deployed?
A) Star
B) Ring
C) Full Mesh
D) Bus
Ans: C | Speed Solution: Reverse engineer N(N-1)/2 = 45. 10(9)/2 = 45. It's a Full Mesh.
3. If the central switch fails in a Bangladesh Bank regional office, all 50 PCs lose connectivity. Which topology is in use?
A) Ring
B) Bus
C) Star
D) Mesh
Ans: C | Speed Solution: "Central device failure = total network failure" is the classic definition of Star topology.
4. A legacy ATM network uses a single coaxial cable where a cut anywhere brings down all machines. This describes a:
A) Star
B) Bus
C) Ring
D) Mesh
Ans: B | Speed Solution: A single backbone cable without central hubs defines a Bus. A single cut breaks the terminator logic.
5. In a Token Ring network used for high-security bank transfers, what prevents data collisions?
A) CSMA/CD
B) Central Switch
C) Token Passing
D) Subnetting
Ans: C | Speed Solution: "Token" Ring literally uses a digital token. Only the node holding the token can transmit.
6. A CBS (Core Banking System) utilizes a hierarchical structure with a central mainframe connected to regional routers, then to branch switches. This is a:
A) Star
B) Tree
C) Mesh
D) Ring
Ans: B | Speed Solution: Hierarchical = Tree. It's a Star of Stars connected in a top-down approach.
7. Adding a new node to which topology requires shutting down the entire network temporarily?
A) Star
B) Mesh
C) Ring
D) Bus
Ans: C | Speed Solution: Breaking a physical Ring to insert a node disrupts the closed loop.
8. Which topology is the Internet (and BB's connection to global SWIFT) based upon?
A) Full Mesh
B) Star
C) Hybrid (Partial Mesh)
D) Ring
Ans: C | Speed Solution: The Internet is a mix of multiple topologies (Star, Mesh, etc.), making it Hybrid.
9. In a Bus topology, what component is required at both ends of the main cable to prevent signal bouncing?
A) Repeater
B) Terminator
C) Hub
D) Node
Ans: B | Speed Solution: Terminators "terminate" or absorb the electrical signal so it doesn't bounce back.
10. To upgrade a Star topology to a Full Mesh topology for 5 bank servers, how many additional cables are needed?
A) 4
B) 6
C) 10
D) 15
Ans: B | Speed Solution: Star with 5 servers uses 4 cables (to central hub). Mesh needs 5(4)/2 = 10 cables. Difference: 10 - 4 = 6.
11. Which OSI layer is responsible for converting 1s and 0s into voltage pulses on a CAT6 cable?
A) Data Link
B) Network
C) Physical
D) Transport
Ans: C | Speed Solution: Physical Layer (L1) handles raw bits and electrical/optical signals.
12. MAC addresses are used to route checks securely within the local branch switch. MAC addressing occurs at:
A) Layer 1
B) Layer 2
C) Layer 3
D) Layer 4
Ans: B | Speed Solution: Media Access Control (MAC) is the lower sublayer of the Data Link Layer (L2).
13. A BB routing policy sends SWIFT messages using IP addresses. IP addresses operate at:
A) Data Link
B) Network
C) Transport
D) Session
Ans: B | Speed Solution: Logical addressing (IP) and routing occur exactly at Layer 3 (Network).
14. A firewall blocks a specific TCP port (e.g., Port 23 for Telnet). Port filtering operates primarily at:
A) Network
B) Transport
C) Session
D) Application
Ans: B | Speed Solution: Ports (TCP/UDP) = Transport Layer (L4).
15. A banking app creates, maintains, and terminates a secure connection dialog with the CBS. This is handled by:
A) Transport Layer
B) Session Layer
C) Presentation Layer
D) Application Layer
Ans: B | Speed Solution: "Dialog control" and "Connection maintenance" = Session Layer (L5).
16. Which OSI layer ensures that data sent from a Linux bank server can be correctly read by a Windows client via data formatting?
A) Application
B) Presentation
C) Session
D) Transport
Ans: B | Speed Solution: Formatting, translation (e.g., ASCII/EBCDIC), and syntax = Presentation Layer (L6).
17. HTTP and SMTP are used by bank employees to browse and send emails. These protocols live at:
A) Layer 5
B) Layer 6
C) Layer 7
D) Layer 4
Ans: C | Speed Solution: End-user network services and protocols (HTTP, FTP, SMTP) reside at the Application Layer (L7).
18. What is the Protocol Data Unit (PDU) at the Transport Layer?
A) Bit
B) Frame
C) Packet
D) Segment
Ans: D | Speed Solution: L1=Bits, L2=Frames, L3=Packets, L4=Segments. (Mnemonic: Big Friendly Pandas Sleep).
19. What is the Protocol Data Unit (PDU) at the Network Layer?

Ans: C | Speed Solution: L3 routes Packets.
20. What is the Protocol Data Unit (PDU) at the Data Link Layer?
A) Bit

C) Packet
D) Segment
Ans: B | Speed Solution: L2 switches forward Frames.

B) Destination IP Address

A) Hub

D) Repeater
Ans: B | Speed Solution: Switches (L2) separate collisions per port, but forward broadcasts (like ARP) to all ports.
25. Which device operates at Layer 3 and separates BOTH collision and broadcast domains?

D) Layer 4
Ans: A | Speed Solution: Repeaters only boost electrical signals (bits); they do no logic or addressing. Layer 1.
27. To encrypt customer PINs, the POS terminal uses SSL/TLS. Encryption is formally mapped to the:
A) Application Layer
B) Presentation Layer
C) Session Layer
D) Transport Layer
Ans: B | Speed Solution: Encryption/Decryption and Compression are classic Layer 6 (Presentation) duties.
28. TCP provides reliable financial data transfer by using acknowledgments. UDP does not. Both operate at:
A) Layer 2
B) Layer 3

D) Layer 5
Ans: C | Speed Solution: TCP and UDP are Transport Layer (L4) protocols.
29. What port is heavily monitored in banks for secure web traffic (HTTPS)?

30. An AD uses FTP to download bulk clearing data. Which OSI layer does FTP operate on?

D) Layer 7

A) Decapsulation

D) Multiplexing
Ans: B | Speed Solution: Wrapping data in layers of headers (like an envelope) is Encapsulation.

Ans: B | Speed Solution: L2 (Data Link) is the only layer that adds a Trailer (FCS/CRC) alongside a header.

A) Layer 2
B) Layer 3
C) Layer 4
D) Layer 7

42. Which Layer 3 device uses a Routing Table to forward packets?
