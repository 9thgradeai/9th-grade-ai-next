Part 1: Operating System Types & Architectures (1 - 50)
1. Bangladesh Bank's RTGS (Real-Time Gross Settlement) system requires instant transaction finality without delay. Which OS type is strictly required for this server?
A) Time-Sharing OS
B) Batch Processing OS
C) Real-Time Operating System (RTOS)
D) Distributed OS
Ans: C | Speed Solution: "Instant/No delay" = Real-Time. RTOS guarantees strict time constraints.
2. The Bangladesh Electronic Funds Transfer Network (BEFTN) processes millions of salaries overnight without human intervention. This mimics which OS architecture?
A) Real-Time OS
B) Batch Processing OS
C) Network OS
D) Multiprocessing OS
Ans: B | Speed Solution: "Overnight without human intervention" = Batching jobs together to process sequentially.
3. If a banking server divides CPU time equally among 100 logged-in tellers, allowing them to work concurrently, the OS is using:
A) Time-Sharing (Multitasking)
B) Batch Processing
C) Spooling
D) Real-Time Processing
Ans: A | Speed Solution: Dividing CPU time into "slices" for multiple users = Time-Sharing.
4. A CBS (Core Banking System) server utilizes 4 physical CPUs to handle massive query loads simultaneously. This is called:
A) Multithreading
B) Multiprocessing
C) Multiprogramming
D) Multitasking
Ans: B | Speed Solution: Multiple physical CPUs = Multi-PROCESSING.
5. Within a single instance of a bank's mobile app, one background task downloads exchange rates while another allows the user to type. This is an example of:
A) Multiprocessing
B) Multithreading
C) Batch Processing
D) Spooling
Ans: B | Speed Solution: Multiple tasks inside ONE program/process = Threads. Multithreading.
6. Which OS feature allows a slow banking printer to receive print jobs from 50 different branch computers simultaneously without freezing their screens?
A) Paging
B) Spooling
C) Thrashing
D) Booting
Ans: B | Speed Solution: SPOOL = Simultaneous Peripheral Operations On-Line. It buffers jobs in memory.
7. In an OS, the capability to load multiple programs into RAM simultaneously so the CPU always has a task to execute is known as:
A) Multiprogramming
B) Multiprocessing
C) Threading
D) Context Switching
Ans: A | Speed Solution: Multiple programs residing in RAM = Multiprogramming (maximizes CPU utilization).
8. Which type of OS architecture links multiple independent banking servers across Dhaka and Chittagong so they appear to the user as a single powerful system?
A) Real-Time OS
B) Distributed OS
C) Batch OS
D) Standalone OS
Ans: B | Speed Solution: Many independent nodes acting as one = Distributed.
9. Hard Real-Time Systems (like an ATM cash dispenser controller) differ from Soft Real-Time Systems because:
A) Hard RTOS missing a deadline causes total system failure; Soft RTOS degrades performance but doesn't fail.
B) Hard RTOS uses SSDs; Soft uses HDDs.
C) Hard RTOS is open-source.
D) Soft RTOS has no kernel.
Ans: A | Speed Solution: Hard = Absolute deadline (e.g., Pacemaker, ATM). Soft = Preferred deadline (e.g., Video streaming).
10. What was the primary disadvantage of early Batch Processing Operating Systems?
A) High cost of CPUs
B) Lack of interaction between the user and the job while it was executing
C) It required internet access
D) It was open-source
Ans: B | Speed Solution: In Batch OS, you hand over the punch cards and wait. No live interaction.
11. Which scheduling algorithm is typically used by a Time-Sharing OS to ensure fairness among branch users?
A) First Come First Serve (FCFS)
B) Shortest Job Next (SJN)
C) Round Robin
D) Priority Scheduling
Ans: C | Speed Solution: Round Robin gives everyone a fixed "time slice" (quantum) in a circular queue. Fairness = Round Robin.
12. In OS terminology, what is "Context Switching" during a teller's multitasking session?
A) Switching the monitor on and off
B) Saving the state of an old process and loading the saved state of a new process into the CPU
C) Converting code to binary
D) Formatting the hard drive
Ans: B | Speed Solution: CPU switches "context" (environment variables) from App A to App B.
13. A "Network Operating System" (NOS) is primarily designed to:
A) Edit videos
B) Manage data, users, security, and applications across a local area network (e.g., Windows Server)
C) Compile code
D) Act as a firewall
Ans: B | Speed Solution: NOS manages network resources (servers, users).
14. Mobile operating systems like iOS and Android execute apps in isolated environments to prevent a malicious app from accessing banking data. This is called:
A) Compiling
B) Sandboxing
C) Spooling
D) Paging
Ans: B | Speed Solution: Sandbox = isolated safe play area. App cannot touch the OS or other apps.
15. Which OS architecture embeds the operating system directly into the ROM of a specific hardware device, like a microwave or a banking POS terminal?
A) Distributed OS
B) Embedded OS
C) Time-sharing OS
D) Batch OS
Ans: B | Speed Solution: Embedded = built deeply into the specific hardware.
16. The "Bootloader" of an OS is responsible for:
A) Terminating viruses
B) Loading the kernel from secondary storage into main memory (RAM) during startup
C) Formatting the disk
D) Managing printers
Ans: B | Speed Solution: It "loads" the core OS into RAM to "boot" the system.
17. "Multiprogramming" was invented to solve which specific hardware problem in early mainframes?
A) Small hard drives
B) CPU sitting idle while waiting for slow I/O operations (like reading a tape)
C) Overheating CPUs
D) Monitor glare
Ans: B | Speed Solution: If Program A waits for the printer, the CPU jumps to Program B. Eliminates idle time.
18. Which OS component manages the allocation and deallocation of physical memory to banking applications?
A) Shell
B) Device Driver
C) Memory Manager
D) Compiler
Ans: C | Speed Solution: Direct name match. Memory Manager manages memory.
19. What is a "Process" in the context of an Operating System?
A) A physical hardware component
B) A program currently in execution
C) A text file
D) A compiler
Ans: B | Speed Solution: Program = passive file on disk. Process = active program executing in RAM.
20. When an OS uses "Virtual Memory", what happens when the physical RAM becomes 100% full during a massive database query?
A) The computer shuts down
B) The OS uses a designated portion of the hard drive (Pagefile) as temporary RAM
C) The CPU overheats
D) Files are permanently deleted
Ans: B | Speed Solution: Virtual RAM is just borrowed hard drive space.
21. A condition where the OS spends more time swapping pages between RAM and the Hard Drive than executing actual processes is called:
A) Spooling
B) Context Switching
C) Thrashing
D) Booting
Ans: C | Speed Solution: The system "thrashes" around doing zero productive work.
22. In OS memory management, "Paging" eliminates which specific type of memory fragmentation?
A) Internal Fragmentation
B) External Fragmentation
C) Data Fragmentation
D) Disk Fragmentation
Ans: B | Speed Solution: Paging divides memory into equal frames, completely eliminating External Fragmentation.
23. "Internal Fragmentation" occurs when:
A) The hard drive fails
B) The memory allocated to a process is slightly larger than the requested memory, leaving wasted space inside the block
C) The CPU pipeline breaks
D) The network disconnects
Ans: B | Speed Solution: Space wasted inside the allocated block = Internal.
24. Which OS component creates a "Process Control Block" (PCB) for every active banking application?
A) Process Manager
B) Assembler
C) Hardware controller
D) Shell
Ans: A | Speed Solution: The OS Process Manager tracks process state, ID, and priority using the PCB.
25. A bank's database server enters a state where Process A holds Resource 1 and waits for Resource 2, while Process B holds Resource 2 and waits for Resource 1. This is the definition of:
A) Thrashing
B) Deadlock
C) Spooling
D) Interrupt
Ans: B | Speed Solution: Circular waiting = Deadlock (Mexican Standoff).
26. Which of the following is NOT one of the 4 necessary conditions for a Deadlock to occur?
A) Mutual Exclusion
B) Hold and Wait
C) No Preemption
D) Context Switching
Ans: D | Speed Solution: The 4th condition is Circular Wait. Context switching is a normal CPU function.
27. An Operating System handles "Interrupts". An interrupt generated by a hardware device (like a mouse click) is called a hardware interrupt. An interrupt generated by software (like a division by zero) is called a:
A) Trap / Exception
B) Spool
C) Page Fault
D) Thread
Ans: A | Speed Solution: Software interrupt = Trap or Exception.
28. Which of the following best defines "Throughput" in a batch processing OS?
A) Time taken to write a program
B) Number of jobs completed per unit of time
C) The speed of the hard drive
D) The amount of RAM used
Ans: B | Speed Solution: Throughput = Volume of output over time.
29. What is "Turnaround Time" for a process in an OS?
A) Time spent in the ready queue
B) Total time taken from submission of a process to its completion
C) Time taken to print a file
D) Time spent waiting for CPU
Ans: B | Speed Solution: Turnaround = Exit time minus Arrival time.
30. "Starvation" in an OS scheduling algorithm occurs when:
A) A low-priority process is repeatedly denied CPU time because higher-priority processes keep arriving
B) The PC loses power
C) RAM is empty
D) The hard drive is full
Ans: A | Speed Solution: The process "starves" because it never gets fed CPU time.
31. To prevent Starvation, operating systems use a technique that gradually increases the priority of a waiting process. This is called:
A) Thrashing
B) Aging
C) Paging
D) Spooling
Ans: B | Speed Solution: As the process gets "older" in the queue, its priority rises.
32. Which memory management scheme allows the physical address space of a process to be non-contiguous?
A) Fixed Partitioning
B) Paging
C) Dynamic Partitioning
D) Base Register allocation
Ans: B | Speed Solution: Paging chops the process into pages and scatters them into any available RAM frames.
33. The "Translation Lookaside Buffer" (TLB) is an OS hardware cache used specifically to speed up:
A) Internet browsing
B) Logical (Virtual) to Physical memory address translation
C) Booting
D) CPU arithmetic
Ans: B | Speed Solution: TLB caches recent page table translations to save time.
34. In a Windows server, the "NTFS" file system is used. What does the file system primarily do?
A) Edits text documents
B) Determines how data is stored, organized, and retrieved on the storage disk
C) Connects to Wi-Fi
D) Scans for viruses
Ans: B | Speed Solution: File System = The index and storage logic of the disk.
35. A "Device Driver" operates in which mode to interact directly with hardware?
A) User Mode
B) Kernel Mode
C) Safe Mode
D) Boot Mode
Ans: B | Speed Solution: Hardware access requires extreme privilege = Kernel Mode.
36. Dual-Mode operation in an OS protects the system from crashing by dividing execution into:
A) Day Mode and Night Mode
B) User Mode (Restricted) and Kernel Mode (Privileged)
C) Fast Mode and Slow Mode
D) Read Mode and Write Mode
Ans: B | Speed Solution: User Mode keeps rogue apps from touching core hardware. If they need hardware, they must ask the Kernel.
37. How does a user application request a service (like reading a file) from the operating system's kernel?
A) By sending an email
B) Via a System Call
C) Via a Compiler
D) Via a Shell command
Ans: B | Speed Solution: System Call (Syscall) is the API bridge between User space and Kernel space.
38. Which system call is used in Unix/Linux to create a new process by duplicating an existing one?
A) create()
B) fork()
C) exec()
D) spawn()
Ans: B | Speed Solution: fork() splits/clones a process into a parent and child.
39. When an OS boots, the first process created in Unix/Linux systems (PID 1) is typically:
A) bash
B) init / systemd
C) kernel
D) root
Ans: B | Speed Solution: init or systemd is the ancestor of all other processes.
40. A banking OS is experiencing "Memory Leak". What causes this?
A) Physical damage to the RAM chip
B) A program allocating memory but failing to release/deallocate it after use, eventually exhausting RAM
C) A virus deleting files
D) The CPU overheating
Ans: B | Speed Solution: Memory leaks occur from bad coding, causing RAM to fill up over time.
Part 2: Kernel vs. Shell & Core Architecture (41 - 80)
41. An IT officer explains OS architecture. The component that acts as the core heart of the OS, managing hardware directly, is the:
A) Shell
B) Compiler
C) Kernel
D) GUI
Ans: C | Speed Solution: Kernel = the nut/core of the system.
42. The component that provides the user interface (CLI or GUI) to interact with the OS is called the:
A) Kernel
B) Shell
C) Driver
D) Compiler
Ans: B | Speed Solution: Shell = the outer layer covering the kernel.
43. MS-DOS, Bash, and Windows Command Prompt are all examples of a:
A) Kernel
B) Shell (Command Line Interpreter)
C) Compiler
D) Hardware Driver
Ans: B | Speed Solution: They take user text commands and pass them to the kernel.
44. In a "Monolithic Kernel" architecture (like Linux), all core OS services (memory, CPU, drivers) run in:
A) User space
B) A single large block of code in Kernel space
C) The Cloud
D) The ROM
Ans: B | Speed Solution: Mono (one) lithic (stone). Everything is packed into one big, fast kernel block.
45. What is the main advantage of a Monolithic Kernel for high-speed bank servers?
A) It is easy to debug
B) High performance, because there is less overhead/communication between components
C) If a driver crashes, the system survives
D) It uses no RAM
Ans: B | Speed Solution: Direct interaction inside one block = peak speed.
46. What is the main disadvantage of a Monolithic Kernel?
A) It is very slow
B) If one component (like a video driver) crashes, the entire operating system crashes (Kernel Panic)
C) It cannot multitask
D) It cannot access the internet
Ans: B | Speed Solution: Since everything shares the same memory space, one bad driver kills the whole system.
47. In a "Microkernel" architecture (like macOS/QNX), how are services structured?
A) Everything is in the kernel
B) Only the absolute bare minimum (CPU scheduling, basic memory) is in the kernel; drivers and file systems run in User space
C) There is no kernel
D) It only uses a Shell
Ans: B | Speed Solution: Micro (tiny) kernel. Keeps the core small and stable.
48. What is the primary advantage of a Microkernel architecture in secure environments?
A) Extreme speed
B) High stability and security; if a device driver crashes, it doesn't crash the whole OS
C) Requires no RAM
D) Open-source by default
Ans: B | Speed Solution: Isolation. Drivers run in user space, so their crash is contained.
49. Which mechanism is heavily used in a Microkernel to allow the user-space services to communicate with the kernel?
A) Direct Memory Access
B) Inter-Process Communication (IPC) / Message Passing
C) Spooling
D) Compiling
Ans: B | Speed Solution: Because services are separated, they must pass messages (IPC) to talk, which adds slight delay but massive stability.
50. Microsoft Windows NT (the core of modern Windows) uses a hybrid approach called a:
A) Monolithic Kernel
B) Microkernel
C) Hybrid Kernel
D) Nano-kernel
Ans: C | Speed Solution: It mixes monolithic speed with microkernel modularity.
51. When a bank teller types dir in the Windows command prompt, which component interprets this command?
A) The Kernel
B) The Shell (cmd.exe)
C) The Hardware
D) The BIOS
Ans: B | Speed Solution: The Shell translates human text commands for the Kernel.
52. "BASH" is a very popular Unix/Linux shell. What does it stand for?
A) Basic Advanced Shell
B) Bourne Again Shell
C) Binary Applied Shell
D) Basic Artificial Shell
Ans: B | Speed Solution: Written as a replacement for the original Bourne shell (sh).
53. The OS Kernel is loaded into memory during the boot process. Where does it reside during the entire time the computer is powered on?
A) Virtual Memory
B) Protected Main Memory (RAM)
C) Hard Drive
D) ROM
Ans: B | Speed Solution: The kernel is memory-resident in a protected RAM sector.
54. Which of the following is NOT a function of the OS Kernel?
A) Process Management
B) Memory Management
C) Compiling Java Code
D) I/O Device Management
Ans: C | Speed Solution: Compiling code is done by application software (Translators), not the OS core.
55. A "System Call" involves a transition from User Mode to Kernel Mode. This transition is facilitated by changing a hardware bit called the:
A) Mode Bit
B) Carry Bit
C) Sign Bit
D) Parity Bit
Ans: A | Speed Solution: Mode Bit 1 = User. Mode Bit 0 = Kernel.
56. "GUI" stands for Graphical User Interface. It is a type of:
A) Kernel
B) Shell
C) Compiler
D) Driver
Ans: B | Speed Solution: GUI is just a visual shell that lets you click icons instead of typing commands.
57. What is "GUI Shell" called in the Windows operating system?
A) Command Prompt
B) Windows Explorer (explorer.exe)
C) Task Manager
D) Cortana
Ans: B | Speed Solution: Explorer.exe controls the desktop, taskbar, and file navigation windows.
58. Which OS component is directly responsible for translating logical file requests into specific cylinder, track, and sector physical read commands for the HDD?
A) File System Manager (in the Kernel)
B) The Shell
C) The Compiler
D) The CPU
Ans: A | Speed Solution: The Kernel translates generic file paths into physical disk sectors.
59. If a kernel uses "Preemptive Scheduling", it means:
A) The CPU waits for a process to voluntarily yield
B) The OS can forcefully interrupt and pause a running process to give CPU time to a higher-priority process
C) Processes are never interrupted
D) The hard drive schedules data
Ans: B | Speed Solution: Preempt = to interrupt/take over by force. Crucial for multitasking.
60. "Non-preemptive" (Cooperative) scheduling was used in older OS (like Windows 3.1). Its major flaw was:
A) It used too much RAM
B) If one application froze or refused to yield the CPU, the entire system would freeze
C) It was too fast
D) It required a Microkernel
Ans: B | Speed Solution: Cooperative means apps must voluntarily share. A greedy app crashes the PC.
61. A user double-clicks an icon to open MS Word. The OS creates a new process. What data structure does the kernel use to store the state of this process?
A) Master Boot Record (MBR)
B) Process Control Block (PCB)
C) Page Table
D) File Allocation Table (FAT)
Ans: B | Speed Solution: PCB holds process ID, state, CPU registers, and memory limits.
62. In Linux, what command is used in the Shell to list all currently running processes?
A) dir
B) ps / top
C) ls
D) grep
Ans: B | Speed Solution: ps (Process Status) or top (Table of Processes).
63. What happens if the OS Kernel experiences an unrecoverable error in Windows?
A) It restarts silently
B) Blue Screen of Death (BSOD)
C) It opens a web browser
D) It formats the drive
Ans: B | Speed Solution: BSOD is Windows' Kernel Panic screen indicating catastrophic failure.
64. What is the equivalent of a BSOD in a Unix/Linux operating system?
A) Red Screen
B) Kernel Panic
C) Segmentation Fault
D) Core Dump
Ans: B | Speed Solution: A Kernel Panic halts the entire Linux system to prevent data corruption.
65. Which of the following is considered a "Bare-Metal" component that interacts strictly with the Kernel?
A) Web Browser
B) Hardware Device Driver
C) Antivirus GUI
D) MS Excel
Ans: B | Speed Solution: Drivers sit at the lowest level, bridging hardware hardware to the kernel.
66. What is "API" in the context of the OS?
A) Application Programming Interface; a set of routines/protocols allowing applications to communicate with the OS Kernel
B) Advanced Processor Interface
C) An antivirus standard
D) A hardware port
Ans: A | Speed Solution: The API provides user-friendly functions (like ReadFile()) that trigger complex System Calls.
67. A bank's database program tries to access a memory address belonging to the OS kernel. What happens?
A) The kernel allows it
B) The hardware generates a "Segmentation Fault / Access Violation" trap, and the OS kills the program
C) The CPU speeds up
D) The data is encrypted
Ans: B | Speed Solution: Memory protection stops rogue apps from breaching kernel security.
68. The core philosophy of the "Unix" OS architecture relies heavily on:
A) Huge monolithic graphical interfaces
B) Small, modular, single-purpose command-line utilities connected via "Pipes"
C) Complex proprietary code
D) Cloud computing
Ans: B | Speed Solution: The Unix philosophy: "Write programs that do one thing and do it well."
69. What is a "Pipe" (|) in a shell environment?
A) A physical cable
B) A method to pass the output of one program directly as the input to another program
C) A virus
D) A memory address
Ans: B | Speed Solution: ls | grep "bank" takes the list output and pipes it into the search tool.
70. In an operating system, what is an "Orphan Process"?
A) A process with no memory
B) A child process whose parent process has terminated or crashed before the child finished
C) A process with no ID
D) A virus process
Ans: B | Speed Solution: Orphan = Lost its parent. (The init process usually adopts them).
71. What is a "Zombie Process" in Unix/Linux?
A) A process that infects others
B) A process that has completed execution but still has an entry in the process table because its parent hasn't read its exit status
C) A completely deleted process
D) An idle process
Ans: B | Speed Solution: It is "dead" (finished) but its body (PCB entry) is still lingering.
72. Operating systems use a "Page Table" to keep track of:
A) Web pages visited
B) The mapping between Virtual memory pages and Physical RAM frames
C) Printed documents
D) Hard drive partitions
Ans: B | Speed Solution: Paging requires an index map (Page Table) to find where virtual data is actually stored in physical RAM.
73. The component of the OS that decides WHICH process in the ready queue gets the CPU next is the:
A) Long-term scheduler
B) Short-term scheduler (CPU Scheduler)
C) Medium-term scheduler
D) Shell
Ans: B | Speed Solution: Short-term scheduler acts every few milliseconds to swap processes.
74. The "Dispatcher" in an OS is responsible for:
A) Deleting files
B) Actually giving control of the CPU to the process selected by the short-term scheduler
C) Connecting to the internet
D) Booting the PC
Ans: B | Speed Solution: Scheduler chooses who is next. Dispatcher physically does the Context Switch to make it happen.
75. What does the "fork()" system call return to the parent process upon successfully creating a child?
A) 0
B) -1
C) The Process ID (PID) of the newly created child
D) Null
Ans: C | Speed Solution: Fork returns 0 to the child, but returns the child's PID to the parent.
76. Which of the following commands is used to forcefully terminate a process via the Linux shell?
A) stop
B) end
C) kill
D) terminate
Ans: C | Speed Solution: kill -9 [PID] is the universal command to force-kill a process.
77. An operating system's "Root Directory" is represented by which symbol in Linux/Unix?
A) C:
B) /
C) ~
D)
Ans: B | Speed Solution: Forward slash (/) is the absolute top of the Linux file hierarchy.
78. The "Home Directory" for a specific user in a Linux shell is represented by:
A) /
B) ~ (Tilde)
C)
D) @
Ans: B | Speed Solution: Tilde (~) is the shortcut for /home/username.
79. In Windows, which OS utility lets an administrator view hardware driver conflicts (indicated by a yellow exclamation mark)?
A) Task Manager
B) Device Manager
C) Registry Editor
D) Disk Management
Ans: B | Speed Solution: Device Manager handles physical hardware and driver states.
80. What is a "Daemon" in a Unix/Linux operating system?
A) A malicious virus
B) A background process that runs without interactive user input (similar to a Windows Service)
C) The core kernel
D) A visual theme
Ans: B | Speed Solution: Daemons run silently in the background (e.g., httpd for web servers).
Part 3: Translators (Compiler, Interpreter, Assembler) (81 - 140)
81. Humans write programs in High-Level Languages (e.g., Java, C++), which are called:
A) Object Code
B) Source Code
C) Machine Code
D) Assembly Code
Ans: B | Speed Solution: The raw human-typed code is the "Source".
82. The CPU can only execute binary 0s and 1s. This format is called:
A) Source Code
B) Machine Code (Object Code)
C) High-Level Code
D) Pseudocode
Ans: B | Speed Solution: Machine Code is the binary language of the processor.
83. A translator program converts Source Code into Machine Code. Which translator processes the ENTIRE source code at once?
A) Interpreter
B) Assembler
C) Compiler
D) Linker
Ans: C | Speed Solution: Compile = to gather everything together at once.
84. Which translator reads the source code line-by-line, translating and executing each line immediately?
A) Compiler
B) Interpreter
C) Assembler
D) Loader
Ans: B | Speed Solution: Interpret = translating live, one sentence (line) at a time.
85. What is the primary advantage of a Compiler over an Interpreter for a deployed banking application?
A) Compilers use less memory
B) Compiled programs execute much faster because they are already translated into machine code
C) Compilers are easier to debug
D) Compilers do not require an OS
Ans: B | Speed Solution: The heavy lifting is done beforehand. The final .exe runs instantly.
86. What is the primary advantage of an Interpreter over a Compiler during the software development phase?
A) It creates faster programs
B) It stops execution at the exact line of a syntax error, making debugging and testing much easier
C) It secures the code from hackers
D) It creates standalone .exe files
Ans: B | Speed Solution: Line-by-line translation catches errors immediately without needing to recompile the whole file.
87. Which of the following programming languages is strictly compiled?
A) Python
B) JavaScript
C) C
D) Ruby
Ans: C | Speed Solution: C and C++ are classic compiled languages (resulting in .exe or binary files).
88. Which of the following programming languages is primarily interpreted?
A) C
B) C++
C) Python
D) Rust
Ans: C | Speed Solution: Python, Ruby, and JavaScript use interpreters.
89. When a C program is compiled, the compiler produces an intermediate file before linking. What is this file called?
A) Executable file (.exe)
B) Object file (.o or .obj)
C) Text file (.txt)
D) Batch file (.bat)
Ans: B | Speed Solution: Source  Compiler  Object Code  Linker  Executable.
90. What is the function of the "Linker" in the translation process?
A) Converts code to binary
B) Combines multiple object files and standard library files into a single executable program
C) Loads the program into RAM
D) Checks for syntax errors
Ans: B | Speed Solution: "Links" the pieces together into the final .exe.
91. What is the function of the "Loader" in the execution process?
A) Translates source code
B) Places the linked executable program from the hard drive into main memory (RAM) for execution
C) Scans for viruses
D) Links object files
Ans: B | Speed Solution: "Loads" the program into RAM so the CPU can run it.
92. Java is famous for its "Write Once, Run Anywhere" capability. How does it achieve this?
A) It uses a single global Compiler
B) It compiles source code into an intermediate "Bytecode", which is then interpreted by a JVM on any OS
C) It is written in binary
D) It uses no translator
Ans: B | Speed Solution: Java is a hybrid. Compiler  Bytecode  JVM Interpreter.
93. In the Java ecosystem, what does "JVM" stand for?
A) Java Visual Machine
B) Java Virtual Machine
C) Java Variable Method
D) Java Vector Memory
Ans: B | Speed Solution: JVM is the virtual engine that interprets Java Bytecode for the specific host OS.
94. Modern interpreters (like JVM or Google's V8 JavaScript engine) use a "JIT" compiler to massively increase speed. JIT stands for:
A) Just In Time
B) Jump Into Translation
C) Java Internal Thread
D) Joint Interpreter Tool
Ans: A | Speed Solution: JIT compiles heavily used chunks of code "Just In Time" during execution so they don't have to be re-interpreted.
95. Assembly Language uses short English-like abbreviations (e.g., ADD, MOV, SUB). These abbreviations are called:
A) Opcodes
B) Mnemonics (নেমোনিক্স)

D) Syntax

96. Which translator program is specifically designed to convert Assembly Language (Mnemonics) into Machine Code?
A) Compiler
B) Interpreter
C) Assembler
D) Linker
Ans: C | Speed Solution: Direct match: Assembly requires an Assembler.
97. Assembly language is classified as a:
A) High-Level Language (HLL)
B) Low-Level Language (LLL)
C) Scripting Language
