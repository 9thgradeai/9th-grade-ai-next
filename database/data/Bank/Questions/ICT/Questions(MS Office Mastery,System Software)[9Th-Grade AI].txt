Topic 1: MS Word Mastery (Shortcuts, Ribbon, Mail Merge)
1. A Bangladesh Bank auditor needs to double-underline a suspected fraudulent transaction in an MS Word audit report. Which shortcut should be used?
A) Ctrl + U
B) Ctrl + Shift + D
C) Ctrl + Shift + U
D) Alt + U + D
Ans: B | Speed Solution: "D" stands for Double. Ctrl+U is single underline. Shift modifies it to Double.
2. To rapidly align a paragraph containing commercial bank reserve ratios to the right, which keystroke is required?
A) Ctrl + J
B) Ctrl + E
C) Ctrl + R
D) Ctrl + L
Ans: C | Speed Solution: R = Right, E = cEnter, J = Justify, L = Left. Don't confuse E with Right.
3. In MS Word, which Ribbon Tab contains the "Mail Merge" feature used by the HR department to send interview call letters to 500 AD candidates?
A) Insert
B) References
C) Mailings
D) Review
Ans: C | Speed Solution: Name matching trick. Mail Merge is strictly under "Mailings". It is not an "Insert" object.
4. What is the core difference between a Footnote and an Endnote in a central bank policy document?

C) Footnotes are used for citations; Endnotes for web links.
D) There is no functional difference.
Ans: A | Speed Solution: "Foot" = bottom of the current step (page). "End" = end of the journey (document). Both are in the 'References' tab.

Ans: C | Speed Solution: Ctrl+1 = Single, Ctrl+2 = Double. 1.5 spacing is mapped to Ctrl+5 (think 5 as the .5 in 1.5).
