# 9Th-Grade AI Dashboard — Production-Grade Overhaul Plan

## Vision
Transform the dashboard into a **world-class, enterprise-grade AI-powered SaaS exam preparation platform** that rivals Notion, Linear, Vercel, and GitHub in polish, performance, and user experience — tailored for Bangladeshi BCS/Bank/Teacher aspirants.

---

## Phase 1: Design System & Token Architecture (Foundation)

### 1.1 Refined Token System (`app/globals.css` + `frontend/styles/ai-workspace.css`)
- **Semantic color scale**: 10-step OKLCH scales for each semantic token (primary, success, warning, danger, info)
- **Elevation system**: 5 levels (base, raised, overlay, modal, toast) with consistent shadows
- **Spacing rhythm**: 4px base → 8/12/16/20/24/32/40/48/64 with fluid clamping
- **Typography scale**: Clamped fluid type (clamp(min, preferred, max)) for all headings/body
- **Border radius scale**: Consistent 4/8/12/16/20/24/28/32
- **Motion tokens**: Duration/easing curves per tier (instant/150/200/300/500ms)

### 1.2 Component Token Classes (Tailwind v4 utilities)
- `.surface-{base,raised,overlay,modal,toast}`
- `.text-{primary,secondary,muted,inverse,disabled}`
- `.border-{subtle,default,strong,focus}`
- `.shadow-{xs,sm,md,lg,xl,2xl}`
- `.radius-{sm,md,lg,xl,2xl,full}`
- `.transition-{fast,normal,slow}`

### 1.3 Motion System
- **Reduced-motion first**: All animations respect `prefers-reduced-motion`
- **Tier-based**: `instant` (0ms), `fast` (120ms), `normal` (200ms), `slow` (300ms), `cinematic` (500ms)
- **Easing library**: `ease-out-expo`, `ease-spring`, `ease-bounce` presets

## Phase 2: Dashboard Shell & Navigation (Core Infrastructure)

### 2.1 Layout Architecture (`app/dashboard/layout.tsx`)
- **CSS Grid shell**: `grid-template-areas` for sidebar/main/header/bottom-nav
- **Container queries**: Components respond to their container, not viewport
- **Safe-area handling**: Unified `env()` integration for iOS/Android notches
- **Scroll isolation**: Main content scrolls independently; chrome stays fixed
- **Focus management**: Skip links, focus trapping in drawers/modals

### 2.2 SideNav v2 (`frontend/components/dashboard/SideNav.tsx`)
- **Collapsible rail**: 72px collapsed / 280px expanded (was 80/264)
- **Section headers**: Sticky within scroll, keyboard navigable
- **Badge system**: Notification counts, new feature indicators
- **Keyboard shortcuts**: `g` + `1-9` for group, `t` + `1-9` for tab
- **State persistence**: localStorage + URL sync

### 2.3 BottomNav v2 (`frontend/components/dashboard/BottomNav.tsx`)
- **Floating pill**: iOS-style floating bottom bar on mobile
- **Haptic feedback**: `navigator.vibrate()` on tap (where supported)
- **Swipe gestures**: Horizontal swipe between primary tabs
- **More sheet**: Redesigned as bottom sheet with drag handle

### 2.4 Header v2 (`app/dashboard/layout.tsx` header section)
- **Breadcrumb 2.0**: Clickable group > tab with dropdown for siblings
- **Command palette trigger**: Prominent, keyboard-first (`⌘K`)
- **User avatar menu**: Dropdown with profile, settings, theme, logout
- **Ecosystem switch**: Segmented control (BCS/Bank/Teacher) with icon badges
- **Search-in-header**: Inline search for question bank (desktop ≥md)

## Phase 6: Accessibility & Inclusive Design

### 6.1 ARIA & Semantic HTML
- **Landmarks**: `nav`, `main`, `aside`, `header`, `footer` throughout
- **Live regions**: `aria-live="polite"` for timer, AI responses, toasts
- **Focus management**: `focus-trap` in modals/drawers, restore on close
- **Descriptions**: `aria-describedby` for complex widgets

### 6.2 Keyboard Navigation
- **Global shortcuts**: `⌘K` command, `1-9` tabs, `?` help, `Esc` close
- **Tab traps**: In modals, drawers, command palette
- **Roving tabindex**: In lists, grids, tab panels
- **Skip links**: To main content, navigation, search

### 6.3 Visual Accessibility
- **Contrast**: WCAG AAA for text (7:1), AA for UI (4.5:1)
- **Focus indicators**: 3px solid primary, offset 2px, never outline-only
- **Reduced motion**: All animations disabled, instant transitions
- **High contrast mode**: OS-level `prefers-contrast: more` support
- **Color blindness**: Never color-only status; icons + text + patterns

## Phase 7: Mobile-First Responsive Excellence

### 7.1 Breakpoint Strategy
- **320px**: Minimum (Galaxy Fold, small phones)
- **375px**: iPhone SE / 12/13/14 mini
- **430px**: iPhone 12/13/14/15 Pro
- **768px**: Tablet portrait
- **1024px**: Tablet landscape / small laptop (sidebar shows)
- **1360px**: Desktop (max content width)
- **1920px**: Large desktop

### 7.2 Touch Targets
- **Minimum**: 48×48px (Apple/Google guidelines)
- **Comfortable**: 56×56px for primary actions
- **Spacing**: 8px between adjacent targets
- **Hit area expansion**: `::after` pseudo-elements for small icons

### 7.3 Gestures
- **Swipe navigation**: Horizontal between tabs (bottom nav)
- **Pull-to-refresh**: On Home, Practice, Progress
- **Long press**: Context menus (flag, bookmark, share)
- **Drag to reorder**: In Today Mission, Study Planner

## Phase 8: Performance & Engineering Excellence

### 8.1 Code Splitting & Loading
- **Route-level**: Each tab = separate chunk (already done)
- **Component-level**: Heavy charts, editors, AI lazy-loaded
- **Skeleton parity**: Every async component has matching skeleton
- **Prefetch**: Hover/intent-based prefetch for likely next tabs

### 8.2 Caching Strategy
- **Stale-while-revalidate**: SWR for all API calls
- **Optimistic UI**: Immediate feedback, background sync
- **Offline queue**: Practice submits, flashcard reviews
- **Cache keys**: Versioned, invalidated on schema change

### 8.3 Bundle Optimization
- **Tree shaking**: ES modules only, no CommonJS
- **Dynamic imports**: All non-critical components
- **CSS extraction**: Critical CSS inlined, rest streamed
- **Font optimization**: `font-display: swap`, subset Bengali
